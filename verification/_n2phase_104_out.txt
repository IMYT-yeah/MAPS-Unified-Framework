A. N1 的「4π」：它是什么，以及论文没写清的地方
============================================================================================

  论文 N1 原文：「稳态涡需相位累积 **4π 整数倍**【本框架设定】⟹ 必须锁定旋转轴 ⟹ 至少一个平面」

  注意「4π」有两种自洽读法，**论文没有写明是哪一种** ——
    读法 A（φ 单值）：  ∮dφ = 2πw，要求 = 4πn ⟹ **绕数 w = 2n（偶数）** ⟹ 最小涡 = 绕数 2；
    读法 B（序参量是旋量 e^{iφ/2}）：∮d(φ/2) = 2πw ⟹ ∮dφ = 4πw **自动满足**，w 任意。
  两者都给出「有确定的相位累积」，但**最小涡的拓扑荷差 2 倍**。

  NP-1 双覆盖的直接检验（序参量 ψ = e^{{iφ/2}}）
        φ = 0 → 2π：ψ 从 1 变到 -1.000000+0.000000i  （= −1 ⟹ **未回归**）
        φ = 0 → 4π：ψ 从 1 变到 1.000000-0.000000i  （= +1 ⟹ **回归**）
  [OK] NP-1a    2π 累积给 **−1** ⟹ 旋量序参量在 2π 处不回归
  [OK] NP-1b    4π 累积给 **+1** ⟹ **4π 是旋量序参量的最小回归周期**
  [OK] NP-1c    且 `e^{{iφ/2}}` 沿整条路径**模恒为 1、首尾相接** ⟹ 良定义的单值场

  NP-2 SU(2) 旋转算符（j = 1/2，R(α) = exp(−iαJ_z)）
        R(2π) =
[[-1.  0.]
 [ 0. -1.]]
        R(4π) =
[[1. 0.]
 [0. 1.]]
  [OK] NP-2a    R(2π) = **−I**（不是 +I！）
  [OK] NP-2b    R(4π) = **+I** ⟹ 「4π 整数倍」= **SU(2) 旋量单值性**，不是自由参数
  [OK] NP-3     SU(2) 的**最低非平凡**自旋 = **1/2**（j=0 平凡；j=1/2 起 2π 给 −1）⟹ 「4π」是表示论的必然，**零自由参数**

  NP-4 「4π」的两种读法
        读法 A：∮dφ = 2πw = 4πn ⟹ w = 2n ⟹ 只允许 **偶数** 绕数（最小 2）
        读法 B：∮d(φ/2) = 2πw ⟹ ∮dφ = 4πw ⟹ **任意** 绕数（最小 1）
  [OK] NP-4     **两种读法都自洽**（A 限制绕数奇偶、B 不限制），**而论文 N1 未写明是哪一种** ⟹ **口径缺口（C-68）**：两种读法下的「最小涡」拓扑荷差 **2 倍**

B. N2 的相容性方程：把「锁定平面」形式化
============================================================================================

  **定义（本轮的判据）**：「涡锁定平面 i」⟺ 涡态 ψ 是**该平面旋转荷 J_i 的本征态**，
  且本征值 ≠ 0（要有确定的相位累积）。

  ⚠️ 为什么取「本征态」而不是「期望值非零」—— 见 NP-10 的反例。

  NP-5 su(2) 对易关系 [J_i, J_j] = i ε_ijk J_k（j = 1/2 … 5，含半整数）
        最大偏差 = 3.997e-15
  [OK] NP-5     对易关系在全部测试的 j 上精确成立

  **NP-6 相容性方程（本轮的核心）**：
  设两个平面的旋转荷为 A、B（su(2) 的三个生成元里任取两个），[A, B] = iC ≠ 0。
  假设 ψ **同时锁定两个平面**：Aψ = aψ 且 Bψ = bψ，且 a ≠ 0、b ≠ 0。
  则
      ① iCψ = [A,B]ψ = ABψ − BAψ = (ab − ba)ψ = **0**  ⟹  **Cψ = 0**
      ② iAψ = [B,C]ψ = BCψ − CBψ = B·0 − C·(bψ) = −b·Cψ = **0**
         ⟹ **a = 0**，与 a ≠ 0 **矛盾**。∎
  ⟹ **两套 4π 相位锁定不可能同时成立** —— 这就是「共享轴拍频」的严格形式：
     不对易的两个相位不能同时确定（拍频 = 相位不确定的物理图象）。

  NP-6 数值穷举（找 A、B 的共同本征态）

           0.5      2          0          0          -        无

  [OK] NP-7     j = 0（平凡表示）里 A = B = C = 0 ⟹ 共同本征态存在但**本征值全为 0** ⟹ **无涡**（这与 N2 的「0 平面退化」一致）
  [OK] NP-8     **可约表示**（0 ⊕ 1/2 ⊕ 1 ⊕ 3/2，10 维）同样 **0 个**非平凡共同本征态 ⟹ 结论不依赖不可约性

  NP-9 反面检验：**单**平面锁定应当存在

  NP-10 **反例**：为什么「锁定」必须是**本征态**而不是「期望值非零」
        取 H = ω₁J₁ + ω₂J₂（ω = 1, 2），其某个本征态：
          ⟨J₁⟩ = +0.447214   ⟨J₂⟩ = +0.894427   ← **两个都非零**
          但 ‖J₁ψ − ⟨J₁⟩ψ‖ = 0.632456，‖J₂ψ − ⟨J₂⟩ψ‖ = 0.316228   ← **都不是本征态**
  [OK] NP-10a   稳态（H 本征态）可以有**两个都非零的期望值** ⟹ 若用「期望值非零」当判据，会**误判双平面锁定可行**
  [OK] NP-10b   但该态对 J₁、J₂ **都不是本征态** ⟹ **相位没有确定值** ⟹ 不满足 N1 的「相位累积 4π 整数倍」
  [OK] NP-10c   ⟹ **判据必须取「本征态」**；「拍频」的严格含义 = **两个不对易的相位不能同时有确定值**
