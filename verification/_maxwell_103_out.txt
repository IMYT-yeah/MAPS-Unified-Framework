B. 严格化：把「长波 ω→|k|」升级为方向无关的显式误差界
============================================================================================

  定理（MW-3）：设三维立方格点（a=1），ω(k) = 2√(Σ_i sin²(k_i/2))，0 < |k| ≤ √12 = 3.4641。则

        0  ≤  1 − ω(k)/|k|  ≤  1 − √(1 − k²/12)  ≤  k²/12 ,

  且**下界一端在 [100] 型方向（只有一个分量非零）取到**，此时上界是**紧**的。

  证明：① |sin y| ≤ |y| ⟹ 4sin²(x/2) ≤ x²（逐分量求和）⟹ ω² ≤ k²（给出左边不等式）；
        ② 对 0 ≤ y ≤ π/2，sin y ≥ y − y³/6（因 d/dy[sin y − y + y³/6] = cos y − 1 + y²/2 ≥ 0）
           与 |sin y| ≤ y ⟹ sin²y ≥ y²(1 − y²/6)² = y²(1 − y²/3 + y⁴/36) ≥ y² − y⁴/3
           ⟹ 4sin²(x/2) ≥ x² − x⁴/12；
        ③ Σ_i k_i⁴ ≤ (Σ_i k_i²)² = k⁴（交叉项 2Σ_{i<j}k_i²k_j² ≥ 0）
           ⟹ ω² ≥ k² − k⁴/12 = k²(1 − k²/12)  ⟹ ω ≥ |k|√(1 − k²/12)（要求 k² ≤ 12）；
        ④ 1 − √(1−ε) = ε/(1+√(1−ε)) ≤ ε（ε = k²/12）⟹ 结论。
        ⚠️ ③ 的等号只在**单一非零分量**时取到 ⟹ [100] 方向是**最坏方向**，该处上界紧。∎
        ⚠️ 口径：|k| > √12 时 ③ 的无信息（√ 变虚）⟹ 本节只声明 |k| ≤ √12 的界；
           BZ 内 |k| 最大 π√3 = 5.441（超出），那一端本来就不是「长波」。

  MW-3 扫描：7 个 |k| × 400 个随机方向 = 2800 个点（|k| ≤ 3.40 < √12）
        最大「实测偏差 / 界」= 0.995919
        （出现在 |k| = 0.10，方向 ≈ [-0.042, +0.009, +0.999]，偏差 4.150528e-04 / 界 4.167535e-04）
  [OK] MW-3a    **严格界成立**：全部 2800 个点上 `1 − ω/|k| ≤ 1 − √(1 − k²/12)`（无一违反）
  [OK] MW-3b    且界**接近紧**（最大达界的 99.59%）—— 出现在 [100] 型方向，与证明 ③ 的等号条件（单一非零分量）一致
  [OK] MW-3c    顺带：更粗的界 `≤ k²/12` 也成立（实测最大偏差 4.147594e-01 ≤ 9.633333e-01）——注意大 |k| 处该粗界明显松（真实界是 `1−√(1−k²/12)`）
  [OK] MW-3d    ⟹ **这是对「长波 ω→|k|」的严格化**：不再依赖「数值看上去是 0.9999」，而是对**任意方向、任意 0<|k|≤√12** 给出定量上界

  MW-4 四阶系数的方向依赖（取 ω²/k² 展开）
        解析：4sin²(x/2) = x² − x⁴/12 + x⁶/360 − …
        ⟹ ω²/k² = 1 − (1/12)(Σk_i⁴)/k⁴ + O(k⁴)
         [100]: Σk_i⁴/k⁴ = 1.000000 ⟹ 数值系数 = 0.083332222（解析 0.083333333）

         [111]: Σk_i⁴/k⁴ = 0.333333 ⟹ 数值系数 = 0.027777654（解析 0.027777778）
  [OK] MW-4a    [100] 四阶系数 = 1/12 ⟹ 该方向 Σk_i⁴/k⁴ = 1（**偏差最大**的方向）（残差 1.1e-06 = k²/360 的高阶项）
