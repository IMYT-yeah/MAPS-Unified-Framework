一、先澄清问题：真正的二选一不是「串行 vs 并行」

第 21 轮把它表述为「串行（每 tick 一次对换）vs 并行（每格点各一次）」，并担心两者差 N 倍。这个表述不准确：

  • 同步 / 异步（是否同时更新、更新冲突怎么处理）不改变任何物理量级；
  • 真正决定 R_mix 的是每 tick 发生几次对换 —— 即"事件率归一化"。
归一化 每 tick 对换次数 每个诸元的事件率
「串行」（每 tick 全局一对） 1 2/(N_c t_P)
「并行」（每格点恰一次） N_c³/2 1/t_P

两者相差 N_c³/2 = 3.06×10¹⁸² 倍。所以本轮的裁定对象是每格点每 tick 是否必有一次事件。

六、UP-6b / UP-7 三个必要条件（本轮新增两条）

「每 tick 每个格点一次事件」还不够——它只保证了存在一个配对，不保证动力学正确。数值上还发现三个必要条件：

① 轴必须随机（UP-7）：固定轴时 ⟨x²⟩ 仍按 n 增长，但 ⟨y²⟩ = ⟨z²⟩ = 0 ⟹ 只沿一维扩散，各向异性。 取 5 个种子：⟨x²⟩ = 375.3 / 605.8 / 629.6 / 618.8 / 514.9，均值 548.9（期望 600，±20% 内）。

② 相位不能固定（UP-7）：相位固定时，粒子在轴上的奇偶角色被锁定——走一步即翻转奇偶，下一步便换回另一端，形成二周期振荡、位移有界：⟨r²⟩ = 2（600 tick，扩散值应为 600）。即 ⟨r²⟩/n = 0.33%。

③ 相位必须「每线独立」，不能全局统一（UP-6b，本轮的新发现）： 即使每 tick 重抽相位，只要全局共用一个值（同一 tick 内所有线同侧），相位就与「轴」耦合成系统性取向模式：

相位模式 ⟨x²⟩ ⟨y²⟩ ⟨z²⟩ ⟨r²⟩/n
全局统一（种子 1,2） 49 289 256 0.297
全局统一（种子 3,4） 225 225 400 0.425
每线独立 672.9 694.2 614.2 1.00

⟹ 全局统一相位下动力学被钉住（⟨r²⟩ 只有 n 的 30%~43%），且分量明显不均。 「每线独立」是必需条件，不是实现偏好。

归因说明（诚实记录）：我最初把失败归因于「轴/相位交替抽样产生序列相关」，并做了一次 2×2 对照（相位模式 × 是否共用 RNG）。结果否证了我的猜想：决定性因素是每线独立相位，与 RNG 是否分离无关（共用/分离下 ⟨r²⟩ 分别 2386 / 594，但两者分量都不均）。也就是说，先诊断出的原因之一是错的，靠对照实验纠正。
