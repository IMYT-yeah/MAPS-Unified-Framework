2.1 原文已有的推导链（44 页，完整形式化）

设通量密度 ρ_pair(r)（正反物质对湮灭事件率密度）。质量 M 的物体"吞"通量，产生稳态亏损。在无源区域，通量亏损满足泊松型方程（通量守恒 + 球对称）：

∇2 (δρ) = 0 ⇒ δρ(r) = Cr

ρpair(r)ρpair(∞) = 1 - GMc2 r ⇒ C = ρpair(∞) GMc2

g00 = -(dtdτ)2 = -(1-2GMc2 r)
dt(∞)dt(r) = √1-2GMc2 r ≈ 1-GMc2 r

弱场数值验证（本报告计算）：太阳表面 GM/(c²R) = 2.12×10⁻⁶ ≪ 1，弱场近似成立；1 AU 处 GM/(c²r) = 9.86×10⁻⁹。✅

2.2 PPN 形式主义与 γ 的定义

PPN（参数化后牛顿）弱场度规（各向同性坐标）：

g00 = -1 + 2GMc2 r, gij = (1 + 2γGMc2 r)δij

γ 的物理意义：空间曲率与时间弯曲的相对强度。 - γ = 1：GR 值（空间与时间"等权"弯曲）； - γ = 0：只有时间弯曲，空间平坦（牛顿引力 + 无空间效应）； - γ = −1：空间"反向"弯曲（压缩而非拉伸）。

2.3 框架的 g_ij 三种候选情形（本报告的核心推导）

原文未给出 g_ij 的定量形式，只给定性主张（44 页）："空间的那部分弯曲（g_ij 的畸变）可以类似地解释为：正反物质对的通量在径向和角向的分布不再各向同性（因为大质量物体只在一个点'吞'），所以'流形'的横向伸缩率也不均匀"。

据此，g_ij 存在三种互斥候选（【补充推演】）：

情形 A：γ=−1（通量压缩） - 机制：空间径向分量"随通量密度压缩"，g_rr = (ρ_pair/ρ_pair(∞))² = 1−2GM/c²r - 直觉：通量少 → 微变少 → 空间"缩水" - PPN：g_rr = 1+2γU → γ = −1 - 预言：光偏折角 = 0（(1+γ)/2 = 0）→ 与观测 1.75″ 矛盾 → 被实验排除

情形 B：γ=0（无空间弯曲） - 机制：空间分量不受通量亏损影响（只时间变），g_ij = δ_ij - 直觉：空间是"刚性容器"，只有时间柔软 - PPN：γ = 0 - 预言：光偏折 = 0.87″（一半值）、Shapiro = 66.4 μs（一半值） - 判决：1919 年 Eddington 观测（1.75″）即排除；现代 VLBI/Cassini 精度更高 → 被实验排除

情形 C：γ=1（时间-空间互补，GR 值） - 机制：时间分量消耗的"微变权"由空间径向分量继承（守恒补位），g_rr ≈ −1/g₀₀ = (1−2GM/c²r)⁻¹ - 直觉：通量被"吞"走的部分，时间变慢 + 径向拉伸联合"记账"，总微变权守恒 - PPN：γ = +1 - 预言：光偏折 1.75″、Shapiro 133μs、近日点 43″、引力波速度 c —— 全部与观测吻合 ✅

2.4 判决与框架存活路径

判决：三种情形中只有 γ=1 与全部观测一致。框架若主张"引力=通量遮挡"，则必须导出 γ=1。

存活路径：框架需要补充一个机制论证——"微变权守恒"：

【补充推演】"微变权守恒假设"：流形微变的总"记账"在时间与空间之间守恒。引力源吞噬通量后，时间分量记录为 Δt（变慢，权重减少），空间径向分量必须记录等量反向权重（拉伸）。形式化：

grr ≈ -1g00 = (1-2GMc2 r)-1 ≈ 1+2GMc2 r

这使 g_rr 的 PPN 系数 = −g₀₀ 的 PPN 系数 → γ=1。

该假设与框架公理的相容性： - 相容：它正是"流形无限微变"公理的直接推论（微变事件总权重守恒，投影到时间与空间两个通道）； - 原文缺位：44 页只有"横向伸缩率也不均匀"的定性描述，未给出"守恒补位"论证； - 独立支撑：该假设等价于 GR 的 Schwarzschild 解 g_rr=1/g₀₀（Birkhoff 定理），而框架自我定位为"GR 的微观统计力学解释"（44 页"GR 是几何描述，你的图景是统计流体描述——前者是后者的有效理论"）——若框架要与自身定位一致，γ=1 是唯一选择。

2.5 引力波极化交叉验证

框架主张（446–456 页）："自旋 2 = 任何二阶通量涨落的几何必然"；"不是类比，是同类"（南大引力子模/部分子 2026 对接）。

PPN 框架下，引力波的极化与 γ 的关系： - GR：仅张量极化（自旋 2，+、× 两种）； - 标量极化存在 → 对应额外自由度（如 Brans-Dicke 标量场），γ ≠ 1 的典型信号； - GW170817（2017）给出 c_g = c 到 10⁻¹⁵ 精度，且 LIGO/Virgo 未观测到标量/矢量极化的证据。

交叉验证结论：框架的"引力波=二阶通量涨落（自旋 2）"主张与 γ=1 自洽；若框架强行取 γ≠1，则必须同时引入非张量极化（与 GW170817 冲突）。γ=1 与张量极化是框架引力图像的两道一致约束。

2.6 遗留缺口（诚实标注）

  1. β_ppn（g₀₀ 的二阶项）未推导：近日点进动公式含 β_ppn（g₀₀ = −1+2U/c²−2β_ppn U²/c⁴）。框架只推了一阶（g₀₀ ≈ −(1+2Φ/c²)），二阶项无机制 → β_ppn 未定。观测 β_ppn=1±3×10⁻⁴，框架需给出二阶推导（可能涉及"通量亏损的二阶修正"）。【待验证猜想】
  2. 强场区域失效边界：γ 的推导基于弱场近似（GM/c²r ≪ 1）。中子星表面 GM/c²R ~ 0.2、黑洞视界 ~ 0.5，通量遮挡模型在强场的失效边界未定量。【待验证猜想】
  3. 44 页"横向伸缩率不均匀"的定量化：原文说角向伸缩率不均匀，但 PPN 各向同性坐标要求 g_θθ = r²（角向不变）。若框架主张角向也弯曲，将产生非各向同性空间（破坏 PPN 标准框架），需明确是否主张。【原文未定】
