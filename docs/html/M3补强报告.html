1.3 决定性诊断：⟨X⟩ 不是相变序参量

m(h_c) 随 L 外推 → 0.933 ≠ 0（0.798→0.825→0.835→0.845，1/L 线性外推）：

序参量失效证明：若 ⟨X⟩ 是 toric code 横向场相变的序参量，则 m(h_c,L) 应随 L→∞ 收缩至 0（二级相变）。实测外推 m(h_c)→0.93（不趋零）⟹ ⟨X⟩ 是"极化度"类平凡量，非相变序参量。真正的序参量是弦/环算符（Wilson loop ⟨W⟩：hh_c 指数衰减）或拓扑纠缠熵。

这是 v1.23"判据修正"（m=0.5 为半极化点）的机制级确认——系统性偏差的根源是序参量选择错误，而非数值误差。

1.4 相变存在性独立支持

χ_max ∝ L^{1.12}（χ_max：3.08→3.78→4.23→5.07）：2D Ising 类预期 γ/ν=1.75，实测 1.12——χ 峰随 L 增长（真临界特征），但被小格点宽化，位置无法精确定位。相变确实存在，判据定位失效。

1.5 校准后的正确路径

  1. 文献值校准：框架哈密顿量（对称约定 J_A=J_B=1，§5.7 v1.23 已确认与文献 toric code 等价）⟹ h_c 直接取文献精确值 h_c≈0.3285（iPEPS）/ 0.32（X 场版本），内部判据仅作半定量参考；
  2. 序参量升级：改用弦序参量 ⟨W⟩ + Binder 累积量交叉（尺寸无关判据），弃用 m=0.5；
  3. 大格点：MPS/DMRG（L≥8）定位 h_c，与文献交叉验证。

→ 框架真相变点维持 κ_c≈0.25–0.32（与文献一致），但判据基础从"内部 m=0.5"升级为"文献校准 + 弦序参量"。
