一、问题与方法

问题：B5 的读数（每 4l_P² 取 1 纳特）能否是 tick 动力学的不变量？ 若能，则分辨率由衬底动力学给出，B5 少一条公设；若不能，则读数必然是瞬时的， 分辨率必须由观测者自身给出（或作为公设保留）。

方法（本轮的全部工作量都在这句话里）：

把「一次 tick = 沿某轴的二分图完美匹配（轴随机、每线独立随机相位，第 26 轮定案）」的 全部选择枚举出来 ⟹ 它们在构型空间上生成一个置换群 G ⟹ G 的轨道划分就是最大的 tick 不变粗粒化（任何不变的读数都必须是轨道的函数）。

因此「不变的读数最多能带多少熵」= 轨道划分在等分测度下的熵 H = ln M − Σ_O (|O|/M) ln|O|（M = 2^N 个构型）。

可证伪的判据（本轮最有用的一条）：

H/N = ln2 − ⟨ln|O|⟩/N  ⟹  要恰好命中 0.25，需要典型轨道大小 ⟨|O|⟩ = e^{0.4431 N} = 1.557^N

并行 tick 动力学在 N = 16 上给的典型轨道 ≈ 60，而 1.557^16 ≈ 1.2×10³ ⟹ 差约 20 倍。 换句话说：要让"不变的读数"恰好给出 BH 密度，衬底动力学必须以一个非常特定的速率混合 （|G| ≈ 1.557^N）——既没有理由成立，也没有机制支撑。

六、附带（正面）：等分账 = 唯一不变测度；47 μm 的担心解除

  • 均匀分布（= 等分账）在任意 tick 下精确不变（数值：逐项相等）⟹ 等分不需要动力学热化；
  • 但轨道有 1357 条 ⟹ 动力学保持轨道 ⟹ 等分不能由动力学"到达" ⟹ 等分是结构性 / 初值的（与第 21 / 26 轮的结论一致；本轮给出了机制层理由：不变量的存在）；
  • 47 μm 澄清：R_mix(t_H) = l_P√(t_H/t_P) = 4.70×10⁻⁵ m 限制的是诸元的空间输运； 而统计测度的不变性是瞬时的、与输运无关的（置换 ⟹ 熵守恒 ⟹ 均匀自动不变）。 ⟹ 两者不是一回事：等分账可以结构性成立，同时空间上远未热化 ⟹ 第 21 / 26 轮的担心解除。

七、诚实边界

  • ⚠️ 外推未验证：|G| 与轨道结构只在 N ≤ 16 上穷举。格子越大、每条线的相位自由度越多 （4×4×4 就有 513 个生成元）⟹ 群可能大得多 ⟹ H/N 在 N → ∞ 的极限未定。 但 §三的判据 ⟨|O|⟩ = 1.557^N 与 N 无关，是可证伪的目标。
  • ⚠️ 「1 格点 ↔ 1 l_P²」是框架的约定（第 35 轮）；若换约定，「0.44 vs 0.25」的比较要重做， 但判据形式不变。
  • ⚠️ 时间平均那条是量级估计（把块读数当作独立同分布，未做自相关修正）； 结论（零预言力）不依赖精度。
  • ⚠️ 本轮没有给出观测者分辨率的任何机制；本轮的产出是三条路线的排除 + 一条判据 + 一个附带澄清。
