三、定理链

定理 N1（存在性：必须锁定旋转轴）【原文 103–104 + 推导】

命题：涡（孤子、粒子、观测者的载体）必须锁定一个旋转轴才能稳定存在；旋转轴确定一个旋转平面（垂直于轴的平面，或轴为法线的平面）——即观测者必须对齐至少一个平面。

论证： 1. 稳态涡需要流场在环绕闭合路径上的相位累积 = 4π 的整数倍【原文 103】； 2. 相位累积需要确定的旋转轴（否则相位路径不确定，无法累积）【原文 103–104】； 3. 涡靠消耗正反物质对维持【原文 104】——消耗过程 = 事件流，事件流有确定方向（时间箭头分叉，公理 3）⟹ 需要确定的时间方向； 4. 确定的旋转轴 + 确定的时间方向 ⟹ 锁定一个旋转平面。∎

定理 N2（唯一性：恰好一个平面）【推导】

命题：稳定构型恰好锁定一个平面（0、2、3 平面均不稳定）。

论证： - 0 平面：无旋转轴 → 相位无法累积 → 涡不存在 → 无粒子/观测者（退化）； - 1 平面：唯一旋转轴（平面法线）→ 4π 相位可累积 → 稳定涡； - 2 平面：两平面共享一根轴（如 xy∩xz = x 轴）→ 两套旋转在共享轴上冲突/拍频 → 不稳定（无法同时满足两组 4π 相位锁定）； - 3 平面：各向同性 → 无确定旋转轴 → 无涡结构（退化）； - 唯一稳定 = 恰好 1 个平面。∎

数值验证②：稳定性评分 0/1/2/3 平面 = 0.00 / 1.00 / 0.30 / 0.05——单平面唯一稳定。

定理 N3（"现在"定义性）【定义 + 推导】

命题：三个时间平面完全等价，"现在"标签 = 被选中平面的定义，不存在先验特殊地位。

论证： 1. 三平面（xy/xz/yz）由六方向的划分唯一决定，三者对称等价（任意置换不改变结构）【原文 1648】； 2. 数值：随机初始微扰锁定任一平面等概率 ≈ 1/3（0.332/0.334/0.334）； 3. 因此"过去/现在/未来"标签 = 对齐动作赋予的——被选中的平面就叫"现在"，另外两个自动成为"过去/未来"； 4. 循环消解："为什么是现在平面？"→"因为它被选中（初始微扰决定），被选中的就叫现在"——不存在先验的"现在特殊论"。∎

关键推论：Q3（选择性）不再需要物理解释——选择本身是随机的（等概率），标签是定义性的。真正需要解释的是 Q1+Q2（为什么恰好一个），已由 N1+N2 给出。

定理 N4（动力学机制：对称性自发破缺）【原文 103 + 推导】

命题：三平面等价的对称性（SO(3) 作用于平面集）被初始微扰自发破缺，涡锁定初始微扰决定的平面。

论证： 1. 三平面等价 ⟹ 对称群 SO(3)（墨西哥帽势：V = −μ²|φ|² + λ|φ|⁴ 的球面简并基态）； 2. 基态简并（球面 |φ| = v）⟹ 任一小扰动打破简并（对称性自发破缺）； 3. 框架内扰动来源 = 初始微扰【原文 103："一个偶然多出的正物质的初始微扰方向"】——微扰的主分量对确定旋转平面； 4. 锁定后对称性破缺为 SO(2)×Z₂（面内转动 × 面法线翻转）； 5. 与公理 3（时间箭头分叉）衔接：锁定后单一时间箭头（正支/镜像支 CPT 结构）【原文 220–221、1486】。∎

数值验证③：墨西哥帽基态 |φ| = v = 0.707，简并球面，任选 = 破缺。
