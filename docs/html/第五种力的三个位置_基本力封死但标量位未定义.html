§5.5 分波分解 自旋 涨落类型 对应 备注

二、三个候选位，逐一判定

位 ①：自旋 1 的额外规范群 ⟹ 封死

论文 §5.2 原话：「n ≥ 4 排除：空间三维（挂谷维数锁定）⟹ 四阶反对称 ε_ijkl 需 4 维空间」。

本轮数值/组合核验：完全反对称张量 ε_{i₁…i_k} 在 D 维空间的独立分量数 = C(D, k)：

k = 3 k = 4
D = 3 C(3,3) = 1 ✓ C(3,4) = 0 ⭐
D = 4 C(4,3) = 4 C(4,4) = 1

⭐ 3 维空间里 ε_ijkl ≡ 0（4 个指标在 3 个取值里必重复 ⟹ 全反对称强制为零） ⟹ n = 4 的「四阶单态」在 3 维空间不存在 ⟹ 拿不到 n = 4 的禁闭机制 ⟹ 排除。

（为什么需要四阶单态？因为 §5.2 的 S3 判据是「三阶反对称给出禁闭」，n = 3 用 ε_ijk；n = 4 就需要 ε_ijkl。）

位 ②：自旋 ≥ 3 ⟹ 封死

Weinberg–Witten 定理（1980）：在平坦时空的局域量子场论里，无质量、自旋 j > 2 的粒子不可能存在 （等价表述：它不能与任何守恒的 Lorentz 协变流耦合 ⟹ 拿不到普适耦合）。

框架与它的关系（这一步很关键）：框架 §5.8 的自旋 2 判据链里已经有两条同族判据： - 第 ① 条 Fierz–Pauli 唯一性：「无质量自旋 2 ⟹ 线性化 GR」→ Weinberg–Witten 是同一条论证的推广： 自旋 2 刚好在边界上（有唯一自洽选择），自旋 ≥ 3 越界； - 第 ③ 条 Weinberg 软定理 —— 见下，同一条分类也封死自旋 ≥ 3。

⟹ 不需要框架新增任何公设：它引用的两条标准定理，各自都把自旋 ≥ 3 关在门外。

位 ③：自旋 0 的新轻标量 ⟹ ⭐ 未定义（既没封死也没打开）

这是本轮最有意思的一步。先问：「力」在框架里到底是什么？

§5.8 引用的 Weinberg 软定理给出的判据是软极限（q → 0）振幅的奇异幂次：

自旋 软极限 后果 结果
2 ∝ 1/q（奇异） 普适耦合（等价原理） 引力 —— 是「力」
1 ∝ 1/q（奇异） 守恒荷强制（电荷守恒） U(1)/SU(2)/SU(3) —— 是「力」
0 ∝ q⁰（不奇异） 不强制任何守恒荷 Higgs / 模场 —— 不是「力」

⟹ 软定理给出的判据是：「力」= 被软定理强制的普适耦合。 自旋 1 与自旋 2 被强制（⟹ 四力），自旋 0 不被强制 ⟹ 它天生不是「基本力」。 这正是框架 §5.5 把它标为「Higgs/模场」的深层理由。

⚠️ 但这一步必须分清楚：软定理说的是「自旋 0 不构成普适力」， 它没有说「自旋 0 不能有长程相互作用」。标准物理里的第五力正是「非普适的长程标量力」。
