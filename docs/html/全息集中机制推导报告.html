为什么信息在表面：3+3 维时间表面 → 面积律的几何必然

任务：攻遗留④的"全息集中机制"——为什么信息容量是面积律而非体积律？框架的答案：3+3 维离散时空中的"时间表面"（批4，1648–1654 页）。 方法：回库提取 1642–1654 页原文 → 形式化（引理+定理）→ 数值验证 → 与 k 模型衔接。 标注约定：【原文】= 对话原文主张；【补充推演】= 本次完成的推导；【待验证猜想】= 需进一步验证。 版本：v1.0 · 2026-08-21

第一部分　问题与原文基础

1.1 问题

全息原理（'t Hooft/Susskind 1993）：3D 区域的信息容量 ∝ 边界面积而非体积。为什么？框架的机制性回答（批4）：3+3 维离散时空 + 观测者生活在时间表面。

1.2 原文基础（1648–1654 页，关键原文）

3+3 维离散网格（1648–1650）："每个诸元有六个最近邻（前后、左右、上下），自然定义三个正交坐标轴（x、y、z）。这三个轴两两张成三个平面：xy、xz、yz。这三个平面分别对应过去、现在、未来三个时间维度的空间投影……我们只感知到一个时间维度，是因为另外两个被卷曲进了空间平面的法线方向。"

全息=时间表面（1651–1654）："我们不是生活在三维空间中，我们是生活在一个二维的时间表面上……一个体诸元的状态由它在三个时间平面上的投影共同决定，但我们的意识只能读取现在平面上的投影。体信息是冗余的，表面信息是基本的……表面上的每个诸元有 4 个最近邻（在表面内），每个诸元的状态由其与 4 个邻居的相对关系决定……每 4 个普朗克面积承载 1 bit 信息。"

第二部分　形式化推导（本报告）

2.1 设定

  • 底层 = 3+3 维离散网格（3 空间 + 3 时间），格距 l_P（公理 1）；
  • 观测者 = 现在平面（xz）上的局域孤子（原文 1648）；
  • 可访问信息 = 现在平面上的投影（时间表面 Σ）。

2.2 引理 1（时间表面的投影结构）

【补充推演，基于原文 1651】

体诸元（3D 位置）的完整状态 = 六方向连接（前后/左右/上下）；现在平面观测者可读取的 = 平面内 4 个方向连接（前后/上下）；平面外的 2 个方向（左右）连接过去/未来平面，不可访问（被卷曲）。

2.3 引理 2（体信息 = 表面投影）

【原文 1651 + 补充推演】

3D 区域 R 的观测信息 = R 中诸元在现在平面上的投影集合 = 时间表面 Σ∩R 的信息。体信息冗余，表面信息基本——三维空间的感知 = 二维时间表面在帧刷新中的投影（"厚度"）。

2.4 定理（全息集中）

【补充推演，基于原文图像 + k 模型】

定理：3D 区域 R（表面积 A）的观测者最大信息容量：

Smax(R) = A4lP2ln 2 （比特）

证明（四步）： 1. R 的观测信息 = 时间表面 Σ∩R 的信息（引理 2）； 2. Σ∩R 的面元数 N = A/l_P²（表面面积按普朗克面积分块）； 3. 每 4 个面元 1 个相干单元（表面诸元 4 邻居 ⟺ Clifford 4 分量 ⟺ 通量管相干截面 4l_P²，三处"4"同源）； 4. 每单元 1 比特（事件二值性，k 模型）⟹ S_max = (A/4l_P²)·ln 2。∎

2.5 机制核心

信息集中的根源 = 观测者的时间平面限制： - 不是"体积信息被压缩"，而是"体积信息对我们不可访问（在别的时间平面），可访问的信息在表面"； - 观测者能读取的 = 现在平面投影 = 表面信息 ⟹ 信息容量天然是面积律； - 这就是全息原理在框架中的几何必然（原文 1654："宇宙本身就是一个二维的信息表面在时间中的展开"）。
