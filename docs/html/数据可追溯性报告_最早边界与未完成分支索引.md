## 二、三条边界线（为什么是这三个日期）

```
2026-08-20 ──────────────── 2026-09-20 ──────────────── 2026-09-27 ──────→ 今天

    └─ 日志起点 = 项目起点（工作区名就是 2026-08-20-21-43-34）
```

### 2.1 为什么 8-20 是起点
- **工作区名 = `2026-08-20-21-43-34`**（创建时间戳）；
- **8-20 日志的第一条**就是「**四种基本力统一理论框架（深度研究）**」—— 从零开始的任务
  （用户提供《杨韬和元宝的对话》PDF 1693 页），**没有「接续之前」的表述**；
- 8-20 日志的 mtime = `Aug 21 05:19` ⟹ 是**当时（或次日）写的**，不是事后补写。

### 2.2 为什么对话原文只到 9-20
- `~/.workbuddy` 环境的关键文件（`device-id`、`edge-sync-mapping-v4.db`）mtime 都是 **Sep 20 18:33**；

- **8-20 日志里出现旧机路径 `D:/Users/IMYT.YT/…`（2 次）**，而**本机无 D 盘**
  ⟹ 8 月的工作在**旧机**上做，对话原文存在旧机的 `~/.workbuddy/projects/` 下。
- 之前几轮也记录过同类事实：`D:/Users/IMYT.YT/WorkBuddy/_MAPS_explore` 与 `D:/.../MAPS-Unified-Framework` 都**不存在**。
