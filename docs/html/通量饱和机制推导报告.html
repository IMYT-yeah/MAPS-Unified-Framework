第二部分　饱和机制候选检验

2.1 候选一：ρ 下限钳制模型

【推导】通量密度不能为负（原文 46 页"吞灭有最大速率"），玻尔兹曼分布降到下限时被钳制：

ρ(r)ρ∞ = max(e-x, ρmin/ρ∞), x = GMc2 r

光子球分析（解析）：

x_sat（饱和点） r_sat 光子球 与 GR 对照
< 1（r_sat > GM/c²） > a 无光子球（x=1 在饱和区，V_eff 单调） ✗
≥ 1（r_sat ≤ GM/c²） ≤ a x=1（r=GM/c²） ✗ 仍与 EHT 冲突

结论：ρ 下限钳制不能恢复 GR 的光子球 3GM——要么光子球仍在 1GM（冲突），要么消失。

2.2 候选二：通量自引力（Poisson-Boltzmann）

【推导】通量密度贡献能量密度 → 自引力 → 自洽方程：

u'' + 2ru' = 8πlP2e-u, u = Φc2, s = rlP

修正量级分析（局部分析）：

结论：自引力修正局限于普朗克尺度，宏观光子球仍 ~GM/c²——不能恢复 GR 的 3GM。

2.3 决定性洞察：热平衡适用域

【引用遗留④模拟 2 的发现】热平衡证明已确认：纯 1/r 引力势的玻尔兹曼分布发散（r→0），引力系统无全局热平衡，e^{−Φ/c²} 仅局部/弱场/截断下有效。

推论： - 弱场（x ≪ 1）：玻尔兹曼有效，PPN γ=β=1 通过 ✓； - 强场（x ~ 1）：热平衡失效，g₀₀ = −e^{−2x} 外推超出适用域； - ⟹ 框架强场行为未定义——既非"通过"也非"被排除"，而是"缺失"。
