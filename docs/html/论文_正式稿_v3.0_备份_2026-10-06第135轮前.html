1 引言

1.1 动机与背景

现代物理学的两大支柱——广义相对论（GR）与量子场论（QFT）——分别精确描述了引力与其它三种基本力，但两者的统一（量子引力）是物理学最深层的未解问题。标准模型以 SU(3)×SU(2)×U(1) 规范群统一描述强、弱、电磁力，GR 以黎曼几何描述引力，但：

  • 引力不可重整化，且缺乏量子完备描述；
  • 标准模型含 19–26 个自由参数（层级问题、宇宙学常数问题、强 CP 问题）；
  • 四种力的相对强度（1 : 10⁻² : 10⁻⁶ : 10⁻³⁸）缺乏统一解释；
  • 大统一（GUT）、弦论、圈量子引力等候选路径均未获得实验支持。

本框架提出一种不同的统一策略：不假设更大的对称群或额外的维度，而是寻找一个底层统计机制（事件流），使四种力成为同一机制在不同尺度/构型下的涌现模态。这一策略与统计力学之于热力学的关系类似：GR 是几何描述，本框架的统计流体描述是其有效理论。

8.6.7 衬底置换模型与 tick 归一化

【推导 + 数值】§4.2 命题链中「配对的湮灭-再生在 50:50 下与弹性散射动力学等价」需要一个具体机制；本小节给出它，并同时固定其归一化。

(a) 机制：把一个 tick 视为对占据态施加一次相邻对换（对称群 S_N 的相邻生成元）。置换是双射 ⟹ 诸元数自动守恒、每格点恒有且仅有 1 个诸元、真空态永不出现（它是逻辑态，不是占据态）；相邻对换生成整个 S_N，且可逆 ⟹ 底层无熵产生，宏观不可逆只能来自粗粒化。相邻对换 = 全同粒子交换身份 = 一维等质量弹性碰撞（速度互换），故多体层面与弹性散射不可区分。

(b) tick 归一化（v2.9 新增，重要）：真正需要裁定的是每 tick 发生几次对换，而不是是否同步。A1 的 ν ~ 1/t_P 是每个诸元的事件率（不是整个系统的事件率），因此

每 tick 每个格点恰好一次事件 (并行归一化)

  • 轴随机（每 tick 在 x/y/z 中随机选轴）——固定轴只给一维扩散，另两轴冻结；
  • 相位随机（每条线独立、每 tick 重抽）——两种偷懒都会失败：(i) 相位固定时粒子在轴上的奇偶角色被锁定，走一步即翻转奇偶、下一步换回另一端，形成二周期振荡、位移有界（数值：⟨r²⟩ = 2，而扩散值为 600）；(ii) 即使每 tick 重抽，只要全局共用一个相位（同一 tick 内所有线同侧），相位就与「轴」耦合成系统性取向模式，⟨r²⟩ 偏离 n 且不自平均（用 20 个种子复测：均值 1.32 n、相对散布 65%、范围 [0.364, 3.444]；而每线独立时为 1.001 ± 0.027，散布仅 3%）。故「每线独立」是必需条件，不是实现偏好。（原文所引「29.7% / 42.5%（两个种子）」系未自平均量的噪声，且「塌到」的方向亦误 —— 该模式下 ⟨r²⟩ 的均值大于 n 而散布巨大。已修正。）
