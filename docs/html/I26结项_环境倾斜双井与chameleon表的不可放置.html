三、环境倾斜判据（本轮新算）

设定：V_eff(Φ) = −½μ²Φ² + ¼λΦ⁴ + tΦ，t = g⟨ψ̄ψ⟩ = g·n（介质核子数密度）。 参数：m₀ = E(R_H) = 4.1894 meV（第 120 轮 (c) 档）⟹ μ = m₀/√2 = 2.9624 meV、μ³ = 2.5996×10⁻⁸ eV³；g = 1.5729×10⁻¹⁹。

两条分支（小倾斜展开，数值残差 ≤ 7.5×10⁻⁷）：

  • 深井：m² = 2μ² + 3√λ·t/μ（质量随密度增 ⟹ 屏蔽方向）
  • 浅井（亚稳）：m² = 2μ² − 3√λ·t/μ（质量随密度减 ⟹ 反屏蔽方向）
  • spinodal：t_s = 2μ³/(3√3√λ)（浅井与势垒合并、井消失；此后单井，m ≈ √3·λ^{1/6}·t^{1/3} —— τ = 3×10⁵ 处渐近比 = 1.000006）
