1. 定理 B1（涌现规范对称性）【推导 + 数值】

命题：框架哈密顿量 H_F = −Σ_v A_v − Σ_p B_p 与所有顶点/面算符对易：

[HF, Av] = [HF, Bp] = 0 (∀ v, p)

证明（推导）：由 A_v、B_p 的投影性（A_v²=A_v、B_p²=B_p，阶段 A 定理 A3 已证）与两两对易性（[A_v,A_w]=0、[A_v,B_p]=0，阶段 A 数值确认），线性组合 H_F 与每个算符对易。∎

数值验证（Z₂ 2×2 环面，256 态）：

对易项 结果
[A_w, A_v]=0（6 对） ✓
[B_p, A_v]=0（4×4） ✓
[B_p, B_q]=0（6 对） ✓
⟹ [H_F, A_v] = [H_F, B_p] = 0 ✓

物理含义：A_v 是"局域规范变换"（阶段 A 定理 A3），[H_F,A_v]=0 意味着哈密顿量在局域规范变换下不变——规范对称性不是被外加的约束条件，而是哈密顿量自身的动力学对称性。这就是"涌现规范对称性"的严格含义【引用：Kitaev 2003 定理；数值：本次】。

3. 定理 B3（能隙 = 2+1D 质量隙）【推导】

命题：H_F 第一激发能隙 Δ = min(1,1) = 1 > 0（单位耦合）。

证明（推导）：任何非基态至少有一个 A_v 或 B_p 本征值为 0（基态全为 1）；单个违反（一个 A_v 本征 0）的态能量 = −(N−1) = E₀+1 ⟹ Δ≥1；且该态存在（单顶点违反态）⟹ Δ=1。∎

意义【定理，Kitaev 2003】：2+1D 量子双模型是"有正能隙的规范理论"的严格例证——拓扑序（deconfined）的能隙严格正。这是框架"质量隙"叙事在 2+1D 拓扑序中的严格实现；4D 禁闭质量隙（B6）仍为千禧年开放问题，但 2+1D 版本已被严格证明。
