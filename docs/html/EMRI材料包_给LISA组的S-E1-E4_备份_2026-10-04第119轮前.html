一、一页纸

框架：一套从普朗克尺度置换衬底出发的启发式统一框架（自定位：参考架构，非已确立物理）。 它的引力侧给出一个具体度规，该度规在 1PN 与 GR 完全不可区分，但在 2PN/3PN 有确定的偏离：

阶 框架 vs GR 相对偏离 观测窗口
1PN γ = β = 1，其余 PPN 参数 0 无（不可区分） 太阳系 / 双脉冲星 ✅ 已通过
2PN g_rr +2 vs +1.5 33% 当前不可分辨（∝U²）⚠️
3PN g₀₀ −4/3 vs −3/2 11% LISA EMRI / PTA（未来） 🔭

由此得出的可测预言：EMRI 的近日点进动率偏高

δ = κrel(e) xp, κrel(e)=13+e212, xp ≡ GMc2 p (1–3\% 量级)

⚠️ 【第 116 轮更正】 上式原写 δ = 0.30·x_p（唯象斜率，来自测地线数值三点标定）。 第 115 轮已给出解析闭式 κ_rel(e) = 1/3 + e²/12（e→0 时 = 1/3，e→1 上确界 5/12） ⟹ e₀ = 0.3 时 δ = 2.27%（原 2.00%，×1.136）；e₀ = 0.7 时 δ = 3.19%（原 2.56%，×1.247）。

为什么 EMRI 是唯一窗口：EMRI 的轨道圈数 N ~ 10⁴–10⁵，把 ~1–3% 的每圈进动差 累积为可测的相位差 ΔΦ_prec = N·Δω_GR·δ（10²–10³ rad）。

现有定量工作：四份，含 Peters–Mathews 绝热演化波形、LISA 噪声谱、7 参数 Fisher、 Kerr 推广 + 剖面似然/MCMC、以及 a–δ 联合 MCMC（含 Lense–Thirring 进动）。

代表源（模板内单源判决）：ΔlnL ≈ 234（2 yr，SNR 15.3）⟹ GR 模板被排除 ≈ 21.6σ（√(2ΔlnL) = √2·ρ）。 ⚠️ 【第 116 轮更正】 原写 ΔlnL = 357、27σ —— 那是另一台机器（MCMC，其 SNR 固定为 20 ⟹ ρ² = 400）的实测值，与本文件的 Fisher 口径不可混报（见 §2.2d）。

二、⚠️ 请先读：三条诚实边界（放在结果前面）

2.1 度规不是新的

g_μν = diag(−e^{−2x}, e^{2x}, r²e^{2x}, r²sin²θ·e^{2x})，x = GM/(c²r) —— 这就是 Yilmaz–Rosen exponential metric（Papapetrou 1954；Yilmaz 1958/1971；Rosen 1962； 近期 Makukov & Mychelkin 2018；Boonserm et al. 2021）。它的 1PN 性质是文献已确立的。

⟹ 本框架的贡献不在度规本身，而在「为什么是这个度规」 —— 它把这个度规当作 通量海统计力学（玻尔兹曼分布 ρ ∝ e^{−Φ/c²}）的涌现结果，而不是假设。 这个「涌现」是否成立，是本材料最希望被质疑的一步。

2.2 δ = 0.30·x_p 是数值标定，不是解析推导

它来自对框架度规做测地线 RK4 数值积分，在 x_p = 0.020 / 0.033 / 0.045 三点上量出 相对进动差 0.57% / 1.02% / 1.55%，线性拟合得斜率 0.30（即 δ[%] = 30·x_p）。 它不是从某个解析公式推出来的。（我倾向把它标注为【数值】；若你认为应叫【半拟合】，请直说。）

2.2b 【第 112 轮追加】κ 是唯象参数；框架度规自己的值是 κ_rel(e)

⚠️ 这一条把 §2.2 的缺陷再往前推了一步：查阅 stormetric 源码，κ = 0.30 不是标定出来的物理常数， 而是 EMRIPrecession 的默认形参（coupling），docstring 自标 "Phenomenological coupling"， 且类文档注明度规参数是 「kept for interface symmetry, the precession law itself is parametrised by κ」 ⟹ 进动律不经过度规。

⭐ 而用框架自己的度规（g_μν = diag(−e^{−2x}, e^{2x}, r²e^{2x}, r²sin²θ·e^{2x})）做测地线积分 （GR 侧复现闭式 2π[(1−6M/p)^{−1/2}−1] 作为标定），得到的相对进动超额系数是偏心率依赖的：

⚠️ 诚实标注：本轮的 κ_rel(e) 是数值（y→0 外推），解析式未得，精度约 10⁻³ （e-依赖 13%–23% ≫ 求积残差 ~10⁻³）⟹ 本表是「度规不同意单一 κ」的证据，不是最终的预言数值。
