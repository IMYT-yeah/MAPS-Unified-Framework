## 二、N1 的「4π」是什么（＋ 论文没写清的地方）

论文 N1 原文：「稳态涡需相位累积 **4π 整数倍**【本框架设定】⟹ 必须锁定旋转轴 ⟹ 至少一个平面」。

### 2.1 严格化：4π 不是自由参数，它是 SU(2) 的必然

「4π 整数倍」的**精确含义** = **序参量 $\psi = e^{i\varphi/2}$ 是单值的**：

| 累积 | $\psi$ 的变化 | 回归？ |
|---|---|---|
| $\varphi: 0\to 2\pi$ | $1 \to e^{i\pi} = -1$ | ❌ |
| $\varphi: 0\to 4\pi$ | $1 \to e^{2\pi i} = +1$ | ✅ |

数值（$j=1/2$，$R(\alpha)=e^{-i\alpha J_z}$）：$R(2\pi) = \mathbf{-I}$、$R(4\pi) = \mathbf{+I}$（NP-2，精确到 1e-12）。

而 **SU(2) 的最低非平凡自旋 = 1/2**（$j=0$ 平凡、$j\ge 1/2$ 起 $2\pi$ 给 $-1$）
⟹ **「4π」是表示论的必然，零自由参数**（NP-3）。

### 2.2 ⚠️ C-68：两种读法，论文未写明

「相位累积 4π 整数倍」有两种**都自洽**的读法：

| 读法 | 假定 | 推论 |
|---|---|---|
| **A** | $\varphi$ 本身单值 | $\oint d\varphi = 2\pi w = 4\pi n$ ⟹ **绕数 $w$ 必须为偶数**，最小涡 $w=2$ |
| **B** | 序参量是旋量 $e^{i\varphi/2}$ | $\oint d(\varphi/2) = 2\pi w$ ⟹ $\oint d\varphi = 4\pi w$ **自动满足**，$w$ 任意，最小涡 $w=1$ |

⟹ **两种读法下「最小涡」的拓扑荷差 2 倍**，而论文未写明是哪一种。
📌 这不影响本轮的 N2 结论（两者都只说「相位累积确定」），但**下游任何引用「最小涡荷」的地方都会歧义**。

## 三、N2 的相容性方程（本轮核心）

### 3.1 定义（可判定的形式化）

> **「涡锁定平面 $i$」$\iff$ 涡态 $\psi$ 是该平面旋转荷 $J_i$ 的**本征态**，且本征值 $\ne 0$。**

**为什么必须是「本征态」而不是「期望值非零」** —— 见 §四的反例（NP-10）。
直观：只有本征态才有**确定的相位累积**；期望值非零只说明**平均**有旋转，相位仍是不确定的分布。

### 3.2 相容性方程（三行，纯代数）

设两个平面的旋转荷为 $A,B$，$[A,B]=iC\ne 0$。假设 $\psi$ **同时锁定两个平面**：
$A\psi = a\psi$、$B\psi = b\psi$，$a\ne 0$、$b\ne 0$。则

$$\text{①}\quad iC\psi = [A,B]\psi = AB\psi - BA\psi = (ab-ba)\psi = 0 \;\Longrightarrow\; \boxed{C\psi = 0}$$
$$\text{②}\quad iA\psi = [B,C]\psi = BC\psi - CB\psi = B\cdot 0 - C\cdot(b\psi) = -b\,C\psi = 0 \;\Longrightarrow\; \boxed{a = 0}$$

与 $a\ne 0$ **矛盾**。$\blacksquare$

⟹ **两套 4π 相位锁定不可能同时成立**。这就是「共享轴拍频」的严格形式：
**不对易的两个相位不能同时有确定值**（「拍频」= 相位不确定的物理图象）。

### 3.3 数值穷举（不依赖代数推导）

| $j$ | 维数 | 共同本征态数 | 其中「两本征值都非零」的 | 结论 |
|---|---|---|---|---|
| 0 | 1 | 1 | **0** | 平凡（本征值全 0 ⟹ 无涡） |
| 1/2, 1, 3/2, 2, 5/2, 3, 4, 5 | 2…11 | **0** | **0** | 无解 |

⟹ **9 个不可约表示全部无解**（NP-6）；**可约表示**（$0\oplus\frac12\oplus 1\oplus\frac32$，10 维）
同样 **0 个**非平凡共同本征态（NP-8）⟹ **结论不依赖不可约性**。

### 3.4 四档判定全部落地

| 平面数 | 代数条件 | 结论 | 严格性 |
|---|---|---|---|
| **0** | $J_i\psi = 0\;\forall i$ | 无旋转荷 ⟹ **无涡** | ✅ 退化（定义性） |
| **1** | $J_1\psi = a\psi$, $a\ne 0$ | **存在**（$2j$ 个非零本征态，NP-9） | ✅ |
| **2** | $J_1\psi=a\psi$ ∧ $J_2\psi=b\psi$，$a,b\ne 0$ | **不存在**（§3.2） | ✅ **本轮定理** |
| **3** | $J_i\psi = 0\;\forall i$ | 平凡表示 ⟹ **无涡** | ✅ 退化 |

## 四、反面与反例（两个便宜但关键的检查）

**① 单平面锁定确实存在**（NP-9）：每个 $j\ge 1/2$ 有 $2j+1-[j\in\mathbb{Z}]$ 个非零 $J_z$ 本征态
（实测 $j=\frac12\to 2$、$j=1\to 2$、$j=\frac32\to 4$、$j=2\to 4$）⟹ 涡可以有一个确定的旋转轴 ✓

**② ⚠️ 「期望值非零」不是正确判据**（NP-10）：取 $H=\omega_1J_1+\omega_2J_2$（$\omega=1,2$）的本征态，
它给出 $\langle J_1\rangle = 0.447214$、$\langle J_2\rangle = 0.894427$ —— **两个都非零**，
但它对 $J_1$、$J_2$ **都不是本征态**（残差 0.632 / 0.316）。
⟹ 若用「期望值非零」当判据，会**误判双平面锁定可行**。这条反例正是定义必须取「本征态」的理由。

## 七、判决与诚实边界

### 判决

**§10.2#7 的「N2 的 4π 相位锁定相容性方程」结项** ——
方程可写、**无自由参数**、结论是**严格的无解**；N2 的严格性从「⚠️ 启发式」升级为「✅ 定理」。

### 诚实边界（必须一起读）

1. **「锁定 = 本征态」是约定**，其依据是 N1 的相位条件，而 N1 本身标【本框架设定】。
   ⚠️ 但 §四② 的反例说明这个约定**不是随意的**（换成「期望值非零」会得到相反的结论）。
2. **「恰好一个」中的「至少一个」仍用 N1 的原文主张**（「涡 ⟹ 有确定的旋转轴」）。
   本轮严格化的是**上界**（不可能 2 个），不是**下界**。
3. **本轮没有证明「涡态必须是某个不可约表示」** —— 正因为不需要（NP-8 覆盖了可约表示），结论更强。
4. **N4 的初始微扰来源仍未推导**（备忘录遗留 2）—— 本轮未触及。
5. **C-69 的那个数值本轮没有重算**：它测的是「数值稳定性评分」，而本轮给出的是**代数判定**。
   两者不是同一个量 —— 本轮**不声称**复现了 0.00/1.00/0.30/0.05（脚本已丢失，无法复现）。
