一、机制

设衬底 = N 个格点，每格点一个诸元（携带状态）。一个 tick = 对占据态施加一次相邻对换（置换群 S_N 的相邻生成元）：

格点 i 的诸元"湮灭"，格点 j=i±1 的诸元"再生"到 i  ⟺  occ[i] 与 occ[j] 互换

数值验证（N = 400，200,000 次相邻对换）：

  • 结果仍是 0…399 的一个排列（互异计数 400）✓
  • 真空事件计数 = 0（20 万次里一次都没出现空格点）✓

五、化解：持续长度把弹道与扩散接起来（PM-4）

第 18 轮：p_rev = m/m_Pl（每拍反转概率），持续长度 λ_C = l_P/p_rev = ℏ/(mc)。于是：

  • r < λ_C：方向持续 ⟹ 弹道，速度 c；
  • r > λ_C：方向随机化 ⟹ 扩散，D = c²τ_corr/3（d=3，τ_corr = λ_C/c = ℏ/(mc²)）。

⟹ D = ℏ/(3m)：

粒子 p_rev λ_C τ_corr D = ℏ/(3m)
电子 4.185×10⁻²³ 3.862×10⁻¹³ m 1.288×10⁻²¹ s 3.859×10⁻⁵ m²/s
质子 7.685×10⁻²⁰ 2.103×10⁻¹⁶ m 7.015×10⁻²⁵ s 2.102×10⁻⁸ m²/s
普朗克质量 1 1.616×10⁻³⁵ m 5.391×10⁻⁴⁴ s 1.615×10⁻²⁷ m²/s

🎯 意外收获：Nelson 随机力学（从布朗运动导出薛定谔方程的那条路）给出的扩散系数是 D = ℏ/(2m) = 5.788×10⁻⁵ m²/s（电子）。框架的衬底给出 ℏ/(3m)——同形式、同量级，差 1.5 倍 = 维度因子。

⟹ 意义：c 是 p_rev → 0 的极限。这解释了为什么只有无质量者恰好走 c，以及为什么"一步一拍 ⟹ c"必须配 p_rev 才成立。

⚠️ 诚实：扩散给 ⟨r²⟩ ∝ t，而可观测的量子波包展宽是 ⟨r²⟩ ∝ t²（弹道展宽）。这里说的是衬底层面的布朗运动，不是波包展宽，别混为一谈。

六、置换群的代数性质：遍历与可逆（PM-5）

  • 相邻对换生成整个对称群：N=4 生成 24 = 4! ✓；N=5 生成 120 = 5! ✓ ⟹ 动力学在构型空间上遍历（可达任意排列）。

七、诚实边界

是构造 / 已验证的： - 对换保持排列、真空事件 = 0（20 万次模拟）； - ⟨x²⟩ = n（扩散律，数值 2.4% 内）； - D = c²τ_corr/3 = ℏ/(3m)（恒等）； - 相邻对换生成 S₄/S₅（BFS 枚举 24/120）； - R_mix = l_P√(t/t_P) 的换算。

仍是选择 / 未证： - 为什么 tick 恰好是相邻对换（而不是三循环、而不是任意置换）？相邻性来自"手递手"的图像，但没有独立论证； - 每个 tick 是全局一次对换，还是每个格点各一次？本轮按"每 tick 一次相邻对换"的简化模型，全局推广（并行更新）会让混合尺度变大 N 倍——这个选择未定，会显著改变 R_mix，必须标明； - 47 μm 这个数是在"每 tick 一次对换"的串行模型下算的；若并行更新则 R_mix 大得多。

未解决： - 11.0904 的数值； - §4 命题 2.1 的"遍历性"主体是谁（通量 vs 衬底）——待核； - ℏ/(3m) vs ℏ/(2m) 那 1.5 倍是否有内容（目前只当作维度因子）。

八、判决与下一步

判决：✅ 配对机制找到了——湮灭 = 相邻格点的对换。C-1/C-4/C-5 由构造得证，不再靠排除法。✅ 置换群性质（遍历 + 可逆）给"宏观不可逆 = 粗粒化"提供了机制，并给 11.0904 指派了身份。⚠️ 代价是扩散 vs 弹道的张力（靠 p_rev 化解），以及一个哈勃时只混合 47 μm 这条硬约束。
