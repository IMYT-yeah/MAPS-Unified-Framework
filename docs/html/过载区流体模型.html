2 物态方程【推导】

2.1 候选对比（量纲/物理约束）

候选 形式 压强上限 判决
A 辐射气体 P = c²ρ/3 无上限 ✗ 违反"压强有限"
B 因果极限 P = ρc² 无上限 ✗
C 普朗克钳制 P = P_P·tanh(ρ/ρ_P) P ≤ P_P ✅

2.2 普朗克钳制物态【推导】

P(ρ) = PPtanh(ρρP), ρP = c5ℏ G2 ≈ 5.2×1096 kg/m3, PP = c7ℏ G2 ≈ 4.6×10113 Pa
  • 线性区（ρ≪ρ_P）：P ≈ c²ρ/3（恢复辐射气体）；
  • 饱和区（ρ≥ρ_P）：P → P_P（压强钳制在普朗克值——风暴压强有限的定量表达）；
  • 避免奇点：密度可增但压强饱和，不产生无穷大（原文 90）。
