3.1 量子双是什么【定理】

Kitaev 量子双 D(G) 是"非阿贝尔规范从离散代数精确涌现"的严格存在性证明：给定离散群 G，其量子双代数 D(G) = C[G]⋉F(G) 的局域对称性条件精确等于格点 G-规范理论的规范对称性——规范理论不是被"假设"的，而是从离散代数结构涌现的。

D(G) 的任意子（激发谱）= (共轭类 C, 中心化子 Z(g_C) 的不可约表示 ρ)： - 数量 = Σ_C [Z(g_C) 的不可约表示数] - 量子维数 = |C| × d(ρ)，恒等式 D² = |G|²
