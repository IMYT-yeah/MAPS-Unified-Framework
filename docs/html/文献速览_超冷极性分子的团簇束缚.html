核心结论（主论文）

  1. 有效维度约化：在高椭圆率微波场下，三维少分子散射由有效一维模型支配 —— 沿"被压扁"方向的角向涨落（δφ）给出非零零点能，把相互作用势抬平为一个有效势 U(r) = 长程吸引 −r⁻³ + 排斥核 r⁻⁴，其极小在 r_m。 ⟹ 纯粹由相互作用各向异性造成的维度约化，不依赖任何外部约束（这是该工作最强调的一点）。
  2. 团簇谱：四原子束缚态、六原子束缚态（后者的束缚能超过前者两倍）； 与冷原子体系里的 Efimov 束缚有本质不同（Efimov 靠离散标度对称、对短程参数敏感； 这里靠长程偶极 + 大排斥核，只依赖长程偶极强度与微波耦合强度）。
  3. 玻色-费米对偶：同一套束缚态在玻色分子与费米分子体系中具有相同能量与空间密度 （由有效 1D 散射 + 大排斥核促成）；但动量分布仍然不同（Commun. Phys. 那篇明确了这点）。
  4. 多体预言：大分子系综的基态是自束缚的"单分子阵列"（拉长的自束缚液滴 + 晶格图案）， 而不是传统凝聚体或配对超流相 —— 且玻色与费米两种体系都如此。
