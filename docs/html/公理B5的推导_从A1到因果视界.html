二、推导：A1 的三条各干了什么

BX-6（因果优先 / 涌现次序）

框架的核心架构是 引力 = 通量亏损 = 统计涌现（Jacobson 式方向：热力学在先，引力在后）。 所以热力学面必须在引力涌现之前就可定义。

  • R_c = c/H：只需要 (c, H) —— A1 层面就有。
  • R_A = c/(H√λ)：需要 λ = ρ/ρ_c，ρ_c = 3H²/(8πG) —— 需要 G。

G 是涌现量，不在 A1 的基本量表里。 用 R_A 等于用"涌现之后的产物"去定义"涌现之前的基础"， 方向反了。⟹ 热力学面只能是 R_c。

BX-7（观测者相对性）

框架有观测者模型（notes/B-series，B5 观测者模型严格数学化）：观测者是被钉住的孤子。 熵 = 观测者看不到的微观态数。"看不到"是因果概念，不是引力概念： 一个风暴成分能否把信息送回观测者，取决于它的退行速度是否小于信号速度 c。 ⟹ 信息边界 = v_rec = c 的面 = R_c。

BX-8（50:50 与 各向同性的具体分工）

A1 条款 作用
各向同性 观测者的因果边界是以观测者为心的球面（定形状，不定半径）
50:50 无净漂移、无净荷 ⟹ 边界是纯运动学的，不会被不对称通量推移或倾斜
ν ~ 1/t_P 风暴组分以 c 传播 ⟹ 半径由 v_rec = Hr = c 定出 ⟹ R_c = c/H

三条合起来把面唯一确定下来，全程没有用到 λ、k 或 G。

BX-9（反证 / no-free-lunch）

假设取 R_A 为热力学面： ε_bit = √λ·ℏH/(2π)，而 κ = c²/R_A = cH√λ 给出 k_B T = √λ·ℏH/(2π) —— 两者恒等，E = N k_B T 对任意 λ 成立（数值：λ = 0.3/0.6/1/3 比值全为 1.000000000000）。 ⟹ 能账不含任何关于 λ 的信息 ⟹ 引力没有从热力学涌现，只是与热力学同义反复。 ⟹ 与框架的核心主张直接矛盾。 ⟹ 只要框架要求"引力从热力学涌现"具有信息量，热力学面就必须取 R_c。

三、意外收获：λ = 1 不依赖 F3 的系数（稳健性定理）

把熵写成通式 S = k_B A/(ξ l_P²)（ξ 待定，F3 给 ξ = 4），则：

α = 4πξ, β = ξ8π, λ = 4α2β2 = 4·16π2ξ2·ξ264π2 = 1

ξ 完全约掉。 数值核验（ξ = 1, 2, 3, 4, 4ln2, 8, 16）：λ 恒为 1.000000000000， N k_B T 恒为 8.273444294e+69 J = c⁵/(2GH)，与 ξ 无关。

两条重要推论：

  1. λ = 1 极其稳健：即使 F3 的熵系数数错了（ξ ≠ 4），λ = 1 依然成立。 这比上一轮的结果强得多——之前 λ=1 看起来拴在 α = π 上。
  2. 但 β = 1/(2π) 依赖 ξ = 4：β = ξ/(8π)，只有 ξ = 4 才给出 1/(2π)。 ξ = 4 就是 F3 的 S = k_B A/(4 l_P²)，已由太阳黑洞 S/k_B = 1.0494×10⁷⁷ 独立核验。 ⟹ β = 1/(2π) ⟺ 熵系数是 1/4 ⟺ 正确的 Hawking 温度。 三者是同一件事。

四、λ = 1 的新含义：一个一致性条件

把层次分开看，λ = 1 的意思变得很清楚：

  • 基本层（A1）：因果视界 R_c = c/H，只需 c 与 H。
  • 涌现层（引力之后）：表观视界 R_A = c/(H√λ)，需要 G 与 ρ。
  • 一致性：热力学账必须记在基本面上 ⟹ 涌现层必须追平基本层 ⟹ R_A = R_c ⟹ λ = 1。

换句话说：λ = 1 是"涌现出的引力视界成功复现了基本的因果视界"这一要求。 这比"平坦性是个巧合"或"暴胀把它抹平了"都更有结构。它同时也解释了为什么 λ 恰好是 1 而不是 0.7 或 3 —— 因为它是两个面的重合条件，不是一个数值参数。

（严格说：这只给出"必须重合"，没给出"重合如何由动力学保证"。后者需要框架自己的 Friedmann 方程——目前仍缺，见第六节。）

六、还差什么才算定理（诚实标注）

唯一缺环：需要证明

"熵 = 观测者看不到的微观态数"（BX-7 的因果式定义） 与 "熵 = 通量管相干块微态计数"（F3 的统计力学定义） 是同一个量。

两者在黑洞情形给出同一个数（1.0494e77 k_B），这是强证据，但不是证明。 要补的部分： 1. 在因果视界（而非黑洞视界）上重做 F3 的相干块计数——F3 原本是在黑洞视界上做的。 2. 说明为什么"看不到"的判据是因果的（v_rec = c）而不是引力的（俘获面）。 在黑洞情形两者重合，所以在那里区分不了；必须在一个 λ≠1 的玩具宇宙里区分。

另一条更硬的缺环：框架仍未导出 Friedmann 方程。因此 λ = 1 目前是 "一致性要求"，不是"动力学后果"——我们说明了它必须成立，但没说明动力学如何做到。
