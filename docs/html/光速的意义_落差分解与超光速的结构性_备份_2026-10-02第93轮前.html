一、命题的形式化

  • 静止时 v_int = c：全部运动都在内部 zigzag；

⚠️ 「落差」有两种量法，论文里不能混： - 线性落差 δ = c − v（路径长度被浪费的比例）——v=0.6c 时是 0.40c； - 不变量落差 v_int = c/γ（内部运动速度，也是时钟走速）——v=0.6c 时是 0.80c。

只有后者是洛伦兹不变量的构件。要写进论文必须写 v_int = c·√(1−v²/c²)，并指出它就是固有时速率（时钟走多快 = 内部 zigzag 有多快）。
