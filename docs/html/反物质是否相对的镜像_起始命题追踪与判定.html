① 「我们同时是正粒子和负粒子的宏观稳定节点」→ 必须分两层，一层对一层错

层 判定 依据

② 「只观察到正粒子的稳定，其实是世界的假象」→ ❌ 两重问题

（a）与框架自己的机制互斥。 框架对"为什么我们这一支占优"给的是 ε 泄漏（公理 2：正份漏入正支、反份漏入镜像支）—— 一个真实的统计偏向，靠 ε 在宏观上累积。若不对称是"假象"，那 ε 就没有存在的必要。 两者不能同时成立。

（b）不可证伪。 「真实是 A，我们看到 B，且无法区分」按本项目四类判定不进预言表（N-50 族：第 135 轮「纠缠=结构态」、第 146 轮「粒子→层」同一堵墙）。

⚠️ 而且现实里 η ≈ 6×10⁻¹⁰ 是实测物理量（CMB + BBN），不是观测偏差；框架对它的定量解释已被判 N-40（η 能标不可导出）。

③ 「反物质是永远与我们当下状态恒定保持反状态的一团物质」→ ❌ 术语内部互斥

「恒定」与「随当下状态相对」不可能同时成立：

读法 含意 是否固定映射
(a)「恒定」 一个固定的对应关系 ✅ 固定 —— 那它就是 CPT（框架公理 3），与你／观测者无关
(b)「与当下状态相对」 映射随观测者态变化 ❌ 非固定 —— 那就不是"恒定"

二选一。 选 (a) 就是框架已有的公理 3（CPT 联合镜像，不是新东西）；选 (b) 则与"恒定"矛盾。

⚠️ 补一句精度问题：CPT 是联合变换，单独的 C、P、T 在标准物理里都不守恒（弱相互作用破坏 C 与 P）。所以「反物质 = 时间反演的那个东西」不严格 —— 反物质是 C 变换的产物，不代表时间反演。

框架里有没有"相对的观测者"？ 有半个：观测者 = 现在平面孤子（§4.9），但「现在平面」是固定的（N1–N4：由涡动力学锁定 ＋ 对称性自发破缺），不随观测者状态变化。⟹「相对的反状态」在框架里无载体。
