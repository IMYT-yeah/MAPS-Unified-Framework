2 【重要】实现修正记录（本批的诚实核心）

本批在复现热力学极限计算时发现两个独立的实现 bug，均已在 v3 脚本中修正。此记录对学术诚实至关重要：

Bug 1：几何索引约定（hidx/vidx 方向写反）

  • 错误：hidx(i,j)=i·(ny−1)+j（把水平边当成 j 索引）——导致面算符不是正方形而是对角线交叉，A_v/B_p 全部错配；
  • 正确：hidx(i,j)=i·ny+j（i∈0..nx−2, j∈0..ny−1），vidx(i,j)=(nx−1)·ny+j·nx+i（i∈0..nx−1, j∈0..ny−2）；
  • 验证：修正后 3×3 完整对角化 E_min=−13.0000（κ=0，精确 −ΣA−ΣB=−13 ✓）、能隙 1.0000（标准 toric code）、A_v=B_p=1 全满足；
  • 影响：此前"热力学极限有限尺寸标度"（σ_E≈2κ 报告）的 σ 数值可能含此误差（该轮 3×4 报 0.960，修正后 0.9688）——核心结论（禁闭弦张力 σ_E≈2κ 存在）方向正确、数值需以本报告为准。

Bug 2：弦态构造混淆（位翻转 = X 串，非 Z 串）

  • 错误：ψ = v[idx^mask]（位翻转）——这是 X 算符（磁通对），不是电荷对；
  • 正确：电荷对（Z 串）用相位翻转 ψ = v × Π_{e∈path}(−1)^{g_e}（对角算符）；
  • 验证：κ=0 时 Z 串 dE=[2,2]（电荷 deconfined ✓）；X 串 dE=[1,2]（磁通数×1，非距离）；
  • 影响：此 bug 使早前版本测到的是磁通对而非电荷对——修正后 σ_E≈2κ 精确恢复（0.969/1.984/3.992 vs 1/2/4），且 κ=0 正确给出 deconfined（此前版本无法区分）。
