1 问题设定与动机

上一轮（v1.10）的 3D 球对称闭式解 ρ = ρ∞[R·erf(x/√(4Dt)) + x]/r 是半无限近似（外边界在无穷远，x≪R）。遗留问题：

  1. 外边界 L 有限时解是什么？（宇宙学视界/邻近天体/双黑洞系统的物理边界）
  2. 半无限近似的误差界？——L 多大时半无限解可靠？
  3. 稳态形态？——t→∞ 时通量剖面是什么形状？

设定：区域 r ∈ [R, L]，边界 ρ(R,t)=0（视界抽零）、ρ(L,t)=ρ∞（外边界背景），初始 ρ(r,0)=ρ∞。

2 球贝塞尔级数解【定理·严格】

变换 u = rρ（吸收 2/r 项，同 F1″）：∂u/∂t = D·u_rr，边界 u(R)=0、u(L)=Lρ∞。

稳态解（u_rr=0 + 边界）：

uss(r) = ρ∞ (r-R)LL-R

分离变量（u = u_ss + 瞬态）：

u(r,t) = ρ∞(r-R)LL-R + ∑n=1∞ cn sin(kn(r-R)) e-Dkn2 t, kn = nπL-R

系数（初始条件 u(r,0)=rρ∞ 的傅里叶展开）：

cn = 2L-R∫RL [rρ∞ - ρ∞(r-R)LL-R]sin(kn(r-R)) dr

物理图像：稳态 = 视界（u=0）与外边界（u=Lρ∞）之间的线性插值（u 空间）；瞬态 = 球贝塞尔模（sin 基）的指数衰减，最长模 τ₁ = (L−R)²/(Dπ²) 决定整体弛豫时间。

5 重要物理发现：稳态 1/r 形态【验证⑥】

有限 R 稳态解（取 L→∞ 极限）：

ρss(r) = limL→∞ρ∞(r-R)Lr(L-R) = ρ∞(1-Rr)

数值验证（L=10⁶·R、t=50τ₁）：ρ_ss 与 ρ∞(1−R/r) 最大偏差 0.0001%——严格确认。

物理意义【本批最重要成果】：

通量赤字 ≡ ρ∞ - ρss(r) = ρ∞Rr ∝ 1r

稳态通量赤字按 1/r 衰减——与牛顿引力势 Φ ∝ 1/r 完全同形！ 这独立支撑了框架核心主张"引力 = 通量遮挡"：质量在视界处造成的通量抽零，其稳态影响按 1/r 传播，正是引力势的形态（力 ∝ 1/r² 来自势的梯度）。此前从立体角积分推导 1/r² 力（P0），现在从扩散稳态独立得到 1/r 势——两条路径汇合于牛顿引力形态。
