一、一句话结论

框架给不出 ℏ 的独立身份 —— 但准确的说法不是「不是基本常数」，而是「不可辨识」： 框架对 {ℏ, G, l_P} 只有 1 个可辨识组合（Gℏ/c³ = l_P²），自由度 = 2； 而它的核心链（λ = 1 的等分账）里 ℏ 逐项抵消 ⟹ 框架从未在任何可观测处「看见」ℏ 的数值。 附带查出 v1.17 那处「普朗克常数 M²/A = c⁴/(16πG²)」是误标（C-77）：量纲不对、表达式不含 ℏ、 而且是 GR 的代数恒等式（零框架内容）。

3.3 ⭐ 本轮定量产出：λ = 1 链里 ℏ 逐项抵消

§8.6.3 的等分账推导（框架的核心结论）：

⟹ E = R_c²·H₀·c³/(2G)      ← 不含 ℏ

⚠️ 反面读法同样成立：若把 l_P 当作固定输入而只改 ℏ，则 ρ ∝ ℏ （t = 2 与 0.5 之比恰为 4.000000）⟹ 两条读法都只锁住组合 Gℏ/c³。

⟹ 该链对 ℏ 完全不敏感 ⟹ 它不能为 ℏ 的身份提供任何信息；这里 ℏ 是输入 （§8.6.2 已把 1/4 与 β 标为「标准物理输入」）。
