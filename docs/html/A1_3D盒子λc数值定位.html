4 诚实标注与局限

  • chi=8 vs chi=16 截断敏感性（2×2×2 峰区实测）：λ=0.21（峰区附近）chi=8→16 时 ⟨A_c⟩ 从 0.6975→0.6741（Δ=2.3%）、E 从 −10.220→−10.386（Δ=1.6%）——序参量与能量对 bond 相对稳健，χ 峰位 λ_χ（由 −d⟨A⟩/dλ 形状决定）对这种小幅系统偏移不敏感 ⟹ λ_χ=0.230 的峰位判定可信；但 λ_c(∞) 的精细外推需 χ 更高（chi≥16 在 36/52-site 上单点 ~10 分钟，Windows numpy 近奇异矩阵还有偶发 segfault，建议换 TeNPy/ITensor 复核）；
  • 3×2×2 尾端 χ 回升（λ≥0.29，χ 从 1.9 回升至 2.95）：52-site 纠缠更强，chi=8 截断低估序参量所致疑似截断噪声，非物理第二相变；322 主峰（0.19–0.21）与 222 峰（0.230）一致，不受尾端影响；
  • λ_χ=0.230 为有限尺寸值（L=2 盒子的伪临界），热力学极限 λ_c(∞) 估计 ∈ [0.21, 0.23]（两尺寸峰位无漂移），严格 1/L 外推需 L=3 盒子（3×3×2、3×3×3）；
  • χ 峰 vs 其他判据：与 v1.36 相同，χ 峰与 E0 曲率峰可能不一致（小系统判据分歧），需多判据交叉；
  • DMRG 方法学：手写求解器在 2×1×1 精确验证通过；chi≥16 崩溃是数值环境问题（LAPACK 近奇异 segfault），非物理问题。

5 结论（v2.9 增量要点）

  1. v1.36 的 λ_c≈0.14 被证实为棒/板系统伪临界：真 3D 盒子（2×2×2、3×2×2）χ 峰 λ_χ≈0.21–0.23，偏移约 +50–64%；
  2. "维数-临界耦合递减谱系"结论需修正：真 3D 临界耦合 0.21–0.23 与 2D toric code（0.25–0.32）同量级、与 3D Ising β_c=0.2217 高度接近（差 3–7%）——支持"3+1D 弦网 ↔ 3D Z₂ 格点规范 ↔ 3D Ising"对偶自洽（v1.28 对偶映射）；
  3. 凝聚相稳定域：λ<0.21–0.23 凝聚（v1.36 估计 0.14）；σ_E≈2κ 适用域（κ=0.5–2.0）仍远在 λ_c 之上，禁闭相自洽不受威胁 ✓；
  4. λ_c(∞) 估计 [0.21, 0.23]：两尺寸（体积 8→12）峰位无漂移，支持该区间；严格外推需 L=3 盒子（后续工作⑤）。
