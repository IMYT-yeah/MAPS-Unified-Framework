二、「相邻面元强相关」第一次有了机制

B5 原文只写「相邻面元的 4 方向连接强相关（通量管相干）」，从未给出机制。本轮的构造直接给出了它：

面元 P 的「+x 方向连接」与它右邻居 Q 的「−x 方向连接」是同一条键，因此两个槽位必须取同一个值（同一条键承载的正/负支不可能分身）。

⟹ 这不是统计相关，是恒等约束。 数值：绑定对数 = 键数 = 128；独立自由度 = 4N_p − N_b = 2N_p（每面元 2 条独立键）。

四、顺带纠正一处措辞

B5 的「相干块自由度 = 4 面元 × 4 方向 = 16」——实测 2×2 块：

校验：16 = 2×4 + 1×8 ✓。

⟹ 16 是槽位数，不是独立自由度数。 「自由度」一词在这里被滥用了，论文里已加注。
