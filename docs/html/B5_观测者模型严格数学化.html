观测者 = 现在平面孤子【原文 1648–1650】，其信息获取机制： 1. 可读性限制【原文 1651】：观测者只能感知"诸元在现在平面内的四个方向上的连接状态"——平面内 4 方向可读、平面外 2 方向（过去/未来）无信息通道（卷曲）； 2. 体 = 表面投影【原文 1652】："体信息冗余、表面信息基本"——体区域 R 的内部状态由其在表面 Σ 上的投影决定（体单元状态 = 其表面邻居状态的确定性函数）； 3. 帧刷新【推导】：每个普朗克时间，表面状态经平面内连接"广播"给观测者（蓝图重建孤子逐帧读取）。

2.2 互信息定理【推导】

命题：观测者可访问信息 S_access(R) = I(R;Σ)，且

I(R;Σ) = H(Σ) Longleftrightarrow H(R|Σ) = 0 （体由表面唯一决定）

推导：I(R;Σ) = H(R) − H(R|Σ)。由"体=表面投影"（体单元 = 表面邻居状态的确定性函数）⟹ H(R|Σ)=0 ⟹ I(R;Σ) = H(R) = H(Σ) = M bits（M = 面元数 ∝ 表面积 A）——互信息的面积律。∎

3.2 物理图像【推导】

观测者读到的"4 方向连接"是原始可读信息（每面元 4 bits）；但相邻面元的 4 方向连接强相关（通量管相干：相邻面元共享相位）——相干块（4 面元 × 4 方向 = 16 自由度）只携带 1 个独立比特（1D 相干锁定，k 模型）。熵密度 = 可读信息 / 压缩比 = 4/16 = 0.25 bit/面元。

"每 4 面元 1 bit"从原文断言升级为"可读 4 bits × 16 倍相干压缩"的推论——归一化因子 4 的动力学来源 = 相干块结构（与 k=2^{1/4} 的 16 倍压缩同源）。

6 诚实标注

  1. 互信息面积律的证明强度【推导】：H(R|Σ)=0（体=表面投影）是框架主张（原文 1652），非已确立物理；"体单元=表面邻居确定性函数"是 toy 化表述，真实投影规则需从帧刷新动力学严格化；
  2. 16 倍压缩的归一化【推导】："4 方向连接 = 4 bits 独立可读"是理想化（4 个方向连接可能部分相关）；真实可读信息 ≤ 4 bits/面元；
  3. 与 k 模型衔接的强度【推导】：压缩因子 16 与 k=2^{1/4} 模型的"16 倍压缩"数值一致——但两者是同一机制的两种表述还是巧合，需更深论证；
  4. 数值为 toy 模型演示【数值】：面积律与压缩比是简化模型的数值确认，非第一性推导。
