三个要点：

  1. 原设置（22.74%）落在基线 1σ 内 ⟹ A 段与"完全正确的麦克斯韦分布"统计上不可区分。
  2. 加长 4 倍步数，偏差没有下降（0.2274 → 0.2825，1.16 倍基线）⟹ 这直接排除了"弛豫不足"：如果真是没弛豫，加长 4 倍应当显著下降。它没有 ⟹ 该偏差不是"还没均衡"，而是采样统计（＋可能的 2D 长时尾，原稿已诚实标注）。
  3. 换种子给出 0.2274 / 0.2942 ⟹ 样本间散布 ≈ ±0.03，与基线 sd 0.049 同量级 ⟹ 这就是噪声。

⚠️ 唯一需要留意的：N=512 时 1.35×（+1.79σ）——轻微超出基线，可能来自 2D 长时尾（真实物理效应）。但只有 1.8σ，不足以断言，需要更多种子或三维模拟才能分辨。
