二、发现一：第 41/46/47 轮的生成元集在边长 ≥ 6 时是错的

病因

三次推演的脚本里都有同一行：

perm2[coords[i]] = coords[(i + 2) % L]      # ← 把「全体 +2 的纯平移」当成每线 σ_j

但正确的 σ_j（= 相位 1 匹配 ∘ 相位 0 匹配）是偶位 +2、奇位 −2：

单线长度 6 上的置换 是否属于 tick 群
代码用的「纯平移」 (0 2 4)(1 3 5) ❌ 不在
正确的 σ_j (0 2 4)(1 5 3) ✅

单线长度 6 的对照：真 tick 群 ⟨M₀, M₁⟩ = 6 阶；⟨M₀, 纯平移⟩ = 6 阶， 但两者只共有 2 个元素（e 与 M₀）（|并| = 10）⟹ 阶相同、群不同。

判定（_gen_fix2_48.py，决定性）

格点 |⟨全 tick 集⟩| |⟨正确化简⟩| |⟨第41–47轮⟩| 全集 = 正确？ 全集 = 旧？
(2,2,4) 128 128 128 ✅ ✅
(2,2,6) 648 648 648 ✅ ❌ 不同
(2,2,8) 2048 2048 2048 ✅ ❌ 不同

极端反例（单线长 6）：8 个随机真 tick 里，只有 3 个落在旧群里 ⟹ 旧群漏掉 5/8 的真 tick。

受影响范围（比预想窄，但正落在关键算例上）

格点 受影响？ 依据
(2,2,2)、(2,2,4) ❌ 否 边长全 ≤ 4 时两套生成元逐元素相同

(6,6,6) ❌ 否 旧生成元全部落在正确群里 ⟹ 同一群

三、发现二：H/N 的形状依赖 —— 跨过 0.25

用 GAP 的 |O(c)| = |G| / |Stab_G(c)|（Stabilizer(G, c, OnSets)）：

格点 N L = 2 的方向数 |G| H/N 95% 区间 方法
(2,2,2) 8 3 8 0.4679 — 精确划分
(2,2,4) 16 2 128 0.4335 — 精确划分
(2,2,6) 24 2 648 0.4510 — 精确划分
(2,2,8) 32 2 2 048 0.4617 — 采样
(2,2,16) 64 2 32 768 0.5307 ±0.0000 GAP，S=40
(2,4,4) 32 1 2.2015×10¹¹ 0.2834 ±0.0061 GAP，S=60
(2,4,8) 64 1 1.3970×10³⁷ 0.1802 ±0.0034 GAP，S=40
(4,4,4) 64 0 2.7940×10³⁷ 0.1839 ±0.0031 GAP，S=60

⟹ 面积律要求的 0.25 被"跨过"了：(2,4,4) = 0.2834 > 0.25 > (4,4,4) = 0.1839。

判别量不是"各向同性程度"，而是"有几个长度为 2 的退化方向"

⚠️ 本轮的一个自否：我开局预判"越各向同性 H/N 越小"，实测 失败 —— (2,4,8) = 0.1802 低于 (4,4,4) = 0.1839（(4,4,4) 更各向同性，H/N 反而略高）。

替换后的判据（两组完全分离）：

分组 例数 H/N 范围
≥ 2 个 L = 2 方向 5 0.4335 – 0.5307
≤ 1 个 L = 2 方向 3 0.1802 – 0.2834

⟹ 最低值 0.4335 > 最高值 0.2834 —— 两组间有一个空隙，而 0.25 落在空隙里。

（口径说明：L = 2 的方向上没有任何相位自由度 —— 长度 2 的环只有一种完美匹配， 所以 σ_j = 恒等。这两个方向的"退化"正是把 H/N 顶到 0.43 以上的原因。）

(2,4,4) 的首次真值（这是第 47 轮明确列出的缺口）

  • 采样 60 个 k=16 构型；轨道大小 10 368 – 5 971 968（比 (2,2,L) 系列大 3 个数量级）
  • ⟨ln|O|⟩ = 13.1115 ⟹ ⟨ln|O|⟩/N = 0.4097
  • H/N = 0.2834 ± 0.0061 ⟹ 相对 0.25 是 +13.4%（不是 +75%）
  • ⚠️ 这也解释了第 47 轮为什么算不出来：轨道 ~10⁶，Python 的 BFS 上限 4×10⁵ 根本不够， 而按 |G| = 2.2×10¹¹ 判断"不可算"则是判据选错了变量（该看轨道大小，不是群阶 —— 见 N-8）。

四、判决

# 判决 依据
1 ✅ GAP 装上并互验通过 sha256 一致；单元测试三个已知答案全对；与 Python 精确 BFS 在 (2,2,6) 上 8/8 逐位一致
2 ❌ 第 41/46/47 轮的生成元集错误（边长 ≥ 6 的细长格点） 与全 tick 集穷举比较：群不同；8 个真 tick 只 3 个落在旧群里
3 ✅ H/N 的形状依赖：判别量 = L=2 方向数，两组完全分离 上表 8 个算例，无重叠
4 ⚖️ 撤回旧判决 R-1："不变读数偏大 1.75 倍 ⟹ 面积律不成立"（N-2/N-3）是细长格点假象 (2,4,4) 只偏大 13.4%，(4,4,4) 反而偏小 26.4%
5 ⚠️ 不变读数路线并未复活，但也不再是否定态 0.25 落在两组空隙里 ⟹ 需要知道"哪个形状才是真宇宙"，而不是"这条路死了"

五、诚实边界（必须随结论走）

  1. (4,4,4) 与 (2,4,8) 的 95% 区间都在 0.25 的下方（[0.178, 0.190] / [0.174, 0.187]）， 而 (2,4,4) 在上方 [0.272, 0.295] ⟹ "跨过"是确定的，但跨点在哪里未定。
  2. 形状扫描只有 3 个 N=64 点（(2,2,16) / (2,4,8) / (4,4,4)）；"退化方向数"这条判据是 8 个算例上归纳出来的，不是推导出来的。可能还有别的变量在起作用（例如 N 与形状的耦合）。
  3. (2,2,16) 的 H/N = 0.5307 的标准误为 0（40 个采样轨道大小完全相同 = |G|，稳定子平凡） ⟹ 该点是"所有构型等价"，不是统计偶然。
  4. (2,2,16) 与 (2,4,8) 的 |G| 未与 sympy 交叉验证（生成元多、sympy 可能很慢）； 但 GAP 与 sympy 在 (2,2,6) / (2,4,4) / (4,4,4) 上已一致。
  5. N = 64 仍远小于宏观 N_c³ ≈ 6.1×10¹⁸² ⟹ 不得外推（第 41 轮教训）。 本轮的结论全部是 N ≤ 64 的有限格点事实。
  6. k 固定为 N/2；与第 40 轮"全部 2^N 构型"口径不同。
  7. GAP 的 Stabilizer(...,OnSets) 是精确算法（非随机回溯的重试版），但本轮未检查 GAP 是否走过完整回溯链；若某构型的稳定子搜索退化，GAP 仍会给正确结果（只是慢）。
