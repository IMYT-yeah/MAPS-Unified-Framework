二、方法：三档「随机性来源」

⚠️ 一个必须先说清的方法论事实：数值模拟里的「真随机」也只能是伪随机（除非用 os.urandom）。 所以本轮严格比较的是三档：

模式 生成器 身份
sys random.SystemRandom()（os.urandom 真随机源） H1 的严格版本
indep MT19937（random.Random(seed)，确定性但高质量） H2 的好代理
lcg 线性同余发生器（确定性且低质量） H2 的差代理

⟹ 「外生真随机 vs 内生确定」这个本体问题在模拟里无法真正实例化 —— 这本身就是 T-7 答案的一部分。

两类可观测量： - 空间关联 C = ⟨Δ_i·Δ_j⟩ / ⟨r²⟩（按初始间距分 bin；独立游走 ⟹ C = 0） - 时间关联 C(τ) = ⟨Δ(t)·Δ(t+τ)⟩ / ⟨Δ²⟩（某诸元沿一轴的每 tick 位移的自相关）

五、⚠️ 负面发现：周期性判据失效（本轮原设想被自己否证）

原设想：H2 若用有限状态生成器，驱动序列（φ、轴）必然周期重复； 宏观衬底每 tick 需要 L² 个相位 ⟹ 种子即便 256 位，周期也只有 2^256 / L² ≈ 10⁻⁴⁵ tick （即单个 tick 内就重复）⟹ 重复应能在位移序列里看出来。

检验：让 φ 与轴都由模 2⁸ 的 LCG 驱动 ⟹ 驱动序列联合周期 = 256 tick，跑 n = 4000 tick。

结果：

  • 自相关峰在 τ = 1（−0.3486）；τ = 256 处 = −0.3269
  • 严格周期的标志应是 C(T) ≈ +1（位移序列原样重复），实测是负的 ⟹ 位移序列不按驱动周期重复

机制：位移 = 位置之差，而诸元位置在持续演化、不会回到起点 ⟹ 驱动序列的周期不会原样传递到位移上。

⚠️ 但有一个保留：τ=256 处的 |C| = 0.3269，远大于真随机源的同量级水平（≈ 0.02） ⟹ 驱动序列的相关结构在长时标上确实留下痕迹 ⟹ 与 TP-3 一致：低质量 H2 仍可区分， 只是区分的是「相关结构」而非「周期性本身」。

六、诚实边界

是数值 + 推导：空间/时间关联、周期性检验、宏观周期账 —— 全部本轮实测。

方法上的硬限制（必须写）： - 数值模拟里的「真随机」只能是伪随机（除非用 os.urandom）⟹ 本轮严格比较的是「不同质量的确定性生成器 + 一个真随机源」； 真正的「外生真随机」在模拟中无法实例化。 - sys 模式每次运行结果不同（C_near 在 −0.04 ~ −0.01 波动）⟹ 报告的是量级与 σ，不是定值。

是判定（不可判定）： - T-7 的「不可判定」是结构性的：任何多项式时间可计算、且通过所有统计检验的确定性生成器 都与真随机不可区分 ⟹ 不是「暂时算不出」。

未做： - 三点关联、关联随距离的完整形状、更长的时序、其他 PRNG 族（xoshiro、PCG、密码学 PRNG）。 - 从宏观观测量里分离「驱动序列周期」的可行性 —— 已给否定的机制论证（§五），未做定量。 - 未检验：若把「H2 的生成器」当作框架公设写进去（即规定 tick 用某一档）， 会新增多少参数、复用率如何变化。
