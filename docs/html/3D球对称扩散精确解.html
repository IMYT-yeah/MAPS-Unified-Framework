解析积出两项： - 第一项（R·erf）：∫G·R dx′ = R·erf(x/√(4Dt)) - 第二项（x′）：∫G·x′ dx′ = x（可解析验证，镜像法精确相消）

⟹ 3D 球对称扩散精确解【本批核心成果】：

boxedρ(r,t) = ρ∞ · R erf(r-R√4Dt) + (r-R)r
