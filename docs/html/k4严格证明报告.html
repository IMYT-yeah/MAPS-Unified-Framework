一、定理 1：k ≥ 4 下界【新证·严格】

命题

设方向集 V = {v₁,…,v_k} ⊂ S²（量子直线端点的方向簇）。若 V 满足挂谷覆盖要求——覆盖半径严格小于 90°（任意内向方向都能被唯一确定地归属，无"零信息余量"方向）——则 k ≥ 4。

证明

引理 A（3 方向覆盖半径 ≥ 90°）：对任意 3 个单位向量 v₁,v₂,v₃ ∈ S²，存在 p ∈ S² 使 p·vᵢ ≤ 0 对所有 i 成立（即距最近方向 ≥ 90°）。

证明：反设对任意 p 都有 maxᵢ p·vᵢ > 0，则 3 个开半球 {p: p·vᵢ > 0} 覆盖 S²。由分离超平面定理（球面版），这等价于原点 0 ∈ int(conv{v₁,v₂,v₃})（否则存在分离超平面给出 p 使 p·vᵢ ≤ 0 ∀i）。

但 3 个单位向量 0 ∈ int(conv) 仅在共面环绕情形可能（3 个向量非负线性组合为零且零在内点 ⟹ 它们共面）。此时取 p 为该平面法线方向：p·vᵢ = 0 ∀i ⟹ 覆盖半径恰 ≥ 90°。对非共面（一般位置）情形，0 ∉ conv ⟹ 分离超平面直接给出 p 使 p·vᵢ ≤ 0 ∀i。两种情形均与"覆盖半径 < 90°"矛盾。∎

引理 B（90° 是硬下界）：k=3 时最优覆盖半径 = 90°（赤道等边三角形达到，两极距所有 3 方向恰 90°）。

数值验证：k=3 随机配置（150 次尝试取最优）覆盖半径最小值 = 90.05° ≈ 理论下界 90°；赤道三角 = 89.917°。

物理结论：k ≤ 3 时必存在"零信息余量方向"（距最近方向恰 90°，任何微扰即信息缺失）——不满足挂谷"包住所有内向方向"的严格覆盖要求。因此 k ≥ 4。 ∎

二、定理 2：k=4 最优构型 = 正四面体【定理·Tammes 已知结果】

定理（Tammes 问题 n=4）：S² 上 4 点最大化最小角距离的唯一最优构型是正四面体顶点，最小角 arccos(−1/3) ≈ 109.47°。

数值验证（P1' 完成）：正四面体最小角 109.4712° = 理论值；随机 2000 次采样的最好结果仅 96.90°——正四面体全局最优确认。

意义：若方向簇数 = 4（定理 1 给下界），则 4 个方向的最优排列由正四面体唯一确定（无其他选择）。

三、定理 3：Voronoi 精确均分【定理·严格】

命题：正四面体 4 方向将 S² 均分为 4 个全等球面三角形单元，每单元面积 = 4π/4 = π（精确 1/4 球）。

证明：正四面体顶点在 S² 上构成 4 点对称配置（点群 T_d），对称性保证 Voronoi 单元全等；总面积 4π 均分 ⟹ 每单元 π。∎
