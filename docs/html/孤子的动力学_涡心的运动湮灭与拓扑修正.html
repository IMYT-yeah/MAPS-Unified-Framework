五、诚实边界（六条，全部实测）

  1. 动力学是新增假设 —— 框架里「图热流 / Dirichlet 能量 / 联络」各 0 处（§一）。
  2. 裸绕数 ≠ χ（是 3χ），必须曲率修正；且修正只对零点不落在格点上的平滑场成立。
  3. 守恒是"拓扑量子级的近似"，不是逐步严格： Σw 是精确整数（40/40），但逐步严格相同 0/40、极差 ≤ 2 者 39/40、众数 = 终值者 39/40。 原因：涡心在相邻格点间跳跃的那一步落在棱上，离散绕数读出单步 ±1（偶 ±2）抖动，下一步复原 —— 不是漂移。 ⚠️ 且「严格逐步相同」与「涡心数下降」在 40 seed 扫描下互斥（同时成立 0/40）—— 这是数学事实，不是实现问题。
  4. 种子无关性是演化的产物 —— t = 0 时平滑层 5 个种子里 2 个读数是 5（一对相邻涡心被记在同一个顶点），跑到 t = 200 才全部修成 6。
  5. 噪声层没有拓扑荷（§四）。
  6. 稳定 ≠ 动力学稳定 —— 证的是「拓扑上抹不掉」（必要），不是「抗任意微扰」（充分）。 第 66 轮的第 3 条边界仍然成立。
