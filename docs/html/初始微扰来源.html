三、定理链

定理 P1（来源 = ε 泄漏）【原文 103 + 150 + 155】

命题：初始微扰（"偶然多出的正物质"）就是 ε 泄漏事件——每次泄漏产生一个正物质粒子【原文 155】，这个正物质就是涡锁定的种子【原文 103】。

论证： 1. "偶然多出的正物质" = 泄漏产生的正物质【原文 150："每一次泄漏……正这份留在我们支"】； 2. 泄漏产生正物质粒子【原文 155：N_b ≈ εΓVt】； 3. 正物质微扰 → 流场锁定成稳态涡【原文 103】。 ∴ 初始微扰 = 泄漏事件。∎

定理 P2（必然性）【原文 1266 + 519–529 + 推导】

命题：初始微扰必然存在——由真空基态不稳定性 + 毛球拓扑 + 泄漏数统计三重保证。

论证： 1. 不稳定性：绝对均匀的真空基态不稳定，涨落不可避免【原文 1266】； 2. 拓扑强制：毛球定理 ⟹ S³ 切丛非平凡 ⟹ 涡心必然存在【原文 519–529】——ε 不是"概率碰巧"，是拓扑必然的"最小涡心密度"； 3. 统计必然：泄漏率 λ = ε·ν ≈ 6×10⁻¹⁰ × 1.85×10⁴³ s⁻¹ ≈ 1.1×10³⁴ s⁻¹；电弱相变前（t~10⁻¹² s）期望泄漏数 ≈ 1.1×10²² ≫ 1——初始微扰以压倒性概率必然出现。∎

数值验证①：电弱前期望泄漏 1.11×10²²（≫1）；几何分布验证（ε=0.01 模拟 20000 次，平均等待 99.63 vs 理论 100，偏差 −0.4%）。
