一、本轮问题

第 40 轮的判据：

第 41 轮：|G| 在 N ≥ 64 爆炸（N=64 ⟹ 2.79×10³⁷）⟹ |O| ≤ |G| 上界失效； 改用 (Z₂)³ 奇偶差类不变量 ⟹ |O| ≤ ∏_i C(N/8, n_i) ⟹ N=64：5.76×10¹⁴ ⟹ H/N ≥ 0.162， 而界是 0.162–0.693，跨过 0.25 ⟹ 未定。

本轮把这个问题算到底，关键只有一句话：(Z₂)³ 不变量是不是「完备不变量」？

  • 若完备（轨道 = 不变量等值集）⟹ 用组合公式就能精确算任意 N ⟹ N=64 定下来。
  • 若不完备 ⟹ 真实轨道比等值集更细 ⟹ 公式只是上界。

四、判决

① (Z₂)³ 不变量不完备（本轮关键负面结果）

N=8 上 14 = 14 是偶然（每类只有 1 个点，不变量退化）； N ≥ 16 立即不完备，且急剧加剧（N=16：253 vs 155；N=24：6224 vs 1050）。 ⟹ 第 41 轮的公式在宏观格点上不能用，只能作上界。

② 第 41 轮的 0.162 是弱下界

公式高估 9 倍（N=24）且随 N 增长 ⟹ N=64 的真实轨道远小于 5.76×10¹⁴ ⟹ H/N 远高于 0.162。

五、诚实边界（重要）

  1. 格点形状：本轮三个算例都是 (2,2,L) 系列 —— 两个方向长度只有 2， 是细长格点，不代表各向同性的三维宏观格点。奇偶类结构在 L=2 方向上退化。 ⟹ "H/N 饱和在 0.433"这个结论，只在 (2,2,L) 系列上成立。
  2. 算不上去：(4,4,4) N=64 ⟹ C(64,32) = 1.83×10¹⁸（不可穷举）； (2,4,4) N=32 ⟹ C(32,16) = 6.01×10⁸（本轮的穷举法也不可行）。 ⟹ 真正的 3D 宏观格点需要 GAP 的 set-stabilizer 或采样 + 稳定子的新算法。
  3. 口径：本轮的 ⟨ln|O|⟩ 是对 k = N/2 层的构型平均；第 40 轮用全部 2^N 构型。 两者不同（小 k 层轨道更小）⟹ 数值不应直接互换（本轮 N=16 给 0.4335，第 40 轮给 0.4368，接近但非同口径）。
  4. 未做：(3,3,3) N=27、(3,3,4) N=36；未用 GAP 交叉验证；高估倍数的样本量 600，标准误未估。
  5. 外推禁令（第 41 轮教训）：不要把 0.433 外推到 N = 10¹⁸²。本轮只说"在能算的格点上没看到改善"。
