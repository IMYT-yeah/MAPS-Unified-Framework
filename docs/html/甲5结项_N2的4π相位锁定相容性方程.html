三、N2 的相容性方程（本轮核心）

3.1 定义（可判定的形式化）

「涡锁定平面 i」iff 涡态 ψ 是该平面旋转荷 Ji 的本征态，且本征值 ne 0。

为什么必须是「本征态」而不是「期望值非零」 —— 见 §四的反例（NP-10）。 直观：只有本征态才有确定的相位累积；期望值非零只说明平均有旋转，相位仍是不确定的分布。

3.2 相容性方程（三行，纯代数）

设两个平面的旋转荷为 A,B，[A,B]=iCne 0。假设 ψ 同时锁定两个平面： Aψ = aψ、Bψ = bψ，ane 0、bne 0。则

① iCψ = [A,B]ψ = ABψ - BAψ = (ab-ba)ψ = 0 ⟹ boxedCψ = 0
② iAψ = [B,C]ψ = BCψ - CBψ = B· 0 - C·(bψ) = -b Cψ = 0 ⟹ boxeda = 0

与 ane 0 矛盾。blacksquare

⟹ 两套 4π 相位锁定不可能同时成立。这就是「共享轴拍频」的严格形式： 不对易的两个相位不能同时有确定值（「拍频」= 相位不确定的物理图象）。
