五、诚实边界

✅ 属于推导的： - 候选模型枚举与打分矩阵（无自由参数）； - B2 唯一全过（脚本断言）； - 读法 A → A′ 的后果与 Hawking 温度偏差（数值核验）； - 压缩因子、熵密度不变（由 N = 16 唯一确定）。

⚠️ 属于判定 / 假设的： - C-b、C-c 的适用性：把「真空 / 湮灭中不占权重」从衬底占位层（第 20 轮的动力学结论）搬到面元状态计数层——这是跨层的判定，不是直接推论。若这两态确实携带熵权重，则 B2 的论据减弱、A 回升。 - B1 与 B2 未彻底分开：B1 是更字面的读法，只因 C-e（50:50 未用上）而落选。若「连接」本身被证明等价于「分支标签」，两者合并，结论不变；若被证明不等价，则 B2 需要额外说明「为什么 50:50 出现在连接上」。 - B2 要求每条平面内连接恒有通量（满占位的推论），这一推论本身待独立核验。

❗ 仍未解决：11.0904 的自然性；「连接」是否等价于「分支标签」；读法 B2 是否要求在任意时刻 4 条连接同时存在（相干块结构是否容许）。
