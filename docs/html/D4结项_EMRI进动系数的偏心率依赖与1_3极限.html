一、一句话结论

「κ 与 1/3 的 10% 缺口」不是缺一个积分，而是缺一条方程 —— κ = 0.30 在 stormetric 里是 唯象自由参数（coupling 的默认值），进动律根本不经过度规； 而用框架自己的度规真的算一次，得到的是偏心率依赖的函数：κ_rel(e) 从 1/3（e→0） 单调升到 0.4116（e=0.96） —— 于是那个单一常数 0.30 在全部偏心率下偏低 11%–37%。

⚠️ 附带的口径错位（C-78）

代码把 δ = κ x_p 当绝对超额用（Δφ_total = (6π+κ)x_p、n_orbits_to_dephase = 1/(κ x_p)）； 但两度规 1PN 相同（β = γ = 1）⟹ 绝对超额必为 O(x_p²)，只有相对超额才 ∝ x_p。 材料包的 0.57%/1.02%/1.55% 是相对量（三点之比 2.72 ⟹ 随 x_p 变化）， 而代码的 relative_deviation = κ/(6π+κ) = 1.5666% 是常数（与 x_p 无关）⟹ 两者口径不相容。 📌 另一处基线口径：6π x_p（x_p = GM/c²r_p）与真值 6πM/p = 6π x_p(1+q)/(2q) 差 25%（q=2）–45%（q=10）——不影响相对量，但影响绝对去相位预算。

3.1 计算设置与标定

  • 两个度规都在各向同性型坐标里、用同一台机器积分测地线 （ds² = −f dt² + h dr² + ρ²dΩ²；E,L 由两端点 W = 0 解出，线性方程）；
  • 完全正则化：以 W = (r−r_p)(r_a−r)Q(r) 把端点开方奇异性解析消掉 ⟹ 被积函数 I(θ) = L√(h/Q)/ρ²，无奇异、无开方负号；
  • 标定：GR（各向同性 = 史瓦西）复现闭式 Δφ = 2π[(1−6M/p)^{−1/2}−1]，相对差 ≤ 5×10⁻⁵；
  • 膨胀参数用面积半径半通径 p = 2R_pR_a/(R_p+R_a)（坐标无关的定义）；
  • 数值：mpmath 40 位，tanh-sinh 求积。
