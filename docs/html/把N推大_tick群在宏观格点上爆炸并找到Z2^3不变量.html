一、方法：生成集化简 196608 ⟶ 51

一次 tick = 沿某轴的完美匹配，每条线独立相位 ⟹ 生成元个数 = Σ_轴 2^(线数)： 4×4×4 是 196608 个，根本没法算。本轮证明可以压缩：

设 M_a = 沿轴 a 的「全 0 相位」匹配，T(p) = 相位图案 p 的任意 tick，则
    M_a · T(p) = ∏_j m_j(0)·m_j(p_j) = ∏_{j: p_j = 1} s_j      （s_j = 该线「移 2」）
⟹ T(p) = M_a · ∏_{j: p_j = 1} s_j ∈ ⟨M_x, M_y, M_z；{s_j}⟩

⟹ G = ⟨M_x, M_y, M_z；所有 s_j⟩，生成元降到 3 + 3L²（4×4×4：51 个）。 ✅ 已验证：化简集与全集在 2×2×2、2×2×4 上给出逐条相同的轨道划分（46 / 1357 条轨道，完全一致）。

三、结果 B：一个严格不变量 —— (Z₂)³ 奇偶差类

设 π(p) ∈ (Z₂)³ 为格点 p 的三坐标奇偶类。断言：任何 tick 都保持

δ(p,q) = π(p) + π(q) pmod 2 ∈ (Z2)3

理由：s_j（沿某线移 2）保持 π；M_a（沿轴 a 的匹配）把每个 p 送到 p ± ê_a， 即全体格点的奇偶类被同一个 ê_a 平移 ⟹ 差不变。 ✅ 穷举验证：4 个格点 × 全部生成元 × 全部点对，δ 全部被保持。
