0. 一页速览

  • 请求：把 Yukawa 参数 α 的上界在 λ ∈ [40, 60] μm 段再压 ~3.2 倍（到 α_max ≤ 1/3； 稳健版 ≤ 1/6）。
  • 为什么：现在 α = 1/3 的排除边界在 65–87 μm；把它推到 ≤ 47 μm（≈ 该段 ×3.2）后， 一个具体的模型类（KK radion：α_Y = 1/3，标准 KK ⇔ Brans–Dicke ω = 0）在该窗口的存亡即可判定：
  • 无信号（α_max ≤ 1/3）⟹ 该类在该段判死（稳健档：≤ 1/6 ⟹ 2× 裕度）；
  • 有信号（α ≈ 1/3，~5σ）⟹ 首次显形（一个 47 μm 的标量）。
  • 现状：40–60 μm 带自 2020 年后无新实验（Lee 2020：α=1 边界 38.6 μm；Tan 2020：48 μm）； 2025–26 的「大幅收紧」都在别的参数区（见 §3 三拆表）。
  • 可行性：已发表的下一代设计 Du et al. 2022（CQG 39, 105008） 明确瞄准 40–800 μm、 投影总误差 2.0×10⁻¹⁷ N·m（λ ≈ 300 μm 处约 ×10）——该设计在 40–60 μm 段的投影尚未公布 —— 这正是本请求想要的第一个数。

  1. 这不是「又一个新力预言」：α_Y = 1/3 是标准 KK 知识（BD ω = 0 等价；β = 1/√6、α = 2β²）， 不是某一家的推导；变体区间 [1/3, 1]（warped 可达 2/3、dilaton 读法 = 1）。
