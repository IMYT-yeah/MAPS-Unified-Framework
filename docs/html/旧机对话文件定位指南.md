三种结果 → 三条路：

## 三、到旧机上怎么找（三档，由快到彻底）

### 档 1：直接开文件夹（最快）

在旧机地址栏依次粘贴、回车；存在就跳过去，不存在就试下一个：

```
D:\Users\IMYT.YT\.workbuddy\projects
D:\Users\IMYT.YT\.workbuddy
D:\Users\IMYT.YT\
```

### 档 2：PowerShell 一条命令（推荐，2 分钟内出结果）

在本仓库 `outputs/` 下已备好脚本 **`find_transcripts.ps1`**，拷到旧机双击/运行即可：

```powershell
powershell -ExecutionPolicy Bypass -File .\find_transcripts.ps1
```

它会依次打印：① 所有 `.workbuddy` / `.codebuddy` 数据根；② 其中的 `projects\` 目录与子目录名；
③ 每个目录里的 `*.jsonl`（含大小与修改时间）。**只读，不删不改。**

只想手打一条的话：

```powershell
Get-ChildItem D:\ -Recurse -Force -Filter *.jsonl -ErrorAction SilentlyContinue |
  Where-Object { $_.FullName -match 'workbuddy|codebuddy' } |
  Select-Object FullName, @{n='MB';e={[math]::Round($_.Length/1MB,1)}}, LastWriteTime
```

### 档 3：全盘彻底搜（若上面都没命中）

```powershell
# 任何盘的 users 目录下找 .workbuddy
Get-ChildItem C:\,D:\,E:\,F:\ -Directory -Force -Recurse -Depth 3 -Filter ".workbuddy" -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty FullName
```

cmd 版（老系统更稳）：

```
dir /s /b D:\*.jsonl | findstr /i "workbuddy codebuddy projects"
dir /s /b D:\.workbuddy
```

## 四、怎么确认「找到了对的」

打开候选 `.jsonl` 的**第一行**（用记事本会卡，用 VS Code / Notepad++ 更好），应当看到：

```json
{"id":"…","timestamp":1789911384948,"type":"message","role":"user",
 "content":[{"type":"input_text","text":"<system-reminder data-role=\"user-context\">…
            Workspace Folder: C:\\Users\\Administrator\\Desktop\\2026-08-20-21-43-34 …
```

三条判据（都对上才是它）：

1. 出现 `Workspace Folder:` 且路径里含 **`2026-08-20-21-43-34`**；
2. **时间戳落在 2026 年 8 月**（把 `timestamp` 那个 13 位毫秒数换算一下，或直接看文件修改时间）；
3. 体积**几十 MB 以上**（本机单文件 119 MB；8 月那些应当也是 10 MB 量级 —— 若只有几百 KB，那是短会话，不是主线）。
