1. ε 项的设计【推导】

动机：阶段 B 的 H_F 基态 = 所有 A_v=B_p=1（完美湮灭平衡）。框架的 ε 泄漏（湮灭绑定失败）在哈密顿量语言中应表现为破坏完美配对的倾向。最自然的实现 = 弦张力项：

-λ∑e Ze = -λ∑e (-1)ge
  • g_e=0（无弦/完美配对）：贡献 −λ（有利）；
  • g_e=1（有弦/未配对）：贡献 +λ（惩罚）——每条弦有长度成本 λ。

禁闭的种子：ε 泄漏 = 湮灭失败 = 弦断裂（产生端点/电荷任意子）——端点被弦张力束缚（线性势），拉开端点需线性能量 = 禁闭弦。
