2 核心差异：正负粒子从哪里来

2.1 旧框架的答案（三段论）

  1. 粒子对是先验公理级实体：【公理 1】"宇宙底层是正反物质对持续相遇—湮灭—再生的事件流"——事件流永远在那，湮灭后的"再生"由 A2 §6 定理 B 的增益项 +σ∫B f₁(v′)f₁(v₁′)dv′dv₁′（新对注入）描述：配对在原位、由其它湮灭对级联再生，从不解释"第一对"。
  2. 湮灭-再生是纯局域配对过程：A2 §4 定理 P（配对守恒）/定理 C（守恒律）——事件数逐对保持；不存在粒子对从非对源产生的通道（旧论文 溶解/重聚焦/从无产生/空间背景/退局域 全部 0 次）。
  3. 净正物质（重子不对称）来自泄漏分流到镜像支： - 【公理 2】"每次湮灭有极小概率 ε 绑定失败，正份漏入正时间箭头支、反份漏入镜像支"； - §4.9 P1："'偶然多出的正物质'= 泄漏产生的正物质——反份被踢到镜像支、正份留在我们支"； - P2：电弱前期望泄漏 ~10²² + 真空基态不稳定 ⟹ 初始微扰必然存在。

→ 镜像支不仅是"反物质去处"，还支撑 §8.3 暗物质叠加模型（镜像支引力投影）与 §9 void-CPT-κ 异常预言。在旧框架里，粒子对是给定的、对称的；不对称由镜像支收容反物质而实现。

2.2 新 MAPS 的答案（闭环循环）

  1. 粒子对不是基本实体，而是空间的瞬态聚焦：PROMPT P3 / 代码 docstring ——"正反物质对并非'从无产生'，而是空间（=已溶解物质的背景）的重聚焦"。
  2. 物质会真正"溶解"掉：P2 ——"局域物质脱离光锥/趋于无穷远 → 退局域化 → 弥散为空间背景"；"溶解(湮灭) 与 涌现(生成) 是同一相变的两面，互为时间反演"。
  3. 空间概率性重聚焦生成粒子对：P3 + F5 P(L) = (l_P/L)^α · exp(−L/λ_c)——锚点越小涌现概率越大（普朗克尺度随时涌现，黑洞尺度不可能凭空出现）。
  4. 运动 = 湮灭（能量闭环的入口）：P1 + F4 Δm = m(1 − 1/γ)——物质运动的代价是局域质能的湮灭消耗，"近光速运动≈消耗自身质量"。

新答案构成一个自洽循环：质量 →（运动/脱离光锥）→ 湮灭/溶解 → 空间 →（概率重聚焦）→ 新粒子对 → …。"粒子从哪来"被消解为"空间与物质的相变循环"，不存在无中生有。

2.4 本质评价

  • 新 MAPS 用一个"物质↔空间相变循环"替换了旧框架的"永恒事件流 + 镜像支分流"。前者回答"粒子从哪来"的方式是把粒子降格为循环中间态；后者把粒子当作不解释的基底、只解释"为什么正的多"。哲学上：新框架更"关系主义/过程本体论"，旧框架更"实体主义 + 分支选择"。
