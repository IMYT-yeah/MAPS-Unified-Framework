⭐⭐ 结果 B：硬写守恒 ⟹ w = −1/3（零自由参数）

面上的总能量与体积都是 H 的函数：

E(H) = N·k_BT = [πR²/l_P²]·[ℏH/(2π)] = ℏc²/(2l_P²H)      ⟹  E ∝ 1/H
V(H) = (4π/3)R³ = (4π/3)(c/H)³                            ⟹  V ∝ H⁻³

若要求 dE = −p dV（面上绝热守恒）：

p = −(dE/dH)/(dV/dH) = −ℏH²/(8π l_P² c)        ⟹ 负压
w = p/(ρc²) = [−ℏH²/(8πl_P²c)] / [3H²c²/(8πG)] = −ℏG/(3 l_P² c³) = −1/3

ℏ、G、c、H₀ 全部消掉 ⟹ w ≡ −1/3，零自由参数（数值 −0.3333333333， 与解析式相对差 0.0e+00）。 自洽性反算：Ḣ = −4πG(ρ + p/c²) ≡ −H₀²（相对差 1.4×10⁻¹⁶）⟹ H = 1/t、a ∝ t，与 ρ ∝ a⁻² 自洽 ✓。

⭐ 结果 C：w = −1/3 恰好是曲率标度 ⟹ 等分账的 ρ 不是物质

w = −1/3 ⟹ ρ ∝ a^{−3(1+w)} = a^{−2} —— 这正是曲率项的稀释律。 在一个平宇宙里，没有任何守恒物质按 a⁻² 稀释（物质 a⁻³ / 辐射 a⁻⁴ / Λ 常数）。 ⟹ 等分账的 ρ 只能是「约束」，不能是「守恒流体」。
