第四部分　非阿贝尔涌现深化（剩余 #2）

4.1 通量管合并/分裂动力学

【推导】非阿贝尔结构的动力学来源 = 通量管的合并/分裂：

  • 通量管 a、b 相遇合并 → 通量管 c（或分裂为 c、d）；
  • 合并/分裂的守恒约束（通量守恒 + 方向守恒）定义结构常数 f^abc；
  • 三管顶点 ∝ f^abc——这正是 Yang-Mills 场强的非线性项：
Faμν = ∂μ Aaν - ∂ν Aaμ + g fabcAbμ Acν

4.2 配对阶数 = 合并管数

群 配对阶数 n 合并结构 结构常数
U(1) 1 无合并（单管线性） f=0（阿贝尔）
SU(2) 2 2 管合并（平方配对） ε^abc（2 维辛）
SU(3) 3 3 管合并（立方配对） f^abc 三维反对称

涌现逻辑：配对阶数 n = "通量管合并的最小管数"——n=2 时两管合并（SU(2)，平方配对可解）、n=3 时三管合并（SU(3)，立方配对禁闭）。这与批6 的表示论一致（张量积含单态 ⟺ 可配对 ⟺ 合并守恒）。
