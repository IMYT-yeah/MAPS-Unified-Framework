⚠️ 这个模拟器能做什么、不能做什么
能：把 62 轮纸面推演的底层规则变成可以看见、可以玩的东西 —— 看到置换、看到 k 守恒、看到轨迹困在自己那条轨道里、看到弦和粒子成对出现。
不 能：验证框架。它模拟的是框架内部定义的东西， 不是与观测的比较；它也不产生新物理。
⟹ 本项目第 61 轮算过：框架「独有 + 可测 + 已有数字」的预言只有 1 个（EMRI 进动差）， 而那个要等 LISA（约 10–15 年）。这个模拟器改变不了这件事。

它真正有用在哪

① 自查：规则里任何一处笔误（比如相位搞错、配对搞错），画面会立刻不对劲 —— 这比读 1500 行论文快；
② 教学 / 传播：一个能玩的东西，比一份 PDF 更容易让人明白"这套框架到底在说什么"；
③ 底线：它把"框架的底层是可计算的"这件事坐实了 —— 而这一点本身是有价值的（很多"统一理论"连这一步都做不到）。
左：tick 置换（框架 §8.6.7 的底层） 右：真随机白噪声（每帧重新抽）

指数 +1：max / min（涡心） 指数 −1：saddle（反涡心） 背景色 = 场 f 的高低
怎么读：球面（方向空间 S²）上撒一个随机平滑场， 数它的三种临界点 —— 局部最大、局部最小（各算 指数 +1）， 以及鞍点（指数 −1）。
关键：Σ = #max − #saddle + #min **永远是 2**， 不管你怎么随机；而 #max / #min / #saddle 每次都不同。
点「⚡ 湮灭一对」让一个 +1 和一个 −1 配对消失 —— Σ 岿然不动， 最后必然会剩下 2 个 +1，一个也去不掉。这就是「无法湮灭的稳定点」。

为什么 Σ 一定是 2
这是 Poincaré–Hopf / 毛球定理：球面上**任何**连续切向量场 的零点指数和 = χ(S²) = 2。换个曲面就变：
· 环面 χ = 0 ⟹ 可以有**处处非零**的场，一个涡心都不剩；
· S³: χ = 0 且可平行化 ⟹ 毛球定理不适用（框架 §8.2 已澄清）。
所以「无法湮灭」不是概率问题，是几何恒等式。
