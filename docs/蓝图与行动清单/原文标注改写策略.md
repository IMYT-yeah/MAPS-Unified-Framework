## 6. 风险与边界（诚实标注）

1. **归属声明的性质**：改写后论文将声明"对话 = 作者研究笔记"——这要求作者确实认同对话中的物理构思为本人主张。若对话内容部分超出作者意图，需在改写时同步剔除。
2. **【原文 + 推导】类混合标注**（约 4 处）：推导本身是框架成果，剥离【原文】前缀即可，内容不受影响。
3. **不可完全去来源化的主张**：如"事件点状性""配对阶数=表示论阶"等核心设定——改写为【假设】后，审稿人可能追问"为什么是这个假设"——这是**理论论文的正常负担**（所有统一理论都有基本假设），不构成发表障碍，但需在 Introduction 中明确"假设的动机与检验路径"。
4. **版本头信息损失**：发表版不再展示"v1.23 修正 h_c 混用"等过程——**修正历史反而应保留**（在正文以"注"或附录形式呈现 2 次重要修正：文献对照修正、σ_δ 数值修正），这是诚实性资产，不建议全删。
5. **对话 PDF 本身的去留**：发表版不再引用该文件；作者保留原始文档作为工作记录（不对外公开也可，不影响发表）。
