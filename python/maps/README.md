## §3 ⚠️ 两条必须一起读的口径

### ① F3 的单位：纳特 vs 比特（差 ln2）—— **C-58**

原规格把 **比特公式**（`S = A/(4l_P²)·ln2`）与 **纳特数值**（1.05×10⁷⁷）并列 —— 两者差 **0.693**。
论文 §4.8【单位更正】用 Hawking 温度已裁决：**取纳特**（取比特则太阳质量黑洞 T 偏 **+44.27%**）。
⟹ 本包一律**两个都打印**，不替读者选。

### ② α = 1（**第 98 轮反推所得，非原记录**）与 λ_c = 1.3×10²⁶ m

- 反推 ①：差异审计记录原包运行值 **`P(1e-35 m) = 1.616`**，而 `l_P/1e-35 = 1.616` ⟹ `α = 1`；
- 反推 ②：原规格的判据「**L ≥ l_P 才是概率**」⟺ `P ≤ 1` ⟺ **恰好要求 α = 1**。
- 两条独立一致 ⟹ α = 1 记【已恢复】。**λ_c = 1.3×10²⁶ m 是候选值**，其第一性来源包内不存在
  （并轨备忘录 §7 登记为 **O3**：P(L) 谱与 ε_A(E_c) 截断是否同源）。
