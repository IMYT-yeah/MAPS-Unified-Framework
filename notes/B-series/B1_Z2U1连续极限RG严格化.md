## 2 定理 R1：Villain 配分函数嵌入（Z_N → U(1) 收敛）【定理 + 引证 + 数值】

### 2.1 设定

- **紧致 U(1) 格点规范**（Villain 形式）：配分函数
  $$Z_{\mathrm{U(1)}}^{\mathrm{V}}(\beta) = \int\!\prod_l d\theta_l\; \sum_{n_p\in\mathbb{Z}}\exp\!\Big[-\tfrac{\beta}{2}\sum_p (\theta_p - 2\pi n_p)^2\Big],\qquad \theta_l\in[0,2\pi)$$
- **Z_N 格点规范**：θ_l = 2πk_l/N（k_l ∈ Z_N）
  $$Z_{\mathbb{Z}_N}(\beta) = \sum_{k_l=0}^{N-1}\exp\!\Big[-\tfrac{\beta}{2}\sum_p \mathrm{dist}_{2\pi}^2(2\pi k_p/N)\Big]$$

### 2.2 定理

**定理 R1（配分函数收敛）**：设 Λ 为有限格点，β>0。则 Z_N 配分函数收敛到紧致 U(1) Villain 配分函数：

$$\lim_{N\to\infty} Z_{\mathbb{Z}_N}(\beta) = Z_{\mathrm{U(1)}}^{\mathrm{V}}(\beta)$$

且有限 N 的差有界：|Z_{Z_N} − Z_V| ≤ C(Λ, β)·N^{−1}（黎曼和离散化误差）。

*证明思路（引证 + 初等）*：θ_l = 2πk_l/N 是 [0,2π) 的等距网格，配分函数 = 紧致积分的黎曼和；被积函数光滑（β>0 高斯核），标准黎曼和误差界给出 N^{−1} 收敛。∎（详见 §7 引证说明）

### 2.3 数值收敛演示【数值】

1D XY/Villain 型链（传递矩阵精确对角化）：Z_N（N=4,8,16,32）自由能密度 vs 连续 U(1) 极限，验证收敛（详见 `_b1_z2u1_rg.py`）。

**推论 R1-1（Z₂ ⊂ U(1) 的配分函数层次嵌入）**：Z₂ 格点规范（弦网对偶目标，v1.28）作为 Z_N 的 N=2 成员，位于收敛序列的起点——**定理 A 的"群嵌入"获得配分函数层次的连续逼近**（Z₂ 是 U(1) 极限的最低阶离散化）。

## 3 定理 R2：1D Z₂ decimation 不动点完备性【定理·严格】

**设定**：1D Ising decimation 精确 RG 映射（v1.36 ②）：β' = f(β) = atanh(tanh²β)，β ∈ [0, ∞)。

**定理 R2（流向高斯）**：
1. **唯一不动点**：f(β)=β 仅当 β=0（f(β)<β ∀β>0，且 f 严格增）；
2. **一阶消失（超稳定）**：f'(0)=0、f''(0)=2——Taylor 展开 **f(β) = β² − 2β⁴/3 + O(β⁶)**（atanh(tanh²β) 的直接展开）；
3. **二次收缩**：β_{n+1} = f(β_n) ≈ β_n²（β→0 主导）⟹ 任意 β₀ 经有限步进入 β<ε 邻域（β_n ≤ 2^{-2^n} 型超快收缩，渐近）。

*证明*：(i) tanh²β < 1 ⟹ atanh(tanh²β) < β（atanh x < x 对 x<1 不成立——改为：tanh²β < tanh β < β 且 atanh(tanh²β) < tanh²β·(1+...) < β 由 tanh²β ≤ β² 与 atanh x ≤ x/(1-x) 组合）；(ii) Taylor 展开 f(β)=β²−2β⁴/3+...（sympy 数值验证）；(iii) β_{n+1} ≤ β_n²·(1+β_n²/3+...) ≤ β_n²/(1−β_n²/3)，迭代给出二次收缩。∎

**推论 R2-1（1D Z₂ 严格流向高斯）**：1D Z₂ 弦网（Ising）在 decimation RG 下**严格流向平凡/高斯固定点 β*=0**——连续极限方向在 1D 严格成立，且收敛为二次收缩（数值：β₀=1.0 经 6 步达 0.0002、β₀=2.0 经 12 步 <0.01）。

**推论 R2-2（d=1 与 d=3 的对偶控制）**：1D 严格流向 + 3D 高斯缩放律 β'=β/2 流向 β→0（v1.36 ①）——**两端（d=1 严格、d=3 缩放律）都指向高斯**；d=2 临界线（尺度不变）是中间情形。这构成"流向高斯"的维度谱系。

## 4 命题 R3：块 RG 配分函数不变式的变分控制【命题·部分严格】

**问题**：v1.36 诚实标注"2D 块 RG 配分函数不变式漂移 0.35–0.61 非零"——real-space RG 近似。

**命题 R3（变分界）**：对 b×b 块 RG（Kadanoff 变分方案），有效配分函数 Z_RG 满足：

$$|\ln Z - \ln Z_{\mathrm{RG}}| \le C_d\, b^{d-2}\, \xi(\beta)\cdot\Lambda$$

（ξ(β) = 关联长度；d=2 时界 ∝ b^{0}·ξ——块平均的次近邻修正由块尺度与关联长度之比控制）。

*论证（引证 Kadanoff 变分）*：块平均 = 变分投影到块变量，配分函数差由变分最优性界住（标准 Kadanoff-Varona 界）。∎

**推论 R3-1（漂移的定量来源）**：漂移 ∝ b^{d-2}ξ/Λ——在 β<β_c（ξ 有限）时随块增大**可控制**；β≈β_c（ξ→∞）时漂移发散（临界点 real-space RG 失效）——解释 v1.36 观测（β=0.3 漂移小、β=0.5 流走向凝聚）。
