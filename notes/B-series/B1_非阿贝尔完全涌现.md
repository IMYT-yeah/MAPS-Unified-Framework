## 2 拼图 A：通量管顶点 → 结构常数 f^abc【推导 + 数值】

### 2.1 三顶点守恒

【推导】通量管（色方向 a）在顶点合并/分裂：三条管（色 a,b,c）在顶点相遇，色荷守恒要求顶点张量反对称：

$$\underbrace{\text{三管顶点}}_{f^{abc}} :\qquad f^{abc} = -f^{bac}\quad\text{（交换两条管 = 顶点反对称）}$$

- **SU(2)**：f^abc = ε^abc（Levi-Civita）——非零顶点仅当三条管色方向**全不同**（0,1,2 的置换）；
- **SU(3)**：f^abc 标准表（18 个独立项）——非零顶点编码规范代数。

### 2.2 Jacobi 恒等式 = 通量管网络闭合性【新洞察】

【推导】Jacobi 恒等式：

$$f^{ab}_{\ \ d}\,f^{dc}_{\ \ e} + f^{bc}_{\ \ d}\,f^{da}_{\ \ e} + f^{ca}_{\ \ d}\,f^{db}_{\ \ e} = 0$$

的动力学翻译：**四条管（a,b,c→e）的两种合并路径必须拓扑等价**——

```
(a*b)*c          a*(b*c)
  |                |
  d → e           d' → e
  （先并 ab）      （先并 bc）
```

- 若 f^abc 满足 Jacobi：合并顺序无关（网络自洽）；
- 若违反：合并结果依赖顺序（网络拓扑不一致）→ 物理上不可能。

**⟹ 规范代数一致性 ⟺ 通量管网络的拓扑一致性**——结构常数不是"假设的李代数数据"，而是**通量管顶点拓扑的必然结果**（动力学来源）。
