## 2 Kerr 波形构建【推导 + 引用】

- **Kerr 圆轨道频率**（共转赤道面）：Ω = √(GM)/[r^{3/2} + a√(GM/c²)]【引用，Kerr 测地线】；
- **绝热收缩**：quadrupole 辐射 dr/dt = −(64/5)G³M²μ/(c⁵r³)（Kerr 修正略）；
- **近日点进动**：GR 自旋无关部分 ω_GR = 6πx_p(1+3x_p)（1PN+2PN），**框架差 δ 注入**：ω_total = (1+δ)·ω_GR，δ = 0.30·x_p（2PN g_rr 33% 分叉签名）；
- **波形**：h(t) = h₀·cos[2λ + 2(1+δ)ω_peri + φ₀]，h₀ = 4(Gμ/c²)x_a/D。

**参数**：M=10⁶ M☉、μ=10 M☉、**a=0.9**（高自旋）、r₀=15 GM/c²、D=3 Gpc、T_obs=2 yr；δ_true = 0.30·x_p₀ = **2.00%**；注入 SNR = 20。
