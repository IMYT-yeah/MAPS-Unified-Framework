## 2 推导：动量分辨湮灭损失率 Γ(p)【推导】

### 2.1 物理出发点

A2 §3.1 碰撞核的 Ω 积分：

$$\int_{S^2} d\Omega\, |(\mathbf v_1 - \mathbf v_2)\cdot\hat\Omega| = 2\pi\, |\mathbf v_1 - \mathbf v_2|$$

（∫₀^π|cosθ|sinθdθ = 1，Ω 球面积 4π → 2π|v₁−v₂|。）

故在分子混沌 + 局域化核 g_{r_c}→δ(r_1−r_2) 极限下，**单事件在动量 p 处所受的湮灭损失频率**（partner 速率为 v₁）：

$$\Gamma_\mathrm{ann}(p) = \sigma_\mathrm{ann}\, n \int d^3p_1\, \frac{|\mathbf v - \mathbf v_1|}{v_{th}}\; \hat f_1(\mathbf p_1), \quad \hat f_1 = f_1/n \text{ 归一}$$

### 2.2 麦克斯韦背景闭式

对各向同性平衡态，角平均后 1D 积分：

$$\Phi(s) \equiv \int d^3p_1\, \frac{|\mathbf v - \mathbf v_1|}{v_{th}}\, \hat f_1(\mathbf p_1) = \frac{4}{\sqrt\pi}\int_0^\infty \frac{[(s+s_1)^3 - |s-s_1|^3]}{6 s s_1}\, s_1^2 e^{-s_1^2}\, ds_1$$

**闭式结果**（完整解析角平均 + 已知积分 antiderivative）：

$$\boxed{\Phi(s) = \left(s + \frac{1}{2s}\right)\mathrm{erf}(s) + \frac{e^{-s^2}}{\sqrt\pi}}, \qquad \Phi(0) = \frac{2}{\sqrt\pi}\text{ 解析延拓}}$$

**数值验证 [S1]**：闭式与独立 1D `scipy.integrate.quad` 求积在 s∈[0.05, 4] 上 40 点的最大相对误差 **2.83×10⁻¹²**。✅

**极限**：
- s→0：Φ(0)=2/√π（零动量极限 = 静止粒子在麦克斯韦气体中的平均相对速率 /v_th = ⟨v_gas⟩）
- s→∞：Φ(s) ~ s（高速测试粒子相对速率 = 其自身速率，线性渐近）

**单调性**：dΦ/ds > 0（数值验证整段 [0, 6]，min dΦ = 3.76×10⁻⁷）✅

**小 s 级数**（耦合常数展开 [S3]，拟合 vs 解析）：

|---|---|---|
| s²  | +1/3 = +0.333333 | 0.33333 |
| s⁴  | −1/30 = −0.033333 | −0.03327 |
| s⁶  | +1/210 = +0.004762 | 0.00440 |

（s⁶ 拟合偏高因高阶截断与拟合区上限；解析级数系数从 antiderivative 递推精确导出。）

### 2.3 归一化净损失谱 ψ(s)

定义无量纲归一化谱（令全动量平均 = 1，恢复 A2 零动量态的 σn 行为）：

$$\psi(s) = \frac{\Phi(s)}{\Phi_\mathrm{av}}, \qquad \Phi_\mathrm{av} = \int g(s)\,\Phi(s)\,ds = 2\sqrt{\frac{2}{\pi}}\approx 1.5958$$

**数值验证 [S4]**：⟨Φ⟩_M 精确等于 2√(2/π) 至 **4.4×10⁻¹⁶**（机器精度级）。✅

**Γ(p) 归一化定义**：

$$\boxed{\Gamma(p) = \sigma\, n\, \psi(s) = \sigma n \frac{\Phi(s)}{\Phi_\mathrm{av}}}, \qquad s = |p|/\sqrt{2mk_BT}$$

ψ(0) = Φ(0)/Φ_av = (2/√π)/(2√(2/π)) = 1/√2 ≈ 0.7071（**有限非零**！零动量极限下事件仍被周围移动伙伴碰撞）。

**小 s 展开（动量分辨损失谱的"超额部分"）**：

$$\frac{\psi(s)}{\psi(0)} - 1 = \frac{1}{3}s^2 - \frac{1}{30}s^4 + \frac{1}{210}s^6 + O(s^8)$$

首项 **1/3·s²** 是 PPN 2PN 通道识别的关键系数（见 §3）。

### 2.4 与 A2 命题 L 的对接：能量加权谱因子 κ_E

A2 §7.1 命题 L 给出**单粒子能量矩损失**：

$$\int \tfrac{1}{2}v^2\, Q_\mathrm{ann}(f_1)\,d^3v = -2\delta\sigma\,\bar E_0$$

（A2 粗粒化零动量形式，**无 |v−v₁| 核**。）

把粗粒化核 w→Φ_av 替换为有限动量核 w→v_th·Φ(s) 后，能量加权矩获得额外谱因子：

$$\kappa_E = \frac{\langle s^2\,\Phi(s)\rangle_M}{\langle s^2\rangle_M \cdot \langle\Phi\rangle_M}$$

**数值 [S4]**：⟨s²⟩_M = 3/2、⟨s²Φ⟩_M = (7/2)√(2/π)、⟨Φ⟩_M = 2√(2/π)，故

$$\boxed{\kappa_E = \frac{7}{6} = 1.1666666667\ldots}$$

数值积分至 **2.2×10⁻¹⁶ 精度**（机器精度级）。✅

**物理含义**：麦克斯韦气体中高速事件（高 s、高能）相互碰撞更频繁 → 损失谱偏向高能 → 能量加权平均碰撞率高于数加权平均碰撞率，**能量矩损失比 A2 粗粒化快 16.7%**。

**修正后的速度分辨命题 L**：

$$\int \tfrac{1}{2}v^2\, Q_\mathrm{ann}\, d^3v = -2\delta\sigma\, \kappa_E\, \bar E_0, \qquad \kappa_E = 7/6$$

**数值验证 [S5]**：取 A2 模拟参数（δ=0.33、σ=0.75，E:1.97→0.79），有限动量核有效冷却指数 = 0.5775 = 2δσ·κ_E；Euler 显式积分 vs 解析 E(t)=E₀e^{−0.5775t} 最大误差 **0.00e+00**（机器精度）。A2 粗粒化 0.495 vs 有限动量 0.5775，**冷却加快 16.7%**。✅

**零动量还原**：s→0 时 κ_E→1（高能尾部权重 0），回到 A2 命题 L 形式。ψ(0)=1/√2 仅是归一化常数（不改变谱因子），A2 数值（ΔE=E0−0.79，t=1.8460）由粗粒化极限精确再现。

### 3.3 通道 C：暗能量与 w(z)（IR 端 ε→1 饱和）

**Γ(p) 在 IR 端（s→0）的行为**：

$$\frac{\psi(s)}{\psi(0)} - 1 = \frac{1}{3}s^2 + O(s^4) \to 0 \quad (s \to 0)$$
