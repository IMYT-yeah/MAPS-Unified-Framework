## 2 并轨枢纽：两支耦合的空间库（SPB 模型）

把旧真空/新空间统一为一个可计算对象——**两支耦合的空间库**：

```

        │   （旧公理2/3：CPT 镜像支；反物质归宿；暗物质投影源 §8.3）        │
        │                                                                │
        │   库间耦合：泄漏 ε(E)=ε₀(M_Pl/E)^β，方向性跨支                  │
        │             反份 → B−；正份 → B+   （旧公理2 的方向性，不可删）  │
        │                                                                │
        └──────────────▲───────────────────────────────▲────────────────┘
                       │ ε 分流                          │ 重聚焦(镜像侧)
       ┌───────────────┴────────────────────────────────┴───────────────┐
       │                    本支空间库 B+（= 旧真空本支 = 新"已溶解背景"）│
       │                                                                  │
       │  库内：湮灭-再生(环1，局域、保净荷) + 溶解-涌现(环2，跨域、P(L)) │
       └───────▲──────────────────────────────────▲──────────────────────┘
               │ ① 湮灭进入库             ② 重聚焦出粒子对（P3）
        ┌──────┴───────┐          ┌─────────┴─────────┐
        │ 稳定物质（正份）│          │  从 B+ 凝结的粒子  │
        └────────────────┘          └───────────────────┘
```

- **库内动力学（旧，环 1）**：湮灭-再生局域配对 → A2 定理 P/C/E、玻尔兹曼、度规。适用域：局域、分子混沌、δ=0 完美平衡。
- **库间耦合（旧，保留）**：ε(E) 的方向性跨支转移——反份进镜像支 B−、正份留本支 B+。**方向性=镜像支**，是旧框架特有的、新思考未覆盖的部分（用户确认：正常，补回来）。
- **库-粒子相变（新，环 2）**：溶解（脱离锚点/光锥外/强引力→回 B+）与重聚焦（B+→粒子对），速率由 P(L)=(l_P/L)^α·e^{−L/λ_c} 控制。这是新 MAPS 放进体系的新环节。

**并轨亮点（三处旧预言因此自动获得新语言）**：
1. **暗能量 = 本支空间库的饱和区**：新"已溶解物质背景"在 ε→1 的低能端（E_c=1.01 meV）即旧 §8.1/§8.4 的 ρ_Λ~(E_c)⁴ 与 C1 报告的 Γ(p) IR 饱和——三个不同入口指向同一个"库的饱和残余"。

## 3 粒子来源完整统一链条（旧环节 + 新环节，无删除）

一次湮灭事件后，产物有且只有三种去向（三通道并存、按尺度分工）：

| 通道 | 来源 | 尺度/域 | 净荷 | 旧/新 |
|---|---|---|---|---|
| **① 原位配对再生** | 事件流级联（A2 定理 B gain 项） | 局域、普朗克尺度 | 0 | 旧（主通道） |
| **② 泄漏跨支分流** | 绑定失败 ε(E) | 全尺度，方向性跨支 | **+ε 入 B+**（反份→B−） | 旧（镜像支） |
| **③ 溶解-回流** | 脱离锚点/光锥外/过载区 | 退局域、宏观/宇宙学 | +（正份）回 B+ | 新（P2） |

然后由新 P3 收口：**B+ 经概率重聚焦（速率 P(L)）凝结出本支粒子——观测到的正物质 = ②的净流入 + ③的回流，经 P(L) 凝结的产物**；镜像支 B− 累积的反模态成为暗物质投影源。

**来源问题的最终表述（两代合并后）**：
> 正反粒子对既不是"从无产生"，也不是"永远在那"——它们是**空间库（=事件流热力学极限）在局部重聚焦的凝结态**（新）；而"为什么我们这一支净正"则由**镜像支的方向性分流**回答（旧，公理 2：正份留本支、反份入镜像支）。粒子存在性问题由新 P3 承担，粒子不对称性问题由旧镜像支承担——**两者是同一因果链的不同环节，不是对手。**

## 5 分支定义（各自保留，不互删）

### 5.1 分支 A（默认，保守兼容）——"保净荷重聚焦"
- 内容：P3 的每次重聚焦在**联合系统（B+ ∪ B− ∪ 物质）中保净荷**——每凝结一个正粒子，要么伴生一个反粒子（50:50 对），要么等价地在 B− 侧结算。净正物质**完全来自**通道②（镜像支分流）与通道③（正份回流）。
- 与旧理论关系：A2 定理 P（配对守恒）/定理 C（守恒律）**全局严格成立**，旧证明一行不改；P(L) 只是"凝结率/产生率"，不引入净荷源项。
- 代价：新 P3 的"空间重聚焦"在 A 下不产生新净荷——它回答"粒子以多大概率、在多大尺度凝结"，仍把"净不对称从哪来"留给镜像支。
- **推荐采用**（零破坏、可立即并入）。

### 5.2 分支 B（激进，保留为开放）——"库净产生"
- 内容：B+ 携带"已溶解净物质"，重聚焦能局部净产正物质（B+ → 净粒子），即 A2 全局守恒律的适用域声明需修改。
- 可证伪判据：若分支 B 的净产生率有物理上限 R_net ~ (E_c)⁴/ħ × 体积（暗能量标度），则真空净产生对当前精度不可测 ⇒ B 与 A **观测等价**；未来若有实验对"净粒子从真空产生"给出更紧截面约束，则 B 收缩、A 胜出。在出现判据前两者都保留。
- 诚实标注：目前无任何观测区分布分支 A/B（差异在记账层），**不声称 B 被支持**。

### 5.3 F4 的解释分支（"运动=湮灭"的两种读法）
- **读法 1（标准记账，并入旧）**：K=(γ−1)mc² 是动能，Δm=m(1−1/γ) 是"动能/总能量"的账目重排；物体静止系 Δm≡0。无质量损失，无新物理。
- **读法 2（P1 湮灭账，保留为解释分支）**：动能来自粒子与事件流背景的持续湮灭-再生循环所注入的动量（"运动 = 从背景汲取配对动量"）——这恰是旧框架"运动是事件流的集体模态"的自然延伸。
- **协变安全表述（两读法通用）**：不要用标量"质量减少"，改用 4-动量账——P^μ=(γm, γm𝒗)；"湮灭消耗"是背景通量 J^μ_背景 向粒子 4-动量 P^μ 的**转移**（∂_μJ^μ_总=0 在 ε→0 扇区成立）。静止系下表现为背景通量变化而非 Δm≠0。
- 判定：读法 1/2 在可观测层等价（记账差异），保留为解释分支；不要求删除任何一方。
