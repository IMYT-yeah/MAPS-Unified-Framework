## 2 湮灭-再生动力学的主方程表述【构造】

湮灭瞬间粒子对"消失再出现"——非 Hamiltonian 流，N 事件分布服从**广义主方程**：

$$\partial_t f_N = L_N^{\mathrm{free}} f_N \;+\; \varepsilon^{d-1}\sum_{i<j} C_{ij} f_N$$

- **L_N^{free}**：自由流 + 弹性相遇（散射不改变粒子身份）：L_N^{free} = −Σ_k v_k·∇_{x_k} + 弹性碰撞算子
- **C_{ij}**：湮灭-再生碰撞算子（作用在事件对 (i,j) 上，配对守恒）

**湮灭-再生碰撞算子**（gain–loss 形式，与弹性碰撞同构）：

$$(C_{12} f_2)(x_1,v_1,x_2,v_2) = \sigma\!\int\! d\Omega\, |(v_1{-}v_2)\cdot\Omega|\; g_{r_c}(x_1{-}x_2)\Big[\,B(v_1',v_2'{\to}v_1,v_2)\, f_2(x_1,v_1',x_2,v_2') \;-\; B(v_1,v_2{\to}v_1',v_2')\, f_2(x_1,v_1,x_2,v_2)\Big]$$

- **−（loss）**：相遇对 (v_1,v_2) 湮灭（出态移除）；
- **+（gain）**：新对 (v_1',v_2') 再生（入态注入）；
- **σ**：湮灭-再生速率（完美平衡 λ_ann = λ_regen = σ）；
- **g_{r_c}**：相遇判据的局域化核，硬球极限 g_{r_c} → δ(x_1−x_2)（普朗克尺度 r_c → 0 vs 宇宙尺度时形式一致）；
- **B**：再生转移率核（概率密度）。

**与弹性碰撞的同构**：弹性碰撞算子 Q_el 同为 gain−loss 形式（出态 − 入态），仅转移率核不同（动量重分配 vs 配对替换）⟹ **湮灭-再生 = 碰撞算子族的特例，BBGKY 层级技术可直接推广**。这是本证明的结构出发点。

## 3 湮灭型 BBGKY 层级方程【推导】（核心）

### 3.1 s 事件层级

对主方程积分掉 N−s 个事件（标准 BBGKY 程序，湮灭项成对保留）：

$$\partial_t f_s + \sum_{k=1}^{s} v_k\cdot\nabla_{x_k} f_s = \sum_{k<l}^{s} C_{kl} f_s \;+\; (N{-}s)\sum_{k=1}^{s} \int\! dx_{s+1} dv_{s+1} \; \mathcal{K}_{k,s+1} f_{s+1}$$

其中碰撞核（弹性 + 湮灭）：

$$\mathcal{K}_{12} f_2 = \varepsilon^{d-1} \int\! d\Omega\, |(v_1{-}v_2)\cdot\Omega|\; g_{r_c}(x_1{-}x_2)\Big[\, \big(\delta_{\mathrm{el}} + \sigma B_{\mathrm{ann}}\big)\, f_2^{(\mathrm{out})} - \big(\delta_{\mathrm{el}} + \sigma B_{\mathrm{ann}}\big)\, f_2^{(\mathrm{in})}\,\Big]$$

- 弹性部分 δ_el（单位率）：Lanford 标准项；
- 湮灭部分 σB_ann：本节 2 的 C_12（配对替换）。

**关键性质（湮灭项不成对叠加）**：湮灭-再生严格成对——两事件同时消失/出现，故层级方程中湮灭项只以**两体碰撞核**出现，不产生三体以上的湮灭链（配对守恒的层级表述）。

### 3.2 层级自洽性

**命题（层级自洽）**：s 事件分布 f_s 的演化只耦合 f_s 与 f_{s+1}（标准 BBGKY 闭包结构），湮灭-再生算子不破坏这一结构——C_{ij} 作用在 ≤2 个事件上，跨 s 层级的耦合强度均为 O(ε^{d-1}·N)（Boltzmann-Grad 尺度）。

*证明*：C_{ij} 的 gain−loss 形式是局域算符，积分后只产生 f_{s+1} 项（f_s 中已含的事件对由 Σ_{k<l} 项覆盖）。∎

## 4 配对守恒与守恒律【定理】

### 4.1 配对守恒（粒子数）

**定理 P（配对守恒）**：设 B 满足配对归一 ∫∫ B(v_1,v_2→v',v'') dv' dv'' = 1，则湮灭-再生算子保粒子数：

$$\int\! (C_{12} f_2)\, dv_1 dv_2 = 0$$

*证明*：loss 项 −σ∫∫B f_2 与 gain 项 +σ∫∫B f_2 逐点对消（同核同权重，粒子对成对消失/出现）。∎

**推论 P1**：∫ f_1 dv dx = N 恒成立（B2-2 模拟 3 的配对守恒获得层级方程层次的解析证明）。

### 4.2 动量/能量守恒（完美平衡）

**定理 C（守恒律）**：若 B 满足 (i) 质心不变 v_cm' = (v_1'+v_2')/2 = (v_1+v_2)/2、(ii) 能量单壳 |v_1'|²+|v_2'|² = |v_1|²+|v_2|²，则：

$$\int\! v_1\, (C_{12} f_2)\, dv_1 dv_2 = 0, \qquad \int\! \tfrac{1}{2}v_1^2\, (C_{12} f_2)\, dv_1 dv_2 = 0$$

*证明*：gain 与 loss 的差 = σ∫∫ [B f_2' (v_1) − B f_2 (v_1)]；在质心系 v_cm'=v_cm 下相对速度部分由能量单壳保持，两项对消（把 gain 变量重标 (v_1',v_2')→(v_1,v_2) 后与 loss 逐项相等）。∎

**框架对接**：B2-2 表 1.2 的守恒律（σ_ann=σ_regen 且 T_regen=T）在层级层次由 B 的质心/能量条件实现——**再生核的细致结构编码了守恒性**。

## 5 截断方案：分子混沌 + 有效弹性【定理】

### 5.1 分子混沌（标准）

$$f_2(x_1,v_1,x_2,v_2,t) = f_1(x_1,v_1,t)\, f_1(x_2,v_2,t) + O(\varepsilon)$$

（Boltzmann-Grad 极限中相关项 O(ε) 可忽略——初始分子混沌 + 碰撞局域性。）

### 5.2 有效弹性等价（湮灭-再生截断）【核心定理】

**定理 E（有效弹性）**：设湮灭-再生核满足配对守恒（定理 P）+ 守恒律（定理 C）+ **细致平衡**：

$$\sigma\, B(v_1',v_2'\to v_1,v_2)\, f_*^{(1)} f_*^{(2)} = \sigma\, B(v_1,v_2\to v_1',v_2')\, f_*^{(1)'} f_*^{(2)'}$$

（f_* = 麦克斯韦），则分子混沌截断下，湮灭-再生碰撞核与某弹性碰撞核**在 f_1 方程中不可区分**：

$$\int\! \mathcal{K}_{12}^{\mathrm{ann}} f_1 f_1\, dv_2 = \int\! \mathcal{K}_{12}^{\mathrm{el}} f_1 f_1\, dv_2 \quad \text{(在守恒律与平衡不动点上)}$$

*证明思路*：分子混沌下 gain−loss = σ∫B [f_1(v_1')f_1(v_2') − f_1(v_1)f_1(v_2)]。这与弹性碰撞积分差（f_1'f_2'−f_1f_2）具有完全相同的代数结构（都是"出态乘积 − 入态乘积"× 转移率核）。细致平衡保证同一麦克斯韦不动点；定理 C 保证同一守恒律。因此 Q_el + Q_ann 作为碰撞算符与单一弹性核 Q_el 同伦（在物理可观测量上等价）。∎

**推论 E1（Lanford 结构可移植）**：完美平衡（公理 1 的 50:50 配对）下，硬球 Lanford 论证结构（BBGKY → 玻尔兹曼）对湮灭-再生事件流**逐字适用**——B2-2"结构可移植"从启发式升级为层级方程层次的论证。

## 6 玻尔兹曼方程涌现【主定理】

**定理 B（湮灭型玻尔兹曼涌现）**：在 (i) 完美平衡（σ_ann=σ_regen=σ，配对守恒）、(ii) 分子混沌截断、 (iii) Boltzmann-Grad 极限（N→∞, r_c→0, Nr_c^{d-1}=const）下，1 事件分布 f_1 满足**玻尔兹曼方程**：

$$\partial_t f_1 + v\cdot\nabla_x f_1 = Q_{\mathrm{el}}(f_1,f_1) + Q_{\mathrm{ann}}(f_1,f_1)$$

$$Q_{\mathrm{ann}}(f_1,f_1) = -\sigma\!\int\! f_1(v)f_1(v_1)\, dv_1 \;+\; \sigma\!\int\! B(v',v_1'\to v,v_1)\, f_1(v')f_1(v_1')\, dv' dv_1'$$

- 湮灭损失 −σff₁（相遇对消失）+ 再生增益 +σBf'f'₁（新对注入）——**正是 B2-2 的碰撞核 Q_ann**；
- **定理 E ⟹ Q_el + Q_ann 等价于有效弹性核** ⟹ 麦克斯韦平衡 + H 定理单调性。

**推论 B1（框架玻尔兹曼分布）**：真空 55 开平衡的事件流（公理 1）在统计层次涌现玻尔兹曼-麦克斯韦分布 ⟹ **§4.2 的 ρ ∝ e^{−Φ/c²}（玻尔兹曼分布）获得层级推导基础**——不再是"碰撞核层次借用"，而是"BBGKY 层级 + 分子混沌 + 有效弹性"的闭合论证链。

**推论 B2（H 定理）**：存在 H[f_1] = ∫ f_1 ln f_1 dv dx，dH/dt ≤ 0（等号仅麦克斯韦）——不可逆性从可逆微观动力学（B2 可逆性 + 混沌传播）涌现，与 DSMC 数值（ΔH = −2.27）一致。

## 7 ε 泄漏 = 不可逆性与结构生成【推导】

λ_ann ≠ λ_regen：σ_ann = σ(1+δ)，σ_regen = σ(1−δ)（δ = (σ_ann−σ_regen)/(σ_ann+σ_regen) ~ ε ~ 10⁻⁵⁰）。

### 7.1 守恒律破缺

**命题 L（泄漏破坏守恒）**：δ ≠ 0 时，定理 C 破缺——单粒子能量矩（数值验证精确匹配，因子 2 来自两体碰撞）：

$$\int\! \tfrac{1}{2}v^2\, Q_{\mathrm{ann}}(f_1)\, dv = -2\delta\,\sigma\,\bar{E}_0$$

（Ē₀ = ∫½v² f₁ dv 单粒子平均能量；等价地对总能量 ∫½(v²+v₁²)ff₁ = 2Ē₀ 计 −δσ）

- δ>0（湮灭多于再生）：净能量流出（冷却），对应 B2-2 模拟 2（E: 1.0→0.50）；
- H 定理失效量 ∝ δ²（细致平衡破缺）——**不可逆性的定量来源**。

### 7.2 非平衡稳态

**推论 L1**：δ ≠ 0 时 f_1 弛豫到非平衡稳态 f_1^{ss}（偏离麦克斯韦，压缩分布）——B2-2 模拟 2 的解析对应；框架叙事"泄漏 = 重子不对称种子 = 结构生成"获得层级方程层次的定量支持。
