## 3 定理 J：配对耦合的第一性表达式【推导】

**定义**：J = 单次配对事件的凝聚能——n_G 个事件在普朗克元胞（格点 v 的邻域）内同时相遇并形成规范单态（A_v 算子）的能量。

**推导**：
1. **能量标度**：配对 = n_G 个事件同时出现在同一普朗克元胞。每个事件携带能量 E_P，配对凝聚的总能量标度 = n_G × E_P（n_G 个事件的能量叠加——三事件（SU(3)）比两事件（U(1)）多一个事件能量）；
2. **组合因子**：n_G 个事件同时相遇的组合数为 1/n_G!（全同事件，泊松涌撒），但规范单态的构造通道唯一（ε_ijk 三阶反对称单态 / 正反配对的共轭单态）——组合抑制与单态唯一性合并为 O(1) 几何因子 g；
3. **结论**：

$$J_G = n_G\, E_P\, g,\qquad g = O(1)\ \text{(公理 1 相遇几何)}$$

- J_SU(3) = 3E_P·g（强/色，配对阶数 3）
- J_U(1) = 2E_P·g（电磁正反配对）

**框架对应**：配对 = 色禁闭的表示论根源（三阶反对称 ε_ijk，§5.2）——J ∝ n_G 使"配对阶数越高耦合越强"获得动力学来源（强 > 电磁的表示论原因）。

## 4 定理 K：闭合耦合的第一性表达式【推导】

**定义**：K = 最小通量闭合环的能量——通量管（湮灭-再生环流，B_p 算子）绕卷 m_G 次闭合的能量。

**推导**：
1. **弦张力**：通量管张力（框架数值，v1.20）σ ~ E_P/l_P²（普朗克尺度）；
2. **最小环**：最小闭合环 = 绕卷 m_G 次的普朗克环，周长 ~ m_G × l_P；
3. **能量**：K = σ × 周长 = (E_P/l_P²) × (m_G·l_P) = m_G × E_P；

$$K_G = m_G\, E_P\, g,\qquad g = O(1)\ \text{(同源几何因子)}$$

- K_U(1) = 1·E_P·g（单通量量子闭合——电磁）
- K_SU(3) = 3·E_P·g（三绕卷闭合）

**框架对应**：闭合 = 通量管（磁通），电磁 = 单通量量子（U(1) 通量量子化，m=1）——K ∝ m_G 使"电磁 = 最小闭合"获得动力学来源。

## 5 主定理：J/K 第一性比值【核心推导】

**定理 A3-1（J/K 第一性）**：在公理 1 的事件流动力学下（同源几何 g_J = g_K = g），

$$\frac{J}{K} = \frac{n_G\, E_P\, g}{m_G\, E_P\, g} = \frac{n_G}{m_G}$$

对强（配对通道，n_SU(3)=3）与电磁（闭合通道，m_U(1)=1）：

$$\boxed{\;\dfrac{J}{K} = \dfrac{n_{\mathrm{SU(3)}}}{m_{\mathrm{U(1)}}} = \dfrac{3}{1} = 3\;}$$

*证明要点*：(i) E_P 与 g 相消——同一事件流、同一相遇几何（同源假设）；(ii) 剩余比值 = 配对阶数/绕卷模数 = 3/1，全部来自表示论唯一值（§5.2 三准则筛选）。∎

**推论 A3-1（相变点预言）**：H_F 的横向场相变发生在 K/J = h_c 处（X 场/σ^x 版本，Z₂ toric code 约定）：

$$h_c = \frac{K}{J} = \frac{m_{\mathrm{U(1)}}}{n_{\mathrm{SU(3)}}} = \frac{1}{3} \approx 0.333$$

**——这是 J/K=3 的独立可检验预言**（相变点不依赖 J、K 绝对值，只依赖比值）。
