## 一、五条独立理由

### R1【无定义】框架里没有任何「衰减率」实例

全文检索（论文 v2.9）：

| 检索词 | 处数 | 分布 |
|---|---|---|
| 「衰减率」 | 5 | **全部**是 S-E5 那一句（第 808 行）＋ 第 53 轮加入的更正块 |
| 「寿命」 | **0** | — |
| 「线宽」 | 3 | 也全是 S-E5 / 第 53 轮块 |

⟹ 框架算过的量全都是：**能谱 / 能隙 / 简并 / 序参量 / χ / 熵 / 指数**。
给 `Γ_flux` 不是「补一个表达式」，而是要**从零建立一套衰减率计算**（需要连续谱、多模耦合、谱函数拟合）。

### R2【⭐ 无手性】弦网哈密顿量是实对称的 ⟹ 不可能给出手性模态

框架的两处弦网哈密顿量（原文）：

```
2+1D：H_F   = −J Σ_v A_v − K Σ_p B_p          （§5.7）
3+1D：H(λ)  = −Σ_c A_cube − λ Σ_f X_face       （§5.8）
其中 A_c = Π_{f∈∂c} Z_f（Z 的乘积）；X_face 是 X 型算子
```

⟹ **所有算符都是实算子（Z、X 的乘积）⟹ H 是实对称矩阵 ⟹ 时间反演不变 ⟹ 无手性**
（手性要求复相位 / 破缺 T / 陈–西蒙斯项）。

对照 FQH 侧：引力子模的**手性是实测量** ——
**Liang et al., Nature 628, 78 (2024)** 用圆偏振 Raman 区分 spin +2 / −2，直接确认了零动量磁旋子的手性；
标准侧的手性来自 FQH 的**陈–西蒙斯项**（拓扑序的组成部分，不是可选附加）。

框架侧：「手性」只出现在与弦网**无关**的语境（§5.2 的 SU(2)_L 手性、§4.10 的 Cl(1,3) 旋量
「时间双向×手性双向」）⟹ **弦网侧零处**。

### R3【不判别】「自旋 2」被框架自己论证为不是判别特征

§5.8 v1.29 原文（第 805 行）：

> 「二阶无迹对称张量（5 分量 m=±2,±1,0）在 SO(3) 旋转下 h→R h Rᵀ 的 5 维表示本征值 = {e^{±2iθ}, e^{±iθ}, 1}
> ——**自旋 2 是任何二阶张量涨落模态的几何必然**【本框架定义 D-2】」

⟹ **框架自己说：自旋 2 是数学上自动的**。度规扰动、应力张量、量子度规扰动、声学剪切模……都是 ±2。

而「自旋 2 三层论证」（第 807 行）的**唯一共同点**正是「自旋 2」：

| 层 | 内容 |
|---|---|
| ① 框架层 | 旋转本征值定理（= 上述几何必然） |
| ② 弦网层 | Wen 2006「集体模式 = 度规型扰动」（半严格，**引用**） |
| ③ 观测层 | 南大 FQH 引力子模（自旋 ±2 手性）【本框架定义 D-2 + **观测投影**】 |

⟹ 用一个**框架自己承认不判别**的特征去判三层等价 ⟹ **依据不成立**。

### R4【⭐ 差 10³⁰】弦网模态与 FQH 引力子模不在同一个能量尺度

框架自己的耦合强度定义（第 736 / 1312 行原文）：

> `J = n_G·E_P·g`（配对 = n_G 事件凝聚）、`K = m_G·E_P·g`（闭合 = m_G 绕卷通量环）；
> 「**绝对尺度普朗克标度**（J ~ 3 E_P g, K ~ E_P g）」

⟹ 弦网模型取**本体论**读法：格距 = l_P、耦合 ~ E_P。数值：

| 量 | 值 |
|---|---|
| E_P | 1.2209×10¹⁹ GeV = **1.2209×10³¹ meV** |
| J ≈ 3 E_P（g~1） | 3.66×10³¹ meV |
| 弦网自旋 2 能隙 Δ±2 = **0.49 J** | **1.79×10³¹ meV** |
| FQH 引力子模能隙 Δ_GMP ≈ 0.6 E_C | **8.26 meV** |
| **量级比** | **2.17×10³⁰ ≈ 10³⁰·³** |

⟹ 按框架**自己的**读法，弦网自旋 2 模态在**普朗克尺度**，FQH 引力子模在 **meV** ⟹
两者**不是同一个物理模态**，除非存在一个 ~10⁻³⁰ 的压制因子 —— **框架没有给任何这样的因子**。

### R5【不可识别】接两个层次需要 2 个换算因子，且没有独立约束

要把「普朗克格点的弦网模态」与「meV 的 FQH 引力子模」接起来，至少要：

1. **长度**换算 `l_P → l_B`（磁长度）
2. **能量**换算 `E_P → E_C`（Coulomb 能标）

两条路都不通：

- **若由 FQH 提供**这两个数（本身可算：8.11 nm、13.76 meV @ 10 T）⟹ 那是把 FQH 的答案当输入 ⟹ **postdiction**；
- **若不提供** ⟹ 这两个因子没有独立观测约束 ⟹ **未知量 > 方程**。

⟹ 与第 45 轮（公设上移）、第 52 轮（不可识别拆分）、第 53 轮（能标错置）**同源 —— 这是第五次**。

## 二、附带：就算接上了，判别力也是零

| | 值 |
|---|---|
| 弦网：Δ±2 / J | **0.49**（尺寸无关：0.4919 双立方体 / 0.4864 三链） |
| 标准：Δ_GMP / E_C | 0.5 – 0.7（GMP 磁旋子，文献值） |

⟹ 两个数在 **O(1) 水平相近** ⟹ **不构成判别**（区分不了「框架对」与「框架错」）。
按本项目铁律：**数值接近只可登记为「无机制」，不得作证据、不得写进正文**。
更强的：`0.49` 是**数值 Lanczos 的输出**，不是解析推导 ⟹ 连「为什么是 0.49」都无机制。

## 三、裁决

```
T-11 = ②【降调】
```

理由不止「做不出来」，而是**R2 与 R4 是结构性的**：

⟹ S-E5 的终态定位：

> **S-E5 = 方向性主张、无定量，且「FQH 引力子模 = 框架弦网模态」这一等同的依据不成立。**

不再是「待完成的预言」，也不再需要「继续找 `Γ_flux`」。

## 诚实边界

**是引文核对/算术（可逐步复核）**：
- 「衰减率/寿命/线宽」的全文计数；两处弦网哈密顿量的原文；J = n_G·E_P·g 的原文；
  Δ±2 = 0.49 与 Δ_GMP/E_C ≈ 0.5–0.7；E_P 与 meV 的换算；量级比 2.17×10³⁰。

**是判定（需要后续验证）**：
- **「实哈密顿量 ⟹ 无手性」这一步**：本轮用的是「所有算符都是 Z/X 的乘积 ⟹ H 实对称 ⟹ 时间反演不变」
  这条标准推理链，**没有**独立跑数值验证弦网谱的时间反演性质（论文也未给弦网侧的 chirality 数值）。
  ⚠️ 严格说：实对称 ⟹ 本征值实 ⟹ **无手性配对**；这是充分条件式的论证，我认为成立，
  但若要写成「定理」，应补一个小的数值检查（同一个本征值是否有简并的手性配对）。
- **Δ±2/J = 0.49 是否就是「能隙」而非其他谱特征**：本轮直接引用论文第 817 行与变更日志的记述，
  未重跑 Lanczos。
- **R4 是否可被「有效理论」读法规避**：本轮指出框架第 1312 行**自己**取的是本体论读法（普朗克标度）。
  若改取有效理论读法（J 任意），则 R4 消失 —— **但代价是框架放弃"弦网 = 本体论衬底"这个最核心的主张**。
  这是一个**框架侧的选择**，不是审查能替它做的。

**没做**：
