> "毛球定理其实是更一般的**庞加莱-霍普夫定理**的特例：对于一个紧致可定向曲面上的连续切向量场，其所有零点处的指数之和等于该曲面的欧拉示性数。球面的欧拉示性数 χ(S²) = 2。所以球面上任何连续切向量场的零点指数之和必须等于 2。这就意味着零点必然存在——而且它们的指数加起来要凑出 2（比如两个指数 +1 的零点……）。"

【原文 517】（涡心 = 物质必然）：

## 二、定理链

### 定理 H1（S² 方向空间 ≥2 涡心）【定理：Poincaré–Hopf，严格】

**命题**：S² 方向空间上的任何连续切向量场（风暴方向场）至少有两个涡心（零点）。

*证明*：Poincaré–Hopf 定理——紧致可定向曲面上连续切向量场的零点指数和 = 欧拉示性数。χ(S²) = 2 ⟹ Σ Ind(v) = 2 ⟹ 至少 2 个指数 +1 零点（或 1 个 +2 零点）。∎【定理 515 页】

**数值验证①**：常向量场 (0,0,1) 的切向投影在南北极各有指数 +1 零点，指数和 = 2 ✓；随机切向场零点指数和为拓扑不变量（与场无关）。

**物理翻译**：方向空间（S²）的"配对方向场"必有涡心——每个普朗克尺度系统至少 2 个"拓扑失败点"（涡心 = 孤子种子【原文 516】）。

### 定理 H2（涡心占比 ε_topo）【推导】

**命题**：事件方向落在涡心（拓扑失败点）的概率 ε_topo(R) = (l_P/R)²/(2π)。

*推导*：
1. S² 方向空间离散化为 N_dir = 4πR²/l_P² 个普朗克方向单元（每单元立体角 ΔΩ = l_P²/R²）；
2. 拓扑强制 ≥2 个涡心（H1）⟹ 涡心单元数 = 2；
3. 事件方向随机（各向同性，公理 1）落在方向空间 ⟹ 落中涡心单元的概率 = 2/N_dir = l_P²/(2πR²)。∎

**数值验证②**：普朗克尺度 ε_topo = 0.159；meV 尺度 2.7×10⁻⁶⁵；TeV 尺度 4.2×10⁻³⁵；宇宙尺度 2.15×10⁻¹²⁴。

**物理含义**：ε_topo 是泄漏率的**拓扑结构分量**——涡心（孤子种子）处配对"必然失败"的几何概率。

### 定理 H3（ε 的分量结构）【修正】

**命题**：完整泄漏率 ε_total = ε_topo + ε_A——ε_A（F26 动力学概率）只是动力学分量，拓扑分量 ε_topo 由涡心密度保证。

*论证*：
1. 事件方向落在涡心 → 配对必然失败（贡献 ε_topo）；
2. 事件方向不在涡心 → 配对失败概率 ε_A（F26 能标依赖）；
3. 总泄漏率 ε_total = ε_topo×1 + (1−ε_topo)×ε_A ≈ ε_topo + ε_A（ε_A ≪ 1 时）；
4. **普朗克尺度**：ε_topo = 0.159 ≫ ε_A = 7.67×10⁻²⁰——拓扑主导；
5. **TeV 以上**：ε_topo → 0，ε_A 主导（重子不对称 6×10⁻¹⁰、暗能量 (meV)⁴）。∎

**数值验证③**：ε_total 表——M_Pl 处 0.159（拓扑主导）、1 TeV 处 6.00×10⁻¹⁰（动力学主导）、1 meV 处 2.94×10⁻⁶（动力学主导）。

**对 F26 的意义【修正】**：ε₀ = 7.67×10⁻²⁰ 应理解为**动力学分量在普朗克能标的锚定值**，而非完整泄漏率——完整普朗克泄漏率由拓扑主导（~0.16）。这修正了"ε₀ = 普朗克泄漏概率"的隐含表述。

### 定理 H4（ε_B ≈ ε_topo(宇宙)——重大发现）【推导】

**命题**：暗物质的统计衰减因子 ε_B 恰好处于拓扑分量的宇宙尺度值（差因子 2π）。

*数值*：
- ε_B = (l_P/R_U)² = 1.35×10⁻¹²³
- ε_topo(宇宙) = (l_P/R_U)²/(2π) = 2.15×10⁻¹²⁴
- 比值 = 2π（同量级）✓

**物理意义**：ε_B 的几何来源（(l_P/R_U)²，P0 已定）与拓扑强制最小值 ε_topo 同量级——**暗物质衰减因子 = 拓扑分量的宇宙尺度值**。原文 519–529"ε 是拓扑强制的'最小涡心密度'"获得定量背书：ε_B 正是那个"最小密度"。

**S³ 注意【修正】**：χ(S³) = 0 且 S³ 可平行化（切丛平凡）——毛球定理不适用于三维空间切片；空间切片的涡心强制需挂谷（方向包）+ 泄漏（P1–P4）补充（原文 525 自我修正一致）。
