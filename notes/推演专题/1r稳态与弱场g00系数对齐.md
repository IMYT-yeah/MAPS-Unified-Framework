# 1/r 稳态与弱场 g₀₀ 系数对齐：因子 2 的解答

> **批次**：引力侧自洽性核对（衔接 v1.11 有限 R 严格解遗留）
> **任务**：解决"通量赤字 ∝ 1/r 与牛顿势同形，但系数 R/r = 2GM/(c²r) 与 Φ/c² = GM/(c²r) 差因子 2"的疑点
> **性质标注**：【公理】= 框架公理；【定理】= 严格数学/物理结果；【推导】= 框架内推导；【验证】= 数值验证；【预言】= 可检验预言

## 1 问题陈述

上一轮（v1.11）发现有限 R 稳态解 ρ_ss(r) = ρ∞(1−R/r) 中，若取 R = 史瓦西半径 2GM/c²，则通量赤字 ρ∞−ρ_ss = ρ∞·2GM/(c²r) 与牛顿势 Φ/c² = GM/(c²r) 差**因子 2**。遗留问题：**这个 2 从哪来？框架弱场 g₀₀ 如何与 GR 精确对齐？**

## 2 核心解答：平方结构 g₀₀ = −(ρ/ρ∞)²【定理】

**关键洞察【公理 3 的数学化】**：公理 3（时间 = 事件频率）⟹ 固有时比 = 通量密度比：

$$\frac{d\tau_\infty}{d\tau(r)} = \sqrt{-g_{00}(r)} = \frac{\rho(r)}{\rho_\infty}$$

⟹ **g₀₀ = −(ρ/ρ∞)²**（平方结构！）

这个平方结构是因子 2 的**真正来源**：

| 量 | 表达式 | 一阶系数 |
|---|---|---|
| 通量赤字 | ρ∞−ρ_ss = ρ∞·GM/(c²r) | **1**（与势 Φ/c² 同形） |
| g₀₀ 平方结构 | −(1−GM/(c²r))² = −(1−2GM/(c²r)+…) | **2**（与 GR 一致） |

**即：通量赤字本身只有 1 倍 GM/(c²r)（与势同形），g₀₀ 的 2GM/(c²r) 来自平方 (ρ/ρ∞)²——"2"是平方结构的产物，不是额外假设。**

## 3 定理链【定理】

**定理 A（时间-通量对应）**：√(−g₀₀) = ρ/ρ∞（公理 3 直接数学化）

**定理 B（平方度规）**：g₀₀ = −(ρ/ρ∞)²（定理 A 平方）

**定理 C（稳态通量剖面）**：ρ_ss(r) = ρ∞(1−R/r)，R = 通量抽零半径【v1.11 有限 R 稳态】

**定理 D（系数对齐）**：R = GM/c² 时——
- ρ_ss/ρ∞ = 1−GM/(c²r) = 1−Φ/c²（与玻尔兹曼 e^{−Φ/c²} 弱场一致 ✓）
- g₀₀ = −(1−GM/(c²r))² = −(1−2GM/(c²r)+…)（与 GR 弱场 g₀₀ = −(1−2GM/(c²r)) 一阶一致 ✓）

**⟹ 因子 2 完全解决：通量抽零半径 R = GM/c²（非 2GM/c²），g₀₀ 的"2"来自平方结构。**

## 5 重要预言：框架视界位置【预言】

| 结构 | 视界位置（g₀₀=0 或 ρ=0） |
|---|---|
| 平方结构（R=GM/c²） | **r = GM/c²（半史瓦西半径）** |
| GR 史瓦西 | r = 2GM/c² |
| 玻尔兹曼 e^{−2Φ/c²} | 永不归零（r→0 才 →0） |

**⟹ 框架预言：视界在 r = GM/c² = 半史瓦西半径**——比 GR 视界靠内 2 倍。这是可检验的强场预言（与 B1–B5 互补；但注意框架强场机制尚未完整定义，此预言需与"通量饱和/过载区"机制衔接——见遗留）。

**两条路径（玻尔兹曼热平衡 vs 扩散稳态）在弱场一致、中场分叉**——这指向强场区需要"通量饱和"机制裁决（与 v1.1 撤回强场外推、强场未定义的定位一致）。中场差异本身是**可检验的**（r~3–10 GM/c² 区域，如 QNM 高阶模/吸积盘内缘）。
