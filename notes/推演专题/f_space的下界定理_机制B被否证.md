# f_space 的下界定理：机制 B 的物理图像在算术上不成立

> 日期：2026-09-17 ｜ 核验脚本：`_fspace_nogo.py`（FN-1…FN-5，纯标准库）
> **一句话：只要 f_space 是局部物质密度的函数、且空洞里 f_space ≈ 1（原文自己的话），
> 那么 ⟨f_space⟩ 就有下界 0.5–0.8——比需要的 1/32 大 16–26 倍。
> 这不是"律还没找到"，是**满足前提的律不存在**。**

上一轮（`f_space的第一性定义_机制B零预言力.md`）结论：机制 B 需
`⟨f_space⟩ = 1/32`，而 f_space 是自由函数 ⟹ 零预言力。

本轮加一条**更硬的约束**：原文自己对 f_space 的描述
（"真空地带活跃度高、物质区域低"，`批05` §2.3）在算术上是否可能？

## 二、FN-1：需要什么

| 量 | 值 |

## 三、FN-2：下界定理（本轮核心）

**三个前提**：
- (a) 原文自己说：**"在真空地带 f_space ≈ 1"**（`批05` §2.3）
- (b) f_space 是**局部物质密度**的函数 `f_space(ρ_m)`（这是"空间活跃度"的自然读法）
- (c) 观测：**空洞占体积 50–80%**

由 (b)+(c)：

$$\langle f_{space}\rangle = \frac{1}{V}\int f_{space}(\rho_m)\,\mathrm{d}V
\;\ge\; \frac{V_{void}}{V}\cdot f_{space}(\rho_{void})
\;\approx\; 0.5\!\sim\!0.8 \times 1 \;=\; \mathbf{0.5\!\sim\!0.8}$$

**需要的是 0.03125 —— 比下界小 16–26 倍。**

⟹ **对任何"局部密度抑制律"，⟨f_space⟩ 都不可能低到 1/32。**
这不是"律还没找到"，是**满足前提的律不存在**。

## 四、FN-3：四个自然抑制律，全部落空

| 律 | 全球 ⟨f_space⟩ | 与 1/32 之比 |
|---|---|---|
| 位点占据 `1 − n_b l_P³` | **1** | 32 |
| 消耗型 `σ = l_P²` | **1** | 32 |
| 通量绑定 `1 − ρ_m/ρ_bare` | 0.962865 | 30.8 |
| 正比 `ρ_m/ρ_bare` | 0.037135 | 1.188 |

前三个都 ≈ 1（差 30 倍以上）。第四个 0.037 只差 19%，**但没有机制**（且它是"正比"而非"抑制"，
与原文描述的方向相反）。**四个都不成立。**

## 五、FN-4：消耗型模型要凑数，需要荒谬的截面

若取 `f_space = 1/(1 + n_b σ c t_P)`，凑到 1/32 需 `n_b σ c t_P = 31.00`：

$$\sigma = \frac{31}{n_b c t_P} = 7.568\times10^{36}\ \mathrm{m^2}$$

对照普朗克面积 `l_P² = 2.612×10⁻⁷⁰ m²` ⟹ **需要大 2.9×10¹⁰⁶ 倍**。荒谬。

反推：若 σ 取自然的 `l_P²`，则 `n_b σ c t_P = 1.07×10⁻¹⁰⁵` ⟹ **f_space = 1（零抑制）**。

## 六、诚实边界

| 项 | 状态 |
|---|---|
| ⟨f_space⟩ = 1/32 | ✅ 被观测唯一确定 |
| **下界定理（FN-2）** | ✅ 对**局部密度律**成立 |
| 四个自然律 | ❌ 全部落空（差 19%–35 倍） |
| 32 的来源 | ❌ 无机制 |

**定理的适用范围**：仅对 `f_space = f(ρ_m)`（局部密度律）成立。
若 f_space 是**非局部**的（依赖视界尺度、或含时），下界论证不适用 —— 但那样
原文"真空活跃度高、物质区低"的**物理描述本身就错了**。

## 七、判决

❌ **机制 B 的物理图像被否证，不是"待补"。**

原文的图像（"真空活跃度高、物质区低" ⟹ 低 ⟨f_space⟩）**在算术上不成立**：
**因为空洞占了大半体积，而空洞的 f_space 恰恰是 1。**

**唯一能救的三条出路**（都不轻松）：
1. **放弃"局部密度抑制"图像** —— 但那样就没有 `f_space(ρ_m)`，原文描述即错；
2. **让 ε 不是 1/N**（改变 ρ_bare）—— 但那会牵动前面已定的全息链条（λ=1、β=1/(2π) 都挂在上面）；
3. **承认 f_space 是非局部的**（依赖视界尺度）—— 需要全新机制，等于重写这一块。

⟹ **结论：暗物质定量解释 = 框架的第四个空白。**
这一条现在有了**结构性论证**（下界定理），不只是"未解决"。
