# 把 N 推大：tick 群在宏观格点上**爆炸**（并找到一个严格不变量）

> **日期**：2026-09-20（第 41 轮）
> **脚本**：`outputs/_orbit_scaling.py`（检查项 GS-1 … GS-7，**12 项 0 失败**）
> **一句话结论**：第 40 轮说「tick 群很小、动力学非遍历」——**那是小格点假象**。
> 本轮把生成集从 **196608** 个化简到 **51** 个，第一次能用 Schreier–Sims 精确算大格点的群阶：
> |G| = 8（N=8）→ 128（N=16）→ **2.79×10³⁷（N=64）** → **6.18×10²²²（N=216）**，
> ln|G|/N = 0.26 → 0.30 → **1.35** → **2.37**，**远超**判据阈值 0.4431。
> ⟹ 第 40 轮三难的第 ① 条（不变读数偏大 1.75 倍）**只在 N ≤ 16 成立，不可外推**。
> 同时找到一个**严格不变量：(Z₂)³ 奇偶差类** ⟹ 点对恰有 8 条轨道，|O₂| = (N/4)²（四算例全中）。

## 一、方法：生成集化简 196608 ⟶ 51

一次 tick = 沿某轴的完美匹配，每条线独立相位 ⟹ 生成元个数 = Σ_轴 2^(线数)：
4×4×4 是 **196608** 个，根本没法算。本轮证明可以压缩：

```
设 M_a = 沿轴 a 的「全 0 相位」匹配，T(p) = 相位图案 p 的任意 tick，则
    M_a · T(p) = ∏_j m_j(0)·m_j(p_j) = ∏_{j: p_j = 1} s_j      （s_j = 该线「移 2」）
⟹ T(p) = M_a · ∏_{j: p_j = 1} s_j ∈ ⟨M_x, M_y, M_z；{s_j}⟩
```

⟹ **G = ⟨M_x, M_y, M_z；所有 s_j⟩**，生成元降到 **3 + 3L²**（4×4×4：51 个）。
✅ 已验证：化简集与全集在 2×2×2、2×2×4 上给出**逐条相同的轨道划分**（46 / 1357 条轨道，完全一致）。

## 二、结果 A：**修正第 40 轮** —— 「tick 群很小」是小格点假象

| 格点 | N | **\|G\|** | ln\|G\|/N | 阈值 0.4431 |
|---|---|---|---|---|
| 2×2×2 | 8 | 8 | 0.2599 | 下（上界可用） |
| 2×2×4 | 16 | 128 | 0.3033 | 下（上界可用） |
| **4×4×4** | 64 | **2.794×10³⁷** | **1.3472** | **上（上界失效）** |
| **6×6×6** | 216 | **6.176×10²²²** | **2.3750** | **上（上界失效）** |

（|G| 是 **Schreier–Sims 的精确值**；2×2×2 ⟹ 8、2×2×4 ⟹ 128 与第 40 轮的穷举 BFS **逐位一致** ✓）

**后果**：第 40 轮靠 `|O| ≤ |G|` 得到「不变读数的熵密度 > 0.25 ⟹ 偏大 1.75 倍」。
在 N ≥ 64 上 |G| 已远大于需求 `1.557^N`（N=64：|G| = 2.79×10³⁷ vs 需求 2.08×10¹²），
**这个上界完全失效** ⟹ **第 ① 条不能外推到宏观格点**。
（第 40 轮自己写了「N ≤ 16 未外推」的诚实边界，本轮正是把它推进 —— 结果是**推翻**。）

## 三、结果 B：一个**严格不变量** —— (Z₂)³ 奇偶差类

设 π(p) ∈ (Z₂)³ 为格点 p 的三坐标奇偶类。断言：**任何 tick 都保持**

$$\delta(p,q) \;=\; \pi(p) + \pi(q) \pmod 2 \;\in\; (\mathbb{Z}_2)^3$$

**理由**：s_j（沿某线移 2）保持 π；M_a（沿轴 a 的匹配）把每个 p 送到 p ± ê_a，
即**全体格点的奇偶类被同一个 ê_a 平移** ⟹ 差不变。
✅ **穷举验证**：4 个格点 × 全部生成元 × 全部点对，δ 全部被保持。

**推论与实测**：

| 格点 | N | \|O₂\|（点对轨道） | C(N,2) | (N/4)² |
|---|---|---|---|---|
| 2×2×2 | 8 | 4 | 28 | 4 ✓ |
| 2×2×4 | 16 | 16 | 120 | 16 ✓ |
| 4×4×4 | 64 | **256** | 2016 | 256 ✓ |
| 6×6×6 | 216 | **2916** | 23220 | 2916 ✓ |

⟹ **经验律 |O₂| = (N/4)²（四算例全中）**，且**点对恰有 8 条轨道**（δ 的 8 个取值）；
δ = 0 那一族大小 = 8·C(N/8, 2)，δ ≠ 0 者 = (N/4)²。
⟹ 群**不是 2-可迁的**，尽管 |G| 已经爆炸（`|O_3| = 1792 ≪ C(64,3) = 41664`）。

**对 k 子集的一般化**：不变量 = 各奇偶类中的选中数 `(n_0,…,n_7)` **模 (Z₂)³ 平移**。
⟹ 给 k = N/2 的轨道一个上界 `|O| ≤ ∏_i C(N/8, n_i)`（均分 n_i = N/16 时最大）：

| 格点 | \|O_{N/2}\| 上界 | ⟹ H/N 下界 |
|---|---|---|
| 2×2×4 | 2.56×10² | 0.3466 |
| 4×4×4 | 5.76×10¹⁴ | **0.1621** |
| 6×6×6 | 2.62×10⁵⁸ | 0.0704 |

⚠️ 该上界仍**不足以判定**（0.162 < 0.25 < 0.693）⟹ 精确值仍需 set-stabilizer。

## 五、诚实边界

- ⚠️ **没能**算 k = N/2 的真实轨道：N = 64 时 C(64,32) = 1.8×10¹⁸，BFS 不可行；sympy **无 set_stabilizer**。
  ⟹ 宏观 H/N 的**精确数值仍未定**，本轮给的是**方向 + 结构 + 界**。
- ⚠️ `|O| ≤ ∏C(N/8,n_i)` 用的是**不变量类的大小**，是轨道大小的上界（轨道 ⊂ 不变量类），
  一般**不是等式**（2×2×4 实测：轨道 1357 条 vs 不变量类 ≈ 820 条 ⟹ 轨道严格更细）。
- ⚠️ 只算了偶数边长格点（完美匹配要求）；未做 8×8×8（N = 512）。
- ⚠️ 经验律 |O₂| = (N/4)² 在 4 个算例上全中，但**未证明**（证明方向：δ 不变量 + 群在 δ 类内可迁）。
- 本轮**未**给出观测者分辨率的任何机制（那是第 40 轮改派后仍未解决的问题）。
