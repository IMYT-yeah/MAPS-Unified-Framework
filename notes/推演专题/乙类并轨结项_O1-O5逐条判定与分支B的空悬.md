## 四、O1｜P(L) ↔ 度规耦合 —— 构造可行、**验证不可行**

**判据**：能否构造一个截断，使 (a) 弱场 PPN 不变、(b) 过载区有可计算效应？

**截断示例**（备忘录 candidate 的显式化）：`Θ(x) = 1 − exp(−(x/ε_c)^n)`，`x = |Φ|/c²`。

| |Φ|/c² | Θ（ε_c = 10⁻³, n = 4） | 判定 |
|---|---|---|
| 地球表面 6.95×10⁻¹⁰ | **0**（机器零） | 安全 ✓ |
| 太阳表面 2.12×10⁻⁶ | **2.0×10⁻¹¹** | 安全 ✓（比安全线 10⁻¹⁰ 低 5 倍） |
| 视界 1/2 | **1.000** | 修正全开 ✓ |

**两端都对 ⟹ 可构造** ✓。但**把 ε_c 消掉**才是真判据（两条件相除）：

```
过载区开启：  (|Φ|_over / |Φ|_sun)^n  ≳  1e10     ⟹  所需场强比 = 10^(10/n)
```

| |Φ|_over/c² | 所需场强比 | 所需 n 下限 |
|---|---|---|---|
| 10⁻² | 4.72×10³ | 2.72 |
| 10⁻¹ | 4.72×10⁴ | 2.14 |
| 1/2 | 2.36×10⁵ | 1.86 |

**ε_c 的可用窗口**（给定 n）：n = 2 ⟹ **空集**；n = 3 ⟹ 0.3 个数量级；
n = 4 ⟹ 1.2；n = 6 ⟹ 2.0。

⟹ **判决：O1 = 构造可行、验证不可行**。理由三条：
1. **判据两端各含一个未定量**：右端是 **n**（本轮新增的自由参数、无依据），
   左端是 **|Φ|_over**（框架对「过载区」只有定性描述：退局域／光锥外／强引力，**无定量门槛**）；
2. **「n ≥ 3」这个下界不是框架给的**，而是由「太阳表面的场强」这个**外部事实**逼出来的；
3. 代价是 **自由参数 +2**（ε_c、n）—— 框架的「参数表 0 处」会变成 +2 处，且二者**不可识别**（**铁律 5**）。

⟹ **不建议做**；若要做，必须同时登记这两个参数不可识别。

## 五、O3｜P(L) 与 ε_A(E_c) 是否同源 —— **不可判定**

两套函数的参数账：

| 谱 | 形式 | 参数 |
|---|---|---|
| 凝结谱 | `P(L) = (l_P/L)^α · exp(−L/λ_c)` | α、λ_c |
| 泄漏截断 | `ε(E) = ε₀(M_Pl/E)^β` | β、ε₀ |

可用锚点：**只有 η**（重子不对称 6×10⁻¹⁰）。而：
- ρ_Λ **已放弃定量**（C-54，差 23.76 倍）；
- **E_c 是恒等式**（第 53/95 轮：`E_c = 1TeV·ε(1TeV)^{1/β}`，**M_Pl 消掉**）；
- **η 能标不可独立导出**（**N-40**：一维简并族 ⟹ 任意 E* 都能配住）。

⟹ **可识别性判据**：待定参数 **4** 个 > 独立锚 **1** 个 ⟹ 「同源」**加不出新约束**（**铁律 5**）。
「同源」的实质 = 用一个关系把 4 个参数换成 3 个 + 1 个关系 ⟹ 这是**记法选择**，
**不是可检验命题** —— 除非有**第三方观测量**同时钉住两套，而 N-40 说没有。

⟹ **判决：O3 = 不可判定**。（且 `λ_c = 1.3×10²⁶ m` 本身是**候选值**，第 98 轮登记为 O3。）
