  2. 网格差本身随尺寸增大（0.008 → 0.018 → 0.025）⟹ 网格不确定度与尺寸漂移（~0.03）无法分离 ⟹ 任何"尺寸漂移"的解读都被网格效应污染。
  3. 1/L̄ 外推给出荒谬值：6 个数据点线性外推 ⟹ λ_c(∞) = 0.4361（斜率 −0.4154）。这个值比全部数据点都大，而 λ=0.40 时 ⟨A_c⟩ 已降到 0.24（系统明显在无序侧）⟹ 外推完全不成立。

2.1 原求解器的瓶颈（诊断）

_lc3d_box.py::dmrg1 在每个 site 都调用 env_left_at / env_right_at，二者各自从 0 重新缩并到底 ⟹ 单 sweep 成本 O(n²) 次张量缩并。规模对比：

3×2×2 52 15 ✅

3×3×3 108 30 ❌ 约 3 小时 / λ 点

2.2 两级优化

① 环境增量推进：左环境在正向扫中逐步右推、右环境预建后缓存 ⟹ O(n²) → O(n)。 ② BLAS 化（第二轮才发现真正的瓶颈）：单 sweep 2×2×2 实测 2.10 s，而 142 次环境推移只需 0.04 s ⟹ 瓶颈在 build_heff1_dense。把它的两级收缩改成「先缩 n、再 BLAS matmul」，中间张量从 (χ,2,χ,χ,2,χ)=16384 降下来。

实测：2×2×2 单点 36.5 s → 12.9 s（2.8×）；3×3×3 单 sweep 23.6 s → 约 8–10 s（从不可行变为 9 分钟/λ 点）。

C-61 ⭐⭐ A1 的「λ_c(∞) ∈ [0.21, 0.23]」是过度解读

A1 报告原文：「两尺寸最小线性尺寸均为 L=2，λ_χ 基本不随体积漂移（0.230 → 0.21）——支持 λ_c(∞) 落在 0.21–0.23 区间」。

C-62 ⭐ 把 h 轴的 λ_c 与 3D Ising 的 β_c = 0.221654 直接比较，轴混淆

A1 报告与论文中文稿 L2033 写：「真 3D 临界耦合 0.230 与 2D toric code（0.25–0.32）同量级、与 3D Ising β_c=0.2217 高度接近（差 3.7%） —— 支持『3+1D 弦网 ↔ 3D Z₂ 格点规范 ↔ 3D Ising』对偶自洽」。

问题： - 3D Ising 的 β_c 是耦合常数倒数（温度）；本模型的 λ 是 X 场强度。对偶映射（Fradkin–Shenker 型）连接的是 Ising 的 β 与规范的 plaquette 耦合 K，不是 X 场 h。 - 本模型 K = 1 固定、λ = h 变化 ⟹ 走的是 h 轴。由 β_c = 0.221654 反推规范侧 K_c = −½ln(tanh β_c) ≈ 0.7615，而 K = 1 > K_c ⟹ λ=0 侧确在解禁闭相 ✓（与 ⟨A_c⟩(λ=0)=1 一致），但沿 h 轴的相变点不是 0.2217。 - ⟹ 「差 3.7% ⟹ 对偶自洽」缺乏依据，是两个不同轴的数碰巧接近。

处置：论文该处改为「与 3D Ising β_c 的接近不构成对偶检验（轴不同）；精确对偶映射（h ↔ β）未建立」。⚠️ 本轮不声称 λ_c ≈ 0.31–0.34 与任何文献值一致。

六、判决与下一步

判决：λ_c(∞)（§10.2 #13 的剩余开放项）本轮未解决，且被证明在本方法下不可解 —— 判据分辨率（~0.04）与尺寸漂移（~0.04）同量级。登记为「方法学不足，未定位」，而不是给一个数。

要真正定位，需要（按必要性排序）： 1. 换判据（而不是换尺寸）：⟨A_c⟩ 的 χ 峰不是可靠序参量 —— 与论文已记录的 2D 诊断「m(h_c) 外推 → 0.93 ≠ 0 ⟹ ⟨X⟩ 非相变序参量」同族。3D 侧应改用 't Hooft 环 / Wilson 环的周长–面积律交叉（非局域序参量）。 2. 换算法：3D 盒子的 MPS 截断太狠（χ=8 在 L=2 上就偏 3%）⟹ 应换 PEPS / 3D DMRG / 量子蒙特卡洛（QMC 对本模型无符号问题，应是最优选择）。 3. 建立精确对偶映射（h ↔ β），否则无法与任何文献值对照。

⚠️ 本轮明确不做的：不声称 λ_c ≈ 0.31–0.34 是热力学极限值（它来自 L≤3 且 χ=8，且交叉判据本身没有误差棒）。
