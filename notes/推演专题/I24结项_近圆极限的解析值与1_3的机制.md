## 一、一句话结论

**`κ_rel(e→0) = 1/3` 现在是解析结论（不再是数值外推）**，而且 `1/3` **有机制**：
它是「**2PN 系数之差**」÷「**1PN 斜率**」＝ `Δc₂/c₁ = 1/3`，
其中 `Δc₂` 可**严格分解**为 `g_rr/g_θθ` 侧 `+1.25` 与 `g_tt` 侧 `−0.25`（净 `1`）。
⚠️ **一般偏心率的解析式仍未得**（登记为 **I-25**，见 §六）。

---

## 二、方法（可复算）

圆轨道上的**本轮频率比** `Γ ≡ ω_φ/ω_r`，近日点进动 = `2π(Γ−1)`：

```
ω_φ = L/ρ²                       （角向）
ω_r² = −V''_r/(2h) ,  V = E²/f − 1 − L²/ρ²   （径向本轮，V=V'=0 定 E²、L²）
```

两个度规都在**各向同性型**坐标里（`f(x), h(x)`，`x = M/r`），全部按 `ε ≡ M/r` 的**级数解析**求；
最后经 `y = M/R_areal = ε/√h` 换到观测变量 `y`。

### ⭐ 标定（本轮的关键验证）

**GR 侧必须复现精确闭式** `Γ_GR = (1−6y)^{−1/2}`：

| 阶 | 我的机器（换式后） | 闭式 `(1−6y)^{−1/2} − 1` | 判定 |
|---|---|---|---|
| `y¹` | `3` | `3` | ✓ |
| `y²` | `27/2 = 13.5` | `27/2` | ✓ |
| `y³` | `135/2 = 67.5` | `135/2` | ✓ |

⟹ **机器与 `ε↔y` 换式都正确**。

## 三、主结果

### 3.1 两个度规的 `Γ − 1`（在**观测变量** `y = M/p_areal` 下）

| | `y¹` | `y²` | `y³` |
|---|---|---|---|
| **GR**（= 闭式 ✓） | `3` | `27/2` | `135/2` |
| **框架**（`e^{−2x}`, `e^{2x}`） | `3` | **`29/2`** | `77` |

⟹ **`κ_rel(e→0) = Δc₂/c₁ = (29/2 − 27/2)/3 = 1/3`** ✅（**精确有理数**）

与第 112 轮的数值外推 `0.33332` 相差 **1.3×10⁻⁵** ⟹ **数值结论升级为解析定理**。

### 3.2 ⭐ 机制分解：`1/3` 来自哪一侧

只换一侧度规（其余保持 GR），测得 `c₂`（以 `ε` 为变量）：

| 组合 | `c₂(ε)` | 相对 GR |
|---|---|---|
| `(f_GR, h_GR)` | `21/2` | 基准 |
| `(f_GR, h_FW)` | `47/4` | **`+1.25`（h 侧）** |
| `(f_FW, h_GR)` | `41/4` | **`−0.25`（f 侧）** |
| `(f_FW, h_FW)` | `23/2` | `+1.00`（总） |

**`1.25 + (−0.25) = 1.00`** ⟹ **严格可加**（无交叉项）⟹

$$\kappa_{rel}(e\to0)=\frac{\Delta c_2}{c_1}=\frac{+1.25}{3}+\frac{-0.25}{3}=+\frac{5}{12}-\frac{1}{12}=\frac13$$

⟹ **`g_rr/g_θθ` 侧贡献 `+5/12`（主要），`g_tt` 侧贡献 `−1/12`（抵消 20%）**。

### 3.3 圆轨道的 `y` 修正

`κ_rel(y; e=0) = 1/3 + (5/3)y + O(y²)` —— 在 EMRI 的 `y ~ 0.01`（`x_p ~ 0.02`）下修正 **+1.7%**，
与该链其它不确定度同级（不改变结论，但引用 `κ_rel` 时应写明 `O(y)` 阶）。

## 四、诚实边界

- **【推导】** §二、§三 全部为解析计算（sympy 有理数），并用**精确闭式**在 GR 侧标定到 `y³`。
- **【本轮踩的坑（已进技能）】** ⚠️ **`ε↔y` 换式第一次"没生效"**：我把 `h` 的级数（以 `r` 为变量）直接放进
  `y = ε/√h` 再对 `ε` 展开 ⟹ `h` 被当成了与 `ε` 无关的常数 ⟹ 换式退化为 `ε = y`
  ⟹ `c₂` 输出 `10.5` 而非 `13.5`。**只有在用已知闭式标定之后才发现**。
  📌 教训：**换式必须显式把变量代进去再展开**；且**任何解析链都必须先用已知闭式标定**。
- **【未做】**
  - **一般 `e` 的解析式未得** —— 尝试了「两点积分 `2∫du/√F` ＋ 全级数」的完整路线，
    sympy 计算量过大（多次超时）⟹ 登记 **I-25**。
    现有的只有第 112 轮的**数值**表（`κ_rel(e)`：`1/3 → 0.4116`，`e: 0 → 0.961`）。
  - **没有**把 `κ_rel(y)` 的 `O(y)` 修正并入 EMRI 的可观测预言（那属材料包的重算，见 I-25 之后的步骤）。
- **【口径】** 本轮的 `κ_rel` 是**相对**超额系数（第 112 轮 **C-78** 已登记该口径 ⚠️）；`y = M/p_areal` 用**面积半径**。
