## 一、命题的形式化

你的原话拆成三条可判定的陈述：

1. **微观恒 c**：诸元本来就以 c 运动，宏观速度是「相对落差」（净漂移 ÷ 路径长度）。
2. **落差不能再次成为光速**：有质量者的净漂移严格小于 c。
3. **超光速 ⟺ 连续无穷多个绝对真空**：影响只能靠「湮灭 → 相邻处再生」的手递手传递，一步 l_P、一拍 t_P；要跨越距离直接作用于远端，除非沿途的每个状态都是绝对真空。

第 3 条立刻给出 `c = l_P/t_P` —— **c 不是外加的速度上限，而是衬底的传递速率**（性质上像声速，但数值由 l_P、t_P 锁定为常数）。

## 二、落差的正确量法（LS-1）

若瞬时速度恒为 c，则它正交分解为「净漂移」与「内部运动」：

$$\left(\frac{v}{c}\right)^2 + \left(\frac{v_{\rm int}}{c}\right)^2 = 1,\qquad v_{\rm int} \equiv \frac{c}{\gamma} = c\sqrt{1-\frac{v^2}{c^2}}$$

| v/c | γ | v_int/c = dτ/dt | 检验 |
|---|---|---|---|
| 0 | 1 | 1.0000 | 1.000000000000000 |
| 0.5 | 1.1547 | 0.8660 | 1.000000000000000 |
| 0.9 | 2.2942 | 0.4359 | 1.000000000000000 |
| 0.9999 | 70.71 | 0.01414 | 1.000000000000000 |

- 静止时 **v_int = c**：全部运动都在内部 zigzag；
- v → c 时 **v_int → 0**：无内部运动，纯漂移。

⚠️ **「落差」有两种量法，论文里不能混**：
- 线性落差 `δ = c − v`（路径长度被浪费的比例）——v=0.6c 时是 0.40c；
- 不变量落差 `v_int = c/γ`（内部运动速度，**也是时钟走速**）——v=0.6c 时是 0.80c。

只有后者是洛伦兹不变量的构件。**要写进论文必须写 `v_int = c·√(1−v²/c²)`，并指出它就是固有时速率**（时钟走多快 = 内部 zigzag 有多快）。

## 三、质量 = 每普朗克拍的反转概率（LS-2，本轮最硬的结果）

设诸元每拍以 c 跳一步，以概率 `p_rev` 发生「反向」而非「前进」。要求内部时钟频率等于 zitterbewegung 频率 `mc²/ℏ`：

$$\omega = \frac{p_{\rm rev}}{t_P} = \frac{mc^2}{\hbar} \;\Longrightarrow\; \boxed{m = p_{\rm rev}\,m_{\rm Pl}}$$

（换算恒等 `m_Pl·t_P = ℏ/c²` 已核验，相对误差 <10⁻¹²。）

| 粒子 | p_rev = m/m_Pl | (m/m_Pl)/t_P (s⁻¹) | mc²/ℏ (s⁻¹) | 比值 |
|---|---|---|---|---|
| 电子 e | 4.1855×10⁻²³ | 7.763440711×10²⁰ | 7.763440711×10²⁰ | 1.000000000000000 |
| 质子 p | 7.6851×10⁻²⁰ | 1.425486242×10²⁴ | 1.425486242×10²⁴ | 1.000000000000000 |
| 顶夸克 t | 1.4150×10⁻¹⁷ | 2.624686445×10²⁶ | 2.624686445×10²⁶ | 1.000000000000000 |
| 普朗克质量 | **1** | 1.854858630×10⁴³ | 1.854858630×10⁴³ | 1.000000000000000 |

由此：

- **m = 0 ⟹ p_rev = 0 ⟹ 从不反向 ⟹ 净漂移恒为 c**（光子）——不需要单独假设；
- **m > 0 ⟹ p_rev > 0 ⟹ 必然存在反向步 ⟹ 净漂移严格 < c**。
- ⟹ **「落差速度不能再次成为光速」由公理变成了后果。**
- **m = m_Pl ⟹ p_rev = 1**：每拍都反转，持续长度降到 l_P。故 `p_rev > 1` 不可能 ⟹ **m_Pl 是这套图景里的质量上限**（与"不存在超过普朗克质量的基本粒子"的普遍预期一致，但此处有机制）。

**持续长度 = 约化康普顿波长**（LS-3，数值恒等）：

$$\lambda_C = \frac{\hbar}{mc} = l_P\cdot\frac{m_{\rm Pl}}{m}$$

| 粒子 | ℏ/(mc) (m) | l_P·(m_Pl/m) (m) | 比值 |
|---|---|---|---|
| 电子 | 3.861592677×10⁻¹³ | 3.861592677×10⁻¹³ | 1.000000000000000 |
| 质子 | 2.103089102×10⁻¹⁶ | 2.103089102×10⁻¹⁶ | 1.000000000000000 |
| 顶夸克 | 1.142202942×10⁻¹⁸ | 1.142202942×10⁻¹⁸ | 1.000000000000000 |

⟹ **惯性 = 反转频率**：质量越大 ⟹ 反转越频繁 ⟹ 持续长度越短 ⟹ 越难被加速。这是框架此前完全没有的语言。

## 四、超光速：不是被「禁止」，而是「无定义」（LS-5/LS-6）

手递手 ⟹ 一步 l_P、一拍 t_P。要跳过中间诸元、直接作用于远端，要求沿途**每一个**格点都是空位（绝对真空），概率 `P = (1−f)^N`，`N = L/l_P`：

| L | N = L/l_P | log₁₀P（若 f = 1/32） |
|---|---|---|
| 1 nm | 6.19×10²⁵ | −8.5×10²³ |
| 1 μm | 6.19×10²⁸ | −8.5×10²⁶ |
| 1 m | 6.19×10³⁴ | −8.5×10³² |

- **f = 1（满占位）**：空位概率 = 0 ⟹ 任何距离上的超光速都严格不可能；
- **f = 1/32**：即便 96.9% 是空位，宏观连续链的概率仍是 10^(−10²³) 量级 ⟹ 同样不可能。

⟹ **更准确的表述是「无定义」而非「被禁止」**：构成超光速前提的那条连续绝对真空，恰恰把要穿过的空间取消了——框架中空间由风暴生成，**没有诸元就没有「那里」**。这比"光速是上限"强：它把超光速从"不允许"变成了"没有意义"。
