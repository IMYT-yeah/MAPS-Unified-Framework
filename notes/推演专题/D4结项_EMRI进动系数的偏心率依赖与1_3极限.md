## 一、一句话结论

**「κ 与 1/3 的 10% 缺口」不是缺一个积分，而是缺一条方程** —— `κ = 0.30` 在 `stormetric` 里是
**唯象自由参数**（`coupling` 的默认值），**进动律根本不经过度规**；
而**用框架自己的度规**真的算一次，得到的是**偏心率依赖的函数**：`κ_rel(e)` 从 **1/3（e→0）** 单调升到
**0.4116（e=0.96）** —— 于是那个单一常数 `0.30` 在**全部偏心率**下**偏低 11%–37%**。

## 二、取证：`κ = 0.30` 是什么

`outputs/stormetric/src/stormetric/emri.py`（源码原文）：

| 位置 | 原文 | 含义 |
|---|---|---|
| L88 | `Phenomenological coupling κ (default 0.30).` | **自标唯象** |
| L91 | `def __init__(self, metric: Metric, coupling: float = 0.30)` | κ 是**形参默认值** |
| L85-86 | `metric` … **"kept for interface symmetry, the precession law itself is parametrised by κ"** | **进动律不经过度规** |
| `cli.py` L149/158 | `--kappa`, `default=0.30` | **命令行可改** |

并且 C1 报告自承：「`κ=0.30` **不是从 `Γ(p)` 第一性推导的**」。
⟹ **「10% 缺口」是「一个输入参数」与「一个解析系数」的比较。**

### ⚠️ 附带的口径错位（**C-78**）

代码把 `δ = κ x_p` 当**绝对**超额用（`Δφ_total = (6π+κ)x_p`、`n_orbits_to_dephase = 1/(κ x_p)`）；
但两度规 **1PN 相同**（β = γ = 1）⟹ **绝对**超额必为 `O(x_p²)`，**只有相对**超额才 ∝ `x_p`。
材料包的 `0.57%/1.02%/1.55%` 是**相对**量（三点之比 2.72 ⟹ 随 `x_p` 变化），
而代码的 `relative_deviation = κ/(6π+κ) = 1.5666%` 是**常数**（与 `x_p` 无关）⟹ 两者**口径不相容**。
📌 另一处基线口径：`6π x_p`（`x_p = GM/c²r_p`）与真值 `6πM/p = 6π x_p(1+q)/(2q)` 差
**25%（q=2）–45%（q=10）**——不影响相对量，但影响绝对去相位预算。

## 三、判据与数值表

### 3.1 计算设置与标定

- 两个度规都在**各向同性型**坐标里、用**同一台机器**积分测地线
  （`ds² = −f dt² + h dr² + ρ²dΩ²`；`E,L` 由两端点 `W = 0` 解出，线性方程）；
- **完全正则化**：以 `W = (r−r_p)(r_a−r)Q(r)` 把端点开方奇异性解析消掉
  ⟹ 被积函数 `I(θ) = L√(h/Q)/ρ²`，**无奇异、无开方负号**；
- **标定**：GR（各向同性 = 史瓦西）复现闭式 `Δφ = 2π[(1−6M/p)^{−1/2}−1]`，相对差 **≤ 5×10⁻⁵**；
- 膨胀参数用**面积半径**半通径 `p = 2R_pR_a/(R_p+R_a)`（**坐标无关**的定义）；
- 数值：`mpmath` **40 位**，`tanh-sinh` 求积。

### 3.2 ⭐⭐ 主结果：`κ_rel` 是**偏心率依赖**的

定义 `相对超额 ≡ (Δφ_FW − Δφ_GR)/Δφ_GR ≡ κ_rel(y)·y`，`y = M/p`；下表为 `y → 0` 外推值：

| `e` | 0（圆） | 0.091 | 0.200 | 0.333 | 0.500 | 0.600 | 0.714 | 0.818 | 0.905 | 0.961 |
|---|---|---|---|---|---|---|---|---|---|---|
| `κ_rel` | **0.33332** | 0.33557 | 0.33810 | 0.34394 | 0.35547 | 0.36463 | 0.37716 | 0.39045 | 0.40291 | 0.41163 |

- **近圆极限 `κ_rel(e→0) = 0.333316`**，与 `1/3 = 0.333333` 差 **1.7×10⁻⁵**（表内数值外推，精度 ≤ 10⁻⁴）；
- **单调递增**：`e` 从 0 到 0.961，`κ_rel` 增 **+23%**；
- **数值稳健性**：`R_p = 1000` 与 `500` 的最大相对差 **0.463% < 0.5%**。

### 3.3 与两个候选值的比较

| 参照 | 值 | 与度规的关系 |
|---|---|---|
| 代码默认 | **0.30** | **偏低 11.1%（e→0）→ 37.2%（e=0.96）** |
| `Γ` 的 `s²` 系数 | **1/3 = 0.33333** | **恰是 e→0 极限**（差 1.7×10⁻⁵） |
| 2PN `g_rr` 分叉 | **1/3** | 数值相同，**代数无关**（见 §四） |

⟹ **「10% 缺口」的正确内容**：它比较的是「唯象输入 0.30」与「某个 `1/3`」，
**恰好掩盖了「κ 是偏心率依赖的、真值在 0.333–0.412」**这个事实。

### 3.4 ⭐ 正面产出：一个**自由参数被消掉**

```
改前：δ = κ·x_p ，  κ = 0.30（唯象自由参数，进动律不经过度规）
改后：δ_rel = κ_rel(e)·y ，  κ_rel(e) 由框架度规的测地线积分给出（数值表见 §3.2）
⟹ 参数 −1
```

⚠️ **但这是「可升级」而不是「已完成」**：`κ_rel(e)` 目前是**数值**，**解析式未得**；
且代码的 `n = 1/(κ x_p)` 按**绝对**相位用量，与 `κ_rel`（相对量）**口径不一致**，两侧须一并改。

### 3.5 λ 对照实验（确认「2PN `g_rr` 系数确实影响进动」）

构造 `h(r) = (1+M/2r)⁴ + λ(M/r)²`（**只改 2PN `g_rr` 系数**，1PN 不动 ⟹ γ 不变）：
λ = 0.5（= 框架的 2PN 值 2，而 GR 是 3/2）在 `q = 2` 给出相对超额系数 **0.426**（`Rp=500`／`2000` 一致到 0.1%），
`q = 4` 给 **0.447** ⟹ **2PN `g_rr` 分叉确实在进动的 O(y) 相对超额上留下痕迹**（量级与 §3.2 同阶）。
📌 该实验同时说明：**进动确实「看得见」2PN 度规系数**，所以 §3.2 的 `κ_rel ≳ 1/3` 不是零信号。

## 四、**N-42**：三处 `1/3` 不能叫「同源」

| 链 | `1/3` 的来源 | 精确性 |
|---|---|---|
| ① `Γ(p)` 的 `s²` 系数 | `Φ(s) = (s + 1/2s)erf(s) + e^{−s²}/√π` 的级数（`2/√π·(5/6)` 与 `−1` 相消） | **精确有理数** |
| ② 2PN `g_rr` 分叉 | `(2 − 3/2)/(3/2)`：`e^{2x}`（系数 `2²/2!`）vs `(1+x/2)⁴`（`C(4,2)/4`） | **精确有理数** |
| ③ `κ_rel(e→0)` | 测地线积分 × 面积半径半通径的 `y→0` 极限 | **数值**（1e-4） |

**三条链的输入集合两两不相交**（级数系数 / 二项系数 / 测地线积分）⟹ 只能登记为
**「无机制的一致性」**（铁律 2：数值接近只可登记，不得作证据）
⟹ ⛔ 08-29 日志与 C1 报告的「与 2PN `g_rr` 分叉 1/3 **同源**」措辞**应改**。

## 五、诚实边界

- **【推导 / 数值】** §3.1–3.3 全部可复算（脚本给出）；标定误差 ≤ 5×10⁻⁵。
- **【未做】**
  - **`κ_rel(e)` 的解析式未得** —— 这是本轮的**主要缺口**，登记 **I-24**
    （要证 `e→0` 时为何**恰**为 `1/3`、要 `e` 依赖的闭式）。
  - **没有重算 `ΔlnL` / `σ_δ`** —— 那正是 **C-7 / C-74** 已登记的坏口径区（σ 与 ΔlnL 不自洽），
    在没有把口径问题清完之前重算只会再加一层不确定。
  - **未做 Kerr / 自旋**（材料包自己已标：波形简化在 Kerr 上做、非 Teukolsky）。
- **【口径声明】** 本轮的 `κ_rel` 是**相对**超额系数；代码用的是**绝对**相位超额的线性律
  ⟹ 引用时必须写明是哪一个（**同族 C-72 / C-75 / C-76**：一条式子被两套口径读）。
- **【数值边界】** `κ_rel` 的**绝对值**精度约 **10⁻³**；但 `e` 依赖达 **13%–23%**，
  远大于求积残差（同一 `q` 在 `R_p = 500/1000` 相差 ≤ 0.46%）⟹
  **「度规不同意单一 κ」这个定性结论是稳的**；`κ_rel → 1/3` 这个**精确值**是数值外推，**未解析证明**。
