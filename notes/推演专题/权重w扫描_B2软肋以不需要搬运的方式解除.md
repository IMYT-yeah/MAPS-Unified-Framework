# 权重 w 扫描：B2 的软肋以「不需要搬运」的方式解除

> **日期**：2026-09-20（第 33 轮）
> **脚本**：`outputs/_weight_scan.py`（检查项 W-1 … W-6，**失败项：无**）
> **一句话结论**：第 32 轮取读法 B2 时留的软肋是「C-b / C-c 是否属于把衬底占位动力学的结论跨层搬运到面元状态计数」。本轮显式引入权重 w 扫描后，答案是**B2 根本不需要这一步搬运**——在槽模型里留出「空槽」态并赋予权重 w，BH 熵定标 + 满占位共同解出 **w = 0**（另一根 w = 0.7729 意味着 77% 的连接是空的，被 C-b 排除）。反过来，模型 A 的 w 被 BH 锁在 **0.500**、而 C-b/C-c 要 **0**，落差 0.5 ⟹ **A 是被两头夹死，不是略差**。副产品：B2 的「每条平面内连接恒有通量」从此有了出处，不再是构造假设。

---

## 一、为什么需要这一轮

第 32 轮的裁决矩阵里，读法 A 因 C-b（满占位 f = 1 ⟹ 真空不占权重）与 C-c（湮灭中零测度）落选。但这两条原本是**衬底占位动力学**（第 20 轮）的结论——把它搬到**面元状态计数**层，是一次跨层使用。若这一步不成立，A 就只是"略差"，而非"被排除"。

办法：不辩论搬运是否合法，**直接把权重变成一个自由参数 w，看观测能把它压到多窄。**

---

## 二、模型 A：w 被 BH 锁在 0.5

`H_A(w) = ln 4（方向）+ h₂(w) + ln 2`，其中 {正, 负} 共占 (1−w)、{湮灭中, 真空} 共占 w（各半）。

| w | H_A（nats/面元） | S/S_req | 温度偏差 |
|---|---|---|---|
| 0.000 | 2.079442 | 0.750000 | **+33.33%** |
| 0.050 | 2.277957 | 0.821599 | +21.71% |
| 0.100 | 2.404525 | 0.867249 | +15.31% |
| 0.200 | 2.579844 | 0.930482 | +7.47% |
| 0.300 | 2.690306 | 0.970323 | +3.06% |
| 0.400 | 2.752453 | 0.992738 | +0.73% |
| **0.500** | **2.772589** | **1.000000** | **0.00%** |

⟹ BH 要求 **w = 0.500 精确**（四态等权）。而 C-b / C-c 要求 **w = 0**。

即便放宽到"温度偏差 ≤ 1%"，也要 **w ≥ 0.3833**（≤ 5% 需 w ≥ 0.2489）。**落差 0.5，不可调和。**

## 三、槽模型 S：w = 0 是解出来的，不是搬来的

4 个平面内连接，每槽 ∈ {正, 负, 空}，空槽权重 w：

```
H_S(w) = 4·[ h₂(w) + (1−w)·ln 2 ]
```

| w | H_S（nats/面元） | S/S_req | 温度偏差 |
|---|---|---|---|
| **0.000** | **2.772589** | **1.000000** | **0.00%** ← B2 |
| 0.020 | 3.109293 | 1.121441 | −10.83% |
| 0.050 | 3.428020 | 1.236397 | −19.12% |
| 0.200 | 4.219681 | 1.521928 | −34.29% |
| 0.333 | 4.394449 | 1.584963 | −36.91%（= ln 81，三值等权） |
| 0.700 | 3.275234 | 1.181291 | −15.35% |
| **0.7729** | **2.772589** | **1.000000** | **0.00%** ← 第二根 |
| 0.800 | 2.556127 | 0.921928 | +8.47% |

`H_S(w) = ln 16` 在 (0,1) 上有**两个根**：

- **w = 0**（平凡解）——每条连接都有通量，正是 **B2**；
- **w = 0.7729**——意味着 **77.3% 的平面内连接是空的**，与 C-b（满占位 f = 1）直接冲突 ⟹ **排除**。

⟹ **w = 0 是由「BH 熵定标」与「满占位」共同解出来的，不是从衬底搬运来的假设。** 软肋因此以最干净的方式解除：B2 不需要那个跨层步骤。

## 五、副产品：B2 的构造假设变成了结论

B2 需要「每条平面内连接恒有通量」。此前这一条是无依据的构造假设；现在它由 **(i) BH 熵定标 + (ii) 满占位** 共同确定。物理链条也直接：

```
满占位 f = 1 ⟹ 每个格点被占 ⟹ 每条键承载通量 ⟹ 4 条平面内连接全活
          ⟹ A1 的 50:50 给每条连接分配正支 / 负支 ⟹ 2^4 = 16
```

## 六、诚实边界

**✅ 属于推导的**：
- 两个模型的熵表达式与 w 扫描（无自由参数，BH 定标唯一）；
- 槽模型两个根的求解与被排除的理由（C-b）；
- 模型 A 的 w 落差 0.5 与温度偏差 +33.33%。

**⚠️ 属于判定 / 假设的**：
- **槽模型的空槽率 w 与衬底占位率 f 是否为同一个量，未独立论证**（本轮默认同一）。若两者不同，w = 0 与 f = 1 的联动会松脱。
- **w = 0 是 BH 的精确要求**——它依赖压缩因子 11.0904 不变。若压缩因子被重新导出，该约束会随之移动（但方向不变：任何低于 ln16 的熵都会让温度偏高）。
- **B1（连接 / 不连接）仍未彻底排除**（只因 C-e 落选）；本轮不触及。

**❗ 仍未解决**：11.0904 的自然性；「连接」是否等价于「分支标签」；w 与 f 的同一性。
