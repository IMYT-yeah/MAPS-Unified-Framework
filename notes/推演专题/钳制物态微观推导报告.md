## 2 推导链（三条微观机制）

### 机制① 普朗克填充率：ρ/ρ_P 的物理意义【推导】

碎片质量 m_P（正物质最基本单位，能标由公理 1 事件流锁定）。每普朗克体积 l_P³ 可容纳的最大碎片质量 = m_P。定义**普朗克填充率**：

$$x = \frac{\rho}{\rho_P},\qquad \rho_P = \frac{m_P}{l_P^3} = \frac{c^5}{\hbar G^2}\approx 5.2\times10^{96}\ \text{kg/m}^3$$

- x ≪ 1：碎片稀疏，每普朗克体积远少于一个碎片质量（宏观黑洞）；
- x ~ 1：碎片填满普朗克体积（普朗克质量黑洞）；
- x ≫ 1：碎片超填 ⟹ 合并（机制④）。

**ρ_P 不再是拟合参数，而是"每普朗克体积一个碎片质量"的几何标度。**

### 机制② 双向净动量流的罗吉斯蒂饱和 ⟹ tanh【推导 + 验证】

过载区压强 = 碎片-风暴动量交换的**净效应**，分两个竞争通道：
- **反射通道**（碎片把风暴动量"顶回"，抵抗压缩）：贡献 +J_max；
- **放行通道**（碎片被风暴冲开，等效负压）：贡献 −J_max。

净动量流 J = I₊ − I₋ ∈ [−J_max, +J_max]。碎片反射能力随密度增强（遮挡/反射增多），但受普朗克速率钳制。**净流的演化是罗吉斯蒂型**（增长率 ∝ 距上限距离 × 距下限距离——反射增强的边际收益递减、放行衰减的边际阻力递增）：

$$\frac{dJ}{d\rho} = \frac{\alpha}{J_{max}}\left(J_{max}^2 - J^2\right),\qquad \alpha = \frac{1}{\rho_P}$$

解（解析）：**J(ρ) = J_max·tanh(ρ/ρ_P)**。数值积分 vs 解析：最大偏差 8×10⁻⁴ ✓。

**tanh 的涌现**：双向竞争的对称饱和（反射 +J_max / 放行 −J_max）的罗吉斯蒂演化 ⟹ 双曲正切——不是假设，是两通道竞争的动力学结果。

### 机制③ 普朗克压强 P_P：饱和值的微观构成【推导】

每个普朗克体积单元被碎片"激活"时，与风暴交换动量的上限：
- 单次碰撞最大动量：p_P = ℏ/l_P（普朗克动量，单事件能标 E_P）；
- 最大碰撞频率：ν_P = c/l_P（普朗克频率，公理 1 事件流上限，【原文 46】最大吞灭速率）；
- 单元表面力：p_P·ν_P = E_P/l_P，作用在单元面积 l_P² 上 ⟹

$$P_P = \frac{E_P}{l_P^3} = \frac{c^7}{\hbar G^2} \approx 4.6\times10^{113}\ \text{Pa}\qquad\text{(普朗克压强)}$$

### ③' 求和：钳制物态的涌现【推导】

总压强 = 单元活性比例 × 单元最大压强：

$$\boxed{\,P(\rho) = P_P\tanh\!\left(\frac{\rho}{\rho_P}\right)\,}$$

- **线性区**（ρ≪ρ_P）：P ≈ P_P·ρ/ρ_P = c²ρ（相对论性最大因果；与辐射气体 P=c²ρ/3 差 1/3 各向同性几何因子，可由 ρ_P 的 1/3 重定义吸收——诚实标注）；
- **饱和区**（ρ≫ρ_P）：P → P_P（压强钳制——【原文 90】"风暴压强有限"的定量表达）；
- **普朗克钳制是涌现的**：单次碰撞 ≤ E_P × 最大频率 ν_P / 单元面积 l_P²，三因子全部来自框架既有前提（公理 1 + 原文 46 + 原文 90），无新假设。

### 机制④（附产物）碎片合并与有效质量【推导】

活性单元数密度 n_eff = tanh(ρ/ρ_P)/l_P³（随密度饱和）。有效碎片质量：

$$m_{eff}(\rho) = \frac{\rho}{n_{eff}} = m_P\cdot\frac{\rho/\rho_P}{\tanh(\rho/\rho_P)}$$

- x ≪ 1：m_eff → m_P（独立碎片）；
- x ≫ 1：m_eff ∝ ρ（风暴把碎片压成团块——"浆糊"的微观图像，【原文 90】）。

**碎片合并是饱和的物理载体**：ρ 增长时碎片合并减少独立单元数，使每普朗克体积动量流饱和在 P_P——合并阈值恰在 ρ_P = m_P/l_P³（每普朗克体积一个碎片）。

## 3 推导产物：新物理【推导 + 预言】

### 3.1 声速剖面（新预言）

$$c_s^2 = \frac{\partial P}{\partial\rho} = \frac{P_P}{\rho_P}\text{sech}^2\!\left(\frac{\rho}{\rho_P}\right) = c^2\,\text{sech}^2\!\left(\frac{\rho}{\rho_P}\right)$$

| 区域 | c_s | 物理 |
|---|---|---|
| ρ ≪ ρ_P | c_s = c | 相对论性最大因果 |
| ρ = ρ_P | c_s² = 0.420 c² | 声速显著下降 |
| ρ ≫ ρ_P | c_s → 0 | **钳制区无弹性波——"浆糊"无结构** |

**声速消失 ⟹ 过载区信息传播抑制**——衔接七环机制环 2（挂谷集信息测度≈0）与 v1.18 §4 辐射特征（"最大熵无结构 ⟹ 无特征辐射"）的**动力学表达**：不是假设无辐射，而是声速剖面使弹性/波状结构无法传播。

### 3.2 能量条件与稳定性【推导】

- **因果性 P ≤ ρc² 处处满足**：ρ≪ρ_P 时 P/ρc² → 1（饱和因果极限）；ρ≫ρ_P 时 P/ρc² → ρ_P/ρ → 0（**深度亚因果**——对比候选 B 恰在边界 P=ρc²，钳制物态更安全）；
- **无热力学不稳定性**：∂P/∂ρ = (P_P/ρ_P)·sech² ≥ 0 恒成立 ⟹ 无坍缩（对比 GR 奇点 ρ→∞）。

### 3.3 物态定位【验证】

|---|---|---|---|
| 太阳质量黑洞 | 3.6×10⁻⁷⁸ | ~10⁻⁶ P_P（线性区，P≈c²ρ） | ≈ c |

**宏观黑洞过载区压强 ≪ P_P、声速≈c**；仅普朗克质量黑洞接近钳制——与 v1.18 数值一致，且新增声速信息。

## 8 诚实标注【开放】

1. **线性区系数**：P≈c²ρ vs 辐射气体 P=c²ρ/3 差 1/3 各向同性几何因子——可由 ρ_P 重定义吸收，或要求碎片-风暴碰撞含 1/3 角平均（未推导，留开放）；

4. 过载区径向密度分布（ρ(r)）仍未建模（遗留②保留）。
