### ⭐ 本轮的方法学产出：**α = 1 的两条独立反推**

`P(L) = (l_P/L)^α · exp(−L/λ_c)` 里的 **α 在原规格与所有记录中都没有写**（只有 `λ_c ≈ 1.3×10²⁶ m`）。
但两条**互不相干**的记录把它钉住了：

1. 差异审计（**包尚在时实际运行**）记录 `L = 1e-35 m` 时 `P_emerge = 1.616`；
   而 `l_P/1e-35 = 1.6163` ⟹ `1.616^α = 1.616` ⟹ **α = 1**；
2. 原规格的判据「**L ≥ l_P 才是概率**」⟺ `P ≤ 1` ⟺ **恰好要求 α = 1**（因为 `P(l_P) = 1^α`）。

⟹ 两条独立一致 ⟹ **α = 1 记【已恢复】而不是猜的**。
📌 **可复用手法**：**规格缺一个参数时，先去"运行时输出"里反推** —— 比在文档里找措辞便宜得多。
