## 1. 定理 B1（涌现规范对称性）【推导 + 数值】

**命题**：框架哈密顿量 H_F = −Σ_v A_v − Σ_p B_p 与所有顶点/面算符对易：

$$[H_F, A_v] = [H_F, B_p] = 0 \quad (\forall v, p)$$

*证明（推导）*：由 A_v、B_p 的投影性（A_v²=A_v、B_p²=B_p，阶段 A 定理 A3 已证）与两两对易性（[A_v,A_w]=0、[A_v,B_p]=0，阶段 A 数值确认），线性组合 H_F 与每个算符对易。∎

**数值验证（Z₂ 2×2 环面，256 态）**：

| 对易项 | 结果 |
|---|---|
| [A_w, A_v]=0（6 对） | ✓ |
| [B_p, A_v]=0（4×4） | ✓ |
| [B_p, B_q]=0（6 对） | ✓ |
| **⟹ [H_F, A_v] = [H_F, B_p] = 0** | **✓** |

**物理含义**：A_v 是"局域规范变换"（阶段 A 定理 A3），[H_F,A_v]=0 意味着哈密顿量在局域规范变换下不变——**规范对称性不是被外加的约束条件，而是哈密顿量自身的动力学对称性**。这就是"涌现规范对称性"的严格含义【引用：Kitaev 2003 定理；数值：本次】。

## 2. 定理 B2（真空 = 完美湮灭平衡）【推导 + 数值】

**命题**：H_F 的基态 |GS⟩ 满足 A_v|GS⟩=|GS⟩、B_p|GS⟩=|GS⟩（所有顶点规范不变 + 所有面通量闭合），能量 E₀ = −(N_v + N_p)。

**对应【框架】**：基态 = **完美湮灭平衡**——每一对正反物质都正确配对、每一环流都闭合——这正是框架公理 1 的"真空 = 55 开动态湮灭平衡态"的哈密顿量表达【原文：真空=动态湮灭平衡】。

**数值验证**：⟨GS|H_F|GS⟩ = **−8.000**（理论 −(4+4)）✓——构造的 |GS⟩ = Π_v A_v|0⟩ 确为基态。

## 3. 定理 B3（能隙 = 2+1D 质量隙）【推导】

**命题**：H_F 第一激发能隙 Δ = min(1,1) = 1 > 0（单位耦合）。

*证明（推导）*：任何非基态至少有一个 A_v 或 B_p 本征值为 0（基态全为 1）；单个违反（一个 A_v 本征 0）的态能量 = −(N−1) = E₀+1 ⟹ Δ≥1；且该态存在（单顶点违反态）⟹ Δ=1。∎

**意义【定理，Kitaev 2003】**：2+1D 量子双模型是"**有正能隙的规范理论**"的严格例证——拓扑序（deconfined）的能隙严格正。这是框架"质量隙"叙事在 2+1D 拓扑序中的**严格实现**；4D 禁闭质量隙（B6）仍为千禧年开放问题，但 2+1D 版本已被严格证明。

## 4. 定理 B4（泄漏激发 = 任意子/通量管）【推导】

**命题**：H_F 的激发（违反 A_v 或 B_p 的态）对应**任意子激发**（拓扑荷/磁通荷），其世界线即框架的**通量管**（量子直线）。

| 违反类型 | 激发 | 框架对应 |
|---|---|---|
| A_v=0（电荷违反） | 电荷任意子 e | 相遇配对失败（泄漏事件） |
| B_p=0（磁通违反） | 磁通任意子 m | 通量管端点（湮灭-再生环流未闭合） |
| e⊗m（复合） | 任意子复合体 | ε 泄漏 + 通量管组合 |

**意义【推导】**：框架的"ε 泄漏 = 重子不对称种子"在哈密顿量语言中 = 顶点违反（电荷激发）的涌现——泄漏事件正是破坏完美湮灭平衡的激发过程。2+1D 中任意子为分数统计（阿贝尔/非阿贝尔由 G 决定，阶段 A 定理 A2）【定理，Kitaev 2003】。

## 8. 诚实标注与阶段 C 入口

**严格性分级**：
- 【定理】B3 能隙、B5 简并（Kitaev 2003，Z₂ 数值确认）；B1 对易（阶段 A 基础 + 本次数值）；
- 【推导】B2 基态、B4 激发对应；
- 【框架】哈密顿量"形状"（−JΣA−KΣB 的选择来自公理 1 的对应表——这是映射构造，非第一性推导）。

**诚实缺口**：
1. **J、K 耦合强度的来源未推导**——框架公理给出哈密顿量的"形状"（哪些算符、对称性），但耦合强度需从事件流微观动力学推出（开放）；
2. **ε 泄漏项的哈密顿量形式未构造**——B4 的激发对应是概念性的，具体 ε 项（如 −λΣ_e(−1)^{g_e≠e} 质量项）会驱动拓扑序→禁闭转变，这是阶段 B 之后的重要开放方向；
3. **2+1D ≠ 4D**——拓扑序质量隙是 deconfined，4D 禁闭质量隙（B6）仍为千禧年问题；
4. Z₂ 数值验证，Z₃/S₃ 环面简并引用定理（阶段 A 已验单面算符代数）。

**阶段 C 入口**（Wen 弦网 3+1D）：

- 2+1D 量子双（严格）→ 3+1D 弦网（涌现光子/引力子，半严格）；
- 4D 质量隙 = 千禧年（诚实标注）。
