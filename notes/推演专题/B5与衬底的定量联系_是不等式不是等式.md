## 一、B5 的链条（引文 + 算术）

| 出处 | 内容 | 定性 |
|---|---|---|
| §8.6.8(d) / 设定表 | **简单立方格距 = l_P** ⟹ n = 1/l_P³、σ = l_P²、碰撞率 1/t_P | **【本框架设定的自然选择】**（l_P 是唯一长度标度），**非强制推导** |
| §4.8【微态计数命题】 | 视界表面 **N = A/l_P² 个面元**；**每 4 面元 1 个相干单元**（Clifford 4 分量）；**每单元 1 纳特** | 设定 + 单位更正（第 39 轮） |

**算术**：

```
单元数 = N/4 = A/(4 l_P²)
S      = A/(4 l_P²) × 1 纳特 = A/(4 l_P²) 纳特          ✓ 与 S = A/(4l_P²) 一致
⟹ 每面元（= 每格点）的熵份额 = 1/4 = **0.25 纳特** = 0.3607 比特
```

⟹ **0.25 不是"待命中的目标"，而是两个设定算出来的输入。**

## 三、⚠️ 方向错误：应该是 `H/N ≤ 0.25`，不是 `H/N = 0.25`

**论证**（两步，都在框架内部）：

1. **第 40 轮已证明**：观测者的读数**不能**是 tick 不变量（三难：不变读数熵太多 / 太少 / 时间平均零预言力）
   ⟹ 观测者用的是**瞬时**读数（非不变），即 **B5 的公设**。
2. 瞬时读数 ⊇ 不变读数（不变读数是瞬时读数的一个函数）
   ⟹ **H(不变读数) ≤ H(观测者读数)** ⟹

```
H/N（tick 不变读数的熵密度）  ≤  0.25（观测者的读数分辨率，纳特/格点）
```

⟹ **这是必要条件（不等式），不是待命中的目标。**

**后果**：第 46–50 轮沿着"找 H/N = 0.25 在哪个 N"走了五轮，其中

- 第 46 轮：H/N 落在 0.43–0.53 ⟹ 那时读作"面积律未命中"；
- 第 48 轮：(2,4,4) = 0.2834、(4,4,4) = 0.1839 ⟹ 读作"0.25 被**跨过**"；
- 第 49 轮：夹住"跨点 N ∈ (32, 48)"；
- 第 50 轮：扫 k 也收窄不了。

正确的读法是：**0.2834 违反了不等式（不自洽），0.1839 满足（自洽）** —— 不是"跨过"。

## 五、反过来：哪一个 N 让不等式刚好饱和？

```
3.01·N^{−2/3} = 0.25  ⟹  N^{2/3} = 12.04  ⟹  **N_c = 41.8**
⟹ 对应视界半径 R = √(N_c/4π)·l_P = **1.82 l_P**（普朗克尺度黑洞）
```

⟹ **凡 N ≥ 42 的视界都自洽**；N < 42 的（普朗克尺度）不自洽。

**与第 49 轮交叉验证 ✓**：N_c = 41.8 **落在**第 49 轮那个 (32, 48) 区间内。
**数值一致，但语义变了** —— 不是「0.25 的跨点」，而是「**自洽性的下界**」。
