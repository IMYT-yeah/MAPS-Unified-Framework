# 有限 R 严格解：火墙扩散的球贝塞尔级数解与 1/r 稳态形态

> **批次**：火墙厚度判定系列第 3 弹（F1 → F1′ 1D → F1″ 3D 半无限闭式 → **F1‴ 有限 R 严格解**）
> **任务**：把上一轮半无限近似（x≪R）升级为**带外边界 L 的有限区域严格解**，量化半无限近似的误差界，并揭示稳态剖面的 1/r 形态
> **性质标注**：【定理】= 严格数学/物理结果；【推导】= 框架内推导；【验证】= 数值验证；【待验证】= 需进一步验证

---

## 1 问题设定与动机

上一轮（v1.10）的 3D 球对称闭式解 ρ = ρ∞[R·erf(x/√(4Dt)) + x]/r 是**半无限近似**（外边界在无穷远，x≪R）。遗留问题：

1. **外边界 L 有限时解是什么**？（宇宙学视界/邻近天体/双黑洞系统的物理边界）
2. **半无限近似的误差界**？——L 多大时半无限解可靠？
3. **稳态形态**？——t→∞ 时通量剖面是什么形状？

**设定**：区域 r ∈ [R, L]，边界 ρ(R,t)=0（视界抽零）、ρ(L,t)=ρ∞（外边界背景），初始 ρ(r,0)=ρ∞。

## 2 球贝塞尔级数解【定理·严格】

**变换 u = rρ**（吸收 2/r 项，同 F1″）：∂u/∂t = D·u_rr，边界 u(R)=0、u(L)=Lρ∞。

**稳态解**（u_rr=0 + 边界）：

$$u_{ss}(r) = \rho_\infty \frac{(r-R)L}{L-R}$$

**分离变量**（u = u_ss + 瞬态）：

$$u(r,t) = \rho_\infty\frac{(r-R)L}{L-R} + \sum_{n=1}^{\infty} c_n \sin\!\big(k_n(r-R)\big) e^{-Dk_n^2 t},\quad k_n = \frac{n\pi}{L-R}$$

**系数**（初始条件 u(r,0)=rρ∞ 的傅里叶展开）：

$$c_n = \frac{2}{L-R}\int_R^L \left[r\rho_\infty - \rho_\infty\frac{(r-R)L}{L-R}\right]\sin\big(k_n(r-R)\big)\,dr$$

**物理图像**：稳态 = 视界（u=0）与外边界（u=Lρ∞）之间的**线性插值**（u 空间）；瞬态 = 球贝塞尔模（sin 基）的指数衰减，**最长模 τ₁ = (L−R)²/(Dπ²)** 决定整体弛豫时间。

## 4 半无限近似的误差界【验证④】

**火墙探针 r = R+δ、t = t_rec = R/c**（火墙厚度计算的标准条件）：

| L/R | L/δ | 有限R vs 半无限偏差 |
|---|---|---|
| 1.05 | 23.5 | 9.07%（边界效应显著） |
| 1.10 | 24.6 | 0.0001% |
| 2.0 | 44.7 | 0.0001% |
| 5.0 | 111.8 | 0.001% |
| 10 | 223.6 | 0.005% |
| 20 | 447.2 | 0.022% |

**结论【验证④】**:半无限近似在 L/R ≥ 1.1 时偏差 < 0.01%；L/R ≥ 5 时 < 0.01%。**唯一失效场景是外边界紧贴视界（L/R < 1.1，如双黑洞极近并合末期）**。

**有效时间窗【验证⑦】**：半无限近似在 t < τ_L = (L−R)²/(Dπ²) 内偏差 < 1%（L/R=2~20 全部成立）；火墙恢复时间 t_rec = R/c ≪ τ_L（差 ~10²–10⁴ 倍）——**火墙厚度计算中半无限近似完全可靠**。

## 5 重要物理发现：稳态 1/r 形态【验证⑥】

**有限 R 稳态解**（取 L→∞ 极限）：

$$\rho_{ss}(r) = \lim_{L\to\infty}\rho_\infty\frac{(r-R)L}{r(L-R)} = \rho_\infty\left(1-\frac{R}{r}\right)$$

数值验证（L=10⁶·R、t=50τ₁）：ρ_ss 与 ρ∞(1−R/r) **最大偏差 0.0001%**——严格确认。

**物理意义【本批最重要成果】**：

$$\text{通量赤字} \equiv \rho_\infty - \rho_{ss}(r) = \rho_\infty\frac{R}{r} \propto \frac{1}{r}$$

**稳态通量赤字按 1/r 衰减——与牛顿引力势 Φ ∝ 1/r 完全同形！** 这独立支撑了框架核心主张"引力 = 通量遮挡"：质量在视界处造成的通量抽零，其稳态影响按 1/r 传播，正是引力势的形态（力 ∝ 1/r² 来自势的梯度）。**此前从立体角积分推导 1/r² 力（P0），现在从扩散稳态独立得到 1/r 势——两条路径汇合于牛顿引力形态。**

## 6 原初黑洞场景【验证⑤】

R ~ l_P（δ ~ R，半无限近似理论上最差）：R=1~100 l_P 时有限 R vs 半无限偏差 < 0.004%——因为 t_rec 极短，扩散前沿尚未抵达外边界 L=20R。**半无限近似即使在普朗克尺度也可靠**（在火墙形成时间内）。
