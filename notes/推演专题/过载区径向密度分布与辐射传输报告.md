## 2 核心论证：等温球超重 ⟹ 内部无引力梯度 ⟹ 均匀浆糊【推导 + 验证】

### 2.1 尝试一：线性区静水平衡（等温球）——失败【推导 + 验证】

假设过载区内部有牛顿引力梯度（dP/dr = −ρ·GM(r)/r²），且密度远低于 ρ_P（线性区 P≈c²ρ，宏观黑洞成立）：
- c²dρ/dr = −ρGM(r)/r²，dM/dr = 4πr²ρ ⟹ **奇异等温球** ρ(r) = c²/(2πG)·r⁻²，M(r) = 2c²r/G；
- **在视界 r_h=2GM/c² 处：M(r_h) = 4M——恒定超重 4 倍**（奇异等温球无标度自相似解，与 M 无关）；

**数值验证**（6 个质量：太阳/Sgr A*/M87*/原初 10¹¹/10¹³ kg/普朗克质量）：M_iso(r_h)/M = **4.0×M 全部** ✓——线性区静水平衡与总质量守恒**不相容**。

**推论**：过载区内部**不存在**净引力梯度。

### 2.2 框架机制的独立印证【推导】

框架中引力 = 通量遮挡亏损（P0：质量遮蔽通量产生 1/r² 力）。但：
- 【原文 88–90】视界 = **通量降到零的等势面**（风暴压强临界面）；
- 七环机制环 1：黑洞 = **风暴压制区**——视界内部净通量被压制到 0；
- ⟹ 过载区内部**无净通量梯度 ⟹ 无引力梯度**（引力 = 通量遮挡，遮挡亏损消失）；
- ⟹ 静水平衡 dP/dr = 0 ⟹ P = 常数 ⟹（钳制物态单调）**ρ = 常数——均匀浆糊**。

**两条独立路径收敛**：① 等温球超重 4M 排除内部引力；② 框架机制（视界通量=0 + 风暴压制）给出内部无引力的本体论理由。

### 2.3 均匀解【推导】

总质量 + 体积锁定：

$$\bar{\rho} = \frac{M}{\frac{4}{3}\pi r_h^3} = \frac{3c^6}{32\pi G^3 M^2},\qquad P = P_P\tanh(\bar{\rho}/\rho_P),\qquad c_s^2 = c^2\,\text{sech}^2(\bar{\rho}/\rho_P)$$

**与 v1.18 ρ_avg 精确一致**（太阳 ρ̄=1.842×10¹⁹ kg/m³ ✓、Sgr A* 3.94×10⁶ ✓、M87* 1.73 ✓）——自洽性验证。

**均匀 = "最大熵无结构"的动力学表达**【原文 90】：无内部梯度 ⟹ 无内部结构 ⟹ 无特征辐射（遗留②关闭）。

碎片散射截面取普朗克单元截面 σ = l_P²（碎片 = 普朗克尺寸，最小截面假设）。过载区光学深度：

$$\tau = \int_0^{r_h}\frac{\rho(r)}{m_P}\,l_P^2\,dr = \frac{\bar{\rho}}{m_P}l_P^2\,r_h = \frac{3c^6}{32\pi G^3 M^2}\cdot\frac{l_P^2}{m_P}\cdot\frac{2GM}{c^2} = \frac{3c^4 l_P^2}{16\pi G^2 m_P M}$$
