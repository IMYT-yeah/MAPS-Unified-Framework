# 因果视界上的块计数：最后一环闭合到 10⁻⁶¹，附带查出 λ 的重言式

> **日期**：2026-09-17（第 16 轮）
> **脚本**：`outputs/_b5_horizon_count.py`（检查项 CG-0 … CG-6，全部通过，失败项：无）
> **一句话结论**：B5「同一批相干块」这一环**可以闭合**，但闭合的理由不是零表面，而是**时间尺分离**（残差 O(H₀t_P) = 1.18×10⁻⁶¹）；同时查出两件更重要的：① 框架的面**不是**零表面，「因果补丁边界」的说法要废弃；② `λ = 4α²β² = 1` 是**恒等式**，不构成平直性的证据。

## 一、要证的命题

上一轮（09-16 第 15 轮）把 B5 的最后一环定形为：

| 端 | 计数方式 | 结果 |
|---|---|---|
| 观测者端（B5） | 面元 → 4 bits → 16 倍压缩 | 每相干块 **1 nat**（修正后） |
| 统计端（F3/BH） | 通量管相干块计数 | 每 `4l_P²` **1 nat** |

单位已由 Hawking 温度裁决（1 nat，不是 1 bit）。**剩下没证的**是：两端数的**是不是同一批块**。
此前只能靠「涌现次序」的架构论证，本轮要把它变成可核验的命题。

**做法**：不再纠结「定义是不是同一个」，改问一个可量化的版本——
**在什么精度上，两种分解可以不同？** 若答案是 O(H₀t_P)，则这一环对一切物理目的都已闭合。

## 三、CG-2　时间尺分离：这一环在 10⁻⁶¹ 上闭合

```
ν  = 1/t_P                  = 1.85486×10⁴³ s⁻¹
ν/H₀                        = 8.45924×10⁶⁰      （= R_c/l_P，精确）
H₀ t_P                      = 1.18214×10⁻⁶¹
```

**论证**：块的分解是**瞬时量**——它由风暴当前的微观结构定义，不带历史。风暴以 ν = 1/t_P 刷新（一个哈勃时内每个面元被刷新 **8.46×10⁶⁰ 次**），而视界几何只以 H₀ 变化。因此两端的分解**只能**是同一套，除非微观结构被冻结。

**量化残差**：唯一可能造成失配的机制是「面在移动时扫过新面元、历史分解留下痕迹」，其特征量级为 `H₀/ν = H₀t_P = 1.18×10⁻⁶¹`。

对照两个尺度：

| 量 | 数值 | 与本残差之比 |
|---|---|---|
| 本轮残差 `H₀t_P` | 1.18×10⁻⁶¹ | — |
| 上一轮解决的分歧 `ln2` | 0.6931 | **5.86×10⁶⁰ 倍** |
| 冻结结构时的失配 `β_s` | 0.4667 | 3.95×10⁵⁹ 倍 |
| `β_s²` | 0.2178 | 1.84×10⁵⁹ 倍 |

⟹ **「同一批块」在 O(10⁻⁶¹) 的意义上成立，比它要确立的效应小 60 个数量级。**
反过来说：**若风暴不刷新（ν → 0），失配会是 O(β_s) = 0.47 乃至 O(β_s²) = 0.22——即 20%~47% 的块数误差**，那时这一环就是假的。**A1 的 ν ~ 1/t_P 正是让这个链接成立的东西**，这一点此前没有被量化过。

## 四、CG-3　但「零表面」这条理由被否证

上一轮的直觉是「框架的面是因果面，所以分解是标准的」。检验一下 `R_c` 是不是零表面——看它相对共动观测者的外移速度 `dR_c/dt = (1+q)c`：

| w | q = (1+3w)/2 | `dR_c/dt / c` | 性质 |
|---|---|---|---|
| −1.0000（纯 dS） | −1.00000 | **0.00000** | **零表面 ✓** |
| −0.6889（ΛCDM 有效值） | −0.53335 | 0.46665 | timelike |
| −0.5 | −0.25000 | 0.75000 | timelike |
| 0（物质） | 0.50000 | 1.50000 | spacelike |
| 1/3（辐射） | 1.00000 | 2.00000 | spacelike |

ΛCDM 的 q₀ = −0.5333 ⟹ `dR_c/dt = 0.4667c`。

⟹ **只有纯 de Sitter 时框架的面才是零表面。** 真实宇宙里它以 0.467c 外移，是 **timelike 面**，不是任何意义的「因果视界」。

**这条要写进论文**：B5 不能表述为「观测者因果补丁的边界」（那是事件视界，见 CG-4 会被观测排除），只能表述为**运动学上的平流停滞面**（风暴向外以 c 平流、与退行速度相等之处）。正确的理由链条是 CG-2 的时间尺分离，不是零表面。

## 六、CG-5　顺带查出的结构问题：`λ = 4α²β² = 1` 是重言式

框架定义 `α = 4π/ξ`（熵系数）、`β = ξ/(8π)`（第一定律反解），于是

```
λ = 4α²β² = 4 · (16π²/ξ²) · (ξ²/64π²) = 1
```

**对任意 ξ 恒成立。** 逐值核验（ξ = 1, 2, 3, 4, 4ln2, 8, 16）全部给 `1.000000000000`。

上一轮我把这件事记为「**ξ-稳健性**」并当作增益。**换个说法它就是：重言式。** 一个对任意 ξ 都等于 1 的量，不可能携带关于宇宙的信息。

对照装配分账那条路（CG-4 甲式，`λ = (R/R_c)²`）——它**真的依赖 R**：

| R/R_c | λ | Ω_K |
|---|---|---|
| 1.0000 | 1.0000 | 0.0000 |
| 1.1473 | 1.3163 | −0.3163 |

**两条路只在 R = R_c 处重合。** 所以：

1. `α–β` 路**看不见 R**，因此它**不可能用来挑面**；
2. 它更**不能**作为「λ = 1 已获独立验证」的证据——λ = 1 只是「Bekenstein-Hawking 熵系数 × 标准 GH 温度」的乘积关系，是标准物理的重言式；
3. **真正有内容的只有一条**：等分账 `E = Nk_BT` 写在 `R_c = c/H` 上 ⟹ 解出 `ρ = 3H²/(8πG)`（09-17 第 4 轮的结果）。这一条才是「平坦性」的来源。

**建议**：论文中把 ξ-稳健性从「支持性结果」降为「一致性检查」；并把 λ 的定义统一为**操作式** `λ ≡ ρ/ρ_crit`（面敏感），删掉把它与 `4α²β²` 并列的写法。

## 七、诚实边界

**是推导的**：
- `ν/H₀ = R_c/l_P = 8.45924×10⁶⁰`、`H₀t_P = 1.18214×10⁻⁶¹`（纯运动学，精确）；
- `R_EH/R_c` 的积分（对 4 个闭式解校验通过，收敛到 10 位）；
- `λ = 4α²β² = 1` 对任意 ξ 成立（代数恒等）。

**是论证而非证明的**（CG-2 的「同一批块」）：
- 我把「两端数的是同一批」转化为「两种分解的差异上界」。上界 O(H₀t_P) 依赖两个前提：
  (i) 两端都是**瞬时**的分解（不带历史累积）；(ii) 风暴刷新率 ν ~ 1/t_P。
  若任一端实际是历史累积量（例如熵按「曾经扫过的面元」累加），本论证失效。**这一点没有独立证明**，只能靠 A1 的湮灭-再生循环图像支持。
- 因此结论是「**在 O(10⁻⁶¹) 精度上同一**」，不是「严格同一」。

**是数据参与的**（CG-4 的唯一性）：
- 排除事件视界用的是 Ω_K 观测值，属数据倒推，不是先验推导。B5 的地位仍然是**准定理 + 数据辅助**，不是定理。

**未动的**：
- `α = π` 与 `β = 1/(2π)` 仍是标准物理的输入（BH 熵、GH 温度）。框架的原创性在「把它们用在 `R_c` 上」这一步，不在它们的数值。

## 八、判决与下一步

**判决**：
- ✅ **最后一环闭合**：「同一批块」在 O(10⁻⁶¹) 上成立，比要确立的 ln2 分歧小 60 个数量级。**机制是 ν ≫ H，不是零表面。**
- ❌ **「零表面」理由废弃**：框架的面以 0.467c 外移，是 timelike 面。
- ❌ **事件视界候选被排除**（Ω_K = −0.15 ~ −0.32，最宽约束 5.7σ）。
- ⚠️ **`λ = 4α²β² = 1` 是重言式**，须在论文中降调；λ 应统一为操作式 `ρ/ρ_crit`。
- ⟹ **B5 重述为**：热力学面 = **平流停滞面（v_rec = c）**，建立精度 O(10⁻⁶¹)，在自然候选面中唯一不被观测排除。

**下一步（按价值排序）**：

2. **载流子两类型收口**（唯一还有产出空间的独立支线）：空腔（电子）如何间接获得横向耦合（候选 A/B/C），判别预言 = WF 定律违反幅度 + `η/s → 1/(4π)`。
3. `O-Λ` 的 23.76 倍：已翻过原文 2/3、守恒流、镜像支、微扰尺度四条路，均无解——除非有新结构，否则登记为第四个不可约参数。
