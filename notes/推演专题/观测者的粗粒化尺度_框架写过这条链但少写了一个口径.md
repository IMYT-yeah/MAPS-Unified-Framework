## 四、⭐ 本轮的发现：Nyquist 那一步缺一个口径（OS-2）

论文第 531 行的原话：

> 「方向簇 k≥4（定理 1）+ Tammes 正四面体 ⟹ 每面元 4 独立方向模式；
> **Nyquist 采样定理：4 模式需 ≥4 采样点**（数值秩验证：4 模式×2/3 点秩 2/3 欠采样、×4 点秩 4 满秩）」

**独立复算**（构造 `k×4` 采样矩阵 `M[i][a] = f_a(p_i)`，测秩）：

| 模式基底 | k = 2 / 3 / 4 / 5 / 8 时的秩 |
|---|---|
| **正四面体 · 线性**（`n_a·p`） | 2 / 3 / **3** / **3** / **3** |
| **随机 4 泛函**（与框架无关） | 2 / 3 / **3** / **3** / **3** |
| 正四面体 · `\|n_a·p\|` | 2 / 3 / 4 / 4 / 4 |
| 正四面体 · 高斯 | 2 / 3 / 4 / 4 / 4 |
| （若模式满 4 维）`min(k,4)` | 2 / 3 / 4 / 4 / 4 |

**根因**：`Σ n_a = 0`（精确，数值 `[0, 0, 0]`）⟹ 正四面体的 4 个方向在 **3D 里线性相关** ⟹
若模式取**线性**泛函，独立维度只有 **3** ⟹ **下界是 3 个采样点，不是 4**。

⚠️ **但这不等于论文错**：框架的「4 个方向模式」更可能指「4 个方向上的**连接状态**」
（是非线性/离散量）⟹ 那样确实可以 4 维。**缺的是口径，不是结论。**

**⭐ 而口径分歧直接改变结论**：

| 模式 | 相干块下界 | **尺度下界** |
|---|---|---|
| 线性（3 维） | ≥ 3 l_P² | **√3 l_P = 1.7321 l_P** |
| 非线性（4 维） | ≥ 4 l_P² | **√4 l_P = 2.0000 l_P** |

⟹ **保守可声称的是区间 `1.73 – 2.00 l_P`。**

## 五、尺度换算（OS-4 / OS-5 / OS-6）

**单位核对**（OS-4）：`0.25 纳特/l_P²` ⟺ `1 纳特/(4l_P²)`，差 0.0×10⁰ ✓
折合 **0.3607 bit/l_P²**。

⚠️ **不是 1 比特**：论文第 337 行已裁 —— 取 1 bit 会让太阳质量黑洞温度偏 **+44.27%**
（8.8995×10⁻⁸ K vs 标准 6.16868×10⁻⁸ K）；取 1 纳特偏差 < 10⁻⁹。
⟹ 这是 **B5 唯一带观测成分的一环**（被 Hawking 温度钉住）。

**icosphere 换算**（OS-5）：按「面元 = l_P²」的口径（表面 N = A/l_P² 个面元）：

```
icosphere(3)：642 顶点 / 1280 面 / 1920 边（欧拉 ✓）
4πR² = 1280 l_P²  ⟹  R = 10.0925 l_P
单位球上的平均边长 = 0.150875 rad  ⟹  1-ring 平均边长 = 1.5227 l_P
                                    ⟹  与 2 l_P 之比 = 0.76
```

⟹ **icosphere 的 1-ring 尺度（1.52 l_P）与框架的粗粒化尺度同量级，但略小** ⟹
第 66/67 轮在 1-ring 上数 Morse 谱/绕数**恰好在这个尺度附近**（略欠粗粒化，不改变结论）。

**第 66/67 轮的平滑核**（OS-6）：

| σ (rad) | 弧长 | 相对 2 l_P |
|---|---|---|
| **0.55**（第 66/67 轮用的） | **5.55 l_P** | 2.78 倍 ⟹ **更粗、保守安全** ✓ |
| 0.35 | 3.53 l_P | 1.77 倍 |
| 0.25 | 2.52 l_P | 1.26 倍 |
| 0.15 | 1.51 l_P | **0.76 倍** ⟹ 按框架口径**欠粗粒化** |

⟹ 第 66/67 轮的结论**不会被「平滑不足」推翻**（用的是更粗的核）；
但 σ = 0.15 那一档的数字**不该用**。

## 八、诚实边界

1. ⚠️ **第 ② 环是设定**（「方向管最细尺度 = l_P」标【本框架设定】），不是推导 ⟹
   整条链**第一环是公理、第二环是设定**，之后才是数学。
2. ⚠️ **第 ⑦ 环是额外假设**（「最大压缩」）⟹ 等号 `= A/(4l_P²)` **不因此成立**。
3. ⚠️ **Nyquist 那一步的口径未写明**（OS-2 的发现）⟹ 下界是**区间 1.73–2.00 l_P**，
   不是单值。**这是本轮新查出的一个文档缺口。**
4. ⚠️ **icosphere 的 R = 10.09 l_P 依赖「面元 = l_P²」这个口径** —— 那是论文的约定
   （表面 N = A/l_P² 个面元），把它用在**弯曲球面**上是**类比**，不是严格推导。
5. ⚠️ **本轮没有给出「观测者的读数算子」** —— 第 40 轮的三难仍然成立；
   本轮只给**尺度的下界**，不给读数本身。
6. ⚠️ **「k ≥ 4 由 LST 定理」这一环用了球面覆盖定理** —— 把它用在「方向空间」上是
   框架的识别（`§4.10 定理 1`），**不是**从公理 1 直接推出。
