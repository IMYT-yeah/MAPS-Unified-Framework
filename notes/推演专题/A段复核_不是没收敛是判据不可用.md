## 一、噪声基线：判据的盲区（HA-1，决定性）

直接**从精确麦克斯韦分布抽样** N 个速度，用与论文**完全相同**的 bins/权重口径算同一个加权偏差指标（400 次平均）：

| N | 噪声基线（均值±sd） | 论文判据 <10% |
|---|---|---|
| **256** | **0.2427 ± 0.0494** | **基线已超判据 ✗** |
| 500 | 0.1657 ± 0.0294 | 基线已超判据 ✗ |
| 512 | 0.1646 ± 0.0323 | 基线已超判据 ✗ |
| 1000 | 0.1137 ± 0.0198 | 基线已超判据 ✗ |
| 1024 | 0.1138 ± 0.0204 | 基线已超判据 ✗ |
| 2000 | 0.0802 ± 0.0139 | ✓（余量仅 ~1.4σ） |
| 8000 | 0.0394 ± 0.0067 | ✓ |

⟹ **分布完全正确时，N=256 的偏差就有 24.3%。** 绝对判据「<10%」在 **N ≲ 1600 时不可用**。
⟹ 顺带：判据在 N=2000 时也只比基线高约 1.4σ，**辨别力本就有限**。

## 二、A 段实测 vs 基线（HA-2）

| 设置 | N | 步数 | 实测偏差 | 噪声基线 | 比值 | 偏离基线 |
|---|---|---|---|---|---|---|
| **基线（原设置）** | 256 | 5000 | **0.2274** | 0.2427 | **0.94×** | **−0.31σ** |
| 加长 4× | 256 | 20000 | 0.2825 | 0.2427 | 1.16× | +0.81σ |
| 换种子 | 256 | 5000 | 0.2942 | 0.2427 | 1.21× | +1.04σ |
| 加大 N（同堆积率） | 512 | 6000 | 0.2223 | 0.1645 | 1.35× | +1.79σ |

三个要点：

1. **原设置（22.74%）落在基线 1σ 内** ⟹ A 段与"完全正确的麦克斯韦分布"**统计上不可区分**。
2. **加长 4 倍步数，偏差没有下降**（0.2274 → 0.2825，1.16 倍基线）⟹ **这直接排除了"弛豫不足"**：如果真是没弛豫，加长 4 倍应当显著下降。它没有 ⟹ 该偏差不是"还没均衡"，而是**采样统计**（＋可能的 2D 长时尾，原稿已诚实标注）。
3. **换种子给出 0.2274 / 0.2942** ⟹ 样本间散布 ≈ ±0.03，与基线 sd 0.049 同量级 ⟹ 这就是噪声。

⚠️ **唯一需要留意的**：N=512 时 1.35×（+1.79σ）——轻微超出基线，可能来自 **2D 长时尾**（真实物理效应）。但只有 1.8σ，**不足以断言**，需要更多种子或三维模拟才能分辨。

## 三、C 段两项同样是噪声

| 配置 | 实测 | 对应 N 的基线 | 比值 | 偏离 |
|---|---|---|---|---|
| v0=2.0 / N=1000 | 13.6% | 11.37% ± 1.98% | 1.19× | +1.13σ |
| v0=1.0 / N=500 | 20.7% | 16.57% ± 2.94% | 1.25× | +1.40σ |

⟹ **两项都在噪声量级**（1.1σ / 1.4σ），不是物理失败。

**B 段反向验证**：N=2000 的基线 8.02%，实测 **7.02% = 0.88 倍基线** ⟹ B 段**真的**通过（不是擦边）。

## 四、结论与建议

**结论**：三段曾被记为"未通过"的项，**全部是判据不可用**，不是物理问题：
- A 段 = 0.94× 基线（与完全正确的分布不可区分）；
- C 段两项 = 1.19× / 1.25× 基线（1.1σ / 1.4σ）；
- B 段 = 0.88× 基线（真通过）。

**建议**（已写进论文）：
1. 判据改为**相对式**：「实测偏差 / 噪声基线 ≲ 1.5」；
2. 或者把第 2 类对照（无分子混沌）的规模提到 **N ≥ 2000**（基线 8.0%）再用绝对判据；
3. 报告偏差时**一律附上该 N 的噪声基线**，否则数字无法解读。

## 六、诚实边界

**是数值事实**：噪声基线表（400 次抽样）、A/C/B 段的实测值与比值、各 σ。

**是推断**：
- 「排除弛豫不足」依据的是"加长 4× 未下降"——**单种子**的结论，没有做多种子平均；严格说只有 1 组数据支持。
- N=512 的 +1.79σ 归因于 2D 长时尾是**推测**（原脚本早已标注 2D 长时尾，但本轮没有独立验证其大小）。

**未做**：
- 多种子统计（每配置只跑 1 个种子，除了基线补了 seed=43）；
- 三维硬球（全部 2D）；N≥2000 的确定性硬球（受运行时间限制）。
- 噪声基线假设"速度独立同分布"——若系统存在空间关联（如 2D 长时尾），基线可能被低估，这也是 N=512 略超基线的另一种可能解释。
