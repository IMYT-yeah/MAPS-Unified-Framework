## 一、结论（先说）

**本轮没能定位 `λ_c(∞)`，并且给出了它为什么难定位的量化证据。更重要的：本轮推翻了 A1 报告的 `λ_c(∞) ∈ [0.21, 0.23]`。**

| 判据 | 2×2×2 (L̄=2.00) | 3×2×2 (2.289) | 3×3×2 (2.621) | **3×3×3 (3.00)** |
|---|---|---|---|---|
| **J1 χ 峰（粗 0.05）** | 0.2425 | 0.2459 | 0.2826 | **0.3075** |
| **J1 χ 峰（细）** | **0.2348**（0.0125） | **0.2281**（0.0125） | **0.2572**（0.02） | 未做 |
| ↳ **网格差** | 0.008 | 0.018 | **0.025** | — |
| J1s χ 峰（平滑，粗） | 0.2192 | 0.2414 | 0.2859 | 0.4000（越界） |
| J2 保真度磁化率峰（粗） | 0.2802 | 0.2801 | 0.3035 | 0.3008 |

**三条硬事实：**

1. **`λ_χ` 在粗网格上单调上升（0.2425 → 0.3075），但在细网格上不单调（0.2348 → 0.2281 → 0.2572），且两组数据在不同尺寸处给出相反的趋势** ⟹ A1 报告说「两尺寸峰位无漂移 ⟹ λ_c(∞) ∈ [0.21, 0.23]」—— **那是 2 点样本的假象**；而且**连"漂移方向"本身都依赖于扫描网格**。
2. **网格差本身随尺寸增大**（0.008 → 0.018 → **0.025**）⟹ **网格不确定度与尺寸漂移（~0.03）无法分离** ⟹ 任何"尺寸漂移"的解读都被网格效应污染。
3. **1/L̄ 外推给出荒谬值**：6 个数据点线性外推 ⟹ `λ_c(∞) = 0.4361`（斜率 −0.4154）。这个值**比全部数据点都大**，而 λ=0.40 时 ⟨A_c⟩ 已降到 0.24（系统明显在无序侧）⟹ **外推完全不成立**。

**⟹ 判据的可用性排序（本轮实测）：**

| | 判据 | 状态 |
|---|---|---|
| ✅ | **⟨A_c⟩ 跨尺寸交叉点** | 集中在 **0.32–0.34**（8 组配对全部落在 0.279–0.344），且**不需要数值微分** |
| ⚠️ | χ 峰 | **最不可靠**：网格差随尺寸增大（0.008→0.025），粗/细给出相反趋势 |
| ⚠️ | 保真度磁化率 | 对简并点/正交点敏感（λ≤0.05 处 F≈0 ⟹ 必须剔除）；网格差也大 |
| ❌ | E0 二阶导 | 峰始终落在区间边界（越界）—— 不可用 |
| ❌ | **Binder 累积量** | **恒等失效**：`A_c² = I` ⟹ ⟨A²⟩≡1、⟨A⁴⟩≡1 ⟹ Binder ≡ 2/3（0 信息） |

**两个独立判据（χ 峰 @ L=3 的 0.3075、交叉点 0.32–0.34）都指向 `λ_c ≈ 0.31–0.34`**，**远离** 3D Ising 的 `β_c = 0.221654` —— 但 ⚠️ 见 **C-62**：两者**不在同一个轴上，不能直接比较**。

## 二、工程：让 3×3×3 从「不可行」变「可行」

### 2.1 原求解器的瓶颈（诊断）

`_lc3d_box.py::dmrg1` 在**每个 site** 都调用 `env_left_at` / `env_right_at`，二者各自**从 0 重新缩并到底** ⟹ 单 sweep 成本 **O(n²)** 次张量缩并。规模对比：

| 系统 | 面数 n | MPO bond D | 旧版可行？ |
|---|---|---|---|
| 2×2×2 | 36 | 11 | ✅（~1.8 s/sweep） |
| 3×2×2 | 52 | 15 | ✅ |
| 3×3×2 | 75 | 21 | 勉强 |
| **3×3×3** | **108** | **30** | ❌ 约 3 小时 / λ 点 |

### 2.2 两级优化

① **环境增量推进**：左环境在正向扫中逐步右推、右环境预建后缓存 ⟹ **O(n²) → O(n)**。
② **BLAS 化**（第二轮才发现真正的瓶颈）：单 sweep 2×2×2 实测 **2.10 s**，而 142 次环境推移只需 0.04 s ⟹ **瓶颈在 `build_heff1_dense`**。把它的两级收缩改成「先缩 n、再 BLAS matmul」，中间张量从 `(χ,2,χ,χ,2,χ)=16384` 降下来。

**实测**：2×2×2 单点 **36.5 s → 12.9 s**（2.8×）；3×3×3 单 sweep **23.6 s → 约 8–10 s**（**从不可行变为 9 分钟/λ 点**）。

### 2.3 验证（三道关，全过）

| 检查 | 结果 |
|---|---|
| BLAS vs 原版（含边界 `aL=1`） | 4 组全过，Δ ~ **1e-13** |
| 2×1×1 对**精确对角化** | ΔE₀ = **8.9e-16**、Δ⟨A_c⟩ = 5.6e-16 |
| 2×2×2 复现原报告 λ_χ | **0.230**（原 0.230）、χ_max **3.076**（原 3.08）、⟨A_c⟩ 逐点最大偏差 **5e-5** |
| 跨系统自洽 **E(λ=0) = −N_c** | **四个尺寸全部精确成立**：−8 / −12 / −18 / −27 |

> ⚠️ **自己踩的一个真 bug**（已修）：第一版 `push_left`/`push_right` 把 L（或 R）的两个 bond 都当成 χ，而**边界位点 aL=1**（`init_left` 是 `(1,1,D,D)`）⟹ 正向扫 `c=0` 时 reshape 直接崩。**两个 bond 必须分开写**（`aL = T.shape[0]`、`ar = T.shape[2]`）。

**读法**：
- **λ ≤ 0.25**：⟨A_c⟩ 随 L **单调增大**（大系统更有序）⟹ **符合 λ < λ_c** 的预期 ✓
- **λ ≥ 0.35**：随 L **单调减小** ⟹ **符合 λ > λ_c** ✓
- ⚠️ **λ = 0.30 与 0.35 处出现非单调**（3×3×2 的 0.46299 < 3×2×2 的 0.50390；3×2×2 的 0.40292 反常偏高）—— **而那正是 χ 峰所在区** ⟹ 该区的数值已不可靠。

### 3.2 判定「λ_χ 不可外推」的三条证据

**(a) 峰位随尺寸单调上升（不收敛）**
`0.2425 → 0.2459 → 0.2826 → 0.3075`（L̄ = 2 → 3）。若按 L^{−1/ν}（ν=0.63）外推，`λ_c(∞)` 会给出 **0.435** —— 更荒谬。

**(b) 峰位随网格漂移，且漂移量随尺寸增大**（同一尺寸，两种网格）

| | step 0.05 | step 0.0125 / 0.02 | 差 |
|---|---|---|---|
| 2×2×2 χ 峰 | 0.2425 | **0.2348** | 0.008 |
| 3×2×2 χ 峰 | 0.2459 | **0.2281** | 0.018 |
| 3×3×2 χ 峰 | 0.2826 | **0.2572** | **0.025** |
| 2×2×2 χ_max | 2.945 | **3.100** | — |
| 3×2×2 χ_max | 2.447 | **3.431** | — |
| 3×3×2 χ_max | 3.778 | **4.727** | — |

⟹ **网格差单调增大（0.008 → 0.018 → 0.025）** —— 恰好与"尺寸漂移"同量级 ⟹ **二者在现有精度下不可分离**。这是本轮判 `λ_c(∞)`「未定位」的**决定性一步**。

**(c) 四判据在同一尺寸上的分歧 ~0.04**（2×2×2 细）：J1=0.2348、J1s=0.2253、J2=0.2647 ⟹ 跨度 **0.039**；而跨尺寸漂移也只有 0.073（0.2348→0.3075）。

### 3.3 ⭐ χ 截断测试（`_lc3d_chitest.py`）—— 判据可靠性的一票否决

| 系统 | λ | χ=8 ⟨A_c⟩ | χ=16 ⟨A_c⟩ | 跨度 | χ=8 的 E 误差 |
|---|---|---|---|---|---|
| 2×2×2 | 0.22 | 0.66777 | 0.64728 | **+0.0205（3.17%）** | ΔE = −0.182（1.7%） |
| 2×2×2 | 0.24 | 0.60411 | 0.59649 | +0.0076（1.28%） | ΔE = −0.210（1.9%） |
| 2×2×2 | **0.26** | 0.51355 | 0.47417 | **+0.0394（6.93%）** | ΔE = −0.214（1.9%） |

⟹ **即使在最小的 2×2×2 上，χ=8 的 ⟨A_c⟩ 也偏 1–3%**，而**在 λ=0.26（最接近相变点处）偏到 6.93%** —— **恰恰是最需要精度的地方误差最大**。
而 3×3×3 的纠缠只会更强 ⟹ **χ=8 在 L=3 上的误差 ≥ 3%（未量化，且无法量化 —— 见下）**。

> ⚠️⚠️ **为什么不能像原计划那样「用 discarded weight 判断 χ 够不够」**：
> **1-site DMRG 的 1-site 更新不增长 bond** —— SVD 的 `min(aL·2, aR)` 恰好 ≤ χ ⟹ **丢弃权重恒为 0**。
> 所以 `dw = 0` 是**恒等式，不是质量指标**。本轮实测四个尺寸的 dw 全部为 **0.00e+00**。
> **唯一可用的 χ 质量指标就是「χ=8 vs 16 的能量/⟨A_c⟩ 差」** —— 而 3×3×3 的 χ=16 单点约需 **1 小时**，本轮未做。

**⟹ 结论：3×3×3 的 0.3075 是「χ=8 层面上的数」，误差未量化。**

## 五、⚠️ 三条更正（相对 A1 报告与论文）

### C-61 ⭐⭐ A1 的「`λ_c(∞) ∈ [0.21, 0.23]`」是**过度解读**

A1 报告原文：「两尺寸**最小线性尺寸均为 L=2**，λ_χ 基本不随体积漂移（0.230 → 0.21）——支持 λ_c(∞) 落在 0.21–0.23 区间」。

**更正**：两个尺寸的**最短边都是 2** ⟹ 它们**不是独立的标度点**（标度变量在这些尺寸上几乎不变）。补上 L̄=2.62 与 **L̄=3** 后，峰位升到 0.2826 / 0.3075 ⟹ **原「无漂移」是样本选择的产物**。
**正确表述**：`λ_χ(L̄) = 0.24 (L̄=2) → 0.31 (L̄=3)`，**单调上升，外推不成立**；`λ_c(∞)` **仍未定位**。

### C-62 ⭐ 把 h 轴的 `λ_c` 与 3D Ising 的 `β_c = 0.221654` 直接比较，**轴混淆**

A1 报告与论文中文稿 L2033 写：「真 3D 临界耦合 0.230 与 2D toric code（0.25–0.32）同量级、与 3D Ising `β_c=0.2217` **高度接近（差 3.7%）** —— 支持『3+1D 弦网 ↔ 3D Z₂ 格点规范 ↔ 3D Ising』对偶自洽」。

**问题**：
- 3D Ising 的 `β_c` 是**耦合常数倒数**（温度）；本模型的 `λ` 是 **X 场强度**。对偶映射（Fradkin–Shenker 型）连接的是 Ising 的 `β` 与规范的 **plaquette 耦合 K**，**不是** X 场 `h`。
- 本模型 `K = 1` **固定**、`λ = h` 变化 ⟹ 走的是 **h 轴**。由 `β_c = 0.221654` 反推规范侧 `K_c = −½ln(tanh β_c) ≈ 0.7615`，而 `K = 1 > K_c` ⟹ λ=0 侧确在解禁闭相 ✓（与 ⟨A_c⟩(λ=0)=1 一致），但**沿 h 轴的相变点不是 0.2217**。
- ⟹ 「差 3.7% ⟹ 对偶自洽」**缺乏依据**，是**两个不同轴的数**碰巧接近。

**处置**：论文该处改为「与 3D Ising `β_c` 的接近**不构成对偶检验**（轴不同）；精确对偶映射（h ↔ β）未建立」。⚠️ 本轮**不**声称 `λ_c ≈ 0.31–0.34` 与任何文献值一致。

### C-63 ⭐ 中英不同步（A1 的 3D 盒子结果**只进了中文稿**）

- **中文稿** L2031–2037：有完整的「真 3D 盒子 DMRG（A1）」段（λ_χ=0.230、估计 [0.21,0.23]）。
- **英文稿** L2000：仍是旧版 —— 「conservative interval `λ_c(∞) ∈ [0.140, 0.140]`」；L2004 仍写「`λ_c(∞)` is an **open numerical problem**」。
- ⟹ 英文稿**完全没有** A1 的内容。本轮**一并修正**（改为本轮结论）。

## 六、判决与下一步

**判决**：`λ_c(∞)`（§10.2 #13 的剩余开放项）**本轮未解决**，且**被证明在本方法下不可解** —— 判据分辨率（~0.04）与尺寸漂移（~0.04）同量级。**登记为「方法学不足，未定位」**，而不是给一个数。

**要真正定位，需要（按必要性排序）：**
1. **换判据**（而不是换尺寸）：`⟨A_c⟩` 的 χ 峰**不是**可靠序参量 —— 与论文已记录的 2D 诊断「m(h_c) 外推 → 0.93 ≠ 0 ⟹ ⟨X⟩ 非相变序参量」**同族**。3D 侧应改用 **'t Hooft 环 / Wilson 环的周长–面积律交叉**（非局域序参量）。
2. **换算法**：3D 盒子的 MPS 截断太狠（χ=8 在 L=2 上就偏 3%）⟹ 应换 **PEPS / 3D DMRG / 量子蒙特卡洛**（QMC 对本模型无符号问题，应是最优选择）。
3. **建立精确对偶映射**（h ↔ β），否则无法与任何文献值对照。

**⚠️ 本轮明确不做的**：不声称 `λ_c ≈ 0.31–0.34` 是热力学极限值（它来自 L≤3 且 χ=8，且交叉判据本身没有误差棒）。
