## 一句话结论

**I-14 的原表述是错的，但它的方向是对的——精确化之后结论更强。**

> 原表述：「框架的全部定量输出（能谱/能隙/简并/序参量/χ/弦张力/熵/指数）**没有一个「两态之差」**。」
>
> ❌ **字面错误**：弦网能隙 `Δ = 2`（λ=0，**严格**）**就是**「两态之差」（基态 vs 激发态）。
>
> ✅ **修订版（本轮结论）**：
> **框架的「差」只有三类 —— 谱内差 / 参数差 / 无极小弦势；没有第四类「势阱型的构型差」。**
> 机制是：**位置与能量在框架里分层居住 —— 有位置的层没有能量，有能量的层没有位置。**
> 而化学键恰恰要求这两者**耦合**。

⟹ **边界从「不覆盖储能」扩大为：化学键 / 相变潜热 / 电离能 一并落在框架语言之外。**

## 一、三个反例候选（引文清点发现的，逐个判定）

清点先发现 I-14 有**三个**可能的证伪点，本轮的力气主要花在把它们逐个判掉。

### 反例 1：弦网能隙 `Δ = 2` —— 它**就是**两态之差 ⟹ I-14 原表述不成立

论文 §5.8 原文：λ=0 弦网凝聚严格证明 ⟹ `E0 = −N_c` 精确、激发能隙 **Δ = 2**（严格）。

**所以「有没有差」这个问法本身就是错的。** 正确的问法是**差的是什么**：

| 类型 | 定义 | 差分的是 |
|---|---|---|
| **谱内差** | 同一格点、**同一参数**下的两个本征值之差 | 「通量构型」 |
| **构型差** | 同一组分、**两个物质排布**之间的能量差 | 「物质排布」← **化学键需要的是这个** |

**本轮数值（自建 toric code，`_i14_60.py`）**：

| 系统 | 能级 | 简并 | E0 | **Δ** |
|---|---|---|---|---|
| 2+1D，L=2 环面（解析）| −8, −4, 0, 4, 8 | 4, 48, 152, 48, 4 | −8.0 | **4 J** |
| 2+1D，L=2 环面（**256 态数值**）| 同上，**逐项一致 ✓** | 同上 ✓ | −8.0000 | **4 J** |
| 2+1D，L=3 环面（解析）| −18, −14, …, 14 | 合计 2^18 = 262144 ✓ | −18.0 | **4 J** |
| 3+1D 单立方体（64 态）| −1, +1 | 32, 32 | −1.0 | **2 J** |
| 3+1D 双立方体（2048 态）| −2, 0, +2 | **512, 1024, 512** | −2.0 | **2 J** |

解析谱的来由（不是拟合）：`Π_v A_v = 1`、`Π_p B_p = 1` 是**算符恒等式** ⟹ `#(A_v=−1)`、`#(B_p=−1)` 必须为**偶数** ⟹
`E(a,b) = 2(a+b) − (N_v + N_p)`，简并 `4·C(N_v,a)·C(N_p,b)`（4 = 环面拓扑简并 `|G|²`）。
**总和校验**：2+1D L=2 给 4+48+152+48+4 = **256 = 2⁸** ✓；L=3 给 **262144 = 2¹⁸** ✓。

**顺带两处交叉验证**（证明实现无误）：
- 论文 §5.7 的 `E0 = −8.0000`、**基态简并 4 = |G|²** ⟹ **逐位一致 ✓**
- 论文 §5.8 的 3+1D 严格结果 `E0 = −N_c`、简并 `2^(n−N_c) = 512/1024/512`、`Δ = 2` ⟹ **全部一致 ✓**

> ⚠️ **待核实（本轮顺带发现，不属本轮主题）**：论文 §5.7 记「能隙 **Δ=1**」，而本轮 2+1D 环面（2×2 与 3×3、解析与数值四个独立算例）**一律给 Δ = 4J**。
> 结构上的理由：3+1D 的 `A_c` 共享面出现 **2 次** ⟹ `Z²=1` ⟹ **无约束** ⟹ 可独立翻转 ⟹ 单激发（2J）；
> 2+1D 的 `A_v` 共享边 ⟹ `Π_v A_v = 1` **构成约束** ⟹ 激发**必须成对** ⟹ 4J。
> 两者不能同时是 2 与 1。**仅登记，不改数值**（来源未查明）。

### 反例 2：禁闭弦势 `E_pair(d) = 2E_m + σ_m·d` —— 唯一的「位置依赖」能量

论文 §5.7：约束扇区法给出**真正的磁通对弦势**，且「κ=0/λ=0 严格 deconfined：**dE 与距离无关**（= 2E_m 常数）」。

| λ | σ_m | `E_pair(d) − 2E_m`（d = 0…5） | 严格单调 |
|---|---|---|---|
| 0.5 | 0.21 | 0, 0.21, 0.42, 0.63, 0.84, 1.05 | ✓ |
| 1.0 | 1.09 | 0, 1.09, 2.18, 3.27, 4.36, 5.45 | ✓ |
| 2.0 | 3.04 | 0, 3.04, 6.08, 9.12, 12.16, 15.20 | ✓ |
| 0（deconfined） | **0** | 常数（论文：「与距离无关」） | — |

**⟹ σ_m ≥ 0 在所有可用数值里成立 ⟹ 弦势恒单调不减 ⟹ 没有极小 ⟹ 不存在势阱。**

**束缚态的判据就是「势有极小（势阱）」**（等价地：连续谱下有孤立能级）。
**单调势 ⟹ 无束缚态** —— 这不是「还没算出来」，是**结构上不可能**。

而且它的物理身份是**禁闭**：论文 §5.7 自己写着「胶球 = 通量自束缚态」（BESIII X(2370) 锚点），
那是 **QCD 色禁闭**（拆开通量管长出新配对），**不是化学键**。

### 反例 3：空间平移 → 动量（Noether）

论文原文（守恒律表）：【推导】时间平移→能量、空间平移→动量、转动→角动量、内部 U(1)→电荷。

框架**确实有**平移对称性，所以有位置与动量的**概念**（作为守恒荷）。但：
- Noether 给的是**守恒量**（动量），**不是势能面 V(R)** —— 要得到 V(R) 还得有一个具体的**两体哈密顿量**（框架没有）；
- 这个平移是**格点背景的**对称性（格点标号可整体平移），不是「物质可在其中移动并改变相对距离」的自由度。

> 附：框架**继承**了标准 GR 的引力束缚（§4.5b 的 EMRI / Kerr 测地线，有束缚轨道）。
> 但那是**继承**的（框架只在其上叠加 PPN 偏离），且尺度是 `GM/c²`（天体尺度）—— 与化学键（Å 尺度）不同类。

## 二、核心判据：位置与能量**分层居住**

把框架的两层摊开，问同一个问题：**这一层的「态」里有没有位置？有没有能量？**

| 层 | 态是什么 | 有位置？ | 有能量？ |
|---|---|---|---|
| **衬底层**（tick 置换群） | k-子集 = k 个格点的**空间分布** | ✅ **有位置** | ❌ 只定义 `H/N`（**熵密度**） |
| **弦网层**（`H_F` / `H(λ)`） | 面变量 `Z_f ∈ {±1}`（**通量**） | ❌ 不是位置 | ✅ **有哈密顿量与能量谱** |
| **弦势**（唯一的位置量） | 缺陷间距 `d`（**格点计数**，离散） | ⚠️ 半有 | ⚠️ 但**无极小**（见反例 2） |
| **事件层**（`H_event`） | —— | ❌ | ❌ `V_contact` 无函数形式 |

**⟹ 有位置的层没有能量；有能量的层没有位置。**
**⟹ 化学键需要「能量 × 位置」的耦合（E 随核间距 R 变化），框架没有这一项。**

衬底层对「排布」给出的**全部**信息（第 46/50 轮的 `(2,2,L)` 系列）：

| 格点 | N | H/N（纳特/格点） | 这是 |
|---|---|---|---|
| (2,2,2) | 8 | 0.4679 | **熵**，非能量 |
| (2,2,4) | 16 | 0.4335 | **熵**，非能量 |
| (2,2,6) | 24 | 0.4334 | **熵**，非能量 |
| (2,2,8) | 32 | 0.4617 | **熵**，非能量 |

**⟹ 框架能说「哪个排布更无序」，不能说「哪个排布能量更低」。**

## 三、三类差的总表

| 类 | 例 | 差的双方 | 为什么不能做束缚能 |
|---|---|---|---|
| **谱内差** | `Δ = 2J`（λ=0 严格）、`Δ±2 = 0.49J` | 同一格点、同一参数下的两个本征值 | 差的是**通量构型**，不含物质排布信息 |
| **参数差** | `E0(λ)`、`m(κ)` 单调 | 同一系统在两个**耦合值** | 那是**相图**，不是两个态之差 |
| **弦势差** | `E_pair(d) = 2E_m + σ_m·d` | 两个拓扑缺陷的距离 `d` | **无极小**（`σ_m ≥ 0`）⟹ **无势阱** ⟹ 无束缚态 |

**三类差都成立，但都不等价于「束缚能」。**

## 四、被覆盖的物理（边界扩大）

| 现象 | 它需要什么 | 框架 |
|---|---|---|
| **化学键 / 键能** | `V(R)` 势阱（极小在 `R_eq ≈ 0.15 nm`） | ❌ 无势阱 + 无位置 |
| **相变潜热** | 两相自由能差 `ΔU` / `TΔS` | ❌ **有相变点、无自由能** |
| **电离能** | 中性原子与离子的能量差 = **一个电子被移走后的排布差** | ❌ 无「排布」自由度 |
| **储能容量**（第 56 轮） | `f = ΔE_bind/(m·c²) ≪ 1` | ❌ 全部机制都是 `f = O(1)` |
| **色禁闭 / 弦张力**（**框架能做的**） | 线性势、**无极小**、尺度 ~`E_P` | ✅ **这正是框架的强项** |

**相变潜热那一条值得单说**：框架**有相变**（3+1D 弦网 `λ_c(∞) ∈ [0.21, 0.23]`、2D toric code `κ_c ∈ [0.25, 0.32]`），
但它的相变是**用 `χ` 峰 / 序参量 `m=0.5` 交叉点定位**的 —— 给的是**临界点的位置**，不是**两相的自由能差**。
⟹ **有相变 ≠ 有潜热。**「自由能 / 潜热 / 化学势」**实质各 0 处**。

**尺度**：`J = n_G·E_P·g ≈ 3 × 1.2209×10²⁸ eV = 3.6627×10²⁸ eV`；
化学键（Li–O₂ 天花板口径）= 1.4798 eV/原子 ⟹ 比值 **2.475×10²⁸ ⟹ 28.4 个数量级**。
且弦势的单位是「1 个格点」，换成物理长度还需要**格点间距 a**（框架**未给**）⟹ **两个换算因子都缺**（陷阱 40 第 3 步）。

## 六、诚实边界

**是推导/计算的**：
- 2+1D 与 3+1D 弦网的全部谱（解析公式 + 256/2048 态数值交叉验证，逐项一致）；
- 弦势单调性（直接代入论文给的 σ_m 值）；
- 尺度比 28.4 个数量级（纯算术）；
- 词条清点（含元文本排除，可复算）。

**是判定的（不是证明）**：
- 「谱内差 ≠ 构型差」这个**区分**是本轮**定义**的，不是从公理推出的；它的依据是「化学键在 Born–Oppenheimer 下要求 `E(R)` 随**核位置**变化」，而框架没有核位置自由度；
- 「束缚态 ⟺ 势有极小」用在**离散格点**上是**类比**（严格版本需要连续谱的概念）；
- 「框架不覆盖化学键」是**边界判定**，与第 55/56 轮的「不覆盖储能」同级，不是定理。

**⚠️ 未做的（诚实列出）**：
- **未证明**「框架不可能涌现出势阱型构型差」——本轮只证明**现有的四个哈密顿量**里没有。若将来框架引入位置算符或两体势，结论需重审；
- **未解释** 2+1D 「Δ = 4J vs 论文记 1」的差异来源（仅登记为待核实）；
- 未把「谱内差 / 参数差 / 弦势差」的分类**形式化**为公理级命题（本轮是清单式穷举，不是定理证明）。
