### 2.2 Δ 与 L 无关（解析交叉验证）

### 2.3 ⭐ 口径差异的真正来源：**边界条件**，不是维度

| 情形 | 边界 | Δ |

### 2.4 ⚠️ 为什么「1」无法被唯一确定（一个可复用的教训）

### 3.2 ⚠️ 第 0 批的核对：**用错了公式**

第 0 批的算法：按 §8.1 的 `ε(E) = ε₀(M_Pl/E)^β`，取 ε₀ = 7.731×10⁻²⁰、β = 0.615，

**本轮的反向检验**：把 ε = 10⁻⁵⁰ 代进**同一个公式**，反推它对应的能标：

```
(M_Pl/E)^β = 10⁻⁵⁰ / 7.731×10⁻²⁰ = 1.293×10⁻³¹
⟹ M_Pl/E = (1.293×10⁻³¹)^(1/0.615) = 5.96×10⁻⁵¹
⟹ E = 1.2209×10¹⁹ / 5.96×10⁻⁵¹ = 2.05×10⁶⁹ GeV
```

⚠️⚠️ **2.05×10⁶⁹ GeV ≫ M_Pl = 1.22×10¹⁹ GeV** —— 反推能标**超出普朗克能标约 49 个数量级**。

⟹ ⭐ **第 0 批的「40 个数量级不一致」是「把两个不同的量当成同一个 ε」造成的假警报。**
（与**陷阱 45「符号撞车」**同族，但这次是**跨章节的同一符号两个身份**：
