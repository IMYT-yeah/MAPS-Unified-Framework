# 视界热力学的两个包：第一定律选定的是 Kodama 温度，不是 GH 温度

> 日期：2026-09-16 夜 ｜ 性质：**修正**此前"代数等分 vs 微分定律不相容"的框定
> 脚本：`_firstlaw_check.py`（逐项数值）、`_firstlaw_trial.py`（判决性检验）、
> `_firstlaw_resolve.py`（温度反解）—— 三者均纯标准库
> **一句话：不是谁算错了。是两套不同的热力学结构，框架选了其中一套，代价是放弃从视界热力学推 Friedmann。**

---

## 一、起因：一段被框错的结果

我在《β 的框架推导》里写过：取 `T = ℏH/(2πk_B)` 时，微分第一定律不闭合，
`w = 0` 给出 `(TdS + WdV)/dE = 3.5`。当时把它读成"两条定律不相容"。

先做判决性检验：**在 λ≠1 的弯曲宇宙里、把定律写在表观视界上**，同一套约定给出：

| Ω_K0 | w | `(TdS+WdV)/dE` |
|---|---|---|
| 0 | 0 | **3.500000** |
| +0.1 | 0 | **3.500000** |
| −0.1 | 0 | **3.500000** |
| +0.1 | −1 | **5.000000** |

比值**与 λ、z 全无关**，恒为 `(7−3w)/2`。
表观视界上也是 3.5 ⟹ **不是"R_c 特别"，是我的约定里有一个温度选错了。**

## 二、反解：把 T 当未知数

约定固定为（全部显式写出，便于复核）：

```
E = R c⁴/(2G)      Misner-Sharp，在表观视界上恒等
S = k_B A/(4 l_P²) = k_B π R² / l_P²
W = (ρ_E − p)/2    Hayward 工作密度
dV/dt = 4π R² Ṙ
```

要求 `dE = T dS + W dV` 闭合，解出：

$$\boxed{T_{\text{要求}} = \frac{\hbar H(3w-1)}{8\pi k_B} = T_{\text{Kodama}}}$$

**数值验证（平直情形）**：

| w | T_GH 闭合 | **T_Kodama 闭合** |
|---|---|---|
| 0 | 3.500000 | **1.000000** |
| −1（de Sitter） | 5.000000 | **1.000000** |
| 1/3（辐射） | 3.000000 | **1.000000** |

**`T_Kodama` 一列精确等于 1.000000。** 结论确定。

（弯曲情形给出 0.97–0.98，非 1：因为上式是**平直**的 Kodama 表达式，
弯曲时需用完整的 Hayward 表面引力。平直情形才是干净的判决。）

## 三、结构：两个包

| | 温度 | 定律 | 表面 | 对 λ 说什么 |
|---|---|---|---|---|
| **标准包** | `T_Kodama` | `dE = TdS + W dV` ⟺ Friedmann | 表观视界 `R_A` | **不受约束**（λ 是初始条件） |
| **框架包** | `T_GH = ℏH/(2πk_B)` | 代数等分 `E = T·S` | 因果视界 `R_c` | **预言 λ = 1** |

两个包不是"谁对谁错"，而是**不同的热力学结构**：
- 标准包把热力学与动力学绑死（第一定律 ⟺ Friedmann），代价是 λ 自由。
- 框架包把热力学与几何绑死（E = TS ⟹ λ=1），代价是热/功分解不成立。

想两者兼得？需要 `W = −ρ_E/3`（**负**工作密度）。框架等分隐含的正是这个数：
数值上 `W_frame = S·dṪ/V̇` 在各红移**恒等于 −ρ_E/3**，而 GR 的 `W = (ρ_E−p)/2 ≈ +0.84 ρ_E`。
**分歧在符号**：框架是"视界膨胀降温"（`S dT < 0`），标准定律是"压强做正功"（`W dV > 0`）。

## 四、代价与收益（必须点名）

**收益**：λ = 1（k = 0，Ω_K ≡ 0），且已证明该结论**不依赖熵归一化 ξ**。

**代价**：框架**放弃了"由视界热力学推出 Friedmann"这条路**。
因为那条路（第一定律）选定的温度是 `T_Kodama`，而框架用的是 `T_GH`。

**这不是矛盾，而是自洽**：框架本来就没有导出 Friedmann（它把 `ρ_c = 3H²/8πG`
当输入用）。现在的发现说明这个缺口**不是暂时的**——

> **方向性结论：Friedmann 必须从 A1/A2 的微观物理推（泄漏 ε(E) 与膨胀的耦合），
> 不能从视界热力学推。视界热力学这条路对框架是封死的。**

## 五、这也解释了 09-12 那个 217σ

09-12 记录："Kodama 温度被观测否证（217σ）"。现在看懂了：
- Kodama 温度**作为第一定律的温度是对的**（它让 dE = TdS + WdV 成立，⟺ Friedmann）。
- 但它**作为框架等分 `E = T·S` 的温度是错的**（给出 λ = (1−3w)²/16 ≠ 1）。
- 两者不冲突：一个温度管"热/功账"，另一个管"等分账"。框架认定等分账在因果视界上、
  用 GH 温度；热/功账框架**根本不要求成立**。

## 六、遗留

1. 弯曲情形的完整 Kodama 温度表达式需补（本轮只验证了平直）。
2. 框架若想同时兼容第一定律，必须构造出 `W = −ρ_E/3` 的物理机制——
   一个**负**工作密度在框架里对应什么？（候选：通量亏损的反向贡献 / 视界"制冷"）
3. **Friedmann 必须改从 A1/A2 微观物理推**（见第四节）。
