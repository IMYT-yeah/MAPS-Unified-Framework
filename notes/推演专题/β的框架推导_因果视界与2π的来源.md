## 二、修复：换"因果视界"，不用"表观视界"

框架自己的视界概念来自**风暴本身**，不是 GR 的俘获面。

### BX-1（因果视界定理）
框架的微观速度是 `c`（对风暴组分的传播速度）。均匀膨胀的运动学恒等式是
`v_rec = H·r`（精确，**与 k 无关**）。风暴成分无法回传的界面在

$$R_c = \frac{c}{H}$$

这不是"假设 k=0"。表观视界 `R_A = c/(H√λ)` 是另一个面，两者只在 λ=1 时重合。

### BX-2（表面引力配平）
在 `R_c` 上取 de Sitter 型表面引力：

$$\kappa = \frac{c^2}{R_c} = cH$$

（等价说法：速度梯度 `dv/dr = H`，乘以风暴微观速度 `c` 得加速度 `cH`。）

### BX-3（目标结论）

$$k_B T = \frac{\hbar\kappa}{2\pi c} = \frac{\hbar H}{2\pi}\quad\Longrightarrow\quad \beta \equiv \frac{k_B T}{\hbar H} = \frac{1}{2\pi}$$

**注意 β 与 λ 无关**——这是关键：它不再是一个待拟合参数。

### BX-4（全息能账 ⟹ λ = 1）
在 `R_c` 内：`E = (4π/3)ρ R_c³ c² = λ·c⁵/(2GH)`（含 λ）；
`N = π(R_c/l_P)²`，`k_B T = ℏH/(2π)` ⟹ `N k_B T = c⁵/(2GH)`（**不含 λ**）。
令 `E = N k_B T`：

$$\boxed{\lambda = 1}$$

代数的：左边正比于 λ，右边不依赖 λ，相等即定 λ。

### BX-5（自洽性）
λ = 1 ⟹ `R_A = c/H = R_c` ⟹ 因果视界 = 表观视界 = 内质量的史瓦西半径 ⟹
**"黑洞宇宙"条件自动成立**（不再是 09-11 那个"待解释的巧合"）。
