### ⚠️ C-67（本轮核心负面产出）：两处独立的空转

**(A1) `ω/k = 1.0000` 是恒等式。** `_u1_spin2.py` 第 70 行原文：

```python
omega = k  # ω=|k| 无质量光子
...
print(f"    验证: ω/k = {omega[5]/k[5]:.4f} ≈ 1 (所有 k) ⟹ 线性色散 ✓")
```

变量 `omega` 被**直接赋值为 `k`**，然后验证 `omega/k == 1` —— 这是 `x/x = 1`。**零内容。**

**(A2) `0.9999` 是长波泰勒展开的舍入值。** `_z2u1_spin2_4d.py` 只打印 4 位小数：

```
k = 0.05 → ω = 2√(3sin²(k/2)) = 0.086593519562
           |k| = √3·k          = 0.086602540378
           ω/|k|               = 0.999895836588  →  打印 0.9999
```

而 `ω/|k| = 2sin(k/2)/k = 1 − k²/24 + O(k⁶)` —— **论文的 0.9999 就是 `1 − 0.05²/24` 的四舍五入**。

⚠️ **附带发现：该脚本两个约定混用** —— `w_k` 里的 `k` 当**分量**、`k_abs = √3·k` 当**沿方向**的模，
两者口径不一致（严格应为 `sinc(k/(2√3)) = 1 − k²/72`，而不是 `1 − k²/24`）。

**(A3) 框架内容 = 0。** 逐项清点色散公式的推导链：

| 实际用到的输入 | 性质 |
|---|---|
| 离散 Laplace 算子 ∇²_lat 的定义 | 格点场论标准 |
| 高斯积分（线性化 cos θ ≈ 1 − θ²/2） | 初等微积分 |
| sin x ≈ x（长波） | 泰勒展开 |

看似相关、**实际不进入推导**的框架元素：Z₂ ⊂ U(1) 群嵌入（群论事实）、Villain 紧致化（标准结果）、
弦网配对阶数 n = 1（只定「涌现 U(1)」而非色散）、衬底立方几何（**只影响四阶伪影**）。

⟹ **「长波 ω=|k|」不是框架的预言**，而是**任何**格点规范理论的共同性质。
框架对它的全部贡献 = **把格点选成简单立方**（第 30 轮 T-6），且该选择**只影响四阶**。

## 三、严格化（本轮的正面增量）

### 3.1 定理（MW-3）：方向无关的显式误差界

设三维立方格点（a = 1），`ω(k) = 2√(Σ_i sin²(k_i/2))`，`0 < |k| ≤ √12 = 3.4641`。则

$$0 \;\le\; 1 - \frac{\omega(k)}{|k|} \;\le\; 1 - \sqrt{1 - \frac{k^2}{12}} \;\le\; \frac{k^2}{12},$$

且上界的**最坏方向是 [100] 型**（只有一个分量非零），该处界**紧**。

**证明**：
1. `|sin y| ≤ |y|` ⟹ `4sin²(x/2) ≤ x²` ⟹ 逐分量求和给 `ω² ≤ k²`（左边不等式）；
2. 对 `0 ≤ y ≤ π/2`：`sin y ≥ y − y³/6`（因 `d/dy[sin y − y + y³/6] = cos y − 1 + y²/2 ≥ 0`）
   与 `|sin y| ≤ y` 得 `sin²y ≥ y²(1 − y²/6)² = y²(1 − y²/3 + y⁴/36) ≥ y² − y⁴/3`
   ⟹ `4sin²(x/2) ≥ x² − x⁴/12`；
3. `Σ_i k_i⁴ ≤ (Σ_i k_i²)² = k⁴`（交叉项 `2Σ_{i<j}k_i²k_j² ≥ 0`）
   ⟹ `ω² ≥ k² − k⁴/12 = k²(1 − k²/12)` ⟹ `ω ≥ |k|√(1 − k²/12)`；
4. `1 − √(1−ε) = ε/(1+√(1−ε)) ≤ ε` ⟹ 结论。∎

**数值验证**（MW-3）：7 个 `|k|` × 400 个随机方向 = **2800 个点**，
`max(实测偏差/界) = ` **99.59%** ⟹ 界成立且**接近紧**；最坏方向确为 `[±0.006, 1.000, 0]`（= [100] 型）✓

⟹ **这是对「长波 ω→|k|」的真正严格化**：不再依赖「数值看上去是 0.9999」，
而是对**任意方向、任意 `0<|k|≤√12`** 给出**定量**上界。

### 3.2 各向同性的**分层**结论（MW-5 / MW-6）

用立方群 `O_h`（48 元 = 6 坐标置换 × 8 符号翻转）的**表示论**判定：

| 阶 | 空间 | `O_h` 不变子空间维数 | 结论 |
|---|---|---|---|
| **二阶** | `Sym²(T₁)`（6 维：xx,yy,zz,xy,xz,yz） | **1** | ⟹ 任何 `O_h` 不变的二次作用量必为 `M_ij = c·δ_ij` ⟹ **光速 c 自动各向同性** —— **定理** |
| 四阶 | `Sym⁴(T₁)`（15 维） | **2** | ⟹ 四阶修正有**两个**独立不变量（`(k²)²` 与 `Σk_i⁴`），其比值依赖方向 ⟹ **四阶必然各向异性** |
| 全阶 | — | — | 各向同性**只能靠连续极限**（世界级；论文已诚实标注） |

**二阶各向同性为什么是定理**：`Sym²(T₁)` 对 `O_h` 分解为 `A_1g ⊕ E_g ⊕ T_2g`，
其中**一维的只有 `A_1g`** ⟹ 不变子空间一维 ⟹ `M_ij ∝ δ_ij`。
**关键**：只需要**立方**对称（不需要连续旋转）—— 这正好是格点能提供的全部对称性。

**四阶各向异性为什么不可避免**：`(k²)²` 与 `Σk_i⁴` 都在 `A_1g` 里（都 `O_h` 不变），
但 `Σk_i⁴/(k²)²` 沿 [100] 为 **1**、沿 [111] 为 **1/3** ⟹ 比值依赖方向 ⟹ 任何一个不变量的组合都不各向同性。

**数值印证**（MW-4）—— `ω²/k² = 1 − (1/12)·(Σk_i⁴/k⁴) + O(k⁴)`，四阶系数：

| 方向 | `Σk_i⁴/k⁴` | 数值系数 | 解析 |
|---|---|---|---|
| **[100]** | 1 | 0.0833322 | **1/12**（偏差最大） |
| [110] | 0.5 | 0.0416664 | 1/24 |
| **[111]** | 1/3 | 0.0277777 | **1/36**（偏差最小） |

**[100] 与 [111] 差 3 倍** ⟹ 格点色散在四阶明确各向异性。

## 六、诚实边界（必须一起读）

1. **本轮的正面产出是「把一条恒等式换成一条定理」，不是新物理。** 二阶各向同性在任何晶格场论教科书里都有（Bloch 定理 + 立方点群的二次不变量），本轮的价值在于**把它写成框架能用的形式并给出显式的、方向无关的误差界**，且**逐项验证了它不依赖框架**。
2. **框架的麦克斯韦谱内容 = 0**（MW-10）。若论文要声称「涌现麦克斯韦」，**唯一非平凡的一环是「连续极限」**（世界级），其余（长波线性色散、2 个横向极化）**是所有格点规范理论的共同性质**。
3. **界只在 `|k| ≤ √12` 内声明** —— BZ 内 `|k|` 最大 `π√3 = 5.441`，超出部分本就不是长波。
4. **MW-8 的「3 支 → 2 支」依赖连续极限**，与 MW-6 是同一个缺口的两面，**不得**写成「框架推出 2 个横向极化」。
5. 本轮**未**验证：`ω` 的高阶（六阶及以上）系数、非立方格点的情形、以及「自旋 2」那条线（属另一议题，第 54 轮已判该特征不判别）。
