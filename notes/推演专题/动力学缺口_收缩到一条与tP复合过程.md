# 动力学缺口：从两条收缩到一条，且微观模型要求一个 t_P 复合过程

> 日期：2026-09-17 ｜ 核验脚本：`_dynamics_probe.py`（纯标准库，DY-1…DY-5 全绿）
> **一句话：缺口没原来那么大（两条 ⟹ 一条），但真缺的东西变了——

## 一、DY-1：连续性 ⟺ 加速度（缺口两条 ⟹ 一条）

约束方程 `ρ = 3H²/(8πG)` 上一轮已经导出。对它求导：

$$\dot\rho = \frac{3H\dot H}{4\pi G}$$

代入连续性 `ρ̇ = -3Hρ(1+w)`：

$$\frac{3H\dot H}{4\pi G} = -3H(1+w)\frac{3H^2}{8\pi G}\quad\Longrightarrow\quad \dot H = -\tfrac32(1+w)H^2$$

于是 `ä/a = Ḣ + H² = -½(1+3w)H² = -(4πG/3)(ρ+3p/c²)` —— **就是加速度方程**。

数值（w = −1 / −0.6889 / 0 / 1/3）：两条路给出的 `ä/a` 之比恒为 `1.000000000000`。

⟹ **给定约束方程，连续性与加速度等价。框架只需再补一条，不是两条。**

## 二、DY-2：对 `E = T·S` 求导是恒等式（此路封死）

上轮我说"候选入口是把等分账对时间求导"——试了，**不通**：

```
dE/dt             = 8.465625756e+51
T dS/dt + S dT/dt = 8.465625756e+51     比值 1.000000000000
```

`dE = T dS + S dT` 就是 `E = T·S` 的微分，**恒等**，不产生任何新约束。
⟹ 别再往这条路撞。动力学必须来自别处：**组分状态方程，或 A2 的泄漏率**。

## 三、DY-3：微观模型的生产率自洽性检查（**发现问题**）

用微观模型自己的参数反算生产率：

| 量 | 值 |
|---|---|
| `Γ = c/l_P⁴` | 4.393×10¹⁴⁷ m⁻³s⁻¹ |
| `ε_eff = 1/N` | 1.397×10⁻¹²² |
| `Π = Γ·ε_eff·E_P` | **1.201×10³⁵ J m⁻³ s⁻¹** |
| `3Hρ_E`（膨胀稀释率） | 5.084×10⁻²⁷ J m⁻³ s⁻¹ |
| **比值** | **2.36×10⁶¹** |

**生产率超出稀释率 61 个量级。** 若没有复合过程，ρ 会在一个哈勃时内涨到 10⁵² J/m³，
而不是观测的 10⁻⁹。⟹ **上一轮那个"给出正确标度 ρ ∝ H²"的微观模型，其实不自洽。**

## 四、DY-4：引入复合时标 τ ⟹ 唯一出路是 τ = t_P

稳态：`ρ̇ = Π - ρ/τ - 3H(ρ+p)` ⟹ `ρ_E = Πτ / (1 + 3Hτ(1+w))`

| τ | 稳态 ρ_E | 相对 ρ_crit |
|---|---|---|
| **t_P（普朗克时标）** | 6.474×10⁻⁹ J/m³ | **8.377580** ✓（= 8π/3） |
| 1/H（哈勃时标） | 1.369×10⁵² J/m³ | 10⁶¹ ✗ |

且精确成立：`Π·t_P = ρ_P/N`（核验 `6.474385857e-09 = 6.474385857e-09`）。

⟹ **框架需要一个普朗克时标的复合过程**，否则微观模型自相矛盾。
⟹ **物理读法**：风暴以速率 Π 处理能量，每份只停留 `t_P` ⟹ 存量 `ρ = Π·t_P`。
   这不是"稳定物质"的图像，是**风暴自身存量**的图像——与 A1「湮灭-再生循环」一致。

## 五、DY-5：准静态条件极好，且所有 H 依赖都归到一个无量纲量

```
3H·t_P = 3.55×10⁻⁶¹ ≪ 1        ⟹ 稳态近似 ρ ≈ Πτ 的修正是 O(10⁻⁶¹)
H·t_P  = 1.18×10⁻⁶¹ = l_P/R_c = 1/√N
```

**⟹ 一切对 H 的依赖，都是 `H t_P = l_P/R_c = 1/√N` 这个无量纲量的幂次。**
这是个有用的组织原则：微观模型给 `ε_eff = 1/N = (H t_P)²`，所以 `ρ ∝ (H t_P)² × ρ_P ∝ H²`。

## 六、所以到底缺什么（结论修正）

| 旧说法 | 修正后 |
|---|---|
| 缺"动力学"（两条方程） | **只缺一条**；且对 `E=T·S` 求导这条路**封死** |
| 缺的是加速度/连续性 | 真正缺的是 **ρ 如何随 a 稀释**，即**组分与状态方程** |

具体说：有 `w` 就有 `ρ ∝ a^{-3(1+w)}`，配上已导出的 `ρ = 3H²/8πG` 就得到全部 `H(a)`。
**但框架现在的状态方程（w = 0 / 1/3 / −1）是从标准物理借来的，不是从 A1/A2 推出来的。**
⟹ 真正的开放问题是：**A2 的 `ε(E) = ε₀(M_Pl/E)^0.615` 能否推出宇宙的组分比例？**
