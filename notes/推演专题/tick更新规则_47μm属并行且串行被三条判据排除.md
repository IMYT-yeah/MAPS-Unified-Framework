# tick 的更新规则：47 μm 属并行，串行被三条独立判据排除

> 日期：2026-09-18 ｜ 脚本：`outputs/_tick_update_rule.py`（UP-1…UP-8，**19 项检查、失败 0**）
> 补丁：`outputs/_patch_tick_rule.py`（5 项）+ `_patch_tick_rule2.py`（2 项），中英同步、0 失败
> **一句话结论**：第 21 轮留下的问号解开——**47 μm 本来就是并行归一化的值**（第 21 轮贴错了标签）；
> 而并行不是选择，是被 **A1、A2、§4 三条独立判据强制**的：tick 的规则是「每 tick 每个格点恰好一次事件」，
> 实现 = 沿随机轴的二分图完美匹配交换 + **每线独立**随机相位。

---

## 一、先澄清问题：真正的二选一不是「串行 vs 并行」

第 21 轮把它表述为「串行（每 tick 一次对换）vs 并行（每格点各一次）」，并担心两者差 N 倍。这个表述**不准确**：

- **同步 / 异步**（是否同时更新、更新冲突怎么处理）**不改变任何物理量级**；
- 真正决定 `R_mix` 的是**每 tick 发生几次对换** —— 即"事件率归一化"。

| 归一化 | 每 tick 对换次数 | 每个诸元的事件率 |
|---|---|---|
| 「串行」（每 tick 全局一对） | 1 | `2/(N_c t_P)` |
| 「并行」（每格点恰一次） | `N_c³/2` | **`1/t_P`** |

两者相差 `N_c³/2 = 3.06×10¹⁸²` 倍。所以本轮的裁定对象是**每格点每 tick 是否必有一次事件**。

## 二、UP-1 口径辩识：47 μm 属于哪种归一化

把 47 μm 反推成步数：

| 量 | 值 |
|---|---|
| `t_H/t_P` | 8.4918×10⁶⁰ |
| 由 `R_mix = 47 μm` 反推的步数 `n = (R_mix/l_P)²` | 8.4562×10⁶⁰ |
| 相对差 | **0.42%** ✓ |

⟹ **47 μm 隐含「每 t_P 移动一步」**，即"每个诸元每 tick 一次事件"——**这是并行归一化的值**。
第 21 轮在同一段里把它标成「串行（每 tick 一次对换）」，**标反了**。

## 三、UP-2 三种归一化下的混合尺度

| 归一化 | `R_mix = l_P√(2n_tick/N_site)` | 值 |
|---|---|---|
| **并行**（每格点每 tick 一次） | `l_P√(t/t_P)` | **47.0989 μm** ✓ |
| 半速（每格点每 2 tick 一次） | — | 33.304 μm |
| 串行（每 tick 全局一次） | `l_P√(2t/(N_c³ t_P))` | **2.6917×10⁻⁹⁶ m** |

串行值 = `1.67×10⁻⁶¹ l_P` —— **比普朗克长度还小 61 个量级**。这不是"另一个可选方案"，是荒谬。
⟹ **47 μm 与并行归一化互相锁定**：保住 47 μm 就必须并行；取串行则 47 μm 无法成立。

## 四、UP-3 / UP-4 / UP-5 三条独立判据排除串行

| 判据 | 并行 | 串行 | 判决 |
|---|---|---|---|
| **A1 的 per-诸元事件率 `1/t_P`** | `1.854858×10⁴³ s⁻¹` ✓ | `6.058×10⁻¹⁴⁰ s⁻¹`（差 `10^182.49`） | ❌ 排除 |
| **A2 的泄漏份额 `ε₀ = 7.7×10⁻²⁰`**（per-事件量） | 直接可用 ✓ | 需放大 `3.06×10¹⁸²` 倍 ⟹ ε₀ ≫ 1 | ❌ 排除 |
| **§4.2 速度空间弛豫 ~4 次对换** | 4 t_P 内恰 4 次 ✓ | 4 t_P 内被交换概率 `1.31×10⁻¹⁸²` | ❌ 排除 |

三条判据的**共同根**：A1 的 `ν ~ 1/t_P` 是**单个诸元**的速率（A1 原文：「每个诸元每 t_P 湮灭-再生一次」）。
若每 tick 全局只发生一次对换，单个诸元平均要等 `N_c³/2` 拍才轮到一次——与 A1 差 182 个量级，
而 A2 的 `ε₀` 标定会被同步破坏（`ε₀` 是"一次事件里的泄漏份额"）。

**三条独立判据同向 ⟹ 并行归一化不是选择，是推论。**

（`N_c = R_c/l_P = 8.4918×10⁶⁰`、`N_c³ = 6.1236×10¹⁸²`。）

## 五、UP-6 并行的实现与数值验证

并行归一化要求「每格点每 tick 恰参与一次」，这在格点模型上等价于**二分图完美匹配**：3D 立方格是二分图，沿所选轴做 odd–even 配对即可（L 为偶数时两种相位都给出完美匹配）。数值检查：配对总数 `= N/2`、**每个格点恰好出现一次** ✓。

**数值验证**（L = 10、N = 1000 格点、2000 tick）：

| 检查 | 结果 | 判据 |
|---|---|---|
| 真空事件数（空格点） | **0** | = 0 ✓ |
| 每 tick 仍为置换 | 是 | ✓ |
| `⟨r²⟩` | **1981.28** | = n = 2000（偏差 −0.94%）✓ |
| `⟨x²⟩ : ⟨y²⟩ : ⟨z²⟩` | **672.92 : 694.19 : 614.17** | 各 ≈ n/3 = 666.67（3σ = 13.4% 内）✓ |
| 净漂移 `⟨x⟩` | 0 | ✓ |

⟹ **置换（双射）自动给出：诸元数守恒、每格点恒 1 个、真空零测度、可逆 ⟹ 底层无熵产生**（与第 21 轮一致）；
并行归一化在此之上补上「每格点每 tick 一次事件」，于是 `⟨r²⟩ = n l_P²` ⟹ `R_mix = l_P√(t/t_P) = 47 μm`。

## 六、UP-6b / UP-7 三个必要条件（本轮新增两条）

「每 tick 每个格点一次事件」还不够——它只保证了**存在**一个配对，不保证动力学正确。数值上还发现三个必要条件：

**① 轴必须随机**（UP-7）：固定轴时 `⟨x²⟩` 仍按 n 增长，但 `⟨y²⟩ = ⟨z²⟩ = 0` ⟹ 只沿一维扩散，**各向异性**。
取 5 个种子：`⟨x²⟩` = 375.3 / 605.8 / 629.6 / 618.8 / 514.9，均值 **548.9**（期望 600，±20% 内）。

**② 相位不能固定**（UP-7）：相位固定时，粒子在轴上的奇偶角色被锁定——走一步即翻转奇偶，下一步便换回另一端，形成**二周期振荡**、位移有界：`⟨r²⟩ = 2`（600 tick，扩散值应为 600）。即 `⟨r²⟩/n = 0.33%`。

**③ 相位必须「每线独立」，不能全局统一**（UP-6b，**本轮的新发现**）：
即使每 tick 重抽相位，只要**全局共用一个值**（同一 tick 内所有线同侧），相位就与「轴」耦合成系统性取向模式：

| 相位模式 | `⟨x²⟩` | `⟨y²⟩` | `⟨z²⟩` | `⟨r²⟩/n` |
|---|---|---|---|---|
| 全局统一（种子 1,2） | 49 | 289 | 256 | **0.297** |
| 全局统一（种子 3,4） | 225 | 225 | 400 | **0.425** |
| **每线独立** | 672.9 | 694.2 | 614.2 | **1.00** |

⟹ 全局统一相位下动力学**被钉住**（`⟨r²⟩` 只有 n 的 30%~43%），且分量明显不均。
**「每线独立」是必需条件，不是实现偏好。**

> **归因说明（诚实记录）**：我最初把失败归因于「轴/相位交替抽样产生序列相关」，并做了一次 2×2 对照（相位模式 × 是否共用 RNG）。结果**否证了我的猜想**：决定性因素是**每线独立相位**，与 RNG 是否分离无关（共用/分离下 `⟨r²⟩` 分别 2386 / 594，但两者分量都不均）。也就是说，**先诊断出的原因之一是错的，靠对照实验纠正**。

## 七、UP-8 连带结论

1. **第 18 轮的「诸元微观恒以 c 运动」获得机制**：并行归一化下"每 tick 每诸元走一步"⟹ 微观速率 = `l_P/t_P = 2.997924228×10⁸ m/s`，与 c 相对偏差 `−1.17×10⁻⁷`（来自 `l_P`、`t_P` 各自舍入到 7 位）。第 18 轮的「`p_rev = m/m_Pl`」也接上了：它就是相邻对换**方向反转**的概率。
2. **§4 自洽**：弛豫时标 ~4 次对换 = `4 t_P = 2.1565×10⁻⁴³ s`，恰好是并行下"4 个 tick"，与 §4.2 的遍历性数值证据（麦克斯韦化 7.02%）一致。
3. **⚠️ 并行使 C-2 从「可选」升为「必需」**：并行归一化定义了**全局同时的 tick** ⟹ 衬底存在优先参照系。这正是第 18 轮 C-2 要抹掉的东西（普朗克尺度的绝对性不得泄漏到 1PN；§4.5b 的 PPN 参数 ξ, α₁, α₂, α₃ 全为 0）。⟹ **A1 的 50:50 与各向同性被派定了一个新职责。**
