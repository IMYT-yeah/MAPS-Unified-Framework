## 三、四个专项

### A. 精确平坦性（CD-4）：0 vs 暴胀的 ~10⁻⁵ —— **不可分**

| | 值 |
|---|---|
| 框架 | `Ω_K ≡ 0`（**精确**） |
| 暴胀类模型 | `\|Ω_K\| ≲ 10⁻⁵`（**不是 0**） |
| Planck+BAO | `Ω_K = 0.0007 ± 0.0019` |
| 差 / σ | **5.3×10⁻³** ⟹ 差比精度小 **8 个数量级** |

即使未来把 `σ(Ω_K)` 做到 10⁻⁵，也只能**勉强触及**该量级，而目前**没有这样的路线图**。
⟹ 「精确 0」与「暴胀的 10⁻⁵」**不可判别**（不是「将来可以」）。

### B. `w_a = 0`（CD-5）：**框架与 ΛCDM 共有**，不是框架独有

框架给 `w = −1 + 4ε/3 = −1 + 2ν`（`ν` 自由）⟹ **w 恒定 ⟹ `w_a = 0`**；
而 ΛCDM 给 `w = −1` 精确 ⟹ **也是 `w_a = 0`**。

⟹ **参数集关系**：`(w₀ = −1)` 是框架族的一个特例（`ν = 0`）⟹ **ΛCDM ⊂ 框架**。
⟹ ⚠️ 因此 §8.4 的那句「框架预测 `w = const`（`wa=0`）—— DESI/Euclid 可直接检验」
**不能读作「框架被已有数据判别」**：DESI DR2 那 3.3σ 压力是**框架与 ΛCDM 共同承担**的
（§8.4 原文确实已写「DESI 排除 ΛCDM 3.1σ」，但紧跟的「框架暗能量预言正被已有数据判别」
容易被误读为框架独有地被检验）。**本轮在 §8.4 加判别力标注。**

### C. 唯一数值不同的那条（CD-6）：若当预言，**已被排除到 118σ**

| | 值 |
|---|---|
| 框架（`ρ_Λ = E_c⁴/(ℏc)³`，`E_c = 1.0181 meV`） | `Ω_Λ = 0.0290` |

（这与第 2 轮的判决一致：作为量级机制保留、作为定量预言放弃）。⟹ **仍不构成判别点。**

### D. ⭐「哈勃球 = 史瓦西半径」是**恒等式**（CD-7）⟹ **C-17**

§8.6.3 写 `M = c³/(2GH₀)`、`R_S = R_c`（误差 <10⁻¹²），并称
「哈勃球 = 史瓦西半径：『黑洞宇宙』在此获得机制说明，**不再是数值巧合**」。代回去：

```
R_S = 2G·[c³/(2GH₀)]/c² = c/H₀ ≡ R_c        ← G 与 H₀ 全被消掉
```

数值验证（三个**任意** H₀）：相对差 0.0e+00 / 2.3e−16 / 0.0e+00 ⟹ **对任意 H₀ 恒成立**。
⟹ 它不是「巧合被解释」，而是**比巧合更弱：恒等式，零内容**（**陷阱 39** 家族 ——
与第 53 轮 `E_c ≡ 1 meV`（C-4）同一病症：**把中间参数代回去，结论里什么都不剩**）。

### E. ⭐ §8.4 的 `ε` 是 §8.1 的 `ε` 吗？（CD-8）⟹ **C-16**

- §8.1 的符号约定（行 1081）明写「本文的 `ε` 有**两个互不相干的含义**」，

## 四、结构性结论：为什么「找判别点」这个目标本身错了（CD-9）

框架的宇宙学输出可以写成**一个统一的形态**：

```
{ Ω_K = 0,  w_a = 0,  w₀ = −1 + 2ν（ν 自由）,  ρ = 3H²/8πG,  T = ℏH₀/2π }
```

而 ΛCDM 只是它 `ν = 0` 处的特例 ⟹ **ΛCDM ⊂ 框架**（作为允许的观测集）⟹
框架**比 ΛCDM 更不可证伪** ⟹ **不存在框架独有的宇宙学判别点**。

⚠️ **这与第 51 轮是同一个病**（**判据方向错了**）：

| | 目标 | 实际关系 |
|---|---|---|
| 第 51 轮（**N-13**） | 找 `H/N = 0.25` 的**等式**跨点 | 实为**不等式** `H/N ≤ 0.25` |
| **第 73 轮（N-29）** | 找框架与 ΛCDM 的**判别点** | 实为**包含关系** `ΛCDM ⊂ 框架` |

⟹ **铁律 4 的又一例**：写下 `X = Y` 或「可区分」之前，先问**这两者之间是什么关系**
（等式？不等式？包含？）。**问错了关系，就会白跑几轮。**

## 五、诚实边界（六条）

1. **本轮只有引文取证 ＋ 代数 ＋ 算术，没有新数值**（`R_S` 恒等式的数值验证除外）。
2. `Ω_Λ = 0.0290` 的出处是**第 2 轮的账**（`ρ_Λ = E_c⁴/(ℏc)³`）；本轮只做**σ 换算**，
   **未重新导出**它。σ 取 Planck 2018 的 `Ω_Λ = 0.6889 ± 0.0056`（**外部锚点**）。
3. **`ν` 是否被框架固定，本轮未定**。若将来框架能**唯一**定出 `ν ≠ 0`，则 `w = −1 + 2ν` 会成为
   **真判别点**（能分开框架与 ΛCDM）—— 但那需要 `ν` 有独立约束，而**目前没有**（这正是缺口）。
   ⚠️ 本轮结论的正确表述是：**「在框架目前的表述下」不存在判别点**。
4. **「ΛCDM ⊂ 框架」是按背景量（`Ω_K`、`w`）说的**；扰动层（功率谱等）**框架根本没进**，
   所以谈「包含」在那里没有意义（不是「框架也包含」）。
5. 「暴胀给 `|Ω_K| ≲ 10⁻⁵`」是**文献量级**，不是精确定理（具体数值依赖模型）。
6. **C-17 的措辞留有余地**：`R_S = R_c` 是恒等式，**但** §8.6.3 的等分账推出 `ρ = 3H²/8πG`
   （即平坦性）仍是**有内容的**（它不假设 Friedmann）⟹ 本条更正的是
   **「黑洞宇宙 = 机制说明」这一句话**，不是第 8.6.3 节整体。
