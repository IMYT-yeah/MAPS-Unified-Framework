## 一、一句话结论

框架在 §2.2 **已有**守恒流 `∇·J = 0`（微变权流），而 §8.6.3 的弗里德曼对**依然缺**。
原因不是「还没推导」，而是：

> **等分账的 `ρ` 是「约束」（恒满足 `ρ = 3H²/8πG`），而守恒流 `J^μ` 是「计数」（不带 `p`）——

**硬要在面上写能量守恒，框架会给出一个零自由参数的预言：`w = −1/3`** ——

⟹ **C6 结项**（登记 **I-20**）：缺的**不是方程，是对象**（第 4 种失败形态：**分层**）。

## 二、四条实质结果

### ⭐ 结果 A：等分账**恒成立** ⟹ `Ω_K ≡ 0`（「恒平」，不是「今天平」）

§8.6.3 的等分账 `(4π/3)ρ(c/H)³c² = [π(c/H)²/l_P²]·(ℏH/2π)` 的输入**只有同时刻的 `H`**
（面半径 `R = c/H` 与温度 `T = ℏH/2πk_B`），**没有一处用到 `H = H₀`**。逐点验证：

| `H` | `ρ = 3H²/8πG` | `(4π/3)ρR³c²` vs `N·k_BT` 相对差 |
|---|---|---|
| `H₀` | 8.5987×10⁻²⁷ | 3.7×10⁻¹⁶ |
| `2H₀` | 3.4395×10⁻²⁶ | 3.7×10⁻¹⁶ |
| `0.5H₀` | 2.1497×10⁻²⁷ | 3.7×10⁻¹⁶ |

⟹ **等分账在任意 `H` 上恒成立**，故 `Ω_tot(t) ≡ 1` ⟹ **`Ω_K ≡ 0` 是「恒为 0」而非「今天恰好为 0」**，
且 **`ρ ∝ H²`**。
⚠️ **诚实边界**：论文只在 `t₀` 上写这条等式 ⟹ 「任意 `t`」是**自然外推**，不是论文原话。
（但这是**纯框架内部**的加强，不依赖数据 —— 与第 73 轮「`Ω_K = 0` 无判别力」不冲突。）

### ⭐⭐ 结果 B：硬写守恒 ⟹ `w = −1/3`（零自由参数）

面上的总能量与体积都是 `H` 的函数：

```
E(H) = N·k_BT = [πR²/l_P²]·[ℏH/(2π)] = ℏc²/(2l_P²H)      ⟹  E ∝ 1/H
V(H) = (4π/3)R³ = (4π/3)(c/H)³                            ⟹  V ∝ H⁻³
```

若要求 `dE = −p dV`（面上绝热守恒）：

```
p = −(dE/dH)/(dV/dH) = −ℏH²/(8π l_P² c)        ⟹ 负压
w = p/(ρc²) = [−ℏH²/(8πl_P²c)] / [3H²c²/(8πG)] = −ℏG/(3 l_P² c³) = −1/3
```

**`ℏ`、`G`、`c`、`H₀` 全部消掉** ⟹ **`w ≡ −1/3`，零自由参数**（数值 −0.3333333333，
与解析式相对差 0.0e+00）。
自洽性反算：`Ḣ = −4πG(ρ + p/c²) ≡ −H₀²`（相对差 1.4×10⁻¹⁶）⟹ `H = 1/t`、`a ∝ t`，与 `ρ ∝ a⁻²` 自洽 ✓。

### ⭐ 结果 C：`w = −1/3` 恰好是**曲率标度** ⟹ 等分账的 `ρ` **不是物质**

`w = −1/3` ⟹ `ρ ∝ a^{−3(1+w)} = a^{−2}` —— 这正是**曲率项**的稀释律。
在一个**平**宇宙里，**没有任何守恒物质**按 `a⁻²` 稀释（物质 `a⁻³` / 辐射 `a⁻⁴` / `Λ` 常数）。
⟹ **等分账的 `ρ` 只能是「约束」，不能是「守恒流体」**。

### ⭐ 结果 D：与观测对照 —— 这条路被排除

| | 值 |
|---|---|
| 框架（等分账 ＋ 面上守恒） | **`w = −1/3 = −0.333333`** |
| 观测（DESI 2024+CMB，§8.4 引） | `w = −1.028 ± 0.031` |
| 偏差 | **0.6947 ⟹ 22.4σ** |

## 三、⭐ 核心：**两个 `ρ` 不接**（判据：同行共现 **0** 次）

| | §2.2 的 `J^μ`（微变权流） | §8.6.3 的 `ρ`（等分账） |
|---|---|---|
| 性质 | **守恒**（`∇_μ J^μ = 0`） | **约束**（`ρ = 3H²/8πG` 恒成立） |
| 是什么 | **湮灭事件计数**测度（`W[Σ] = ∫J·dΣ`） | **质量密度**（由面热力学 `N·k_BT` 定） |
| 带 `p` 吗 | **不带** ⟹ 写不出 `ρ̇ + 3H(ρ+p/c²) = 0` | 带 ⟹ 但守恒会强制 `w = −1/3`（22.4σ） |

**判据（最省形式）**：「`J^μ` / 微变权」与「`3H²/8πG`」**在同一行共现 0 次**
⟹ **框架从未把两者连起来**（接口从未被写过）。

⟹ 弗里德曼对需要 **一个既守恒、又是约束的 `ρ`**；框架有的是**两个不同的 `ρ`**
——**缺的不是方程，是对象**（**分层**：两层各自完备、缺接起来的算符）。

## 四、附带的两个口径发现

### C-21：`ρ` 至少 **5 义**、`w` 至少 **2 义**，**均无符号约定**

- `ρ`：`ρ_pair`（事件率密度，§2.2）｜`ρ_raw`（原始涨落密度，§8.2）｜**等分账的 `ρ`（质量密度，§8.6.3）**

- `w`：§8.4 的 `w = −1 + 4ε/3`（**暗能量分量**，来源 = `E_c` 漂移） vs 本轮的 `w = −1/3`

⚠️ 本节**不主张两者矛盾**（它们是不同对象），只主张**引用时必须写明是哪一个**。
与 §8.1 的 `ε`（两义、已约定）、§8.6 的 `λ`（已约定）**同类** ⟹ 与 **C-16 / C-15** 同族（第三次）。

## 五、诚实边界（六条）

1. **结果 B 加了一条框架自己没有的假设**（面上绝热守恒 `dE = −p dV`）。本轮的用法是
   **反证**：「**若**要在面上写守恒，**就**必然得到 `w = −1/3`（22.4σ）」——
   **不是**说框架预言 `w = −1/3`。
2. **结果 A 的「任意 `t`」是外推**（论文只写 `t₀`）。
3. **`s`/`p` 的单位**：全部用 SI（`p` 单位 Pa = J/m³）核对过；解析式与数值解相对差 0.0e+00。
4. **`w` 的观测值**取自论文 §8.4 引的 DESI 2024+CMB（**外部锚点**），本轮未独立核对文献。
5. **本轮不重开第 73 轮**：`Ω_K = 0` 仍**无判别力**（与 ΛCDM 同值）；结果 A 的加强是**逻辑**上的
   （「恒为 0」），不是观测上的。
6. **本轮不主张 `J^μ` 错了** —— 它是**事件计数**的守恒流，本身没问题；
   问题在**没人把它与等分账的 `ρ` 连起来**。
