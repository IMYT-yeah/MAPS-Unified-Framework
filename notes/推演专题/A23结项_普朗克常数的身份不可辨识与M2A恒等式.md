## 一、一句话结论

**框架给不出 `ℏ` 的独立身份 —— 但准确的说法不是「不是基本常数」，而是「不可辨识」**：
框架对 `{ℏ, G, l_P}` 只有 **1 个可辨识组合**（`Gℏ/c³ = l_P²`），**自由度 = 2**；
而它的核心链（λ = 1 的等分账）里 **`ℏ` 逐项抵消** ⟹ **框架从未在任何可观测处「看见」`ℏ` 的数值**。
附带查出 v1.17 那处「**普朗克常数** `M²/A = c⁴/(16πG²)`」是**误标**（**C-77**）：量纲不对、表达式不含 `ℏ`、
而且是 **GR 的代数恒等式**（零框架内容）。

## 三、判据与数值表

### 3.1 ⭐⭐ C-77：`M²/A = c⁴/(16πG²)` 不是「普朗克常数」（三处对不上）

| 检验 | 结果 | 判据 |
|---|---|---|
| **量纲** | `c⁴/(16πG²)` = **(2, −2, 0)** = **kg²/m²** ｜ `ℏ` = **(1, 2, −1)** = **kg·m²/s** | **不同量纲**（C-72 同族） |
| **是否含 `ℏ`** | 把 `ℏ` 当符号代入 ⟹ **指数 0** | 与 `ℏ` 无关 |
| **是不是 GR 恒等式** | 由 `A = 4πr_h²`、`r_h = 2GM/c²` ⟹ `M²/A = c⁴/(16πG²)` **对任意 M 成立**；5 个质量（太阳 / M87\* / Sgr A\* / 地球…）实测与 `M²/(4πr_h²)` 的**最大相对差 2.9×10⁻¹⁶** | **零框架内容**（**C-17** 同族：哈勃球 = 史瓦西半径是恒等式） |

数值 `c⁴/(16πG²)` = **3.6075×10⁵²** kg²/m²（论文写 3.6×10⁵² ✓）。

⚠️ **连带两处**（同一块内）：

1. 「`A = 16πG²M²/c⁴ ⟹ r_h = 2GM/c²`（精确）」是**循环** —— 那个常数**就是**用史瓦西面算出来的：
   由它反解 `r_h` 得 2.954127×10³ m，与输入**逐位相同**（A23-3c）⟹ 它**不能**用来「验证」`r_h`。
2. 末句「`α = 1` 获得**双重来源**（熵一致性 ＋ `M²/A` 普朗克临界）」中**第二条不是独立来源**
   （它无任何框架元素）⟹ **应降为 1 条**（热力学路径）。
   📌 **同族「同源误计为两条」第 3 次**：**C-6**（F2 降标 @ 哈勃半径 ≡ 锚点 2）／
   **C-45**（EMRI 四项同源按 1 条计）。

### 3.2 ⭐⭐⭐ N-41：`ℏ` 的身份**不可辨识**

**主判据（铁律 5：观测锚点 ≥ 待定参数）**

```
框架自有关系：  R1  c = l_P/t_P        （置换动力学）
                R2  l_P² = Gℏ/c³       （普朗克面积的定义）
未知：          c, t_P, l_P, G, ℏ      （5 个）
c 另有外部实测值 ⟹ 剩 {l_P, G, ℏ} 三个未知、一条关系 ⟹ 自由度 = 2
⟹ 观测量 1  <  待定量 2   ⟹ ℏ 不可独立确定
```

⟹ **`ℏ` 与 `G` 只是同一个自由度的两种记账。** 论文 §4.8 那句「`G、ℏ` 作为普朗克面积
`l_P² = Gℏ/c³` 的**复合出现**（非基本常数，是事件流最小尺度的**导出量**）」——
**该式本身就是 `l_P` 的定义** ⟹ 它是**记号陈述**（把 `S = A c³/(4Gℏ)` 改写成 `A/(4l_P²)`），
**不是推导**；标【推导】不成立。

**第二判据（可判定）**：「`ℏ` 是导出量」⟺「框架给了 `l_P` 一个**不依赖 `ℏ`** 的独立数值」。

| 检验 | 结果 |
|---|---|
| 全文 `l_P = <数值> m` | **1 处**（附录参数表：`1.62×10⁻³⁵ m`） |
| 该数值是不是独立的？ | **不是** —— 自洽复算 `√(Gℏ/c³)` = **1.6163×10⁻³⁵ m** ⟹ 它**就是**普朗克长度 |
| 其余 `l_P = <数>` 的 3 处 | 是**系数/比值**（`√3 l_P = 1.7321 l_P`、`N_c = R_c/l_P = 8.49×10⁶⁰`），**不是 l_P 的数值** |

⟹ **「`ℏ` 是导出量」无支撑。**

### 3.3 ⭐ 本轮定量产出：λ = 1 链里 **`ℏ` 逐项抵消**

§8.6.3 的等分账推导（框架的核心结论）：

```
E = N·k_BT ,   N = πR_c²/l_P² ,   k_BT = ℏH₀/(2π) ,   l_P² = Gℏ/c³ ,   R_c = c/H₀
⟹ E = R_c²·H₀·c³/(2G)      ← 不含 ℏ
⟹ ρ = 3H₀²/(8πG)          ← 不含 ℏ
```

**数值验证**（A23-4）：取 `ℏ → t·ℏ`（`t` = 0.5 / 1 / 2 / 10 / 10⁶）并**同步重算** `l_P² = Gℏ/c³`，
`ρ` **逐位相同**（最大相对差 **2.2×10⁻¹⁶**；解析值 `3H₀²/(8πG)` = 8.5972×10⁻²⁷，
数值 8.5972×10⁻²⁷，论文值 8.5983×10⁻²⁷）。

⚠️ **反面读法同样成立**：若把 `l_P` 当作**固定输入**而只改 `ℏ`，则 `ρ ∝ ℏ`
（`t` = 2 与 0.5 之比恰为 **4.000000**）⟹ **两条读法都只锁住组合 `Gℏ/c³`**。

⟹ **该链对 `ℏ` 完全不敏感** ⟹ 它**不能**为 `ℏ` 的身份提供任何信息；这里 `ℏ` 是**输入**
（§8.6.2 已把 `1/4` 与 `β` 标为「**标准物理输入**」）。

### 3.4 ✅ 分层结论（本轮唯一正面产出）

| 常数 | 在框架里的身份 | 依据 |
|---|---|---|
| **`c`** | ✅ **输出** | `c = l_P/t_P`（置换动力学 → 状态图案每拍平移一格）——真推导 |
| **`ℏ`** | ⛔ **不可辨识** | 只以组合 `Gℏ/c³` 出现；自有推导中抵消；其余出现是标准公式引用 |
| **`G`** | ⛔ **输入** | 线性区匹配 GR / PPN（`α = 1 ⟹ G_eff = G`）；无框架内独立推导 |

📌 另外：涉及 `ℏ` 的**其余**式子（Hawking 温度 `ℏc³/(8πGMk_B)`、Compton `ℏc/m`、`ℏω_c`、
`ℏH₀/2π`、`E_c⁴/(ℏc)³`）**都是标准外部公式的引用**，不经衬底推导 ——
它们只能说明「框架借用了 `ℏ`」，不能说明「框架定义了 `ℏ`」。

## 四、诚实边界

  ⚠️ 若将来框架新增一条把 `ℏ` 与衬底参数联系起来的关系（例如给 `t_P` 一个独立动力学来源），
  本条结论要重开。

    本轮用的是**独立复算**，与旧脚本互不依赖。
  - 没有把 §3.4 的身份表写进论文正文（只作备忘录 ＋ 口径注）—— 属**过程结论**，
    论文已有 §8.6.2 的「标准物理输入」标注覆盖输入侧。
- **【顺带发现（未修）】** §8.6.2 那句「`1/(2π)` 源自 F3 中那个『4』，**不是从 QFT 借来的**」与同节
