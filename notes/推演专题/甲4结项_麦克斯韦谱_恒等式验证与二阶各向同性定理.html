3.1 定理（MW-3）：方向无关的显式误差界

设三维立方格点（a = 1），ω(k) = 2√(Σ_i sin²(k_i/2))，0 < |k| ≤ √12 = 3.4641。则

0 le 1 - ω(k)|k| le 1 - √1 - k212 le k212,

且上界的最坏方向是 [100] 型（只有一个分量非零），该处界紧。

证明： 1. |sin y| ≤ |y| ⟹ 4sin²(x/2) ≤ x² ⟹ 逐分量求和给 ω² ≤ k²（左边不等式）； 2. 对 0 ≤ y ≤ π/2：sin y ≥ y − y³/6（因 d/dy[sin y − y + y³/6] = cos y − 1 + y²/2 ≥ 0） 与 |sin y| ≤ y 得 sin²y ≥ y²(1 − y²/6)² = y²(1 − y²/3 + y⁴/36) ≥ y² − y⁴/3 ⟹ 4sin²(x/2) ≥ x² − x⁴/12； 3. Σ_i k_i⁴ ≤ (Σ_i k_i²)² = k⁴（交叉项 2Σ_{i<j}k_i²k_j² ≥ 0） ⟹ ω² ≥ k² − k⁴/12 = k²(1 − k²/12) ⟹ ω ≥ |k|√(1 − k²/12)； 4. 1 − √(1−ε) = ε/(1+√(1−ε)) ≤ ε ⟹ 结论。∎

数值验证（MW-3）：7 个 |k| × 400 个随机方向 = 2800 个点， max(实测偏差/界) = 99.59% ⟹ 界成立且接近紧；最坏方向确为 [±0.006, 1.000, 0]（= [100] 型）✓
