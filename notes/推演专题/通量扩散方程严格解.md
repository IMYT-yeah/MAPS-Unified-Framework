## 一、推导链（严格化）

### 第 1 步：随机游走 → Fick 定律【推导】

公理 1：事件流各向同性随机，事件间距 l_P（普朗克尺度）、步频 ν = c/l_P。通量恢复 = 随机游走（每步 ±l_P，方向随机）。

一维随机游走的连续极限：粒子密度 ρ(x,t) 满足 Fick 第一定律 J = −D ∂ρ/∂x，扩散系数

$$D = \frac{l_P^2}{2t_P} = \frac{l_P \cdot c}{2}$$

（因子 1/2 来自 1D 随机游走方差 σ² = l_P²·N = l_P²·(t/t_P)，σ² = 2Dt ⟹ D = l_P²/(2t_P)。**注意：1D 随机游走给出 D = l_P·c/2，不是 l_P·c**——本推导精确化系数。）

### 第 2 步：扩散方程【推导】

Fick 第二定律（质量守恒 + Fick 第一定律）：

$$\frac{\partial \rho}{\partial t} = D \frac{\partial^2 \rho}{\partial x^2}$$

### 第 3 步：边界条件与初始条件【推导】

- 视界（x=0）为通量抽零面【原文 88–90】：ρ(0,t) = 0（Dirichlet 边界）；
- 初始：视界形成瞬间，外部通量仍为宇宙背景：ρ(x,0) = ρ∞（x > 0）；
- 远处：ρ(∞,t) = ρ∞。

### 第 4 步：误差函数解【推导·标准解】

上述初边值问题的解析解（标准扩散方程解）：

$$\rho(x,t) = \rho_\infty \cdot \text{erf}\left(\frac{x}{\sqrt{4Dt}}\right)$$

**验证**：erf(0) = 0（视界处 ρ=0 ✓）、erf(∞) = 1（远处 ρ=ρ∞ ✓）、满足扩散方程 ✓。

### 第 5 步：恢复时间与火墙厚度【推导】

- 恢复时间：通量从宏观尺度 R 恢复（信息传播时间）t_rec = R/c；
- 特征宽度：erf 过渡宽度（erf 参数 = 1 处 ρ = 0.8427ρ∞）δ ≡ √(4D·t_rec)；
- 代入 D = l_P·c/2、t_rec = R/c：

$$\delta = \sqrt{4 \cdot \frac{l_P c}{2} \cdot \frac{R}{c}} = \sqrt{2 l_P R} = \sqrt{2}\sqrt{R\,l_P}$$

**等等——系数修正**：D = l_P·c/2 ⟹ δ = √(4·(l_P·c/2)·(R/c)) = √(2·l_P·R) = √2·√(R·l_P)。

**精确结果**：δ = √2·√(R·l_P)（1D 随机游走精确系数 √2 ≈ 1.414）。

> 【诚实修正】我上一轮（F1）用 D ~ l_P·c 得 δ = 2√(R·l_P)；严格 1D 随机游走 D = l_P·c/2，给出 δ = √2·√(R·l_P)。两种口径同量级（系数 √2 vs 2），但严格推导（含 D 的 1/2 因子）给出 **δ = √2·√(R·l_P) ≈ 1.41√(R·l_P)**。
