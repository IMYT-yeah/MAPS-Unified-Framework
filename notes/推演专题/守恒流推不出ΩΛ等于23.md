# 守恒流方程推不出 Ω_Λ = 2/3（附原文两处内部不自洽）

> 日期：2026-09-17 ｜ 核验脚本：`_flow_omega.py`（FL-1…FL-5，纯标准库）
> **一句话：推不出。方程的不动点给 1/2，不给 2/3；2/3 是"保留因子"，
> 是另一个量。把 3.2% 的数值接近写成框架预言，目前不够格。
> 顺带查出原文的"稳态解"不是它自己 ODE 的不动点——两处内部不自洽，需修正。**

---

## 一、FL-1：严格解（令 S = J₊+J₋，D = J₊−J₋）

$$\frac{dJ_+}{dt} = -\tfrac13 J_+ + \tfrac13 J_- + \varepsilon\rho,\qquad
\frac{dJ_-}{dt} = -\tfrac13 J_- + \tfrac13 J_+ + \varepsilon\rho$$

$$\dot S = 2\varepsilon\rho \;\Longrightarrow\; S(t) = S_0 + 2\varepsilon\rho t \quad(\text{线性增长})$$
$$\dot D = -\tfrac23 D \;\Longrightarrow\; D(t) = D_0 e^{-2t/3}\quad(\text{指数衰减，时标 } 3/2)$$

**两枝都带 +ερ 源时，S 一直涨，系统没有不动点。**

## 二、FL-2：原文的"稳态解"不是这个 ODE 的不动点 ⚠️

原文称稳态解 `J₊_ss = (1/2+ε)ρ`、`J₋_ss = (1/2−ε)ρ`。代回：

$$\dot J_+ = \tfrac{\rho}{3}(-2\varepsilon) + \varepsilon\rho = \frac{\varepsilon\rho}{3} \neq 0$$

数值（把 ε 放大到 0.1 避开双精度抵消，方程对 ε 线性）：`dJ₊/dt = 0.033333 ρ = ερ/3` ✓。
换算回真实 ε=7.7e-20：`2.567×10⁻²⁰ ρ` —— **极小但不为零**。

⟹ **原文声称的稳态解不是其自身 ODE 的不动点。** 可能漏了汇项（如 `−(J₊+J₋−ρ)/τ`）。
**这是原文第一处内部不自洽，建议在批注中修正。**

## 三、FL-3：加归一化后的真正不动点（第二处不自洽）

若总量被约束为 ρ（`J₊+J₋ = ρ`，这也才让原文那个解的"和为 ρ"说得通）：

$$\dot D = -\tfrac23 D + 2\varepsilon\rho \;\Longrightarrow\; D^* = 3\varepsilon\rho
\;\Longrightarrow\; J_+^{ss} = \rho\left(\frac12 + \frac{3\varepsilon}{2}\right)$$

原文写的是 `ρ(1/2 + ε)` —— **差一个 3/2 因子**。第二处不自洽。

**但无论取哪个，不动点都给 ≈ 1/2，不是 2/3。**

## 四、FL-4：2/3 和 1/2 是两个不同的量

| | 含义 | 值 |
|---|---|---|
| **2/3** | 每周期**保留因子**（走掉 1/3 后剩多少） | 0.6667 |
| **1/2** | 两枝对称时的**稳态分支占比**（不动点） | 0.5 |

前者是"流失后的剩余"，后者是"平衡时的占据"。**定义完全不同，不能互相替代。**

若误把不动点当 Ω_Λ：`Ω_Λ = 0.5`，观测 0.6889 ⟹ **差 −27.4%**（比 2/3 的 −3.2% 差得多）。

## 五、FL-5：强行取 2/3 需要什么假设

| 步骤 | 内容 | 状态 |
|---|---|---|
| (a) | "本应"的总量 = ρ_crit | ✅ 由已导出的约束方程支持 |
| (b) | 跨枝转移后**留在本枝**的那份**就是**暗能量 | ❌ **假设，未导出** |

若 (b) 成立，另一半 1/3 应归物质：

| | 预测 | 观测 | 偏差 |
|---|---|---|---|
| Ω_Λ | 2/3 = 0.6667 | 0.6889 | **−3.2%** |
| Ω_m | 1/3 = 0.3333 | 0.3111 | **+7.1%** |

⚠️ **两者偏差方向相反**——Λ 偏低、m 偏高。若只是"分裂点挪了"，两者应同向。
⟹ **(2/3, 1/3) 与观测不是干净的分裂，两边都对不上同一个偏移。**

## 六、判决

❌ **Ω_Λ = 2/3 不能从守恒流方程推出。**

- 不动点给 **1/2**（对观测差 −27.4%），不给 2/3。
- 2/3 是**保留因子**，与稳态占据无关；把它当 Ω_Λ 需要未导出的假设 (b)。
- 即便接受 (b)，(2/3, 1/3) 分裂与观测**偏差方向相反**。

🔧 **顺带查出原文两处内部不自洽（应修正）**：
1. 声称的"稳态解"不是其自身 ODE 的不动点（代入后 `dJ₊/dt = ερ/3 ≠ 0`）——
   可能漏了汇项。
2. 加归一化后的真正不动点是 `1/2 + 3ε/2`，原文写 `1/2 + ε`（差 3/2 因子）。

## 七、对上一轮"2/3 安错组分"的修正

上一轮我建议把原文的 2/3 从"暗物质占比"改判为"暗能量占比"（3.2% vs 155%）。
**数值上的改判依然成立**（它确实对暗能量更近），但：

> **"改判"只是把存疑从一个组分挪到另一个组分，不等于"推导成功"。**
> 在找到把保留因子接到 Ω_Λ 的机制之前，它仍是**待解释的数值接近**。

建议措辞：论文的"存疑"状态**保留**，但把对照对象从 Ω_dm 改成 Ω_Λ，
并注明"偏差 3.2%，机制未明"。

## 八、要让它成为推导，还缺什么

1. **补上守恒流的汇项**，使其有真正的不动点（否则整个方程无稳态可谈）。
2. **说明为什么"留在本枝的那份"是暗能量**——需要把暗能量与"本枝真空能"挂钩。
3. **解释反向偏差**（Λ 偏低 3.2%、m 偏高 7.1%）——若只是分裂点问题，应同向。
4. 若以上无解，保持"数值接近、机制未明"的诚实标注。
