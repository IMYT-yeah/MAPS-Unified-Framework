> **方法**：解析分析 ρ 下限钳制模型 + 局部分析通量自引力修正量级 + 结合热平衡适用域（遗留④模拟 2 的发现）。

## 第二部分　饱和机制候选检验

### 2.1 候选一：ρ 下限钳制模型

【推导】通量密度不能为负（原文 46 页"吞灭有最大速率"），玻尔兹曼分布降到下限时被钳制：

$$\frac{\rho(r)}{\rho_\infty} = \max\big(e^{-x},\ \rho_{min}/\rho_\infty\big),\qquad x = \frac{GM}{c^2 r}$$

**光子球分析**（解析）：

| x_sat（饱和点） | r_sat | 光子球 | 与 GR 对照 |
|---|---|---|---|
| < 1（r_sat > GM/c²） | > a | **无光子球**（x=1 在饱和区，V_eff 单调） | ✗ |
| ≥ 1（r_sat ≤ GM/c²） | ≤ a | x=1（r=GM/c²） | ✗ 仍与 EHT 冲突 |

**结论**：ρ 下限钳制**不能恢复 GR 的光子球 3GM**——要么光子球仍在 1GM（冲突），要么消失。

### 2.2 候选二：通量自引力（Poisson-Boltzmann）

【推导】通量密度贡献能量密度 → 自引力 → 自洽方程：

$$u'' + \frac{2}{r}u' = \frac{8\pi}{l_P^2}e^{-u},\qquad u = \frac{\Phi}{c^2},\ s = \frac{r}{l_P}$$

**修正量级分析**（局部分析）：

| 量 | 太阳质量黑洞 |
|---|---|
| C = M/m_P | 9.12×10³⁷ |
| GR 光子球 3C | 2.74×10³⁸ l_P |
| 框架光子球 C | 9.12×10³⁷ l_P |
| 自引力修正尺度 | ~1 l_P（相对修正 ~10⁻³⁸） |

**结论**：自引力修正局限于普朗克尺度，宏观光子球仍 ~GM/c²——**不能恢复 GR 的 3GM**。

### 2.3 决定性洞察：热平衡适用域

【引用遗留④模拟 2 的发现】热平衡证明已确认：**纯 1/r 引力势的玻尔兹曼分布发散（r→0），引力系统无全局热平衡，e^{−Φ/c²} 仅局部/弱场/截断下有效**。

**推论**：
- 弱场（x ≪ 1）：玻尔兹曼有效，PPN γ=β=1 通过 ✓；
- 强场（x ~ 1）：**热平衡失效**，g₀₀ = −e^{−2x} 外推超出适用域；
- ⟹ 框架强场行为**未定义**——既非"通过"也非"被排除"，而是"缺失"。

## 第三部分　框架地位修正

### 3.1 修正声明

**撤回**：此前"框架强场预言 g₀₀ = −e^{−2x}（中子星 27%、光子球 35%）"的表述——它是对玻尔兹曼分布的强场外推，**超出框架适用域**（热平衡仅在弱场/截断内成立）。

**修正为**：框架的强场行为（黑洞、中子星内部）**未定义**——需要独立的强场机制，而框架当前没有。

### 3.2 修正后的框架地位

| 区域 | 状态 | 说明 |
|---|---|---|
| **弱场（PPN）** | ✅ 完整且通过 | γ=1、β=1 全通过，与 GR 不可区分 |
| **强场（黑洞）** | ❌ 未定义 | 热平衡失效，无独立强场机制——**框架最大空白** |
| 量子（非交换） | ✅ 闭环 | CHSH=2√2、互补性 |
| 宇宙学 | ⚠️ 部分 | ε 分工清晰，暗物质定量待闭合 |

### 3.3 强场机制候选方向（下一步）

【待验证】三个候选：

| 方向 | 内容 |
|---|---|
| 1. 通量饱和的量子修正 | 普朗克尺度效应（通量管网络）外推到宏观——视界 = 通量管饱和网络 |
| 2. 与 GR 对接 | 混合模型：弱场由框架（玻尔兹曼）、强场由 Einstein 方程接管——框架作为 GR 的弱场统计地基 |
| 3. 通量管非微扰结构 | 强场由通量管网络拓扑决定（视界 = 通量管饱和面，可能自然给出 GR 结构） |

**方向 2 最务实**：框架定位为"GR 的弱场统计力学地基"（与原文 44 页"GR 是几何描述，你的图景是统计流体描述——前者是后者的有效理论"一致）——强场交给 GR，框架只声称弱场涌现。这样框架与 EHT 无冲突，且定位清晰。

## 第四部分　结论

1. **通量饱和机制（两个候选）不能恢复 GR 强场**：ρ 下限钳制（光子球 1GM 或消失）、通量自引力（修正限于普朗克尺度）——均无法消除与 EHT 的本质差异；
2. **决定性修正**：热平衡适用域分析表明**强场本就在框架之外**——框架没有强场预言可被 EHT 检验（撤回 e^{−2x} 外推）；
3. **框架地位修正**：从"强场与 EHT 冲突"（负面）修正为"强场机制缺失"（诚实的不完整）；
4. **下一步**：开发独立强场机制（框架最大空白）——推荐"框架 = GR 的弱场统计地基"的混合定位（方向 2），最务实且与框架自我定位一致。

**本批的意义**：把框架的强场问题从"潜在致命冲突"转变为"明确的不完整 + 清晰的发展方向"——这是框架诚实性的一次重要提升。
