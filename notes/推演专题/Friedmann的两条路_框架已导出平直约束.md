# Friedmann 的两条路：框架其实已经导出了平直约束

> 日期：2026-09-17 凌晨 ｜ 核验脚本：`_friedmann_micro.py`（纯标准库）
> **一句话：被记为"框架最大缺口"的 Friedmann 方程，其实已经导出了一半——
> 等分账直接给出 ρ = 3H²/(8πG)（平直约束，k=0），而且没有预设 Friedmann。
> 真正缺的是动力学（加速度方程 + 连续性方程），不是约束方程。**

## 一、更正：H² = 8πGρ/3 是**输出**，不是输入

从 09-11 起，链条里一直记着"框架未导出 Friedmann 方程"。复核后发现这个判断需要更正——
我们一直把它当输入用，但从没检查过等分账是否已经把它吐出来了。

**输入（全部是定义或框架已有结果，无 Friedmann）**：

| 项 | 来源 |
|---|---|
| `R_c = c/H` | A1 因果视界（`v_rec = Hr = c`） |
| `N = π R_c²/l_P²` | F3 熵 `S = k_B A/(4l_P²)` |
| `k_B T = ℏH/(2π)` | 因果视界 `κ = c²/R_c = cH` + F3 给的 2π |
| `E = (4π/3)ρ R_c³ c²` | Misner-Sharp 质量（**定义**） |
| `E = N k_B T` | 全息等分（公理 B5） |

**解 ρ**：

$$\frac{4\pi}{3}\rho\left(\frac{c}{H}\right)^3 c^2 \;=\; \pi\frac{c^2}{H^2 l_P^2}\cdot\frac{\hbar H}{2\pi}
\quad\Longrightarrow\quad \boxed{\rho = \frac{3H^2}{8\pi G}}$$

数值：解出 `8.598814257e-27 kg/m³`，平直 Friedmann 给 `8.598814257e-27 kg/m³`，**完全相等**。

⟹ **这就是平直（k=0）Friedmann 方程**，而且是推出来的。
⟹ 09-11 记的"黑洞宇宙待解释的巧合"、`Ω = 1` 之谜，至此有了机制。

**仍需诚实区分**：框架假设了 FRW + GR 的几何结构（用 Misner-Sharp 质量就是在用 GR），
所以严格说它是**在 FRW 框架内推出 k = 0**，不是从零推出现代引力。

## 二、微观路径：泄漏给出 ρ ∝ H²（标度对，系数差 8.4 倍）

既然视界热力学那条路对框架是封死的（它选 Kodama 温度，见《视界热力学的两个包》），
试 A1/A2 的微观路径：

- 事件率密度 `Γ = c/l_P⁴ = 4.393×10¹⁴⁷ m⁻³s⁻¹`，普朗克能量 `E_P = 1.956×10⁹ J`
- 普朗克能量密度 `ρ_P = ℏc/l_P⁴ = 4.633×10¹¹³ J/m³`
- 取**全息稀释** `ε_eff = 1/N`，`N = (R_H/l_P)² = 7.156×10¹²¹`

$$\rho_{\text{micro}} = \frac{\rho_P}{N} = \rho_P\left(\frac{l_P}{R_H}\right)^2 = \frac{H^2}{G}
\quad\Longrightarrow\quad \lambda = \frac{H^2/G}{3H^2/8\pi G} = \frac{8\pi}{3} \approx 8.378$$

数值核验：`ρ_micro = H²/G` ✓，`λ = 8π/3 = 8.37758041` ✓。

**标度对了**（`ρ ∝ H²`），**系数差 8.378 倍**。

## 三、分工：微观管标度，全息管归一化

| 路径 | 给出 | 值 |
|---|---|---|
| 微观（A1/A2 泄漏 + 全息稀释） | **标度** `ρ ∝ H²` | `λ = 8π/3 ≈ 8.38`（常数） |
| 全息（等分 `E = T·S` 写在 `R_c`） | **归一化** | `λ = 1` |

两条路差一个 `8π/3`。这不是矛盾，是分工——
**微观保证 λ 是常数（因而平坦性不漂移），全息把它钉成 1。**

## 四、绝对量级：框架**没有**解决宇宙学常数问题

不做全息稀释、直接用 A2 的 `ε₀ = 7.7×10⁻²⁰`：

$$\rho_{\text{naive}} = \frac{\Gamma\,\varepsilon_0\,E_P}{H} = 3.36\times10^{138}\ \text{kg/m}^3
\quad\text{vs}\quad \rho_{\text{crit}} = 8.60\times10^{-27}\ \text{kg/m}^3$$

**超出 3.9×10¹⁶⁵ 倍。** 框架的 50:50 必须提供这个量级的抵消，而且要精确到 10⁻¹⁶⁵。

⟹ 这就是宇宙学常数问题。**框架继承了它，没有解决它**，只是换了套语言表述。
必须在论文里写明，不要让人以为框架解释了暗能量的绝对量级。
