## 一、问题

三条既有结论之间缺一环：

| 轮次 | 结论 |
|---|---|
| 第 21 / 39 / 40 轮 | tick 是**双射** ⟹ 状态信息严格守恒、底层零熵产生 |
| 第 26 轮 / §8.6.7 | tick = **随机选轴 + 每线独立随机相位**（标为【实现选择】） |
| 第 40 轮 | 等分 = 唯一不变测度，但**动力学保持轨道** ⟹ 等分只能是"结构性 / 初值"的 |

缺口：**如果底层不产生熵，熵从哪来？为什么等分"瞬时"成立而不需要热化？**

## 二、结果 A：外生随机性是一个可算的熵源

一次 tick 的选择数 = **3 轴 × 2^(线数)**，线数 = L²（L = 格点边长）。
⟹ 每 tick 注入的**无知**（系综熵的增量）：

$$h \;=\; \ln 3 \;+\; L^2\ln 2 \quad [\text{nats/tick}]$$

| 量 | 值 |
|---|---|
| L ≈ N_c = R_c/l_P | 8.4918×10⁶⁰ |
| h（每 tick） | **4.998×10¹²¹ nats** |
| ḣ = h/t_P | **9.27×10¹⁶⁴ nats/s** |
| 视界 BH 熵 S_BH/k_B = πN_c² | 2.265×10¹²² nats |
| **达到 S_BH 所需** | **`S_BH/h = π/ln2 = 4.532 tick ≈ 2.44×10⁻⁴³ s`** |

最后一行是**解析值**：`πN_c² / (N_c² ln2) = π/ln2`（ln3 项可忽略）。

**关键**：这是**系综（无知）熵**，不是状态熵。单个 tick 仍是双射 ⟹ **状态信息严格守恒**。
「无信息丢失」（第 21 轮）与「系综熵增长」（本轮）**并存**：前者说状态，后者说我们的无知。

## 三、结果 B：解释了第 40 轮 —— 两个速率差 10⁶⁰

| 速率 | 值 |
|---|---|
| 统计饱和（无知饱和） | 2.44×10⁻⁴³ s ≈ 4.53 tick |
| 哈勃时（空间输运走到 47 μm） | 4.58×10¹⁷ s |
| 两者之比 | **1.87×10⁶⁰** |

⟹ **统计混合比物质输运快约 60 个数量级**。第 40 轮说「等分账瞬时成立、不需要热化」，
第 21 轮说「一个哈勃时只混合 47 μm」—— 两者**不矛盾**：
一个是**信息的混合**（外生随机注入，极快），一个是**物质的输运**（扩散，极慢）。
⟹ 第 40 轮那个"结构性"的等号，现在有了动力学理由。

**饱和值**：系综熵饱和于 `ln|O|`，而 `ln|O| ≤ ln C(N,N/2) ≈ 4.24×10¹⁸² nats ≫ S_BH`
（约 1.9×10⁶⁰ 倍）⟹ **容量不是瓶颈，速率才是**；饱和后不再增长。

## 四、结果 C：T-7 判否（结论是否定的）

| 假设 | 内容 |
|---|---|
| H1 | tick 的轴/相位是**外生真随机** ⟹ 未来不是当前状态的函数 |
| H2 | 由更底层的 DOF **确定**（表观随机 = 粗粒化） ⟹ 未来原则上可预测（只是不可算） |

H2 需要把 tick 选择编码进衬底自身，开销 =（tick 选择的比特数 ≈ L²）/（格点数 L³）= **1/L**：

| L | 1/L（bits/格点） |
|---|---|
| 8 | 1.25×10⁻¹ |
| 64 | 1.56×10⁻² |
| 10⁶ | 1.00×10⁻⁶ |
| 8.49×10⁶⁰ | **1.18×10⁻⁶¹** |

⟹ 宏观下开销 → 0，**不与「0.25 纳特/l_P² 次二元」的熵密度冲突**
⟹ **H1 与 H2 在可见衬底层面经验等价 ⟹ 不可判别**。

⟹ 「未来是否原则上可预测」在本框架内**不可判定**；但在**现行表述（H1）**下答案明确：
**不可预测**（信息根本不在当前状态里，不是算不动）。

## 六、诚实边界

- ⚠️ `h = ln3 + L²ln2` 用的是**并行 + 每线独立相位**这一实现；另一实现
  （「每对独立决定是否交换」）的选择数不同 ⟹ h 不同 ⟹ **可用扩散系数交叉检验**（§8.6.7 已给：
  两种实现给不同扩散系数）—— 这是把本轮结果接上观测量的入口，**本轮未做拟合**。
- ⚠️ L ≈ N_c 是把哈勃球当作边长 N_c 的立方格点（粗估数量级）；几何因子（球 vs 立方、4π/3）
  只影响 O(1) 系数，**不改 π/ln2 这个解析结构**（分子分母的 N_c² 同时约掉）。
- ⚠️ H1/H2 不可判别 ⟹ **不要**把「未来不可预测」写成框架的**已证结论**，只能写成
  「现行表述下的性质」。
- ⚠️ 未做：把注入速率与具体可观测量（扩散系数、黑洞蒸发光度等）做定量拟合。
