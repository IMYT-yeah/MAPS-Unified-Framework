## 一、一句话结论

**审计的「未同步残留」是 0 处（正面产出）；但在「定性自评」这一格上翻出一个真问题 ——
§10.1 的「完成度 ~90%」是全文唯一的定量自评，也是全文唯一没有度量的数，
且它与同章 §10.2 的开放问题表、§9 的状态列、§1 的自定位声明三处不相容。**

审计轮**第一次没有找到「数值型」错误** —— 这本身是信息：
前四轮（84–87）每次都抓到「某轮把早期对的结论写反」，而这一轮查的是**同一命题跨章节**，
结论是**数值层面已经干净**；剩下的不一致在**定性表述层**。

## 三、⭐⭐ C-43（本轮唯一实质发现）

### 3.1 事实

| 位置 | 表述 | 与「~90%」的关系 |
|---|---|---|
| **§10.1**（L1926） | 「本框架从四条公理出发，为四种基本力的统一提供了**涌现式统计力学论证**，**完成度 ~90%**：」 | —— **无度量定义**（同行与后 3 行内无「分母 / 分子 / 按条数 / 口径」等任何词） |
| **§10.2**（同章，L1945–1959） | **13 条**编号开放问题，其中 **5 条明示未闭合**（#2「4D SU(3) 完全涌现**仍开放**」、#13「阶段 C **遗留** + 4D YM 质量隙 **不声称**」、#11「强度**未推导**」、#7「剩余严格化（**深度开放**）」等） | 同章并列，**无任何限定语** |
| **§9 表**（L1890–1920） | **25 行**，其中 **5 行**为「**❌ 结项 / 与 LHC 存在张力 / 数值待推导 / 判别中（3.3σ 压力）**」 | 上一章，**无任何限定语** |
| **§1**（L5、L31） | 「**启发式统一框架（参考架构，非已确立物理）**」；「本框架是启发式统一框架，非已确立物理」 | 与 §10.1 **相距 1895 行**；§1 **只指向 §10.2**（开放问题），**不指向 §10.1** |
| **第 61 / 63 轮评估** | 工程出口 = 0、★★★ 清零、「独有 + 可测 + 有数」的预言 = **1**、**参数表 0 处** | 全文「**就绪度**」**0 处** ⟹ 该项评估**从未进入论文** |

### 3.2 判据

> **同一命题（「框架的成熟度」）在文档的四个位置有四种量纲不同的表述，且没有任何一处把它们的差异写出来。**

- §1 用**定性**语言（「非已确立物理」）；
- §10.1 用**定量**语言（「~90%」）但**不给度量**；
- §9 与 §10.2 用**逐条状态**语言（❌ / 待推导 / 仍开放）。

⟹ ⚠️ **「~90%」与「13 条开放问题中 5 条明示未闭合」并列，是审稿人最容易一击命中的地方**：
   读者无法知道 90% 的分母是什么，**也无法复核**。这不是「数值错了」，而是**口径缺失** ——
   与本项目已有的 C-20（面积口径）、C-28（拟合口径）、C-41（外推口径）**同一族**，只是发生在**定性自评**上。

### 3.3 处理（本轮落地）

**不删「~90%」**（它是作者的判断，删了是越权），**而是给它加口径注**：
在 §10.1 该句后插入【第 88 轮口径注（C-43）】，写明
① 该数为**作者自评、无度量定义**；
② 同章 §10.2 有 13 条开放问题（5 条明示未闭合）；
③ 上一章 §9 有 5 行「❌/张力/待推导/判别中」；
④ 与 §1 的「非已确立物理」并列时应读作**主观进度**而非可复核指标。

## 四、⚠️⭐ 本轮踩到的**四类「判据陷阱」**（全部为假警报，已逐条复现）

> 这一轮我在同一类错误上**连犯五次**（1 项 CO-3 ＋ 5 项候选 ＋ 2 项 CR）⟹ 值得单列成条。

| # | 陷阱 | 实测 | 正确判据 |
|---|---|---|---|
| ① | **裸数字串不是「值」的判据** | 用裸串 `148` 查「旧值是否裸留」⟹ 命中 `3.138–3.148`（**区间写法**）的尾三位 ⟹ **假 FAIL** | 要求 **≥ 4 字符** 且（含小数点 **或** 4 位以上整数 **或** 科学计数）；排除年份 |
| ② | **数字子串判据会误命中** | `0.04` ⊂ `0.0493`、`1.00` ⊂ `α=1`（L278/280） | 加**非数字边界**（`(?<![0-9.])…(?![0-9])`），或先证明它是**独立记号** |
| ③ | ⭐ **`X → Y` 不一定是「更正」，也可能是「序列 / 递进」** | `0.4679 → 0.4335 → 0.4334 → 0.4617`（L465）是 **N=8→16→24→32 的曲线**；`0.4335 → 0.4334`（L589）是 **N=16 vs N=24**（原文写「N=16 → 24 几乎饱和」） | 抽取「更正对」前先问：**两侧是同一命题的两个时间版本，还是同一曲线上的两点？** —— 前者才叫更正 |
| ④ | ⭐ **表格行会被拆成多行** | §9 的 **S-C1** 行（L1918）与 **S-E1** 行（L1910），「⚠️ 第 61 轮加注」写在**续行**（L1920 / L1912）上 | 判据要取**行 + 续行**；⚠️ 我第一遍就漏了，误判为「§9 表未同步」 |
| ⑤ | **「同名条目」定位错位**（技能陷阱 73 的新形态） | `[i for i,s in …if "S-C1" in s][0]` 取到的是**第 61 轮块里的 S-C1**（L853），不是 §9 表格行（L1918）⟹ 又一次假 FAIL | 锚定**结构前缀**（`s.startswith("\| **S-C1** \|")`），并打印「另有 N 处同名出现在轮次块里」 |
| ⑥ | **判据太粗会撞上别的小节号** | 用 `"§10" in s` 判「§1 是否交叉引用 §10.1」⟹ 被 §1 里的 **§10.2** 命中 ⟹ 假 FAIL | 交叉引用判据要**精确到小节号**（`§10.1` ≠ `§10`） |

📌 **一句话通则**：**「检索到一个数字」≠「那个数字在那个位置表示那个量」** ——
   一致性审计里，**每一个判据都要先证明「我是拿它当什么用」**（区间？序列？更正？同名？小节？）。

   只能判定**它不可复核**且**与三张表并列时无限定语**。
