### 2.2 `D = ℏ/(3m)` 是**恒等式**

第 18/21 轮的链条：

```
p_rev = m/m_P            ← 【输入】让持续长度恰好 = 康普顿波长
λ_C   = l_P / p_rev = ℏ/(mc)
τ_corr= λ_C/c       = ℏ/(mc²)
D     = c²·τ_corr/3      （d = 3 的各向同性扩散因子）
      = c·λ_C/3 = c·(l_P·m_P/m)/3 = ℏ/(3m)      ∵ l_P·m_P ≡ ℏ/c
```

**判据**：把**牛顿常数 G 缩放 ×0.25 / ×1 / ×4** —— 此时 `l_P ∝ √G` 变 ±2 倍、`m_P ∝ 1/√G` 变 ∓2 倍，
但 `l_P·m_P ≡ ℏ/c` **与 G 无关**：

| G 缩放 | l_P | m_P | l_P·m_P | **D** | 相对差 |
|---|---|---|---|---|---|
| ×0.25 | 8.0813e−36 | 4.3529e−08 | 3.517673e−43 | **3.858921e−05** | 0.0e+00 |
| ×1.00 | 1.6163e−35 | 2.1764e−08 | 3.517673e−43 | **3.858921e−05** | 0.0e+00 |
| ×4.00 | 3.2325e−35 | 1.0882e−08 | 3.517673e−43 | **3.858921e−05** | 0.0e+00 |

⟹ **`l_P` 与 `m_P` 被完全消掉** ⟹ `D = ℏ/(3m)` **只是 `λ_C = ℏ/(mc)` 的重述**，
而 `λ_C` 又是 `p_rev = m/m_P` 的**定义式反解** ⟹ **恒等式，不是框架的预言**
（陷阱 39 / 铁律 7 的标准形态：把中间参数代回去，全消掉）。

### 2.3 「差 1.5 倍 = 维度因子」这个说法**本身**不成立

框架的 `1/d` 是 **d 维各向同性扩散的几何因子**；Nelson 的 `1/2` 来自欧氏 QM，**与维度无关**。
所以正确的对照是**扫维度**：

| d | D_frame(d) = ℏ/(d·m) | D_Nelson = ℏ/(2m) | 比值 |
|---|---|---|---|
| 1 | 1.157676e−04 | 5.788382e−05 | 2.000000 |
| **2** | 5.788382e−05 | 5.788382e−05 | **1.000000** |
| 3 | 3.858921e−05 | 5.788382e−05 | 0.666667 |
| 4 | 2.894191e−05 | 5.788382e−05 | 0.500000 |

⟹ **只有 d = 2 恰好重合**。若两个「1/2」真是同一个东西，必须**在所有维度**都相同。
⟹ 「差 1.5 倍 = 维度因子」是**把 d=3 的『3』与 2m 的『2』摆在一起的数字巧合**，
**不是**可解释的结构关系 ⟹ **不构成判别点**（铁律 2：数值接近只可登记为「无机制」）。

## 三、§7.1 —— 本轮**唯一**的正面产出（QM-5）

**枚举全部 2⁴ = 16 个确定性局域策略**（`A₀,A₁,B₀,B₁ ∈ {±1}`）：

```
max S = 2     （达界策略：A₀=+1, A₁=+1, B₀=+1, B₁=+1）
5000 组随机混合权重：max S = 1.0879 ≤ 2   （凸组合不越过上界）
```

⟹ **经典（交换）局域模型的最大 CHSH = 2**（枚举 + 凸组合闭包）。

于是 **§7.1 的主张可以从「断言」升级为「引用 Fine 定理（1982）的推论」**：

> **定理（升级版）**：若某理论的可观测代数在某个态上允许一个**联合概率分布**
> （⟺ 代数为**交换**），则其关联必然满足 CHSH ≤ 2。故与 CHSH = 2√2 相容的理论，
> **其可观测代数必然非交换**。

⭐ 这是**框架内唯一一条有严格外部定理（Fine / Tsirelson）支撑的「必然性」论证**。

⚠️ **但要说清它证明了什么**：证明的是「**若**可观测代数交换，则不可能」——
**不是**「框架的可观测代数交换」。后者是 §7.1 的**前提**（未证），也是 §7.2 用「升级为算子代数」
这个**动作**绕过去的地方。

### 5.1 弦网代数（框架的规范侧主力）是**交换的**（QM-7）

用 **Pauli 辛表示** `(a|b) ∈ F₂^E × F₂^E`（交换判据 `a·b′ + a′·b ≡ 0 mod 2`）
＋ **L=2 的 256 维全矩阵**交叉验证：

| 格点 | \|E\| | 顶点—面共享边数 | 不交换的 [A_v,A_v′] / [B_p,B_p′] / **[A_v,B_p]** |
|---|---|---|---|
| 2×2 | 8 | {2} | 0 / 0 / **0** |
| 3×3 | 18 | {0,2} | 0 / 0 / **0** |
| 2×4 | 16 | {0,2} | 0 / 0 / **0** |

全矩阵交叉验证（256 维，逐对 `‖AB−BA‖_max`）：**最大 = 0.000e+00**。

**机理**：顶点 v 与面 p 共享**恰好 2 条边** ⟹ `X···X` 与 `Z···Z` 反对易 **2 次** ⟹ **净交换**。

⟹ **§7.2 列的 4 条里没有一条是弦网** —— 而弦网是框架**唯一**有严格哈密顿量与数值验证（§5.7）的部分。
