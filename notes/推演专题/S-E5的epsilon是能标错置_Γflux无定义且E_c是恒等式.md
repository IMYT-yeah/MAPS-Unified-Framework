## 一、证据：ε(E) 的定义（论文 §8.1 原文，第 890–895 行）

```
【推导】ε_A(E) = ε₀(M_Pl/E)^β，两边界条件：
- E ~ 1 TeV  → ε ~ 6×10⁻¹⁰ （重子不对称 η ≈ ε）
- E ~ 1 meV  → ε ~ 1       （暗能量 ρ_Λ ~ (meV)⁴）
- β = log(6×10⁻¹⁰)/log(10⁻¹⁵) ≈ 0.615，ε₀ ≈ 7.6×10⁻²⁰
```

⟹ **ε 是一个能标依赖的递减函数**（E 越低，ε 越大），其归一化点 ε₀ 是 **E = M_Pl 处的值**。

```

```

⟹ 把 M_Pl 处的 ε₀ 直接搬到了 meV 能标的 FQH 平台。**同一个符号 ε，两个不同的能标。**

## 三、⭐ 附带结果：`E_c` 是**恒等式**，不是【推导】

论文第 895 行把截断能标标为【推导】：

```
【推导】概率归一化 ε_A(E_c) = 1 ⟹ E_c = M_Pl·ε₀^{1/β} = 1.0181 meV
        ——与暗能量特征能标 2.3 meV 同量级（(E_c)⁴ 差 27 倍，O(1) 系数待定）
```

但把 ε₀ 的定义代进去，**M_Pl 完全消掉**：

```
E_c = M_Pl · [ε(1TeV)/(M_Pl/1TeV)^β]^(1/β)
    = M_Pl · ε(1TeV)^(1/β) · (1TeV/M_Pl)
    = 1TeV · ε(1TeV)^(1/β)                    ← M_Pl 不见
    = 1 TeV × (6×10⁻¹⁰)^(1/0.61479)
    = 1.000000 meV                             ← 精确
```

**数值 1.000000 meV**（论文的 1.0181 是 ε₀/M_Pl 取值的数值残差，−1.78%）。

⟹ 因为 β ≡ ln(η)/ln(1meV/1TeV) 就是这个等式解出来的，**"E_c = 1 meV 与暗能量能标同量级"是锚点 2 的重述**，
用它去"验证"锚点 2（ρ_Λ ~ (meV)⁴）是**循环**。
⟹ 四类判定：**半拟合**（两个锚点定 β 与 ε₀，第三个量没有独立内容）。
⟹ 附带：**ε₀ 在论文里有四个写法** —— 7.6 / 7.7 / 7.67 / 7.751 ×10⁻²⁰（第 893 / 27·592·1056 / 914 行 + 由 E_c 反推），跨度 2%。**本轮已在论文里统一为 7.731×10⁻²⁰**（由定义式 ε₀ = ε(1TeV)/(M_Pl/1TeV)^β 算得）—— 因为 E_c 对 ε₀ 敏感，这个常数只能有一个值。
