# f_space 的第一性定义：机制 B 不是预言，是拟合

## 一、起点：原文对 f_space 的主张（批05 §2.3 / §3.2）

> 【原文】暗物质 = ε × 原始涨落密度 × **空间活跃度 f_space** ≈ 10⁻²⁶ kg/m³
> 「在真空地带 f_space ≈ 1，这正好与观测到的暗物质密度吻合」
> 「f_space（空间活跃度）正是『真空地带活跃度高、物质区域低』的定量化」

这是"暗物质 = 涨落的空间投影"这一核心主张的定量化形式。本轮检验它。

## 二、FS-1：⟨f_space⟩ 不是自由参数，是被解出来的

| 量 | 值 |
|---|---|
| ρ_raw = ρ_P | 5.15485×10⁹⁶ kg/m³ |
| ε_eff = 1/N | 1.39747×10⁻¹²² |
| ρ_bare = ε_eff·ρ_P | 7.20373×10⁻²⁶ kg/m³ |
| ρ_DM（观测） | 2.25117×10⁻²⁷ kg/m³ |
| **⟨f_space⟩** | **0.0312500 = 1/32.000** |

**它是被解出来的**（观测已给定 ρ_DM）。所以机制 B 的全部内容 =
「算出一个平均值恰为 1/32 的 f_space 场」。

## 三、FS-2：朴素读法（体积分数）被实测否证 16–26 倍

若 f_space 是"体积中处于活跃（真空）态的比例"，则空洞处 ≈ 1、墙区 ≈ 0，
于是 `⟨f_space⟩ ≈ 空洞体积分数`。

| 实测（SDSS 类巡天，量级参考） | 空洞体积分数 | 需 f_space | 实际需 | 差 |
|---|---|---|---|---|
| R > 10 h⁻¹Mpc 空洞 | 0.62 | 0.62 | 0.03125 | **19.8 倍** |
| 含较小空洞 | 0.75 | 0.75 | 0.03125 | **24.0 倍** |
| 上限估计 | 0.80 | 0.80 | 0.03125 | **25.6 倍** |
| 下限估计 | 0.50 | 0.50 | 0.03125 | **16.0 倍** |

**空洞占体积 50–80%，而需要的是 3.1%。** ⟹ **朴素体积读法被否证 16–26 倍。**
f_space **不可能是**体积分数。

## 四、FS-3：换读法就没了预言力

改读：`f_space = (区域刷新率)/(裸刷新率)`，空洞处 = 1。则

$$\langle f_{space}\rangle = \frac{1}{V}\int f_{space}(\rho_m)\,\mathrm{d}V$$

需要**抑制律**才能算。而可选的自洽律至少有四种：

| 律 | 形式 |
|---|---|
| 指数 | `exp(−ρ_m/ρ_c)` |
| 幂律 | `(ρ_c/ρ_m)^p` |
| 阈值 | `θ(ρ_m < ρ_c)` |
| 线性 | `max(0, 1−ρ_m/ρ_c)` |

**四种律给出四个不同的 ⟨f_space⟩，都能靠调 ρ_c 或 p 凑到 1/32。**

⟹ **机制 B 的预言力 = 0**：f_space 是一个自由函数，
给定任意目标 Ω_dm 都能反解出对应的 f_space。**它是拟合，不是预言。**

## 五、FS-4：框架已知的无量纲量里有没有自然给出 1/32 的？

| 候选 | 值 | 对 1/32 的比值 |
|---|---|---|
| 1/N = (H t_P)² | 1.397×10⁻¹²² | 4.5×10⁻¹²¹ |
| H t_P = l_P/R_H | 1.182×10⁻⁶¹ | 3.8×10⁻⁶⁰ |
| ε₀ | 7.7×10⁻²⁰ | 2.5×10⁻¹⁸ |
| β | 0.615 | 19.7 |
| β² | 0.378225 | 12.1 |
| 2/3（跨枝保留） | 0.6667 | 21.3 |
| 1/3（跨枝转移） | 0.3333 | 10.7 |
| 3/(8π) | 0.11937 | 3.82 |

**只有 `(1/2)⁵ = 1/32` 对得上——但那只是恒等式（1/32 ≡ 2⁻⁵），不是机制。**
框架里**没有任何已知量**自然给出 32。

⚠️ `(1/3)³ = 1/27` 离 1/32 只差 19%，同样无机制。**两者都不采信。**

## 六、诚实边界

| 项 | 状态 |

## 七、判决

❌ **机制 B（ε·ρ_raw·f_space）不是预言，是拟合。**

- ⟨f_space⟩ 被观测唯一确定为 **1/32**
- 朴素体积读法 ⟹ 需空洞占 **3.1%** 体积，实测 **50–80%** ⟹ 否证 16–26 倍
- 速率抑制读法 ⟹ 四种自洽律给四个答案，都能凑 1/32
- 框架已知量中**没有一个**给出 32

**建议**：把机制 B 从"候选机制"降为**拟合式**，在论文中明确标注其零预言力；
暗物质的定量解释**仍为空白**。
