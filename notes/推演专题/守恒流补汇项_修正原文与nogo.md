## 一、补上的方程

原文（批05 §1.1）缺汇项 ⟹ `Ṡ = 2ερ` 无不动点。补完：

$$\frac{dJ_+}{dt} = -\tfrac13 J_+ + \tfrac13 J_- \;-\; \nu J_+ \;+\; \tfrac{\nu\rho}{2} \;+\; \varepsilon\nu\rho$$
$$\frac{dJ_-}{dt} = -\tfrac13 J_- + \tfrac13 J_+ \;-\; \nu J_- \;+\; \tfrac{\nu\rho}{2} \;-\; \varepsilon\nu\rho$$

| 新增项 | 物理含义 |
|---|---|
| `−νJ` | **湮灭/周转汇**——A1：对风暴以 `ν ~ 1/t_P` 湮灭-再生循环 |
| `+νρ/2` | 再生源（每枝对称补半） |
| `±ενρ` | 泄漏的**方向性**（正份留本支、反份入镜像支） |

⚠️ **原文把 ε 项写成两枝都 `+ερ`，这是笔误**：那样既无不动点，
也给不出它自己声称的 `J₋=(1/2−ε)ρ`。**必须带方向性符号。**

## 二、SK-1/2：不动点（解析 + 数值）

两式相加 ⟹ `−ν(J₊+J₋) + νρ = 0` ⟹ **`J₊ + J₋ = ρ` 自动成立** ✓（总量守恒内建）

$$\boxed{J_+ = \rho\left[\frac12 + \frac{\varepsilon\nu}{2/3+\nu}\right],\qquad
J_- = \rho\left[\frac12 - \frac{\varepsilon\nu}{2/3+\nu}\right]}$$

数值（ν = 1/t_P；真实 ε 在双精度下会塌缩，故按 ε 线性放大到 0.1 显示）：

| | 值 |
|---|---|
| J₊/ρ | **0.600000000000** = 1/2 + ε ✓ |
| J₋/ρ | **0.400000000000** = 1/2 − ε ✓ |
| J₊+J₋ | **1.000000000000** ✓ |

## 三、SK-3：这就是原文漏掉的那一项

`ν ≫ 2/3` 时 `εν/(2/3+ν) → ε`，**精确恢复原文的 `J₊ = (1/2+ε)ρ`** ✓

物理上完全合理：**湮灭周转（~1/t_P）远快于跨枝转移（~1/3）**。
⟹ **原文的漏项就是 `−νJ`**，其"稳态解"在补上这一项后成立。

## 四、SK-4：严格 no-go（本轮核心）

要让不动点 = 2/3：

$$\frac12 + \frac{\varepsilon\nu}{2/3+\nu} = \frac23
\;\Longrightarrow\; 6\varepsilon\nu = \tfrac23 + \nu
\;\Longrightarrow\; \nu = \frac{2/3}{6\varepsilon - 1} = -0.6667$$

**ν 为负数** ⟹ **不存在正周转率使不动点等于 2/3**。
这不是参数没调好，是**方程结构上的不可达**。

若把不动点当 Ω_Λ：任何 ν 下都得 **~0.5**，对观测 0.6889 差 **−27.4%**。
