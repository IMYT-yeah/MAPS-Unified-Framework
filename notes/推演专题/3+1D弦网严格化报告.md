## 2 严格化 I：量子直线-弦网边 Hopf 桥接【推导】

**A1 定理**（§5.6）：框架事件流三操作（相遇=乘法、湮灭=对合、再生=余乘法）⟹ Hopf 代数结构 D(G)。

**严格化陈述（B8 路线图落地）**：弦网模型的**边/面算符 = Hopf 代数生成元的几何实现**：

| 框架（量子直线语言） | 弦网语言（3+1D Z₂） | 严格对应 |
|---|---|---|
| 量子直线【214-218】= 事件流的直线段 | 弦网边（闭合弦的组成单元） | 直线段端点 = 弦端点 |
| 直线相遇（Hopf 乘法） | 弦网分支（顶点融合规则） | 配对阶数 n（A2）决定分支 |
| 直线湮灭（Hopf 对合） | 弦闭合（A_c 闭合法则） | **A_c=Π_{f∈∂c}Z_f=1 ⟺ 弦无端点** |
| 直线再生（Hopf 余乘法） | 弦网涨落（X_f 翻转） | λΣX_f = 弦网动力学项 |

**严格陈述**：量子直线的**端点** ↔ 弦端点 = A_c 违反（本报告 §3 证明有正能隙 Δ=2 ⟹ **涌现粒子**）——框架"量子直线 = 弦"从图像对应升级为**算符级对应**（Hopf 生成元 ↔ 弦网边算符）。

## 3 严格化 II：λ=0 弦网凝聚的严格证明【推导 + 数值】

**定理（λ=0，严格）**：3+1D Z₂ 弦网 H₀ = −Σ_c A_c（A_c=Π_{f∈∂c}Z_f）：
- **(i) 基态**：所有 A_c=1（闭合弦网凝聚），**E0 = −N_c 精确**（N_c = 立方体数）；
- **(ii) 拓扑简并**：基态简并度 = **2^(n−N_c)**（n = 面数；每个独立 A_c 约束减半维度；双立方体 n=11, N_c=2 ⟹ **512 = 2⁹**，数值验证 ✓）；
- **(iii) 激发能隙**：任一 A_c 翻转（弦端点/环激发）代价 **Δ = 2**（严格；双立方体 E0=−2、E1=0、Δ=2 数值验证 ✓）。

**证明**（λ=0）：A_c 两两对易、A_c²=1，可同时对角化。H₀ 谱 = −Σλ_c（λ_c=±1），基态 λ_c=+1 全部 ⟹ E0=−N_c。激发 = 一个 λ_c 翻转 ⟹ Δ=2。简并：n 面、N_c 个独立约束（∏A_c=1 关联）⟹ 2^(n−N_c)。**严格，无近似**。

**数值验证**（脚本 `_stringnet31d.py`）：
| 系统 | 态数 | E0(λ=0) | 基态简并 | 激发 Δ |
|---|---|---|---|---|
| 单立方体 | 64 | −1（=−N_c=1） | 32 | 2（解析） |
| 双立方体 | 2048 | **−2（=−N_c=2）** | **512（=2⁹）** | **2** ✓ |
| λ=0.1 双立方体 | — | ⟨A_c⟩=0.877（凝聚保持） | — | — |

**弦网凝聚确认**：λ 小（0.1）时 ⟨A_c⟩=0.877→1（基态偏向闭合弦网）；λ=0 时精确 A_c=1 全部。**子区域熵**随边界增长（S_A: 0.39→0.63 单立方体；0.38→1.39 双立方体）——基态含量子纠缠（弦网涨落）。

## 4 严格化 III：对偶映射（弦网 ↔ 格点规范）【推导 + 引用】

**对偶**：3+1D Z₂ 弦网 H(λ) = −Σ_c A_c − λΣ_f X_f 与 3D Z₂ 格点规范理论（H=−Σ_plaq B_plaq − hΣ_link X_link）通过**电磁对偶**关联【引用，Fradkin–Shenker 线；Kogut 1979】：
- **弦网凝聚相（λ 小）↔ 规范禁闭相**：A_c=1（弦无端点）↔ B_plaq=1（无磁通）；弦端点（A 违反）↔ 电荷（电通量终止）——**弦端点粒子 = 禁闭电荷**；
- 对偶是**严格**的（格点电磁对偶），框架弦网的 λ=0 严格结果（§3）通过对偶转移为规范理论禁闭相的严格陈述。

**框架衔接**：配对阶数 n=1（U(1) 电磁，§5.1）在弦网语言 = 弦网凝聚相的低能极限——**电磁力 = 弦网凝聚的涌现规范场**（§5 严格化路径）。
