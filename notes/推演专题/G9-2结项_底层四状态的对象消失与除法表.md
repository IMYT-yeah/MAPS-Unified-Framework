## 二、判据与数值表

### 2.1 ⭐ 主判据：那张「反解 q」表是恒等式（**C-76**）

论文 §4.8 的 v2.9 修正链里有一条（第 19 轮产物）：

> 以 B5 的「原始可读 4 bits/面元」为目标反解每个格点的内部状态数 q，配合方向簇 k = 4：
> q=2 → 3.000 bits、q=3 → 3.585、**q=4 → 4.000（唯一）**、q=5 → 4.322。
> ⟹ 内部四状态正是 {正, 负, 湮灭中, 真空}……（原先这是假设，现在是被推出的）。

本文轮逐项核对该数列：

| q | 论文打印 | `2 + log₂q`（精确值） | 判定 |
|---|---|---|---|
| 2 | 3.000 | 3.000000 | ✓ |
| 3 | 3.585 | 3.584963 | ✓ |
| 4 | 4.000 | 4.000000 | ✓ |
| 5 | 4.322 | 4.321928 | ✓ |

**最大偏差 7.19×10⁻⁵**（= 论文只印 3 位小数造成的舍入）⟹ 该列**逐项等于 `2 + log₂q`**。
而 `2 = log₂4`，所以它整体就是

```
bits(q) = log₂(k·q) |_(k = 4) = log₂(4q) = log₂16 = 4   ⟺   4q = 16
```

即：**它与「`k·q = 16`，k = 4」是同一个式子的两种写法**。三点后果：

1. **「唯一解」不含选择信息** —— 方程 `2 + log₂q = 4` 有唯一实根，**只因 log 严格单调**
   （数值核对：q = 1…63 逐点严格递增；整数根 = [4]）。单调性给「唯一」，**不给「为什么」**。
2. **两条前提都是输入**：`k = 4`（§4.9 引理 1 的「平面内 4 方向」）与 `16`（B5 的「原始可读 4 bits/面元」）
   在论文里**都是给定的** ⟹ 该表对二者**零预言力**（与第 84 轮同步注、第 39 轮块一致）。
3. ⚠️ **约束 `k·q = 16` 单独并不唯一** —— 它有 **5 组**整数解：

```
(k, q) = (1, 16) / (2, 8) / (4, 4) / (8, 2) / (16, 1)      ← 16 的全部因子对
```

它只**排除非整除的 k**（这正是第 31 轮用来排除外空间配位 k = 6 的那一步），
**并不选出 k = 4**。

⭐⭐ **本链条里唯一的真唯一性不在 q 这一边**：

```
2^k = 16  ⟹  k = 4   （2^k 对 k 单射；数值核对 k = 1…16 中只有 k = 4 给 16）
```

这条来自**读法 B2**，而它**完全不经过 q**。
⟹ **精确表述**：被推出的是「**方向数 = 4**」，**不是「内部态数 = 4」**。
（第 19 轮那句「把 B5 的一个输入变成输出」，其真实内容只有「方向数 = 4」这一半。）
