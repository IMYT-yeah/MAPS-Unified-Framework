## §B　新增 §8.6　视界热力学与平坦性

> **符号约定（重要）**：本节的密度比**不使用 λ**——`λ` 在本论文 §5 中已被弦网哈密顿量耦合常数

> 副作用是有益的：早前记录中的「λ = 1」即 **`Ω_tot = 1`**，也就是**平坦性本身**。

### 8.6.1　热力学面 = 平流停滞面

【推导】框架的微观组分以 c 传播。均匀膨胀中存在与 k 无关的精确关系 `v_rec = Hr`，故风暴成分无法向外回传的界面位于

$$R_c = c/H_0 = 14.4516\ \text{Gly}\qquad (H_0 = 2.1927\times10^{-18}\,\mathrm{s^{-1}})$$

该面的表面引力取 `κ = c²/R_c = cH₀`，与 pacientes Unruh 温度给出

$$k_BT = \frac{\hbar H_0}{2\pi} \;\Longrightarrow\; T = 2.66558\times10^{-30}\ \mathrm{K}$$

【假设 B5（准定理）】**热力学面取上述平流停滞面**。这不是 GR 的表观视界，也不是事件视界；判别见 8.6.5。

【诚实标注】框架的这条面**不是零表面**：`dR_c/dt = (1+q₀)c`，ΛCDM 的 q₀ = −0.5333 ⟹ 面以 **0.4667c** 外移，是 timelike 面。仅在纯 de Sitter（w = −1）极限下它才是零表面。**因此不能把它表述为「观测者因果补丁的边界」**；支持它的正确理由是 8.6.4 的时间尺分离。

### 8.6.2　β = 1/(2π) 与 2π 的来源

【推导】每个 Planck 面元 `l_P²` 的平均能量为 `Ė = k_BT = ℏH₀/(2π)`，即

$$\beta \equiv \frac{\text{每bit能量}}{k_BT_{GH}} = \frac{1}{2\pi}$$

**该系数与 Ω_tot 无关**（第 1 轮）；且其来源可追溯至 F3 熵公式：由 `S = k_BA/(4l_P²)` 与 `dE = TdS` 直接得 `T = ℏc³/(8πGMk_B)`，太阳质量黑洞算得 6.1687×10⁻⁸ K，与标准 Hawking 温度偏差 < 10⁻⁹。**即 1/(2π) 源自 F3 中那个「4」**，不是从 QFT 借来的。

【诚实标注】`S = k_BA/(4l_P²)` 的系数 1/4 是 Bekenstein–Hawking 值（已由太阳黑洞 S/k_B = 1.0494×10⁷⁷ 独立核验），属标准物理输入，非本框架推导。

### 8.6.3　等分账 ⟹ 平直 Friedmann 约束方程

【推导】在该面上写代数等分 `E = Nk_BT`，`N = A/(4l_P²) = πR_c²/l_P²`：

$$\frac{4\pi}{3}\rho\left(\frac{c}{H_0}\right)^3 c^2 \;=\; \frac{\pi(c/H_0)^2}{l_P^2}\cdot\frac{\hbar H_0}{2\pi}
\;\Longrightarrow\; \rho = \frac{3H_0^2}{8\pi G}$$

**输入全部为定义或框架既有结果，未预设 Friedmann。** 数值：`ρ = 8.5983×10⁻²⁷ kg/m³`。

⟹ **`Ω_tot = 1`，即 `Ω_K = 0`，即 k = 0**，且

```
M = c³/(2GH₀) = 9.20550×10⁵² kg ； R_S = 2GM/c² = R_c （精确，相对误差 <10⁻¹²）
```

故 **哈勃球 = 史瓦西半径**：「黑洞宇宙」在此得到机制说明，不再是数值巧合。

【诚实标注】上述 `M` 用的是 Misner–Sharp 质量表达式，即**已在 FRW 内部**使用 GR ⟹ 严格地说是「在 FRW 内推出 k = 0」，不是从零推出引力。另外 `*ρ = 3H²/8πG` 是**约束方程**；加速度方程与连续性方程仍缺（二者在给定约束后等价，见下）。

### 8.6.4　为什么两端数的是同一批相干块（时间尺分离论证）

第 15 轮确定：观测者端的相干块单位与统计端一致（**每 4l_P² 为 1 纳特，不是 1 比特**，由 Hawking 温度裁决：1 bit 会给 8.8995×10⁻⁸ K，偏差 +44.27%）。余下的问题是两端是否数同一批块。

【推导】块分解是**瞬时量**——由风暴当前的微观结构定义，不带历史。风暴以 `ν = 1/t_P = 1.85486×10⁴³ s⁻¹` 刷新，而视界几何只以 H₀ 变化：

$$\frac{\nu}{H_0} = \frac{R_c}{l_P} = 8.45924\times10^{60},\qquad H_0t_P = 1.18214\times10^{-61}$$

一个哈勃时内每个面元被刷新 **8.46×10⁶⁰ 次**。因此两种分解之差的上界为 `O(H₀t_P) = 1.18×10⁻⁶¹`。

⟹ **「同一批块」在 O(10⁻⁶¹) 精度上成立**。对照组：**若 ν → 0（冻结微观结构），失配为 O(1+q₀) = 0.47，即 20%~47% 的块数误差**——因此 A1 的 `ν ~ 1/t_P` 正是让这条链接成立的东西。

【诚实标注】这是**上界论证**，不是构造性证明。它依赖两个未独立证明的前提：(i) 两端的计数都是瞬时的（若任一端是历史累积量则失效）；(ii) 刷新率为 1/t_P。

### 8.6.5　为什么不是别的面（判别表）

由 8.6.3 的一般形式（面在半径 R 处）可得 `Ω_tot = (R/R_c)²`（温度由 H₀ 定）或 `= R/R_c`（温度由该面表面引力定）。代入各候选：

| 候选面 | R/R_c | Ω_tot | Ω_K | 判决 |
|---|---|---|---|---|
| 表观视界 + Kodama 温度 | — | 0.59 | +0.41 | ❌ 偏离 **217σ**（第 9/12 轮） |
| 表观视界（λ_micro = 8π/3） | 0.3455 | 0.1194 | +0.881 | ❌ 差 O(1) |
| 事件视界（乙式） | 1.1473 | 1.1473 | −0.1473 | ❌ 78σ（Planck+BAO）/ **5.7σ**（Planck 单独） |
| 事件视界（甲式） | 1.1473 | 1.3163 | −0.3163 | ❌ 167σ / 15.1σ |
| **平流停滞面 c/H** | **1.0000** | **1.0000** | **0.0000** | ✅ |

（`R_EH/R_c = 1.147288`，即 16.5802 Gly；参照 Ω_K 观测：Planck+BAO 0.0007±0.0019，Planck 单独 −0.044±0.018。）

⟹ 在自然候选面中 **`R_c = c/H` 是唯一幸存者**。

【诚实标注】这个「唯一性」是用 Ω_K 观测量排除出来的 ⟹ **B5 带有数据成分，不是纯先验推导**。其先验支持来自涌现次序：`R_c = c/H` 只需 (c, H)，而 `R_A = c/(H√Ω_tot)` 需要 G——G 在框架中是涌现量。

### 8.6.6　关于 α–β 路的说明（为什么它不算证据）

早前记录中有 `Ω_tot = 4α²β²`（α = 4π/ξ 来自熵系数，β = ξ/(8π) 由第一定律反解）。核验表明：

$$4\alpha^2\beta^2 = 4\cdot\frac{16\pi^2}{\xi^2}\cdot\frac{\xi^2}{64\pi^2} = 1 \quad \text{对任意 }\xi\text{ 恒成立}$$

ξ = 1, 2, 3, 4, 4ln2, 8, 16 全部给出 `1.000000000000`。**该式看不见 R**，因此对任何面的选择都不敏感 ⟹ 它既不能挑面，也**不能作为「Ω_tot = 1 已获验证」的独立证据**。早前记为「ξ-稳健性」的这一性质应当降调为**一致性检查**：它不是稳健，它是重言式。

**有内容的只有一条**：等分账写在 `R_c = c/H` 上 ⟹ 解出 `ρ = 3H²/(8πG)`（8.6.3）。
