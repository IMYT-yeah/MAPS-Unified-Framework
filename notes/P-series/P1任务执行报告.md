## 第二部分　P1-A：微变权守恒定理化

### 2.1 目标

把 P0 报告的"微变权守恒"补充假设升级为**形式化定理链**，使"引力=通量遮挡 ⇒ γ=1"成为框架内部的定理而非外加假设。

### 2.2 公理化准备

**公理 1（正反诸元风暴）**【原文】：宇宙底层是正反诸元持续相遇—湮灭—再生事件流，各向同性、50:50 平衡、普朗克尺度频率；流形 = 微变的统计平均。

**定义 1（微变权流）**【补充推演】：设湮灭事件流为时空上的守恒流 J^μ(x)。微变权 W[Σ] = ∫_Σ J^μ dΣ_μ 为类空超曲面 Σ 上事件总数的记账权重。

**公理 1'（微变权守恒）**【补充推演】：湮灭事件流守恒：∇_μ J^μ = 0。（严格说应含泄漏源项 ∇_μ J^μ = ε·δ，但 ε ≪ 1，弱场下可忽略。）

**公理 3（时间箭头分叉）**【原文】：时间 = 相遇/湮灭频率。

**引理 1（时间分量 = 事件率密度）**【批1 数学组 §1.1，引用】：静态度规 ds² = g₀₀ dt² + h_ij dx^i dx^j 下，坐标时事件率密度 f(x) = −J⁰(x)，且 f(x) = f₀√(−g₀₀)，其中 f₀ = 普朗克频率。故 g₀₀ = −(f/f₀)²。

**引理 2（通量亏损的泊松结构）**【P0 报告，引用】：静态球对称源周围，通量密度亏损满足 ∇²(δρ) = 0，球对称解 δρ ∝ 1/r；由 g₀₀ 匹配牛顿势得 δρ/ρ∞ = GM/c²r。

### 2.3 主定理

> **定理（微变权守恒 ⇒ 空间-时间互补 ⇒ γ=1）**
> 设湮灭事件流满足公理 1'（守恒）与公理 1 的各向同性（即存在局域惯性系使事件流各向同性）。则在静态球对称引力源的弱场中，空间度规的径向分量由时间分量唯一决定：
> $$g_{rr} = -\frac{1}{g_{00}}\big(1 + O(\Phi^2/c^4)\big),$$
> 即 g_rr ≈ (1−2GM/c²r)⁻¹，PPN 参数 **γ = 1**。

**证明**（三行）：
1. 局域惯性系（自由落体）中事件流各向同性 ⇒ 事件流在该系无优选方向 ⇒ 坐标系的"时间权"√(−g₀₀) 与"径向权"√(g_rr) 是同一各向同性流在两个方向上的投影，乘积守恒（互补）：√(g_rr)·√(−g₀₀) = 1【补充推演：关键物理输入，见 2.4 假设强度】；
2. 由引理 1：√(−g₀₀) = f(r)/f₀ = 1 − GM/c²r（引理 2）；
3. 代入互补条件：g_rr = (1−2GM/c²r)⁻¹ ⇒ 与 PPN 定义 g_rr = 1+2γU/c² 对照（U = GM/r）⇒ γ = 1。∎

## 第三部分　P1-B：ε_A 截断机制与 w(z) 重推

### 3.1 问题背景

P0 报告发现：ε_A(E)=ε₀(M_Pl/E)^β 在 E<meV 发散（哈勃能标处 2.2×10¹⁸），概率 >1 非物理。P1-B 的任务是给出截断机制，并重推 w(z)。

### 3.2 截断机制：概率归一化

**截断定理**【补充推演】：ε_A 是概率，必须满足 ε_A ≤ 1。由 ε_A(E_c)=1 定义的截断能标：

$$E_c = M_{Pl}\,\varepsilon_0^{1/\beta} = 1.01\,\text{meV}$$

**数值验证**（本报告计算）：
- ε₀ = 7.67×10⁻²⁰（由边界条件 1 确定）；
- E_c = M_Pl·ε₀^(1/0.615) = **1.01 meV**；
- 验证：ε_A(1.01 meV) = 1.000 ✓。

**物理图像**：
- E ≥ E_c：ε_A(E) = ε₀(M_Pl/E)^β < 1，泄漏随能标降低而增大；
- E < E_c：ε_A = 1（饱和），几乎所有事件绑定失败——这是概率的物理上限；
- 截断的物理动机（【待验证猜想】）：低于 E_c 的事件波长远超任何可分辨结构（meV 波长 1.24 mm），其"绑定"在统计意义上无意义。

**惊人自洽**：E_c ≈ 1.01 meV 与暗能量特征能标 ρ_Λ^(1/4) = 2.3 meV **同量级**。截断能标天然给出暗能量尺度：

$$\rho_\Lambda \sim (E_c)^4 = (1.01\,\text{meV})^4 = 1.05\times10^{-48}\,\text{GeV}^4 \quad\text{vs}\quad \rho_\Lambda^{obs} = 2.80\times10^{-47}\,\text{GeV}^4$$

数量级吻合（差 27 倍），精确值需 O(1) 系数修正（E_c=2.3 meV 或谱权重因子）。

### 3.3 原文"meV↔哈勃尺度"对应错误确认

**发现**【补充推演】：原文 156 页声称"ρ_Λ~(meV)⁴ 需要 E_ann~meV 量级——这对应于今天的哈勃尺度上的湮灭事件"。数值核对：

| 量 | 数值 | 差异 |
|---|---|---|
| 1 meV 光子波长 | 1.24 mm | — |
| 哈勃半径 | 1.3×10²⁶ m | 差 **29 个数量级** |
| 哈勃尺度能量 ℏH₀ | 1.45×10⁻³³ eV | 差 **~30 个数量级** |

**结论**：meV 能标与哈勃尺度在数值上差 ~30 个数量级，对应不成立。正确图像是：**meV 是 ε_A 概率归一化的饱和能标**（E_c = 1.01 meV），不是哈勃尺度。这修正了原文的一个具体数值错误，且不破坏框架（截断机制反而更自洽）。

### 3.4 w(z) 参数化闭合

**模型设定**【补充推演】：暗能量密度由 ε_A 饱和区主导：ρ_Λ(z) = [E_c(z)]⁴，其中饱和能标 E_c 随宇宙膨胀有缓慢漂移：

$$E_c(z) = E_{c,0}\,(1+z)^{\varepsilon},\qquad |\varepsilon| \ll 1$$

**w(z) 推导**（标准宇宙学）：ρ_Λ ∝ (1+z)^{4ε} ⇒

$$w(z) = -1 + \frac{1+z}{3\rho_\Lambda}\frac{d\rho_\Lambda}{dz} = -1 + \frac{4\varepsilon}{3} \equiv \text{const}$$

**相干长度版本**：若漂移来自真空相干长度 ξ ∝ t^ν（ν = 演化指数，物质主导期 t ∝ (1+z)^{-3/2}），则 E_c ∝ 1/ξ ∝ (1+z)^{3ν/2}，得

$$w = -1 + 2\nu$$

**观测约束**（本报告计算，DESI 2024+CMB：w = −1.028±0.031）：

| 参数 | 约束上限 |
|---|---|
| |4ε/3| < 0.031 | \|ε\| < 0.023 |
| |2ν| < 0.031 | \|ν\| < 0.0155 |

**红移演化幅度**：ε=0.02 时，z=2 处 ρ_Λ 仅增长 9.2%（与"近似常数暗能量"兼容）。

**DESI 对接**：框架预测 w = const（wa=0）。DESI 2024 的 w0wa 模型 hint（w0≈−0.69, wa≈−0.66，与 ΛCDM 有张力但含 Pantheon+ 减弱）——框架的常数 w 预言可在 DESI DR2/Euclid 数据上直接检验 |1+w| 是否 < 0.01。

### 3.5 可检验预言汇总

1. **w = −1+4ε/3（常数）**，ε 由"饱和能标的宇宙学漂移"决定——DESI/Euclid 测 |ε| 到 0.01 精度；

## 第四部分　P1-C：§规范群结构论文草稿

### §4.1 设定（定义）

**定义（配对阶数）**：规范群 G 的"配对阶数" n = 使表示张量积 ⊗ⁿ 含平凡表示的最小正整数 n。粒子-反粒子"配对" = 张量积中含单态（identity）。

**命题 1（三规范群的配对结构）**（【批1 数学组，可证明定理】）：
- U(1)：任意 q ⊗ (−q) = 1，n=1（线性可配对）；
- SU(2)：基本表示 2 为伪实表示（2 ≅ 2̄，辛形式 ε^ij 保号），2⊗2 = 1⊕3，n=2（平方可配对）；
- SU(3)：3 为复表示（3 ≇ 3̄），3⊗3 = 3̄⊕6 无单态；须 3⊗3⊗3 = 1⊕8⊕8⊕10（ε_ijk 三阶全反对称不变张量），n=3（立方可配对）。

**论证**（色禁闭的表示论根源）：重子 qqq 的无色组合需 ε_ijk 不变张量——"三个夸克借三阶反对称张量构成单态"。介子 qq̄ 用 δ_i^j（n=2 结构）。这是 SU(3) 与 SU(2)、U(1) 的结构性差异。

### §4.2 筛选论证（为什么是 SU(3)×SU(2)×U(1)）

**命题 2（规范群筛选）**（【原文 245–250 + 补充推演】）：

(ii) **SU(2)×U(1) 不可合并**：两种平方结构（无手性 U(1)、手性 SU(2)_L）不可并入更大群而不破坏手性——标准模型电弱部分必须是直积。

**命题 3（三代费米子 = 涡卷绕模）**（【原文 249】）：费米子代数 n=1,2,3 对应涡的三种卷绕模——第一代（e,u,d）基态、第二代（μ,c,s）第一激发、第三代（τ,t,b）第二激发。**第四代预言**：n=4 涡在 z>1000 早期宇宙不稳定衰变，>1 TeV 极重极短命。

### §5.1 动机

### §5.2 因果集公理化

**定义（因果集）**：设事件集 C 配偏序 ≺，满足：(i) 不自反（x ⊀ x）；(ii) 传递（x≺y≺z ⇒ x≺z）；(iii) 局部有限（|{z: x≺z≺y}| < ∞）。

**公理 1 的翻译**：每次"相遇—湮灭"事件 ∈ C；"彼此可影响" = ≺；各向同性 = 泊松涌撒（sprinkling）：在光滑洛伦兹流形 (M,g) 上按泊松过程以密度 ρ = l_P⁻⁴ 随机落点，几乎必然产生满足 (i)–(iii) 的因果集。

**维数估计**：Alexandrov 区间元素数 N ~ (Δτ)^d；Myrheim–Meyer 比 <R>/<P> ~ f(d) 给出维数 d（框架预言 d=4，可检验）。

### §5.3 恢复定理（Malament）

**定理（因果结构 ⇒ 共形类）**【批1 数学组，标准结果】：若 (M,g)、(M',g') 均为过去/将来可区分流形且因果序同构，则 M ≅ M'（微分同胚）且 g' = Ω²g——**因果结构唯一决定度规的共形类**。

**共形因子（事件计数）**【补充推演】：共形因子由事件密度固定：dV = dN/ρ，故

$$g_{\mu\nu}(x) = \Omega^2(x)\,g_0{}_{\mu\nu}(x),\qquad \Omega^4(x) = \frac{dN(x)}{\rho\,dV_0(x)}$$

**"流形微变"三段定理链**【补充推演】：
1. 泊松涌撒（大数定律）：事件集 → 因果偏序；
2. Malament 恢复定理：因果偏序 → 度规共形类；
3. 计数密度：事件密度 → 共形因子 Ω。

### §5.4 频率梯度 ↔ g₀₀（时间生成）

**定理（时间 = 事件率）**【批1 数学组 §1.1】：静态度规下理想钟 = 事件计数器。事件在固有时上以普朗克频率 f₀ 均匀发生，坐标时事件率 f(x)：

$$g_{00}(x) = -\left(\frac{f(x)}{f_0}\right)^2,\qquad \frac{f_B}{f_A} = \sqrt{\frac{g_{00}(B)}{g_{00}(A)}} \approx 1 + \frac{\Phi_B - \Phi_A}{c^2}$$

弱场给出引力红移——频率梯度与 g₀₀ 梯度一一对应。

### §5.5 连续极限（关键缺口）

### §6.2 场方程（变分导出）

**物质场**（对 ψ̄ 变分）【严格推导】：
